## 2. What was stale and how it was repaired

* The matrix and the SRS comparison were generated while the anchor declared four cases. C5 (W = 2 kg, R = 25 m) and C6 (W = 100 kg, R = 20 m) were missing from both tables while `fem_vs_cole.csv` and `grid_convergence.json` already covered all six. Both cases were recomputed through the chain-2 code path and merged; the physics columns of the published rows were not touched.
* Proof that the merged rows come from the same code path: case C1 was recomputed independently and every physics field agrees with the published row to 1.6e-11 (relative), 34 fields compared.
* The three-level values used to correct the GCI columns were themselves cross-checked for C1, C5, C6: worst relative deviation 1.6e-12.

## 3. The GCI columns: argument order and the `n/a` sentinel

`roache_gci` takes `(fine, medium, coarse)`. The chain-2 driver passed the three levels `coarse -> fine`, which flips the sign of the observed order; the order is then clipped to its lower bound 0.5, so every published index was inflated, and a quantity whose levels do not demonstrate convergence was written as `0` -- which reads as *zero discretisation error*. Both are corrected here: the columns are recomputed from the recorded three-level values in the documented order, and an undemonstrated quantity is marked `n/a`.

## 5. Limits of what this record establishes

* The Cole constants are WITHHELD (see `README.md` section 2): every deviation here is measured against the repository's own transcription, not against a deposited copy of Cole (1948).
* The SRS reference is the exact Taylor air-backed *areal-mass* plate at the panel areal mass, so the band deviations measure the panel-flexibility effect (a stated physical difference), not solver error.
* Subtracting the two views never rescues a verdict: the impulse-like comparison and criterion 4 stay FAIL, and this file does not re-score them.
* `fig1`-`fig6` remain the four-case chain-2 figures; only `fig7` covers the six-case ensemble. Regenerating them needs the full six-case driver run (~8 min) and is not part of this change.
