## P19-N01 modal ladder (simply supported beam + rectangular plate)

The cantilever table above is the legacy rung generated by
`benchmarks/structural_ladder.py` (`result.json`) and is kept unchanged.
The P19-N01 mission added a second, independent modal ladder in this directory:

* driver `run.py`, evidence `result_p19.json` + `gates_verified.json`,
  figures `beam_modes.png`, `plate_modes.png`, `modal_convergence.png`;
* simply supported beam (L = 4 m, b = h = 50 mm, steel) modes 1–5 vs
  `ω_n = (nπ/L)²√(EI/ρA)`;
* simply supported rectangular plate (a×b = 1.0×0.75 m, t = 10 mm) modes
  (1,1), (2,1), (1,2), (3,1), (2,2) vs the Navier eigenfrequencies
  `ω_mn = π²√(D/ρt)[(m/a)²+(n/b)²]`;
* meshes N = 10/20/40, consistent mass, hard simple support.
