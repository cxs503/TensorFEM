# 有限宽板圆孔应力集中（Howland / Heywood）：开孔欠账的清偿

**Status:** verification report（把已合并的平面应力生产路径对文献基准复核）
**Repository:** TensorFEM · **Module:** `tensorfem.finite_width_hole`（新）
**Evidence:** `benchmarks/finite_width_hole_reference.json`、`scripts/audit_finite_width_hole.py`、
`tests/test_finite_width_hole.py`（16 项）、图 `docs/assets/compact/finite_width_hole/*.png`（5 张）

## 1. 案例介绍（物理背景 / 几何 / 参数）

船体开孔（舱口角隅、人孔、管系贯穿件、舷侧开孔）的强度筛算依赖 `K_t`。
`docs/kirsch-hole-stress-concentration.md` 已用 Kirsch(1898) 精确解验证了生产
Q4 平面应力链路，但同一文档 §5 明确留下一条欠账：

> 「正交异性板、含裂纹孔、**有限宽板（Howland 修正）**都未覆盖，`K_t = 3` 只对无限大板成立。」

这条欠账不是学术洁癖：船体板格的可宽比 `d/W` 常在 0.1–0.5，此区间净截面因子从
2.73 掉到 2.16；沿用 `K_t = 3` 会把峰值应力高估 **39%**（`d/W = 0.5`）。
本单清偿这条欠账，被验证对象仍是**已合并的生产路径**
（`tensorfem.continuum.ContinuumModel` / `q4_stiffness` / `solve_continuum`），不新增求解器。

四分之一模型（`0 ≤ x ≤ L`、`0 ≤ y ≤ W/2`，孔心在原点）：`y=0` 上 `u_y=0`、`x=0` 上
`u_x=0`（对称），孔边与侧边 `y=W/2` 自由，加载端 `x=L` 上均匀拉应力 `T`。

| 参数 | 符号 | 取值 |
|---|---|---|
| 板宽 / 孔直径 | `W` / `d` | 1.0 m / 0.10–0.50 m（`d/W` = 0.1…0.5，另含 0.02 / 0.05 极限算例） |
| 半长 | `L` | `1.5 W`（整板长 `3W`；`L` 灵敏度另行测量） |
| 板厚 | `t` | 0.01 m（`t/W` 远小于 1，薄板平面应力） |
| 弹性模量 / 泊松比 | `E`, `ν` | 200 GPa / 0.30 |
| 远端拉应力 | `T` | 1 MPa |
| 单元 / 网格 | — | Q4 双线性全积分，孔心放射状（starburst）渐变网格，边界按弧长分布 |
| 网格级 | `n_θ` | 16 / 24 / 32 / 40（自由度 338 … 3362） |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**(A) 基准本身先自证。** 三层锚：

1. **精确极限锚（主）**：固定 `W` 而令 `d/W → 0`，解必须回到 Kirsch 的 `K_t = 3`。
   Kirsch 单元已在同一生产链路上把这个极限验到 0.10%，因此它是「对精确解」的锚，
   不是「FE 对 FE」。
2. **静力学精确锚**：任意截面上的轴力必须等于外载，`∫σ_xx dA = T W t`；
   每个网格都对比 `x=0` 对称面上的支反力与外载。
3. **文献锚**：Howland(1930) 级数解在 Peterson《Stress Concentration Factors》
   （Pilkey & Pilkey, 3rd ed., Chart 4.1）中的表格值，以及 Heywood(1952) 工程拟合
   `K_tn = 2 + (1 − d/W)³`（`d/W→0` 时精确给 3）。

**(B) 口径陷阱（本单实测，写进模块 docstring）。** 文献表是**净截面（韧带）因子**
`K_tn = σ_peak/σ_net`，`σ_net = T W/(W−d)`；若把 FE 峰值直接除以施加的 `T`，
得到的是**毛截面因子** `K_tg = K_tn (1 − d/W)`，两者在 `d/W = 0.5` 相差整整 2 倍。
第一版脚本就是因为把毛截面值当净截面去比，出现「24%–101% 误差」的假失败；
改按净截面比对后误差立刻落到 1% 以内。两种口径在报告与 JSON 中都分开列出。

**(C) 峰值取样与网格。** 峰值位于孔边对称线 `(0, a)`；取该孔边节点的相邻单元
角点应力外推平均。外边界节点按弧长分布，保证加载端与自由边的交角 `(L, H)`
（面力边界条件在此跳变）**永远是网格节点**——第一版漏掉「最后一个加载节点到角点」
那一段，载荷少了 `4/n`（实测不平衡恰为 `4/n_θ`），补上后静力平衡残差降到 `2.4e-13`。

工具链：

OMP_NUM_THREADS=2 PYTHONPATH=src python -m pytest tests/test_finite_width_hole.py -q

## 4. 误差判定（逐项回答「是否 < 3%」）

| 关键量 | 基准 | 最细网格误差 | 判定 |
|---|---|---:|---|
| `K_tn`（`d/W`=0.1…0.5，5 个算例） | Heywood 1952 拟合 | 0.04%–0.98% | **是** |
| `K_tn`（同上） | Peterson/Howland 表 | 0.01%–0.65% | **是** |
| `K_tn` Richardson 外推 | Peterson/Howland 表 | 0.01%–0.18% | **是** |
| `K_tg`（`d/W`=0.02） | Kirsch 精确 3.0 | 0.053% | **是** |
| 静力平衡 | 外载 `T·W·t` | 2.4×10⁻¹³ | **是** |

全部关键量 < 3%；最细网格最差 0.98%，Richardson 外推后 ≤0.18%。
唯一 >3% 的量是「孔边腰部环向应力 vs Kirsch −1」，10.4%——但这是**物理差异不是数值误差**
（有限宽度的腰应力本就不等于无限板值），故单列、不当作验收失败。

## 5. 注意点 / 局限

- **口径**：本报告 `K_tn` 用净截面应力；论文/手册里同一工况既可能给 `K_tn` 也可能给 `K_tg`，
  引用前必须先确认口径，否则误差因子可达 `1/(1−d/W)`。
- **加载端是理想均匀面力**：无限长带受远场拉伸时，真实远场应力沿宽度非均匀；
  用有限长 + 均匀面力会有 Saint-Venant 残差。实测 `L/W` 从 1.0 到 2.5 的带宽为
  1.06%（`d/W`=0.2）/ 2.42%（`d/W`=0.5），随 `L` 增大 `K_tn` 单调略降，
  故本报告的 3% 判定是在该带宽内成立的，**不要**把单个 `L/W` 的值当「无限长带」精确解。
- **`L/H` 大时网格纵横比变差**：`L/W ≥ 2.5` 需同步加密径向分级，否则远场分辨率不足。
- 峰值用孔边节点外推平均（后处理口径），不是单元内部点值；与 Kirsch 单元的点式误差口径不同。
- 只覆盖**平面应力、小应变、各向同性、薄板**：不含壳体、塑性、接触、几何非线性；
  正交异性板、裂纹孔、多孔干涉仍未覆盖。`K_tn = 3` 只在 `d/W → 0` 成立。
- 尝试记录：曾尝试用 Michell/Trefftz 级数（孔边精确无面力 + 矩形边界最小二乘）造
  独立参考解。孔边无面力约束的构造在**外边界为圆**时能把 Kirsch 复现到机器精度
  （`K_t = 3.000000`），但换成矩形边界后因加载端与自由边交角的面力跳变
  （角点奇性）导致截断级数严重病态，`K_tn` 不收敛。该路线**未纳入本单验收**，
  保留为后续可选工作；本单改用「精确极限 + 静力学 + 文献表 + Richardson」四重锚。
