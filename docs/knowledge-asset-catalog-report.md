## Integrity Verification

All assets carry SHA-256 integrity digests computed from
content fields (asset_id, type, title, version, lifecycle,
provenance, evidence, tags). The version_chain is metadata
about lifecycle history and is NOT included in the hash.

To verify:

```python
from tensorfem.knowledge_assets import build_catalog, validate_asset
catalog = build_catalog()
for asset in catalog.assets:
    errors = validate_asset(asset)
    if errors:
        print(f'{asset.asset_id}: {errors}')
```
