# CASE-FEM-KIRSCH-PLATE — 内部应力场逐点复核（m20550）

【锚点=CASE-FEM-KIRSCH-PLATE｜算例池 FEM-KIRSCH-PLATE `K_t = 3`（Kirsch 1898）｜容差 <5%】
本单是**验证欠账**类：把已认证的 Kirsch 锚点从「峰值已复核」推进到「**场已复核**」，
并修掉锚点图像交付契约的一处**永久红灯**。

## ① 案例介绍

无限大平板中心圆孔、远场单向拉应力 `T`。Kirsch (1898) 闭式解（Timoshenko & Goodier 3rd ed.
Art. 39 eqs. (a)-(c)）给出完整场：

    sigma_rr = T/2 (1 - a^2/r^2) + T/2 (1 - 4 a^2/r^2 + 3 a^4/r^4) cos 2theta
    sigma_tt = T/2 (1 + a^2/r^2) - T/2 (1 + 3 a^4/r^4) cos 2theta
    sigma_rt = -T/2 (1 + 2 a^2/r^2 - 3 a^4/r^4) sin 2theta

孔边 `sigma_tt(a,pi/2) = 3T` 即 `K_t = 3`（池容差 <5%）。本单不再重测峰值（已有
0.047% / Richardson 0.31% / Q8 交叉 0.049%），而是检验**峰值之外**的场。

模型：`d/W = 0.02` 有限宽四分之一板（`0<=x<=1.5`、`0<=y<=0.5`，Q4 平面应力，星爆网格
grading 6，生产路径 `tensorfem.finite_width_hole`），远场均匀拉伸、孔边与侧边自由、
两对称轴法向约束——无任何解析位移注入，是真正的边值问题。

## ② 怎么做的

1. 逐点探针：在 `r/a in [1.1, 1.25, 1.5, 2.0]`、`theta in [22.5, 45.0, 67.5] deg`
   采样（偏离两条对称轴，理由见 ⑤），用 `tensorfem.stress_recovery` 的
   `locate_point` + `q4_strain_matrix` 取**原始单元应力**，并用
   `q4_gauss_stresses` + `recover_nodal_stress` + `interpolate_nodal_field` 取
   **Barlow 外推节点恢复应力**；两者与 `kirsch_stress()` 闭式解逐分量比较。
2. 判据预声明（写入 `CRITERIA`）：恢复场逐分量相对误差 <= 5%（分母加 `0.10 T` 下限）、
   细化（n=24 -> 48）误差下降 >= 2 倍、对称轴
   `|tau_rt|/T <= 0.05`。新增门禁 3 条，门禁总数 14 -> 17。
3. 复用 `d/W=0.02` 阶梯已算的 `n`=24/48 算例（内存中 `_case`），
   **零额外求解**；全驱动重跑一次（单进程约 90 s，本机 load15 76 < 100）。
4. 顺带修复：`run.py` 原先把 4 张图写在 `run.py` 旁边，而发布器丢弃 `docs/` 之外的
   `*.png`，导致 `test_committed_figures_exist` 在**任何干净检出**上必红（本轮发现）。
   现在 5 张图统一写到版本受控的 `docs/assets/kirsch_plate/`，测试改判 `result.json`
   声明的路径；4 张旧图重跑后**字节不变**（仓库内 diff 为空），可复现性得到反证。

## ⑤ 注意点 / 局限

* **对称轴上不能用相对判据**：`tau_rt` 在 `theta`=0/90 deg 解析恒为 0，数值上恢复场仍有
  3.1% `T` 的残差（对称边处应力只能取到单侧薄片单元的值），
  相对判据在这里测的是恢复协议的噪声底而不是场误差。因此探针只放在 22.5/45/67.5 deg
  三条一般射线上，对称轴残差单独设门禁（<=5%）。
* **只有恢复场可当逐点值**：同一批点上**原始单元应力**误差高达
  19.5%（`n`=48），不能当"点应力"读；门禁只判恢复场。
* 相对误差分母设 `0.10 T` 下限（与既有 conditioning 审计的绝对底噪结论一致）。
* 范围不变：平面应力、线弹、各向同性、单孔、无塑性/接触/热效应；厚板 `sigma_zz != 0` 不覆盖。
* **预存欠账（非本单引入）**：`tools/verified_anchor_audit.py --write` 刷新后，
  `fem_pinched_cylinder`、`fem_shell_scordelis_lo`、`fem_wave_dispersion` 三个锚点同样因
  "图写在 docs/ 之外被发布器过滤"而缺工件（`E_ARTIFACT_MISSING`），此前**未登记**、
  使 `test_verified_anchor_certificates.py` 在 HEAD 上就是红的。本单如实登记入
  `benchmarks/verified/anchor_certificate_debt.json`（+3 条），修复留作后续单。
