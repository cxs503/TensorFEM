## 共享强度能解释多大差异

以表 1 列印的宽度 $b$、高度 $h$ 和支承跨度 $L=0.180$ m 为输入，简支梁给出 $P=2bh^2s/(3L)$。由实测峰值分别反算的 $s_i$ 为 0.99161、0.77831 MPa。05 的 10% 区间下界 0.89245 MPa 高于 10 的上界 0.85615 MPa，差 0.03630 MPa。即使事后选择使最坏相对峰值误差最小的共同强度 $2s_{05}s_{10}/(s_{05}+s_{10})=0.87211$ MPa，最坏误差仍为 **12.05%**。这是给定几何与梁公式下对全部正共享强度的下界。

显式内聚 FE 的峰值另有一个独立的必要条件：若两件峰值均达标，必有 $P_{05}/P_{10} > (0.9\times441.3)/(1.1\times323.6)=1.11577$。在 0.70、0.80、0.85、0.90、0.95、1.10、1.20 MPa 及标定值 1.01668 MPa 八个共享强度点上，实际 FE 比值只在 **1.08095–1.08213**。固定体模量、断裂能、法向与切向界面初始刚度、各件压头绝对刚度、网格、速度和时间步。0.80 MPa 给出 373.02 / 344.82 N（仅 10 峰值达标），0.85 MPa 给出 397.49 / 367.46 N（仅 05 达标）。此扫描支持共享强度是当前模型的主要障碍；扫描点之间的单调性和其他边界、材料模型的全参数域尚无证明。

**几何精度会改变解析结论的适用范围。** 表 1 的尺寸列精确到 1 mm。额外做一次纯代数情景分析：假设每件的真实宽、高均可独立偏离列印值 ±0.5 mm，载荷和跨度固定。允许各件尺寸在各自范围内取值，则存在共同强度 0.86453–0.88516 MPa 的内部值可同时满足两件的梁公式峰值门限。这是几何舍入假设下的存在性结果。原文没有给出这些尺寸误差、方向或测量不确定度。本次 FE 评分始终使用原表尺寸。[实验图 4、表 1](https://poac.com/Papers/2017/pdf/POAC17_054_Jong-Chun_New.pdf)

## 已执行的成对控制试验

共 25 个工况 × 2 件。基准及 7 个强度控制见上节，其余控制如下。几何、速度、模量、强度和断裂能控制均保持各试件基准的**绝对压头刚度**。改变强度或断裂能时固定界面初始刚度，避免构造器默认的 $K_n=50s^2/G_f$ 引入第二个变化。复现旧网格控制时保持其无量纲压头刚度比；同网格比较两种加载规则时保持绝对刚度相同。[逐工况输入、峰值观测和能量项](../artifacts/ice_coupons/ren_controls.json)

|---|---:|---:|---|

## 固定跨向网格的梁高细化

在上述 50 次计算之外，重新计算两件基线，并分别在梁高方向用 16、32、64 层 Q4 单元做对照，共 8 次显式瞬态计算。三档均固定跨向 24 个单元、$\Delta t=0.1$ µs、每件基线绝对压头刚度、原加载权重、材料、密度及速度。单独复算的原基线沿用 0.2 µs。下表的挠度是最大反力时同一步的梁顶跨中挠度。[输入、逐块峰值和能量项](../artifacts/ice_coupons/ren_depth_controls.json)

| 梁高层数 | 05 峰值 / N | 05 挠度 / mm | 10 峰值 / N | 10 挠度 / mm | 通过联合验收 |
|---:|---:|---:|---:|---:|---:|
| 16 | 479.061 | 0.78950 | 442.992 | 0.79997 | 0/2 |
| 32 | 431.146 | 0.71585 | 395.824 | 0.72082 | 0/2 |
| 64 | 419.157 | 0.69874 | 388.591 | 0.70943 | 0/2 |

10 号的峰值高估从 36.9% 降至 20.1%，挠度低估从 30.4% 扩大至 38.3%。05 号最细网格峰值误差 −5.0%，挠度误差 −30.1%。最细网格的界面段长仍分别为材料特征长度 $EG_f/s^2$ 的 1.90、1.80 倍。细化同时改变体单元纵横比和裂纹积分点间距，尚未分离这两个效应。八行均达到持续卸载停止条件，最大能量相对残差 $4.51\times10^{-6}$。仅凭同步细化结果推断网格影响较小会漏掉上述变化；此次也未得到二维空间收敛解。分离这两种离散误差还需要跨向和梁高独立细化，以及固定物理宽度的加载对照。

复算这一组时，从仓库根目录执行以下两条命令。评分器会核对每件试件的三个细化工况、固定的绝对刚度和同一步峰值记录。第二条命令在当前基线返回退出码 1。

```bash
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python benchmarks/ren_bend_controls.py --through-depth
python benchmarks/score_ren_bending.py --through-depth --controls artifacts/ice_coupons/ren_depth_controls.json --output /tmp/ren-depth-score.json --check
```

## 复算

在仓库根目录使用项目 dev 环境。第一条重建原瞬态基准的 8 行归档；第二条执行 50 次动态 FE；第三条只需要 Python 标准库，直接读实验 CSV 和逐步观测的分块最大值。每块最多 8192 帧，保留最大反力及同一步的三个位移。该压缩保留力峰值，不适合做曲线积分；能量由求解器每一步累计。独立评分器重算末态能量闭合、联合门限和解析下界。基线失败时，带 `--check` 的退出码应为 1。

```bash
export PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python benchmarks/ice_coupon_validation.py transient
python benchmarks/ren_bend_controls.py
python benchmarks/score_ren_bending.py --check --output /tmp/ren-score.json
python -m pytest -q tests/test_ren_bend_audit.py tests/test_cohesive_bending.py tests/test_structural_coupon_paths.py
```
