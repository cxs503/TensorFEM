## 1. Case, geometry and parameters

* Material-point model: infinitesimal-strain J2 (von Mises) plasticity, associative flow, isotropic hardening `sigma_y(alpha) = sigma_y0 + H alpha + Q (1 - exp(-b alpha))`, backward-Euler radial return with an implicit (scalar Newton) multiplier and the consistent algorithmic tangent; module `tensorfem.j2_saturation_hardening`.

* Structural case: plane-strain elastic-perfectly-plastic hollow cylinder under internal pressure (Hill, *The Mathematical Theory of Plasticity*, 1950, §5.3); model `tensorfem.thick_cylinder_plasticity` — axisymmetric Q4 annulus with `u_z = 0` everywhere (exact `eps_z = 0`), internal pressure applied as consistent nodal loads on the bore.

## 2. Method

1. **Return mapping.** With `s_tr` the trial deviator and `q_tr = sqrt(3/2)|s_tr|`, the incremental multiplier solves `f(dg) = q_tr - 3G dg - sigma_y(alpha_n+dg) = 0` by Newton inside the bracket `[0, q_tr/(3G)]`; `f' = -(3G+H) < 0` makes the root unique. The stress is returned radially on the yield surface and the state is committed only on convergence.

2. **Consistent tangent.** Differentiating the *discrete* map gives `C = K 1x1 + 2G beta I_dev - (9G^2/q_tr^2)[1/A - dg/q_tr] s_tr x s_tr`, `beta = 1-3G dg/q_tr`, `A = 3G + H(alpha_{n+1})`; it is verified against central finite differences of the implemented return map (see §5).

3. **Uniaxial check.** The tensor return mapping is driven along a uniaxial stress path (lateral strains relaxed with the consistent tangent until `sigma_22 = sigma_33 = 0`) and compared with the closed-form 1-D solution `sigma = sigma_y(eps_p)`, `eps = sigma/E + eps_p` obtained from an independent scalar root solve.

4. **Cylinder check.** The axisymmetric Q4 model is first verified against the *elastic* Lamé field (below first yield) so that element error is separated from constitutive error, then run into the contained plastic range. The plastic radius is extracted from the computed Gauss-point field by two independent estimators: a model-free bracket (midpoint between the outermost yielded and the first elastic Gauss point) and a Lamé fit (`q = C/r^2` in the elastic zone, `r_p = sqrt(C/sigma_y)`).

## 7. Notes, limitations and what is *not* claimed

* **Classical solution vs finite elasticity.** Hill's plane-strain formula assumes `sigma_z = (sigma_r+sigma_theta)/2` in the plastic zone (i.e. `s_z = 0`, incompressible plastic flow). With `nu = 0.3` the elastic zone obeys `sigma_z = nu(sigma_r+sigma_theta)` instead, so the *exact* solution of the plane-strain boundary-value problem differs from the classical formula by the amount by which `sigma_z` departs from the mean. The effect on the equivalent stress is second order, `q = sqrt(3 D^2/4 + e^2)` with `e = sigma_z - m` (`m = (sigma_r+sigma_theta)/2`), i.e. `~e^2/(2 sigma_y^2)`, which is the sub-percent bias visible in the r_p column and is the dominant residual error once the mesh is fine. The formula becomes exact as `nu -> 1/2`.

* **`sigma_z` at the interface.** Hill's formula makes `sigma_z` jump at `r_p` (mean stress in the plastic zone, `nu`-weighted sum in the elastic zone) — the table shows 13.8% of `p` locally. The FE field is continuous there because `eps_z = 0` and the plastic flow grows smoothly, which is the *physically consistent* plane-strain solution; the discrepancy is therefore an approximation in the classical formula, not an FE defect, and it is localised to the interface. `sigma_r` and `sigma_theta` (the components that equilibrium and traction continuity constrain) agree to a few percent of `p`.

* **Element accuracy.** The exact field has a derivative jump at `r_p`, so Gauss-point stresses converge at first order in the element size; that is why the stress columns are a few percent while the integral quantities `r_p` and `u_r(a)` are sub-percent. The element check at `p = 0.5 p_y` isolates the discretisation error from the constitutive one.

* **Not claimed.** No kinematic/combined hardening, no rate or thermal effects, no damage/fracture, no finite strain, no closed-end (axial-force) loading, no Tresca comparison, no cyclic/ratcheting behaviour, and no experimental calibration: `Q`, `b`, `H` here are representative metal values, not fitted data. The 3-D Lamé and the elastic plane-strain cylinder remain the only *elastic* thick-cylinder qualifications in this repository.

* **Environment.** Python 3.11.6, torch 2.7.1, Linux-6.6.52-1.7.lns23.loongarch64-loongarch64-with-glibc2.38; dense direct solves, `torch.set_num_threads` default.
