# GAP-FEM-3D-COHESIVE · 能量释放率验证：FE 界面功/新裂面积 vs G_Ic（<10 %）（m16698）

锚点：`GAP-FEM-3D-COHESIVE`（FEM 3D cohesive 单元 + 验证算例）。
验收原文：**「P-δ 曲线 + 能量释放率 vs 解析 <10 %」**。

本单补的是**能量释放率那一半**。此前所有已提交证据 JSON 里
`interface_work_per_area = NaN`——因为 quick 工况在任一界面单元完全失效前就
停了，能量释放率从未被量测过。本单把试件驱动到裂纹真正扩展 17.5 mm，量测
`G = dW_interface/dA_cracked` 并对 `G_Ic = 300 J/m²` 判级。

**结论先行：能量释放率判据 PASS。** 稳态扩展窗内局部斜率
`G = 311.1 J/m²`（+3.7 %），窗口最小二乘斜率 `302.5 J/m²`（+0.85 %），
末态全局比 `310.2 J/m²`（+3.4 %）——三者全部落在 ±10 % 内。
（峰值载荷 vs LEFM 仍为诚实 FAIL，属强度控制区，LEFM 非适用基准，
见 `docs/GAP-FEM-3D-COHESIVE-displacement-control-repair.md`，本单不重做。）

## ① 案例介绍

DCB（ASTM D5528 双悬臂梁，Mode I 层间断裂）用于检验 3D 内聚单元在真实三维
应力状态下能否给出可信的能量释放率。几何 / 材料 / 内聚律与位移控制探针
（`benchmarks/cohesive3d_dcb_displacement_control_probe.py`）完全一致：

| 参数 | 值 |
|---|---|
| 梁长 `L` | 60 mm |
| 宽 `b` | 3 mm |
| 每臂厚 `h` | 3 mm |
| 初始裂纹 `a0` | 30 mm |
| 弹性模量 `E` | 70 GPa |
| 泊松比 `ν` | 0.30 |
| 法向强度 `t_n0` | 5 MPa |
| 切向强度 `t_s0` | 3 MPa（0.6·t_n0） |
| 法向刚度 `k_n` | 1e12 Pa/m |
| `G_Ic` / `G_IIc` | 300 / 800 J/m² |
| BK 指数 `η` | 2.2 |
| 网格 `nx × ny × nz` | 60 × 1 × 2（与收敛峰值算例同族） |
| 位移控制 | `δ_max = 4 mm`，160 步，`tol = 1e-8` |

## ② 怎么做的

1. **独立解析锚**（与 FE 无关）：内聚律对单位面积做*完整*分离所做的功，
   按律的构造就是 `G_Ic`（牵引-分离曲线下的面积）。因此准静态推进的裂纹前沿
   每新增单位开裂面积必须释放 `G_Ic`：`G = dW_interface/dA_cracked = G_Ic`。
2. **驱动**：生产 HEX8 adherends + 生产 COH3D8 韧带，位移控制 Newton 路径
   跟随器（`tensorfem.cohesive3d_dcb.solve_dcb`）驱动到 `δ = 2.43 mm`
   （Newton 在远场后停止收敛，`converged_all=false`，但已扩展 17.5 mm，足够）。
3. **量测**（三种独立口径，数字全部来自
   `benchmarks/cohesive3d_dcb_energy_release.json`，零手抄）：
   - **局部斜率**：稳态窗（前沿移动 >1 mm 且距粘结区末端 >2 mm）内
     `(W_hi−W_lo)/(A_hi−A_lo)`——物理上正确的导数；
   - **窗口拟合**：同窗内 `W_interface` 对 `A_cracked` 的最小二乘斜率；
   - **全局比**：末态 `W_interface/A_cracked`（上界，分子含过程区功）。

## ⑤ 注意点 / 局限

- **能量平衡残差 ~50 %**（`energy_balance_rel ≈ 0.5`）：这是**既有**记账
  现象（已提交的 quick 证据 JSON 同为 0.4936），源于 `0.5·uᵀK_solid·u` 只含
  固体弹性能、未含（部分损伤）界面的弹性能。**不影响本判据**——`G` 由界面功
  的增量斜率给出，且 `G≈G_Ic` 本身即界面功被正确累计的证据。列为开放项，
  不在本单范围。
- **强度控制区**：`t_n0 = 5 MPa` 下过程区约占 `a` 的 25 %，峰值载荷由强度而非
  韧性控制，故 LEFM 峰值非适用基准（前一轮已定位）。本单只关能量释放率。
- **适用范围**：纯 Mode I、准静态、位移控制、粘结区未完全贯穿（扩展 17.5/30 mm）。
  混合模式 / 动力 / 全贯穿需另立算例。

## ⑥ 误差判定（逐项，显式回答 <3 %）

| 关键量 | FE | 基准 | 误差 | <3 % ? |
|---|---|---|---|---|
| 能量释放率（局部斜率） | 311.11 J/m² | 300 J/m² | +3.70 % | **否**（但 <10 % 判据 PASS） |
| 能量释放率（窗口拟合） | 302.54 J/m² | 300 J/m² | +0.85 % | **是** |
| 能量释放率（全局比） | 310.22 J/m² | 300 J/m² | +3.41 % | 否（<10 % PASS） |

判据线是 **10 %**（验收原文），局部斜率 +3.70 % 达标；窗口拟合 +0.85 % 满足
更严的 3 %。无基准含糊：基准 `G_Ic` 是内聚律的构造量（牵引-分离曲线下面积），
非拟合调参。
