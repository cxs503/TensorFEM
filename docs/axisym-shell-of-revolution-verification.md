# 轴对称壳环元（回转壳）能力与验证：柱/球压力容器膜态合格，一般曲面子午线未合格

本文件记录 `src/tensorfem/axisym_shell.py`（新增回转壳环元）的资格判定。
所有数字由 `scripts/verify_axisym_shell.py` 程序化写入
[`benchmarks/verified/fem_axisym_shell/result.json`](../benchmarks/verified/fem_axisym_shell/result.json)，
本文件从中回读，不手抄。

## 1) 为什么做这件事（欠账定位）

`docs/benchmark-qualification-status.md` 记录了一条 fail-closed 否定结论：已合并的
Shell4 平面映射面元在**闭合球壳内压**（薄壳、曲面、压力、无边界层的精确膜态解）上，
216 面元时膜力误差 ~1006%（相对 `pR/2`），拟合需 ~2e4 面元才到 3% 门限，并注明
「曲面壳族无合格路线」。该结论把失败归因于「薄 + 曲面 + 压力下折角弯曲主导」。

但该诊断没有把两件事分开：**几何刻面误差** 与 **单元公式误差**。只要单元只认平面弦，
就无法回答「是曲面离散不允许，还是这条单元路线不允许」。本单新增的回转壳环元
（2 节点、每节点 `u/w/beta` 三自由度，子午线可为**真圆弧** `R_s = R`）正是为了把这
两者分开：同一套公式下，`meridian_radius=R` 是精确几何，`meridian_radius=None` 是刻面几何。

## 2) 单元公式（可复核）

五类广义应变（`phi` = 外法线与转轴夹角，`r(s)` = 环向半径，`R_s` = 子午曲率半径）：

| 应变 | 表达式 | 说明 |
|---|---|---|
| `eps_s` | `du/ds + w/R_s` | 子午膜应变 |
| `eps_theta` | `(u cos(phi) + w sin(phi))/r` | 环向膜应变 |
| `kappa_s` | `d beta/ds` | 子午曲率改变 |
| `kappa_theta` | `beta cos(phi)/r` | 环向曲率改变 |
| `gamma` | `dw/ds + beta - u/R_s` | 横向剪切（Kirchhoff 约束残差）|

本构：`N = Cm(eps + nu eps')`，`M = Db(kappa + nu kappa')`，`Q = k G t gamma`，
`Cm = Et/(1-nu^2)`，`Db = Et^3/(12(1-nu^2))`，`k = 5/6`。
膜/弯用 2 点 Gauss，横向剪切只在单元中心取一点（SRI，避免薄壳剪切锁死）；
`2 pi r` 环向度量精确，故压力合力精确等于 `p*A`（下面的轴力平衡测试用到这一点）。
节点排序约定：外法线 `n = (-dz/ds, dr/ds)` 的 `r`、`z` 分量均非负（柱壳 **上→下**、
球壳 **极点→赤道**），反序由构造函数直接报错，不允许静默翻转受压侧。

## 3) 结果表（判据先于计算）

### C1 圆柱内压（膜态精确解，直母线几何被精确表示）

`R=1 m, L=2 m, t=0.01 m, E=2e11 Pa, nu=0.3, p=1 MPa`，8 单元。

| 工况 | 判据 | `N_theta` 最大相对误差 | `w` 最大相对误差 |
|---|---|---|---|
| 开口（无端盖 `N_s=0`） | `N_theta=pR=1e6 N/m`, `w=pR^2/(Et)=5.000e-4 m` | **2.10e-15** | **2.60e-15** |
| 闭口（端盖轴力 `p·pi R^2`） | `N_theta=pR`, `N_s=pR/2`, `w=pR^2(1-nu/2)/(Et)=4.250e-4 m` | **2.21e-15** | **3.32e-15** |

轴力平衡：约束点反力 / 端盖总轴力 = `3.7e-10 / 3.1416e6`（相对 1.2e-16），
即 `2 pi r` 度量与压力合力一致。**结论：圆柱膜态到达机器精度。**

### C2 闭合球壳内压（真圆弧子午线，极点→赤道，四分之一模型 + 两极对称）

`R=10 m, t=0.04 m, R/t=250, E=6.825e7 Pa, nu=0.3, p=1 Pa`；
精确膜态 `N_phi=N_theta=pR/2=5 N/m`，`sigma=pR/(2t)=125 Pa`，
`w=pR^2(1-nu)/(2Et)=1.282051e-5 m`（与 Shell4 否定报告同一算例同一参数）。

| 子午单元数 | `N_theta` 最大相对误差 | `N_phi` 最大相对误差 | 主膜力各向异性 | `w` 相对误差 |
|---|---|---|---|---|
| 4 | 1.13e-05 | 1.96e-05 | 2.31e-05 | 6.96e-05 |
| 8 | 7.31e-07 | 1.20e-06 | 1.52e-06 | 6.26e-06 |
| 16 | 4.60e-08 | 7.00e-08 | 9.36e-08 | 4.81e-07 |
| 32 | 2.83e-09 | 3.64e-09 | 5.72e-09 | 3.31e-08 |

误差随细化单调下降，拟合阶约 2（图 `axisym_shell_qualification.png` 中面板）。
16 单元（即半个子午线 16 个环元，等效面积元远少于 Shell4 的 216 面元）即达 **4.6e-08**
相对误差，比 3% 门限低六个量级。**结论：曲面壳族存在合格路线的存在性证明成立**——
前提是几何按真圆弧进入单元，而不是把球面折成多面体。
（本表不声称 Shell4 的 1006% 已被「修好」；Shell4 仍按其 fail-closed 记录不认证。
本元只是给出另一条路线的合格证据。）

### C3 两端径向夹持的圆柱内压（弯曲边界层，非平凡，对照独立闭式解）

`R=1 m, L=0.5 m, t=0.01 m, R/t=100, E=2e11 Pa, nu=0.3, p=1 MPa`，开口端（`N_x=0`）。
基准 = `tensorfem.cylindrical_pressure_reference.exact_axisymmetric_solution`
（Shell4 资格档使用的两端夹持闭式解，独立推导、导数由自动微分给出），
误差以膜态挠度 `w_mem = pR^2/(Et)` 归一。

| 单元数 | `w` 相对 L2 误差 | `max|w-w_exact|/w_mem` |
|---|---|---|
| 50 | 3.19e-03 | 4.20e-03 |
| 100 | 3.92e-03 | 5.34e-03 |
| 200 | 4.12e-03 | 5.63e-03 |

误差收敛到 ~0.4%（不随细化归零），量级与 Reissner–Mindlin 退化壳与经典薄壳理论之间
`O(t/R) = 1%` 的差一致；**两族单元的挠度场在 1% 内一致**。同时记录：本算例
`t/R=0.01` 全积分与 SRI 给出同一量级结果（全积分 L2 2.60e-03），即**该细长比下未观察到
剪切锁死**，SRI 在此不是精度的必要条件（不据此声称 SRI 无必要，只如实记录测量）。

### C4 几何/排序守门

- 圆弧子午线端点复原节点坐标（误差 ≤1e-12）；
- 弦长超过子午弧直径报错；重节点报错；反序（`dz/ds > 0`）报错；
- 圆柱整体轴向平移应变能为零（刚体模态测试）。

### C5 未合格区（fail-closed，本法必须继续留在账上）

一般曲面/锥形子午线在非均匀膜态下，2 节点假定应变格式出现**短波伪响应**：

| 算例 | 指标 | 测量 |
|---|---|---|
| 闭合截锥（`r 0.5→1.5 m`, `t=0.01`, 12 单元） | `N_theta` 最大相对误差 | **8.05e+00** |
| 四分之一圆环（`R=1, a=0.25, t=0.01`） | `N_theta` 最大相对误差 | 4 单元 3.77e-01 → 64 单元 3.86e-01 |
| 同上（刻面弦几何） | `N_theta` 最大相对误差 | 4 单元 2.59e+01 → 64 单元 2.37e+01 |

判读：误差**网格无关**（38% 不随 4→64 单元变化），故是**格式问题而非分辨率不足**；
轴向力平衡在所测截面被破坏（截锥 12 个 Gauss 点上 `2 pi r N_s sin(phi)` 与 `p pi r^2`
大面积不符），`beta` 场出现逐节点交替符号（锯齿）。`tests/test_axisym_shell.py::test_C5_*`
以 **fail-closed 断言**（断言误差仍很大）锁死该限制，任何未来改动若意外修好，
测试会红并要求同步更新本文件与 JSON，而不是让限制悄悄消失。

诚实边界：本单**没有**定位该伪响应的根因（候选：SRI 单点剪切约束下 `u` 与 `w` 的一阶
插值组合遗留一个整链尺度近零能模态；或锥/环子午线上 `kappa_theta` 与膜-弯耦合的离散
不一致）。这是遗留工作，不是已完成项。

## 4) 结论与适用面

- **可用**：柱壳（开口/闭口）与**真圆弧子午线**球壳的内压膜态，精度 1e-15 / 1e-8 量级；
  圆柱两端夹持的边界层挠度场与独立闭式解 1% 内一致。
- **不可用（已锁）**：锥壳、圆环壳等一般曲面子午线；请继续用 `cylindrical_pressure_reference`
  / `plate` 族既有路线，或等遗留工作修好后再升账。
- **与 Shell4 的关系**：不替代、不推翻其 fail-closed 结论；本元证明「曲面 + 压力」并非
  不可解，刻面几何才是关键变量之一——这一区分本身是本单的主要知识增量。

## 6) 追加（CASE-NAFEMS-LE11，mission 15261）：变曲率子午线的可测边界

C5 记录的是「一般曲面子午线未合格」。椭球壳算例给出了该边界的一个**正面**数据点，
它与 C5 不矛盾，但把可用面扩大了：

- 算例：闭合旋转椭球 $a=1,b=0.5,t=0.01,E=1,\nu=0.3,p=1$（扁椭球，赤道环向膜力**为压**），
  极→赤道半子午线，逐单元给中点密切圆半径 $R_1=W^3/(ab)$；
- 参考解：闭式膜力（截盖轴向静力平衡 + 法向平衡）与独立的 Rayleigh–Ritz 膜位移
  （自检复现闭式膜力 1e-10 量级）；
- 实测：场误差**一阶收敛**（n=32/64/128 的 max$|\Delta N_\varphi|/N_{scale}$
  = 15.20% / 7.94% / 4.06%），n=128 时极部 $N_\varphi$ 0.02%、赤道 $N_\varphi$ 0.31%、
  赤道 $N_\theta$ 2.86%、赤道 $w$ 2.51%，全部 <5%；
- 限制：赤道 $N_\theta$ 相对误差在 n≥128 后**停滞在 ~2.6%**（离散边界层，网格无关），
  且 $a/t=50$ 时赤道 $N_\theta$ 误差 7.11% 已超 5%（弯/膜耦合）。
  故椭球子午线只在**薄壳 + n≥128** 的使用面上合格，粗网格/厚壁不得引用。
