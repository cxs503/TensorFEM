## 2. 根因（三个独立缺陷，全部实测）

### D5 夹持面只夹了两个节点（根因中的根因）

`build_dcb_model` 里：

```python
clamp = nodes[:, 0] == 0.0
fixed = (3 * clamp.numpy()[:, None] + _AR3).reshape(-1)   # 错
```

`3 * clamp` 乘的是**布尔掩码**而不是节点号：`3*True == 3`、`3*False == 0`，
于是固定自由度集合恒为 `{0,1,2} ∪ {3,4,5}`——**前两个节点的 6 个自由度**，
而不是 x=0 夹持面上 16 个节点的 48 个自由度。实测 `m.fixed_dofs.size == 22`
（= 6 个"夹持" + 16 个加载面 z 自由度）。

后果是可测的：自由自由度切向刚度矩阵出现**伪近零模态**

* 修前：\`|λ|_min = 4.7e-11\`，\`|λ|_max ≈ 2.33e8\`（条件数 ≈ 5e18）；
* 修后（`np.flatnonzero`）：\`|λ|_min = 37.5\`（次小 455 / 1170 / 1423）。

线性直接解法能"侥幸"给出正确解（残差 5.7e-12，柔度与梁理论一致），
但牛顿路径跟随器会沿该近零模态**漂移**：实测 6 步内 `max|u|` 从 2.1e-5 m
涨到 1.5 m，而残差判据仍"收敛"——这就是历史上"DCB 夹持端漂移/发散"的真正来源。

### D6 无条件全步长牛顿 + 不可达的绝对容差

* 起裂步上软化段切线不定，全步长牛顿直接把状态推到非物理区（分离量 2.5e13 m）；
* 容差写成 `tol * max(scale, 1.0)`，首步 `scale = 1.0 N`，即绝对 1e-8 N 的判据；
  而罚刚度 `k_n = 2.4e14 Pa/m` 与 `E = 70 GPa` 的对比使 `K` 条件数达 1e10–1e12，
  实测残差地板 ≈ 5e-8 N（δ=12 µm 处），判据不可达 → **伪发散**
  （实测：残差 4.9e-8 时报告"不收敛"）。

### D7 相对收敛判据可以"收敛"掉一个已经跑到天上的状态

修 D6 后一旦把容差改成相对量，一个 \`max|u| = 1 m\` 的野状态也能满足相对判据：
实测被接受并报告 \`final_strain_energy = -13.5 J\`（半正定 `K_solid` 的二次型不可能为负，
这是大幅交替解的相消误差）、能量不平衡 3235 倍。

## 3. 修复与实测效果

| 修复 | 位置 | 实测效果（同一参考试样 nx=100, ny=1, nz=3） |
|---|---|---|
| 夹持面用 `np.flatnonzero` | `build_dcb_model` | 固定自由度 22 → 64；`|λ|_min` 4.7e-11 → 37.5 |
| 残差范数回溯线搜索（Armijo，20 次减半） | `_newton` | 起裂步（δ=5.25e-4）由"发散"变为 3 次迭代收敛 |
| 力尺度相对容差 + 残差地板 1e-6 | `_newton` | δ=12 µm 处伪发散消失 |
| 仅提交**物理可容许**状态（位移上界 100·δ_max、应变能非负） | `solve_dcb` | 负应变能/野状态不再被提交 |
| 加载窗口由梁理论导出 `δ_max = 1.35·P_c·C` | `benchmarks/cohesive3d_dcb_3d.py` | 40 µm（峰值开口的 4.5 %）→ 1.2 mm（135 %） |

## 4. 注意点 / 局限（honest）

* **峰值之后的扩展段仍未拿到。** δ = 9.744e-4 m 处步长塌陷到 1e-6 量级：
  这是位移控制下的**极限点**（dP/dδ → 0，切线奇异），不是容差问题。
  越过它需要弧长控制（arc-length / 局部弧长）或对损伤自由度做约束切换，属下一轮工作。
  因此"R 曲线""界面功/失效面积 = G_Ic""裂纹前缘直线度"三条判据本轮仍然无法判定。
* **峰值判据按 5 % 口径诚实失败**（+5.4 %）。没有在看到数字后放宽阈值；
  同时给出无根旋转参照（-1.6 %）以说明该 5 % 的偏差处在两种梁理论基准之间的正常带内。
* 网格 `nx=100, nz=3` 下过程区约 1.5 mm ≈ 2.5 个单元，仍属粗网格；峰值对网格的敏感性未做收敛研究。
* 小应变、无接触/摩擦、无循环退化；判据只对标梁理论闭式解，未对标实验。
