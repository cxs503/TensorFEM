# 结构-声学双向耦合水下辐射噪声验证面

**节点** `p348w3-n07-fem-structural-acoustic` · **mission** 10695 · **仓库** TensorFEM · **分支** `agent/m10695` · **commit** `d3fa2eb`

## 1 案例介绍（物理背景 / 几何 / 参数）

本节点验证「结构振动 → 声场 → 声功率级」这条辐射噪声主链的**数值正确性**：两个无拟合常数的解析锚定住整条链，双向耦合的流体反作用力按**域解**处理而不是记账项。

**锚 1 — 脉动球（单极子）**：半径 `a` 的球壳呼吸模态以法向振速 `v0` 振动，外部声场为球对称 Helmholtz 问题，精确解

```
p(r) = rho c v0 (a/r) exp(ik(r-a)) / (1 + i/(ka))
W    = 2 pi a^2 rho c v0^2 (ka)^2/(1+(ka)^2)
Z    = p(a)/v0 = rho c (ka)(ka - i)/(1 + (ka)^2)
```

**锚 2 — 带障板圆活塞（平板辐射）**：半径 `a` 的平面圆形声源以均匀法向振速向半空间辐射，远场指向性为 Airy 图样

```
p(r,theta) = i rho c k v0 a^2/(2r) * 2J1(ka sin th)/(ka sin th) * exp(ikr)
sigma_p    = 1 - J1(2ka)/(ka)
```

**结构侧**（双向耦合与能量守恒用）：薄球壳呼吸模态，`a = 1 m`，`h = 0.02 m`，`rho_s = 7850 kg/m3`，`E = 2.1e+11 Pa`，`nu = 0.3` ⇒ 模态质量 `1973 kg`、模态刚度 `1.508e+11 N/m`、干模态频率 `f0 = 1391 Hz`、湿面积 `12.57 m2`。

**流体**：`rho_f = 1000 kg/m3`，`c = 1500 m/s`。**频率档** 50 / 100 / 200 / 500 Hz；**阻尼比档** 0.01 / 0.05 / 0.1。球半径 `1.0 m`、活塞半径 `0.5 m`、径向网格 `48` 个二次单元、截断面 `R = 4.0 a`。

## 2 怎么做的（方法 / 流程 / 工具链）

### 2.1 声学域：球对称 Helmholtz 的径向有限元（新增 `pulsating_sphere.py`）

三维 Helmholtz 算子在球对称场下的**精确一维约化**（不是一维替代模型），Galerkin 弱形式

```
int_a^R (r^2/rho) p' q' dr - omega^2 int_a^R (r^2/rho c^2) p q dr = [ (r^2/rho) dp/dr q ]_a^R
```

- 3 节点二次径向单元、8 点 Gauss 积分、复数稠密直接求解（torch float64 / complex128）。
- 内边界 `r=a`：结构振速给出 Neumann 条件 `dp/dr = i omega rho v0`，即法向加速度连续 `rho_f d2u_n/dt2 = -dp/dn`。
- 外边界 `r=R`：**精确**球形出射波辐射条件 `dp/dr = (ik - 1/R) p`（Bayliss-Turkel 一阶对 l=0 谐波精确），误差只剩径向离散 —— 这才使与闭式解的比对成为**代码验证**而非模型比对。
- 双向耦合：流体反作用以域解阻抗 `Z = p(a)/v0` 进入结构方程（速度未知量的机械阻抗形式）

```
(c_d + i(k - omega^2 m)/omega + A Z) v = F
```

`i(k-omega^2 m)/omega` 是储能（无功）项，必须留在算子里。

### 2.2 平板远场：Rayleigh 积分直接数值求积（新增 `plate_far_field.py`）

`p = i omega rho v0/(2 pi) int_S exp(ikR)/R dS`：极坐标 Gauss（含 `rho d rho` Jacobian）× 方位梯形，**保留精确核**（不做 `kr -> inf` 近似）；另配解析积分得到的轴向精确闭式 `p = rho c v0 (exp(ik sqrt(r^2+a^2)) - exp(ikr))` 作为独立校验（钉住幅值、相位与符号）。J1 由 Abramowitz-Stegun 9.4 有理近似实现（不依赖 scipy）。

### 2.3 声功率级-振速级标度律（新增 `radiation_scale_law.py`）

由 `W = rho c S <v^2> sigma` 直接推出

```
Lw = Lv + C,  C = 10log10(rho c S sigma) + 20log10(v_ref) - 10log10(W_ref)
```

用 ISO 1683 参考量 `W_ref = 1e-12 W`、`v_ref = 1e-09 m/s`，故 `C` 是**推导量**。配套可判别性检查：振速十倍程斜率须恰为 1、面积加倍须恰为 +3.0103 dB，并以「把峰值当 RMS」的 3.01 dB 陷阱作负向标定。

### 2.4 证据与报告

`benchmarks/struct_acoustic_two_way_coupling.py` 跑全部判据 → `artifacts/struct_acoustic_two_way/evidence.json`；本报告每个数字都由该 JSON 注入（零手抄），图由同一脚本 matplotlib 生成。测试面见 `tests/test_struct_acoustic_two_way_coupling.py`。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **节点原式的 `ka -> inf` 属性**：`p = rho c v0 (a/r) e^{ik(r-a)}` 与 `W = 2 pi a^2 rho c v0^2` 是单极子在 `ka -> inf` 的极限（恰为精确解乘 `(1 + i/(ka))`，压力相对误差 `1/(ka)`、功率相对误差 `1/(ka)^2`）。低频时表面压力按 `ka` 塌缩、辐射功率按 `(ka)^2` 走，照抄原式会高估上千个百分点。故本节点双轨：工程频段以精确解为锚（C1/C2），原式在其渐近域单独验证（50 m 球）。

2. **节点原式的 `cos(theta)` 因子**：带障板平面声源远场指向性是 Airy 图样而非 `cos(theta)`；`cos(theta)` 属于无障板偶极子（远场幅值正比于板厚，薄板极限下塌缩）。逐角度偏差已量化登记（0 deg 为 0，60 deg 达 50 %）。C3 以 Airy 闭式为锚。

3. **机械阻抗形式（本节点最大的一课）**：首版把位移形式的 `(k - omega^2 m - i omega c_d)` 直接当速度未知量的算子，量纲错误（N/m 而非 N s/m），功率恒等式按无功份额失效（残差 ≈ 1）。正确形式 `(c_d + i(k-omega^2 m)/omega + A Z) v = F`，储能项必须留在算子里。

4. **外截断通量路线的精度**：它用单元 Gauss 点的场梯度，误差随频率升、随网格密化降（500 Hz：8 单元约 30 % -> 96 单元 0.3 %）。主证据统一用 48 单元（500 Hz 下 <= 1 %），收敛表见 3.6。

5. **适用范围**：单极子锚要求球对称（呼吸模态）；平板锚是平面圆形声源 + 半空间，不含弹性板多模态耦合（仓内 `struct_acoustics.radiation_coupling` 已覆盖矩形板二向耦合）。流体为均匀无衰减介质，未含气泡 / 温跃层 / 海面-海底边界。

6. **J1 精度**：|x| < 12 用幂级数（相对 1e-11），以上用 Abramowitz-Stegun 9.4.6 渐近式（绝对 < 1e-7）；与已知零点 J1(1.84118) = 0.5819 及级数交叉校验。
