## ⑤ 注意点（本审计自身的局限与踩坑）

1. **模型同源性**：本席的 FV 路线与被审计 BEM 共享"自由面镜像 + 折算单位长度"这一**模型**，
   只在**离散族**上独立。故 225.83 vs 225.197 的 0.28% 一致**不能**证明镜像近似本身正确，
   只能证明两条离散的实现都没错。镜像近似适用于深水、细长体、`A33 ≈ A33_2D·L` 的条带假设。
2. **FV 残余误差**：截断（R）是主项（R=120 时 ~+1.5%），故组合估计按 ±1.5% 记；
   本席未做 `R=240 & h≤0.5`（917k→3.7M 未知量，超出本机短测试预算）。
3. **未取值的外界锚**：Vugts (1968) 矩形截面附加质量表本席亦未取得（无外网），
   因此"外部文献锚"在本生态内仍是缺口，`external_anchor` 只能记 `tensor_reports#19234`。
4. **ω→∞ 路线未被独立复核**：FV 只做了 ω→0 变体；奇镜像（φ=0 自由面）路线 234.042 t/m
   本席**未**独立验证（`not_run`）。主参考取两路线均值，其 229.620 的独立支持因此
   只有"落在闭式界内 + ω→0 端被 FV 复核"这一半。
5. **一次失败的独立路线**：MFS（点源、零净通量）在角点奇异矩形上不收敛（BC 残差 ~2、
   `cond≈1e18`），改走 FV 才对上；如实记录为 `not_run`。
6. **平台侧质量审计**：m22319 的 `result.server_quality_audit` 仍是
   `{gate_valid:false, key_present:false, gate_missing_warning:true}` —— 原单 `result` 里
   **没有 `gate` 键**，`succeeded` 由 dev_acceptance 自动批准，不代表门禁被平台认过。
7. **判级只认功能实质**：文档 260 行 + 报告 2 878 字不影响级别；本单级别由
   "有无真实现/有无独立功能/有无集成调用/有无登记基准"四问决定（见发现清单 F1/F2）。

## 发现清单（按严重度）

**F1（blocking-for-L4，平台侧 / 本单最重）基准裁判缺行：该锚没有登记基准用例。**
`tensor_benchmark_cases WHERE anchor_slug='GAP-ICE-GATE-POWER'` → **0 行**（本席亲查，表内 144+ 行，
无任何 `*GATE-POWER*`）。原单声明"sandbox role permission denied"未完成登记，只交了
`docs/oss/GAP-ICE-GATE-POWER-oss_solutions.sql`（那是 `oss_solutions`，**不是**基准用例表）。
⇒ 平台侧无 ref/tolerance 可裁，L4 在法律意义上不可达；"pass=True" 只是被审对象**自己**
算出来的布尔值。
*复现*：`psql -U postgres -d tensorplatform -c "SELECT ... WHERE anchor_slug='GAP-ICE-GATE-POWER'"`。
*返修*：由平台角色登记一行 `(anchor_slug='GAP-ICE-GATE-POWER', case_name='ice_chain_heave_added_mass_2d',
metric='|A33_ref-A33_decl|/A33_ref', tolerance=0.15, ref_source='#19234 Q5 228.6 t/m')`，
并把闸的 got 值指向该行。

**F2（major，集成）判据无调用方，"可机检"是抱负不是事实。**
`grep -rn ice_gate_power` 在生态仓内只命中它自己的 `benchmarks/ice_gate_power/*` 与文档，
**没有**任何主求解器/平台路径调用 `gate_verdict`/`decide`。⇒ 该闸不可能拦住任何真实交付，
L3 不成立（`integration_callers` 本席留空）。
*复现*：`grep -rn "ice_gate_power" --include=*.py .`（除自身与 docs 外无命中）。
*返修*：把闸接进冰区链的 CI/验收路径（例如 `benchmarks/ice_coupled_6dof/run_w23_ice_coupled_6dof.py`
在装载 `radiation` 后调用 `gate_verdict` 并 fail-fast），或在平台 `maturity_gate` 侧读该 JSON。

**F3（minor，证据完整性）生成文档里有一处无出处的字面量 `accept（0.38%）`。**

`-0.44%`，JSON 中不存在 0.38% 这个量（`verify_output_m22346.json` 的
`published.anchor_deviation = -0.004440`）。不改变判决，但违反本单自己宣称的"零手抄"。
*返修*：删掉该括注，或绑定到 JSON 键。

**F4（minor，可审计性）三张生成表的表头缺失。**
`docs/GAP-ICE-GATE-POWER-round2.md` 的 ④-4、⑤-1（两张）、⑤-2、⑤-3 表**没有表头行**
（直接从数据行开始），列语义只能从正文猜；⑤-1/⑤-2/⑤-3 连"per_edge/面板数/值/偏差"都没标。
*返修*：在 `make_doc.py` 的表模板里补 header。

**F5（minor，方法表述）把 u=2.9% 的成因归给面板收敛，与自己的数据不符。**
⑤-1 写"观测阶亚线性…这也是 u 必须取 2.9%（而非'<3% 已足够'）的原因之一"；但本单自己测出
