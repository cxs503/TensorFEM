## ① 案例介绍（物理背景 / 几何 / 参数表）

碎冰场（broken / brash ice）：船在冰区航行时，航道内是大量厘米—数米尺度的浮冰块，
它们浮在水面（阿基米德浮态）、相互接触、被船首侧向排开形成航道。工程关心的两个量是
**(a) 浮冰浮态**（吃水/干舷决定冰面覆盖率、船-冰接触高度）与 **(b) 航道清空率**
（船后航道内残留冰量与推土量，直接进入 brash ice 阻力与通航性评估）。

计算模型（本仓 TensorFEM 侧）：

| 项目 | 设定 |
|---|---|
| 浮冰 | 刚性圆盘，半径 1.5–3.0 m，厚 0.4–1.0 m（默认 80 块，随机顺序吸附布放，seed=20261113） |
| 冰密度 / 水密度 | 900 / 1025 kg/m³（密度比 0.878；判据工况另做 0.85–0.95 扫描） |
| 竖向自由度 | 单自由度垂荡 z（块心相对静水面），浮力 `F_b = ρ_w g A · clip(h/2 − z, 0, h)`，加 ζ=0.7 粘性阻尼 |
| 水平 | 平面刚体圆盘，脉冲法接触（restitution 0.2，默认无摩擦 μ=0） |
| 结构 | 刚性船首楔形：两条半顶角 α 的斜边 + 平行中体（无限质量，定速 V） |
| 场域 | 50 m × 60 m，开放边界；航道走廊 ±(L_bow·tan α) |
| 时间步 | 场演化 dt = 0.018 s（受最薄冰 ω·dt ≤ 0.1 约束），单块浮态验证 dt = 0.005 s |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **解析基准先行**：`archimedes_equilibrium` 给出平浮冰盘 `draft = h·ρ_i/ρ_w`、
   `freeboard = h(1 − ρ_i/ρ_w)`；`heave_natural_frequency` 给出 `ω = sqrt(ρ_w g/(ρ_i h))`；
   楔形面持续接触的稳态解析解 `v = (V·n)n`，对半顶角 α 的斜边法向
   `n = (cos α, sin α)`，故 `v_x = V sin α cos α`。
2. **动力学自行找浮态**：单块验证从「块底刚好触水」(z = h/2) 起步——浮态不是从解析
   平衡态起算，否则「干舷 vs 阿基米德」退化为恒等式。半隐式（symplectic）Euler 积分
   非线性浮力，收敛后读干舷。
3. **垂荡频率独立校验**：解析平衡态 + 2 mm 小扰动、关阻尼，数 `z − z_eq` 的上穿零点得
   周期。注意：该周期不复用构建阻尼时的闭式 ω（m 方程里 c=2ζωm 用的是闭式 ω，周期却是
   从轨迹量的），二者一致才算通过。
4. **接触子模型对解析**：单冰盘被斜面推走的稳态侧向速度 vs `V sin α cos α`；两块对撞
   检查动量守恒 / 回弹系数 / 无能量注入。
5. **航道清空统计**：楔形船首以定速 V 扫过全场，走廊内冰盘分三类——
   `cleared`（块心横向被抛出走廊）、`dragged_forward`（未侧向清出、但被顶出分析窗口
   y > L_field，即"推土"）、`residual`（仍留在走廊内）。另给走廊**面积覆盖率清空率**
   （网格采样 0.25 m，覆盖率下降比），窗口与块心判据统计窗口一致（y ∈ [0, L_field]）。
6. 单一线程跑积分循环（`_single_thread_intraop`）：单步张量只有几千个元素，128 线程的
   调度开销占主导（实测 80 块扫掠从 27.9 s 降到 12.5 s，且消除多线程归约顺序带来的
   **非确定性**——多线程下同 seed 的穿插量 0.063 m vs 单线程 0.018 m）。线程数在用后恢复。

|---|---|---|---|---|

| μ = 0.3 | 0.769 | 1.000 | 0.231 | 13 |

**如实报告的负结果**：在无粘、无回流、无侧壁约束的理想化模型里，侧向清空率对航速
**不敏感**（0.5–3.0 m/s 恒为 12/13）——凡是进入走廊的冰盘最终都会被发散船首侧向抛出，
航速只改变发生时刻、不改变结局（覆盖率高到 0.996–0.998 是同一个饱和机制的另一种度量：
被顶出的 1 块冰落在分析窗口之外）。真正的敏感性出现在**船首半顶角**（19°–40° 扫描下
0.857–0.923）与**摩擦**（μ=0.3 时清空率降到 0.769、推土升到 0.231）。这与"高航速下清空
更好"的工程直觉不符，原因在模型假设（无破冰、无碎冰再循环、冰块不可旋转/不可倾覆），
不是数值误差——故本条作为**适用边界**登记，而非可引用的工程结论。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **浮态必须从非平衡初值沉降**：若从解析平衡态出发验证干舷，等于验证恒等式。
   测试里显式从块底触水起步，并另有一条测试确认起点无关性。
2. **阻尼系数公式坑**：`c = 2ζωm`，曾误写为 `2ζ√(ω²m)`（少乘 √m），阻尼小 123 倍，
   浮冰持续"弹跳"、干舷误差 83%。垂荡周期测试（关阻尼）和浮态测试拆开跑之后才暴露。
3. **法向冲量符号坑**：`closing_speed > 0` 表示接近，冲量应为 `+(1+e)·closing/(1/m_i+1/m_j)`。
   写成负号会被 `clamp(min=0)` 吞掉 → 冰-冰接触**完全不发生**，而"动量守恒""无能量注入"
   这类测试仍然全绿（因为它们对"没有碰撞"也成立）。是"回弹系数复现"这一条断言抓出来的。
4. **楔尖端点接触**：把冰盘放在楔尖附近时，接触法向来自斜面**端点**而非斜面法向，
   15° 工况实测 0.478 m/s vs 解析 0.250 m/s（偏 91%）。改为把冰盘置于斜面中段外法向
   一侧后，15°–50° 全部回到 1e-15 量级。
5. **线程非确定性**：多线程归约顺序让同 seed 的同一次仿真给出不同结果（穿插量 0.063 vs
   0.018 m）。积分循环固定单线程后复现位数级一致。
6. **回弹对"稳态速度"的影响**：`v = (V·n)n` 只是 e→0 持续接触极限；e=0.6 时单次冲击给
   `(1+e)(V·n)`，冰盘会短暂脱离再接触，稳态速度可以被超出。测试因此只断言 e=0 的等值
   与 e>0 的上界 `(1+e)V sin α cos α`，不再断言"与回弹无关"（这是我最初的错误假设，
   已被自己的测试否定）。
7. **适用范围**：刚性圆盘、单竖向自由度、无破冰/无倾覆/无滚动阻力/无碎冰再循环、
   二维平面接触。生产级 DEM（多面体/团簇、粘结破坏、GPU 大规模）属于 TensorDEM 仓
   （`broken_ice_micro`、`brash_ice_rheology`、`buoyancy_verification` 等），本模块是
   **给 DEM 对表用的参考实现 + 解析基准**，不是替代品。
8. 摩擦默认 μ=0（声明：默认无摩擦；μ=0.3 的敏感性另列）。

## ⑥ 误差判定：关键量 vs 基准，逐项回答「是否 < 3%」

| 关键量 | 基准 | 误差 | 是否 < 3% |
|---|---|---|---|
| 干舷（ρ_i/ρ_w = 0.9，h = 0.6 m） | 阿基米德 `h(1−ρ_i/ρ_w)` = 0.0600 m | 1.1e-14 | **是**（且满足 < 5% 锚点判据） |
| 干舷（0.85–0.95 扫描） | 同上 | ≤ 1.7e-14 | **是** |
| 吃水 | `h·ρ_i/ρ_w`，0.540 m（0.9 工况） | ≤ 5%（测试判据线） | **是** |
| 垂荡周期（h = 0.3–1.2 m） | `2π/ω` | ≤ 1.6e-4 | **是** |
| 船首斜面稳态侧向速度（α = 15–50°） | `V sin α cos α` | ≤ 1.9e-15 | **是** |
| 冰-冰接触 | 动量守恒 / 回弹系数 / 能量不增 | 动量残差 < 1e-9 kg·m/s；回弹复现 1e-9；动能不增 | **是** |
| 航道清空率 | **无仓内冰区航道清空实测数据集** | 无法计算 | **不适用（WITHHELD）** |
| 冰-冰穿插量 | 最小冰盘半径的 10%（数值质量判据） | 实测 ~0.018 m（≈1.2% of r_min） | **是（数值质量）** |

**清空率的诚实结论**：本仓没有可对标的冰区航道清空实测统计（也无 brash ice 航道
覆盖率实测数据），所以清空率**只作为模型统计量如实报出**（0.769–0.923 依半顶角与摩擦），
**不声称**与实测 <3% 或 <15% 一致。要把它变成可引用结论，需要（a）实测/模型试验数据入仓，
（b）加入破冰、碎冰再循环与侧壁约束。这两件都不在本单范围内，作为待办登记。
