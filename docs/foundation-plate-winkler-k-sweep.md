## ① 案例介绍（物理背景 / 几何 / 参数）

浮体、浮冰、坐坞船底板、搁浅船底——船舶总体性能里凡是**板与弹性支撑耦合**的弯曲问题，
其力学内核都是 Winkler 地基板：

    D ∇⁴w + k w = q ,      D = E t³ / (12(1−ν²)) ,    l = (D/k)^(1/4)

地基反力 `q = k·w` 直接耦合进板单元刚度：`K_w = k ∫ Nᵀ N dA`（2×2 Gauss）。
**关键点**：单个 k 下任何单位/权重/系数错误都可能被凑巧掩盖，因为 `k l⁴ = D` 把所有长度尺度
绑在一起；只有让 k 跨量级变化，耦合项的错误才会以 **量级差** 暴露。本节点扫 k 跨 3 个量级。

### 算例族

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **单元级耦合**：`tensorfem.foundation_plate_bending` 的 Q4 Mindlin 单元，地基贡献 `K_w = k ∫ Nᵀ N dA`（2×2 Gauss，与弯曲项同一积分规则），梁用 `tensorfem.beam_foundation` 的 Euler–Bernoulli + 一致地基阵 `k ∫ Nᵀ N dx`。
2. **无量纲化建模**：族 A 计算域半宽固定为 `10 l`（`half_width_in_lengths=10`，l 随 k 变化），网格按 l 归一化（graded axis，β=4，n=40）——因此换 k 时是**同一无量纲问题在不同物理尺度下重解**，不是同一个矩阵换个系数。
3. **边界与载荷**：族 A 用 1/4 对称（x=0 上 θ_x=0，y=0 上 θ_y=0）、外缘自由、对称角点施加 P/4；族 B/C 为简支。
4. **对标**：族 A 与 Hetényi (1946) 无限板 Kelvin–kei 闭式解逐点比；族 B 与简支梁傅里叶正弦级数（精确本征展开，200~400 项）；族 C 与 Navier 双级数（199 项）。
5. **判据（硬门）**：挠度误差 ≤5%；族 A 剖面误差（按 w(0) 归一，因 kei 过零）≤5%；族 A 地基反力与外载平衡残差 ≤1%；k 跨度 ≥2 量级且 ≥3 个取值。
6. **工具链**：torch float64 + 稀疏直接解（ndof>3000 时自动切换）；工件 `result.json` / `gates_verified.json` / 3 张 PNG 全部由脚本一次写出。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **kei 解会过零**：`w(r) = -P/(2πkl²)·kei(r/l)` 在 r/l≈2.4 附近变号（板的浅抬高环），该处逐点**相对**误差没有意义（分母→0）。本节点剖面判据改用 `|Δw|/w(0)` 归一，并把无量纲位置 0.5/1/2/3 处的结果逐项列出。首版用逐点相对误差曾读到 3% 的假误差。
2. **简支板不是无支撑板**：族 C 上 `ΣR_foundation ≠ P`——边缘支反力分担了部分载荷，所以那里只能报「地基承担份额」，不能当平衡残差用。首版把 35% 的“残差”当成红门，实为指标错用。
3. **厚板区是模型差不是实现差**：`t/l` 增大时 Mindlin（含横向剪切）必然高于 Kirchhoff 的 kei 解，量级 O((t/l)²)。族 A 因此取 50 mm 钢板（t/l ≤ 0.04）；150 mm 冰板 + k=1e6 的「厚板区诊断」见 ⑥，那里的 ~5% 是**方程差异**，不是单元实现误差。
4. **网格取 n=40 而非最细**：k 越大 l 越小、t/l 越大，误差随 n 增大趋向收敛的 Mindlin 值；族 A 的误差量级 ~0.1%，远低于 5% 门，故 n=40（ndof≈5043）足够且可一键复现。
5. **适用范围**：一参数 Winkler 地基（无剪切层耦合，Pasternak/Kerr 另有节点）；族 A 仅中心载荷（1/4 对称），偏载/非对称未覆盖；域截断在 10l 外缘自由。

### 判据灵敏度（门不是惰性的）

挠度对标度关系 `w ∝ k^(−1/2)`，因此 5% 挠度门 ≈ 对地基系数 k 的 ~10% 门。
把单元内的 k 人为乘 f 而参考解仍用 k 的变异探针（n=20，k=1e3…1e6 取最差）：

| f（单元 k 偏差） | 最大挠度误差 [%] | 是否被 5% 门捕获 |
|---|---|---|
| 1.00 | 0.395 | 否（正常） |
| 1.01 | 0.889 | 否（设计灵敏度极限） |
| 1.25 | 10.910 | **是** |
| 4.00 | 50.193 | **是** |
| 0.25 | 99.468 | **是** |
