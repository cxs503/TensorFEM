# 平面应变近不可压锁定闭环：平均膨胀 Q4（B-bar）对精确 Lamé 基准

本报告补的是**验证欠账 + 该欠账的唯一缺件实现**。已合并的
[`near-incompressible-locking.md`](near-incompressible-locking.md) 第 6 节把这条写成未完成项 1：

> **2D 平面应变 Q4 无 B-bar/EAS/BF 对照实现**，`nu >= 0.499` 时误差 14 %–155 %；
> 船舶结构里橡胶支座、近不可压涂层、复合基体都用平面应变/平面应力 Q4 路径求解。

现在缺件（`src/tensorfem/continuum_bbar.py`）已补，并用同一个精确解打分：标准 Q4 的
155.2 % 径向应力误差在**同一套网格**上降到 **0.574 %**，且误差对 `nu` 完全平坦。

## 1 案例与离散

| 项 | 取值 |
|---|---|
| 问题 | 厚壁圆筒内压，平面应变（`eps_z = 0`） |
| 几何 | 内半径 `a = 0.5 m`、外半径 `b = 0.8 m`（`b/a = 1.6`） |
| 材料 | `E = 210 GPa`，`nu = 0.3 … 0.4999` |
| 载荷 | 内孔均布压力 `p = 100 MPa`，外表面自由（一致节点力，`lame_reference.circular_pressure_loads`） |
| 参考解 | 平面应变 Lamé 闭式解（应力场与 `nu` 无关，位移场含 `nu`） |
| 网格 | 1/4 环扇形结构化 Q4：`n_theta x n_radial`，基准 `16x8 = 128` 单元 / `306` DOF |
| 约束 | 两条对称切割上 `u_theta = 0`（`lame_reference.symmetry_fixed_dofs`），无位移强加 |
| 对照格式 | 标准 Q4（2x2 Gauss 全积分，`solve_continuum`） vs 平均膨胀 Q4（B-bar，`solve_continuum_bbar`） |

两个求解器共用**逐行同构**的边界条件、自由/固定划分与单元中心应力恢复路径，
唯一差别是单元算子本身——比较结果因此不掺杂约束或载荷路径差异。

## 2 方法

**B-bar 单元**（`continuum_bbar.py`，Nagtegaal 1974 / Hughes 1980 的平均膨胀形式）：

```
Bv = B[0] + B[1]                       （膨胀行）
Bv_bar = ∫ Bv dA / ∫ dA                （单元面积加权平均，2x2 Gauss 积分）
B_bar[0] = B[0] + (Bv_bar - Bv)/2
B_bar[1] = B[1] + (Bv_bar - Bv)/2
B_bar[2] = B[2]                        （剪切/偏量项保持全积分）
K_e = Σ_gp w * detJ * B_bar^T D B_bar
```

三个可解析判定的性质，先验于任何数值比较：

1. **协调性（patch）**：常应变场下 `Bv_bar == Bv` 逐点成立 ⇒ `B_bar == B`，
   B-bar 单元的内力向量与标准单元逐项相同（不改动标准单元的精度阶）；
2. **无数值沙漏**：偏量项仍是 2x2 全积分，单元素 8 DOF 只保留 3 个零能模（2 平移 + 1 转动）；
3. **体积约束数**：从每单元 4 条（4 个 Gauss 点各一条）降为每单元 1 条。

**验证流程**（`plane_strain_locking.py` + `benchmarks/plane_strain_bbar_locking.py`）：

1. 先验参考解自检（平衡/面力/本构/`eps_z=0`/应力对 `nu` 不变）；
2. 单元级前提（patch 协调、刚体零能模、`Bv_bar` 与常应变 `Bv` 的一致性）；
3. 固定网格（`16x8`）扫 `nu`：若锁定被治愈，**应力误差**（应力场本与 `nu` 无关）必须对 `nu` 平坦；
4. `nu = 0.4999` 加密：观测阶把"网格粗"与"单元过刚"分开。

复现：

```bash
PYTHONPATH=src python3 benchmarks/plane_strain_bbar_locking.py     # 约 16 s，写出证据 JSON + 3 张图
PYTHONPATH=src pytest tests/test_plane_strain_bbar_locking.py -q
```

## 3 结果

### 3.1 先验判据（参考解与单元前提，全部为残差，不是自述）

| 判据 | `nu = 0.3` | `nu = 0.4999` |
|---|---:|---:|
| 平衡残差 `dσr/dr + (σr-σθ)/r`（相对峰值） | 2.279e-09 | 2.279e-09 |
| 面力残差 `σr(a) = -p`, `σr(b) = 0` | 0.0 | 0.0 |
| 平面应变本构残差 `(εr,εθ) → (σr,σθ)` | 1.735e-09 | 1.864e-06 |
| `eps_z = 0` 一致性 `σz = ν(σr+σθ)` | 3.26e-17 | 3.26e-17 |
| 应力场对 `nu` 的不变性 | 0.0 | 0.0 |

| 单元前提（变形 Q4，`nu = 0.4999`） | 值 |
|---|---:|
| patch：常应变下 B-bar 与标准单元内力向量相对差 | 3.46e-16 |
| patch：常应变应变能 vs `0.5·A·ε:D:ε` | 2.10e-16 |
| 刚体平移零能模残差（相对谱范数） | 1.78e-16 |
| 刚体转动零能模残差 | 3.86e-17 |
| 单元素零能模个数 | **3**（无沙漏） |

### 3.2 误差对 Poisson 比（`16x8`，306 DOF，单位 %）

| `nu` | 位移 L2 标准 | 位移 L2 B-bar | 径向应力 L2 标准 | 径向应力 L2 B-bar | 环向应力 L2 标准 | 环向应力 L2 B-bar |
|---:|---:|---:|---:|---:|---:|---:|
| 0.30 | 0.1537 | 0.0899 | 0.7663 | 0.5725 | 0.2070 | 0.1589 |
| 0.45 | 0.4090 | 0.1061 | 1.3656 | 0.5734 | 0.3482 | 0.1586 |
| 0.49 | 1.6858 | 0.1114 | 4.5433 | 0.5737 | 1.0939 | 0.1585 |
| 0.499 | 14.0439 | 0.1127 | 35.4570 | 0.5738 | 8.3424 | 0.1585 |
| 0.4999 | 61.9144 | **0.1128** | 155.2219 | **0.5738** | 36.4240 | **0.1585** |

标准 Q4 从 `nu = 0.3` 到 `0.4999` 误差涨 **203 倍**（径向应力）；B-bar 只涨 **1.0024 倍**——
而应力场本身与 `nu` 无关，这 0.24 % 的变化就是纯离散噪声，即"无锁定偏置"。

### 3.3 `nu = 0.4999` 加密（`h ∝ 1/n_theta`）

| 网格 | 单元 | DOF | 位移 L2 标准 | 位移 L2 B-bar | 径向应力 L2 标准 | 径向应力 L2 B-bar |
|---|---|---:|---:|---:|---:|---:|
| 8x4 | 32 | 90 | 86.57 % | 0.4506 % | 216.02 % | 2.3043 % |
| 16x8 | 128 | 306 | 61.91 % | 0.1128 % | 155.22 % | 0.5738 % |
| 24x12 | 288 | 650 | 41.99 % | 0.0502 % | 105.35 % | 0.2548 % |
| 32x16 | 512 | 1122 | 28.94 % | 0.0282 % | 72.65 % | 0.1433 % |
| 48x24 | 1152 | 2450 | 15.33 % | 0.0125 % | 38.50 % | 0.0637 % |

观测阶（末两网格，`h` 比 1.5）：B-bar 位移 **1.9998**、径向应力 **2.0005**（Q4 的最优阶）；
标准 Q4 位移 1.567、径向应力 1.566——阶数"看起来正常"但**截距含一个 `1/(1-2nu)` 型放大因子**，
所以 `nu = 0.4999` 下加密到 2450 DOF 仍有 15.3 % / 38.5 %，要达 3 % 需再加密约 5 倍。

### 3.4 机理：体积约束数

| 网格 | DOF | 标准 Q4 独立体积约束 | B-bar 独立体积约束 | 约束/DOF（标准） | 约束/DOF（B-bar） |
|---|---:|---:|---:|---:|---:|
| 8x4 | 90 | 78 | 32 | 0.867 | 0.356 |
| 16x8 | 306 | 286 | 128 | 0.935 | 0.418 |
| 24x12 | 650 | 622 | 288 | 0.957 | 0.443 |
| 32x16 | 1122 | 1086 | 512 | 0.968 | 0.456 |

标准 Q4 在 306 DOF 上强加 **286 条**独立的（近）不可压约束，只剩 20 个自由度承载偏量内容——
这就是锁定的定量定义。B-bar 每单元 1 条（128 条），比值稳定在 0.42–0.46。
（`48x24`（2450 DOF）的标准格式约束秩需 `O(n·dof²)` 的 SVD，本报告未算，是证据范围的限制，不是单元的限制。）

| 关键量 | 基准 | 误差 | < 3 %? |
|---|---|---|---|
| B-bar 径向应力 L2，`nu=0.4999`，`16x8`(306 DOF) | 平面应变 Lamé 闭式 | **0.5738 %** | **是** |
| B-bar 位移 L2，`nu=0.4999`，`16x8` | 同上 | **0.1128 %** | **是** |
| B-bar 环向应力 L2，`nu=0.4999`，`16x8` | 同上 | **0.1585 %** | **是** |
| B-bar 内孔径向位移，`nu=0.4999`，`16x8` | 同上 | **0.1128 %** | **是** |
| B-bar 径向应力 L2，`nu=0.4999`，最粗 `8x4`(90 DOF) | 同上 | 2.3043 % | **是**（最粗网格也已过门限） |
| B-bar 应力误差对 `nu` 的平坦度（0.4999 / 0.3） | 自参照 | 1.0024 | **是**（应力场与 `nu` 无关 ⇒ 无锁定偏置） |
| B-bar 观测收敛阶（末两网格） | 理论最优 2 | 1.9998 / 2.0005 | **是** |
| 标准 Q4 径向应力 L2，`nu=0.4999`，`16x8` | Lamé | 155.22 % | **否**（锁定，fail-closed 断言锁死） |
| 标准 Q4 径向应力 L2，`nu=0.4999`，最细 2450 DOF | Lamé | 38.50 % | **否**（加密不足，见 §3.3） |
| `48x24` 网格的标准格式体积约束秩 | — | 未计算（SVD 成本） | 无基准，声明为证据范围限制 |

结论（限定范围）：在平面应变厚壁圆筒内压、Lamé 精确解基准上，**平均膨胀 Q4 消除了标准 Q4 的
体积锁定**：`306` DOF 即达 0.11 % / 0.57 %，误差对 `nu` 平坦（1.0024 倍），收敛阶 2.00。
本报告不宣称标准 Q4 在任何网格上是可用的近不可压格式，也不宣称 B-bar 在**平面应力**路径上更准
（`nu → 1/2` 时平面应力体积模量有限，本就不是锁定问题；该路径仅为完整性而支持）。

## 5 注意点与适用边界

- **应力恢复与刚度一致**：B-bar 用**单元中心**的 `B_bar` 恢复应变（`K` 与应力同源），
  因此单元内膨胀为常数。若改用原标准 `B` 恢复，应力会与所装配的刚度不自洽，读数偏高。
- **B-bar 不是万能提精度**：它只修正体积项。本案例残余 0.57 % 是纯离散（Q4 双线性位移场），
  与 `nu` 无关；要达到更高精度仍需加密或改用 Q8/EAS。
- **平面应变 ≠ 平面应力**：同一网格下 `plane="stress"` 的标准 Q4 在 `nu = 0.4999` 不锁定
  （体积模量有限），把本报告的结论搬到平面应力是错的。
- **只有稠密装配**：`solve_continuum_bbar` 沿用标准路径的稠密 `n_dof²` 装配，2450 DOF 在本机
  （`torch.set_num_threads(8)`）约 2 s 可解；再上量级需先做稀疏装配（该欠账仍开放）。
- **线程数**：默认 128 线程会让这种几千 DOF 的小规模稠密问题因 OpenMP 竞争慢 5 倍以上，
  基准脚本固定 `TENSORFEM_THREADS=8`（可用环境变量覆盖）。
- **网格/载荷复用**：几何、对称约束、一致压力载荷全部取自 `lame_reference`，若该模块改动，
  本报告数值须重跑（证据 JSON 由脚本程序化生成，无手抄数）。

## 6 由此暴露的未完成项（下次自找活的线索）

1. **稀疏装配**：2-D B-bar 与 3-D B-bar 都只有稠密装配；`10^4–10^5` DOF 认证网格需要 `assemble_coo` 路径（3-D 侧欠账见上一份报告第 6 节第 2 条）。
2. **EAS / Q8 对照**：B-bar 是体积项的一阶治理；增强假设应变（EAS）或八节点单元在**偏量**精度上更强，可作为第二对照格式把 0.57 % 再压一个量级。
3. **非均质/塑性路径**：B-bar 在 J2 塑性（`nu → 0.5` 不可压塑性流）下的表现未验证；仓内已有 `solid_plasticity`/平面应力 J2 切线与一致性审计，可接。
