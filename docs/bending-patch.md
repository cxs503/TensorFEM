# CASE-BENDING-PATCH — constant-curvature (bending) patch test, Q4 Mindlin plate

Generated by `benchmarks/verified/fem_bending_patch/run.py`; every number below is

## 1. Problem and reference

* **Criterion** (the reference): a plate patch with free interior nodes, loaded only
  through boundary displacements from a state of **constant curvature**, must
  reproduce the interior displacement, rotations, moments and strain energy exactly.
  Statement: Irons & Ahmad, *Techniques of Finite Elements* (1980), ch. 8; restated
  for plate elements in Zienkiewicz & Taylor, *The Finite Element Method*, Vol. 2,
  §10.4, and applied in Batoz, Bathe & Ho, *Int. J. Numer. Methods Eng.* **15** (1980)
  1771-1812, §4. Continuum (plane-stress) patch tests — including this repository's
  `docs/patch-test-robinson.md` — say nothing about plate **bending** elements, whose
  independent rotation field and transverse-shear energy can lock; that gap is what
  this anchor closes.
* **Target values are analytic**, evaluated from the closed form below rather than
  copied from a table: `M = Db kappa` with `D = E t^3/(12(1-nu^2))`.
  `oracle_selfcheck()` re-verifies the field (zero transverse shear, constant
  curvature, constant moments) before any assembly: shear residual
  1.42e-13, curvature deviation 2.80e-14, moment deviation 3.89e-10 (finite-difference limited).
* **Reference access note (honest)**: the textbooks were not retrievable in this
  sandbox (no outbound network). What is taken from them is the *criterion* and the
  constitutive form; every target number is then derived in code from that form, so
  nothing depends on an unavailable table. The same convention is used in
  `docs/patch-test-robinson.md`.
* **Case-pool tolerance**: `< 2%` (`tensor_case_pool`, anchor `CASE-BENDING-PATCH`);
  the pass/fail (affine) form is graded far tighter, at `1e-12`.

## 2. Method and implementation

| item | value |
|---|---|
| Young's modulus E | 210000 MPa |
| Poisson ratio nu | 0.3 |
| thickness t | 1 mm (patch 1 x 1 in-plane, L/t = 1) |
| curvature states | cylindrical (kx=0.001,ky=0,kxy=0), twist (kx=0,ky=0,kxy=0.001), double (kx=0.001,ky=0.0006,kxy=0.0004) |
| element | `tensorfem.plate.q4_mindlin_stiffness` (production Q4 Mindlin-Reissner, `shear_treatment='sri'` and `'mitc'`) |
| locking control | 2x2 (full) shear integration, `tensorfem.bending_patch.q4_reference_stiffness(shear_treatment='full')` |
| exact field | `tensorfem.bending_patch.CurvatureState.field` |

Each patch is assembled from the production element, the exact field is prescribed
on every boundary node, and the interior DOFs are solved from
`K_ff u_f = -K_fc u_c` (a genuine solve: the answer is nowhere imposed). Moments are
recovered with the same `Bb` operator the element integrates, at the 2x2 Gauss
points, and compared with `Db kappa`.

## 6. Failure modes, limits and artefacts

* **What this proves**: the production Q4 Mindlin element is *consistent* for
  bending — it reproduces a constant-curvature state to round-off on affine patches
  and converges to it on distorted ones — and the element is not silently locking.
* **What this does not prove**: the patch test is a *consistency* (necessary)
  condition. It says nothing about accuracy on coarse meshes, about pointwise moment
  accuracy away from constant states, about `k`-refinement, or about the element's
  rank deficiency — the one-point `sri` element is rank deficient by two, documented
  separately in `docs/element-rank-deficiency-audit.md`; the patch test cannot see
  zero-energy modes because a Dirichlet-driven patch has none.
* **Evidence defect repaired (m15654 F-CRIT)**: the Poisson cross-check used to
  divide the two *closed forms*, whose ratio is `1/(1-nu^2)` by algebra, so the gate
  always read exactly 0. This report now divides the computed tip deflections and
  records the closed-form ratio separately as an identity; the gate value is a
  measurement with a finite, mesh-dependent residual.
* **Known limitation measured here**: on distorted meshes the bilinear `w` of the
  `sri` element cannot represent a quadratic field, so its distorted-patch numbers are
  an interpolation error (measured in section 5 and inside the pool tolerance). The
  `mitc` element is exact to round-off there, so an observed convergence order is
  *not defined* for it; the order gate is applied only to treatments whose error
  exceeds the declared round-off floor, and that rule is reported, not silent.
* **Model-comparison gate**: `strip_free_w` compares the FE strip with the 1-D beam
  closed form. Section 5.1 shows the residual does not vanish under through-width
  refinement, so it is a comparison of two models (Mindlin plate with free edges vs
  Euler-Bernoulli beam rigidity), not a pure convergence claim; its 2% margin is the
  thinnest in this anchor and is reported as such rather than tightened.
