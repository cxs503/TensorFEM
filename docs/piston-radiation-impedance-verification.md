# Finite-`ka` baffled-panel radiation impedance: verification against Rayleigh's piston closed form

Status: **verification debt closed** for the radiation-damping / finite-frequency branch that
`docs/marine-wet-panel-added-mass-verification.md` §5 explicitly left open
("in-phase limit only … no added damping"). Library: `TensorFEM`.
Module: `tensorfem.hydro_radiation`. Benchmark:
`benchmarks/piston_radiation_impedance.py` →
`artifacts/piston_radiation_impedance/validation_report.json`
(committed copy: `docs/assets/piston-radiation-impedance/validation_report.json`).

## 1. Why this case

The in-phase (Rayleigh) operator of `tensorfem.hydro_added_mass` is a `k -> 0`
model: it gives the added mass of a wetted panel but has no radiation
*damping* (resistance) and no finite-frequency acoustics. For a ship side-shell
strake this matters twice over: (i) wet panel modes are the input of the
comfort/fatigue vibration screen, where the damping — not just the frequency —
sets the response level; (ii) as soon as the panel radiates at `ka ~ 1`
(`a` = panel scale, `k = w / c`), the stored hydrodynamic mass itself collapses,
so an in-phase coefficient used above `ka ~ 1` is simply the wrong number.

Both effects live in one object, the **surface radiation impedance**

```
Z = j w rho  int_S int_S u(x) G(x-y) u(y) dy dx / u^2,
G = exp(-j k r) / (2 pi r),
```

which the repository could not compute. It can now, and it is verified against
the one case with a closed-form answer at **all** `ka`: the circular piston in
an infinite rigid baffle.

## 2. Method

### 2.1 Operator (`tensorfem.hydro_radiation`)

| quantity | expression | implementation |
|---|---|---|
| off-diagonal patch | `rho A_i A_j exp(-j k r_ij)/(2 pi r_ij)` | row-blocked `exp`/`sin`, `O(N)` memory |
| diagonal patch (exact) | `rho A_i (1 - exp(-j k a_i))/(j k)`, `a_i = sqrt(A_i/pi)` | integrable `1/r` singularity integrated over the equal-area disc |
| piston/surface impedance | `Z = j w sum_ij M_ij` | `planar_radiation_impedance` |
| modal impedance | `Z = j w sum_ij phi_i A_i phi_j A_j G_ij` | `modal_radiation_impedance` |
| in-phase added mass | `Re(Z/(j w))` | `effective_added_mass` |
| exact reference | `rho c pi a^2 [R1(2ka) + j X1(2ka)]`, `R1 = 1 - 2J1(x)/x`, `X1 = 2H1(x)/x` | `piston_impedance_exact` |

`J1` and the Struve function `H1` are implemented as power series inside the
module so the package keeps its pure-`torch` dependency set; both are
cross-checked against `scipy.special` to `1e-12` in the test suite. The
leading Struve term `H1 ~ 2z^2/(3 pi)` is exactly what turns `X1` into
`4x/(3 pi)` and therefore `Im(Z)/w -> (8/3) rho a^3` — i.e. the new branch is
anchored on the *same* Rayleigh mass the in-phase module already uses.

### 2.2 Case and anchors

Piston: `a = 0.5 m`, sea water `rho = 1025 kg/m^3`, `c = 1500 m/s`, disc
discretised on a Cartesian staircase (`hydro_added_mass.disc_panels`), so the
residual error is pure geometry, `O(h)`.

| # | Reference | Gate |
|---|---|---|
| A1 | Ray-leigh piston impedance `rho c pi a^2 [R1 + j X1]` | both `Re Z` and `Im Z` < 3 % (64 panels/side for `ka <= 2`, 96 for `ka = 3`) |
| A2 | `k -> 0` collapse onto `hydro_added_mass.dipole_added_mass_matrix` | element-wise deviation < `1e-5`; added mass `(8/3)rho a^3` < 3 % |
| A3 | Modal impedance of the wet strake vs `hydro_added_mass.panel_added_mass_ratio` (independent code path) | < 3 % |
| A4 | (informative) finite-`ka` added-mass collapse | no gate |

Structural case (A3) is the same 1.2 m x 0.8 m x 8 mm steel strake as the
in-phase benchmark, mode (1,1) simply supported, driven at its *wet* frequency
16.25 Hz.

not just for frequencies.

### 3.5 A4 — why an in-phase coefficient cannot be used above `ka ~ 1`

Column `M_eff/M_0` in table 3.1: the finite-frequency added mass keeps 100 % of
the Rayleigh value at `ka = 0.1`, 76 % at `ka = 1`, 31 % at `ka = 2` and 6 % at
`ka = 3` (the reactance zero near `ka = 2.57`). The same collapse is what the
reactance curve of figure 1 shows over the whole range.

## 5. Caveats / scope

* **Constant density, no free surface, no mean flow.** `G = exp(-j k r)/(2 pi r)`
  is the free-space Green function in a rigid infinite baffle. Bubble
  attenuation, the free surface (image source) and boundary-layer/mean-flow
  effects are outside this operator.
* **Panel quadrature.** Flat Cartesian panels with the exact self-patch value and
  midpoint phase; the error is `O(h)` (measured), so 64 panels/side buys < 1 %.
  A boundary-fitted mesh would converge faster but the staircase bias is what
  dominates at 16-32 panels/side.
* **Struve/J1 series range.** The power series are usable to `|z| <= 12`
  (`ka <= 6` at the piston); beyond that the reference implementation raises
  instead of silently returning a wrong number. Ship panel acoustics stay far
  below that.
* **Modal impedance assumes the mode is known.** `modal_radiation_impedance`
  only integrates a *prescribed* velocity shape; it does not solve the coupled
  fluid-structure eigenproblem, so the damping ratio above uses the in-phase wet
  frequency and mass (a first-order, light-damping perturbation: `zeta ~ 0.7 %`
  is consistent with that assumption).
* **One-sided wetting**, in-phase-only geometry of the structural part; two-sided
  wetting doubles the impedance.
* **Bug found and fixed by this work.** The first version of
  `modal_radiation_impedance` dropped the `rho` factor on the self-patch term;
  the A3 cross-check against `phi^T M_in_phase phi` caught it (2.85 %
  discrepancy, now `5e-12 %`). The regression test
  `test_modal_low_frequency_reactance_reproduces_in_phase_added_mass` pins it.
