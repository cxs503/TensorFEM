# 近不可压锁定验证：B-bar HEX8 与精确 Lamé 球壳场对照

本报告补的是**验证欠账**，不是新求解器。已合并的 B-bar HEX8
（`src/tensorfem/solid3d_bbar.py`）此前的唯一锁定证据是
`near_incompressible_cantilever()`（`tests/test_solid3d_bbar.py`）：在
`nu = 0.4999` 下把有限元挠度与 Euler–Bernoulli 悬臂梁公式比。该判据有三个结构性缺陷：

1. 参考量是**细长梁公式**，而 `nu -> 1/2` 时悬臂柔度由剪切/三维效应主导，梁公式本身不是该极限下的真值；
2. 只覆盖**一个** Poisson 比，没有锁定起始（onset）曲线；
3. 没有体积/偏量分解，**无法把"锁定"与"网格粗"区分开**。

因此本报告改用**静水压力下厚壁球壳的三维 Lamé 精确解**打分。选它的理由是决定性的：
该应力场 `sigma_r = A - B/r^3`、`sigma_theta = A + B/(2r^3)`、`A,B` 只含几何与压力，
**与 Poisson 比无关**；而位移场含 `(1-2nu)`、`(1+nu)`，与 `nu` 有关且有闭式。
于是"锁定"这一体积过刚偏差，会直接表现为**应力误差随 `nu` 变化**；无锁定的格式该误差对 `nu` 平坦。

## 1 案例与离散

| 项 | 取值 |
|---|---|
| 几何 | 厚壁球壳，内半径 `a = 8 m`、外半径 `b = 10 m`（`a/b = 0.8`，厚壁） |
| 材料 | `E = 210 GPa` |
| 载荷 | 内表面均布压力 `p = 1 MPa`，外表面自由 |
| 参考解 | 三维 Lamé 闭式（球对称），应力与 `nu` 无关 |
| 网格 | 立方球面 `6x6x6` 面元 × 3 层径向 = 648 HEX8，2616 DOF（细化研究另取 4×2、8×4） |
| 边界 | 六个切向测量约束（去刚体），**不施加任何解析位移**，径向膨胀自由 |
| 载荷一致性 | 复用已验证算例 `sphere_pressure_benchmark` 的一致节点压力与量测约束，不新开载荷路径 |
| 对比格式 | 标准位移 HEX8（全积分，`solve_solid`） vs B-bar HEX8（`solve_solid_bbar`） |

## 2 方法

`src/tensorfem/incompressible_locking.py`：

- `lame_sphere_field`：三维 Lamé 场（位移向量、径向/环向应力）；
- `reference_self_check`：先用三条**独立解析残差**验参考解本身——逐点平衡
  `dsigma_r/dr + 2(sigma_r-sigma_theta)/r`、两侧面力 `sigma_r(a) = -p, sigma_r(b) = 0`、
  各向同性本构（`du/dr` 与 `u/r` 对照 `epsilon_r, epsilon_theta`），并核验应力场对 `nu` 的不变性；
- `solve_case`：给定 `nu` 与格式求解并打分（位移 L2/逐点最大、径向应力 L2/逐点最大、
  平均应力 L2、偏量应力 L2、内表面径向位移相对误差），应力在**单元中心**恢复、按单元体积加权；
- `locking_sweep` / `plane_strain_sweep`：3D 扫描与 2D 平面应变 Q4 扫描（后者记录尚未治理的欠账）。

复现：

```bash
PYTHONPATH=src python3 benchmarks/near_incompressible_locking.py
PYTHONPATH=src pytest tests/test_incompressible_locking.py -q
```

## 4 误差判定（逐项回答是否 < 3 %）

| 关键量 | 基准 | 误差 | < 3 %? |
|---|---|---|---|
| B-bar 位移 L2，`nu=0.4999`，648 HEX8 | 三维 Lamé 闭式 | 3.365 % | **否**（1.8 % 超标，粗网格） |
| B-bar 位移 L2，`nu=0.4999`，1536 HEX8 | 三维 Lamé 闭式 | 2.060 % | **是** |
| B-bar 径向应力 L2，`nu=0.4999`，1536 HEX8 | 三维 Lamé 闭式 | 9.657 % | **否**（按观测阶 1.83 外推需约 3 倍加密才降至 3 %，未做） |
| B-bar 移位 L2 对 `nu` 的平坦度（0.3 → 0.4999） | 自参照 | 2.806 % → 3.365 %（+20 %） | 位移含 `(1-2nu)` 项，随 `nu` 变化属物理，非锁定 |
| B-bar 径向应力 L2 对 `nu` 的平坦度 | 自参照 | 16.329 % → 16.327 %（变化 0.01 %） | **是**（应力场本与 `nu` 无关，误差不变 = 无锁定偏置） |
| 标准 HEX8 位移 L2，`nu=0.4999` | 三维 Lamé 闭式 | 87.74 % | **否**（锁定，且加密不收敛） |
| 标准 HEX8 径向应力 L2，`nu=0.4999` | 三维 Lamé 闭式 | 379.1 % | **否** |
| 2D Q4 平面应变径向应力 L2，`nu=0.4999` | 平面应变 Lamé | 155.2 % | **否**（未治理欠账） |

结论（限定范围）：B-bar HEX8 **在这套精确 Lamé 基准上锁定被治愈**——应力误差对 `nu` 完全不敏感
（16.329 % vs 16.327 %），残余误差是**纯离散误差**，在 `nu = 0.3`（无锁定）时数值相同并随 `h` 收敛（阶约 1.8）。
本报告**不**宣称 B-bar 在 `nu = 0.4999` 下所有量已达 3 %：径向应力在 1536 单元仍有 9.66 %，
需更细网格或应力恢复（外推/超收敛点）才可能达标。

## 5 注意点与适用边界

- 残余 16.3 % 是**径向应力在同半径单元间的振荡**：B-bar 只修正体积项，径向应力 `A - B/r^3` 由
  各向同性关系从位移差分得到，粗网格上界面处天然有跳变；因此它是 `O(h)` 量，不是格式缺陷。
- 平均应力（体积项）误差最能反映锁定：标准 HEX8 从 1.85 % 涨到 68.16 %（37 倍），
  B-bar 从 1.97 % 仅到 2.51 %（1.28 倍）。但**偏量误差也会涨**（标准 HEX8 从 6.23 % 到 88.3 %）——
  锁定破坏的是整个位移场，偏量误差不是"锁定无关"的干净指标；本报告的判据只用应力场对 `nu` 的不变性。
- 标准 HEX8 的失败已用 fail-closed 测试锁死（`> 50 %` 位移误差、`> 10 倍` 于 B-bar），
  任何人不得把它算作通过。
- 几何、载荷、约束复用 `sphere_pressure_benchmark`，若该模块的一致压力构造改动，
  本报告数值须重跑；`benchmarks/near_incompressible_locking_evidence.json` 存全部标量。
- 8×4 网格用稠密求解（5790 DOF）；再往上一档需稀疏 B-bar 装配，仓内尚无。
