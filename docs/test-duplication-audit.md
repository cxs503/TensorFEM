## Consolidation applied to the Cook-membrane family (m4718)

Two changes, both machine-tabulated from the git diff:

1. **Shared session cache.** Eleven inline `reference.solve_q8(...)` / `cook_fields(...)` call sites in
   the four `test_cook_*.py` modules now go through the session-scoped `cook_q8` / `cook_case`
   fixtures in `tests/conftest.py`, so each discretisation is solved once per session
   (11 call sites -> 3 distinct solves for `solve_q8`, 6 -> 3 for `cook_fields`).

   test_cross_check_of_pointwise_recovery_passes` evaluated the *same*
   `cross_check_pointwise_recovery(cook_fields(8))` result as
   `test_cook_oracle_operator.py::test_pointwise_recovery_reproduces_the_stored_q4_centre_stress`
   and asserted a strict subset of it; it was absorbed into that test.
