证据：`benchmarks/kirsch_biaxial_reference.json`（程序化生成，零手抄）、

本单清偿 `docs/kirsch-hole-stress-concentration.md` §5 与
`docs/elliptic-hole-inglis-validation.md` 范围声明里挂着的「双轴/剪切远场未覆盖」一项：
此前的开孔应力集中基准只有**单轴**远场（`K_t = 3`），而船体板（舷侧板、甲板、舱口围板）
实际处于**双轴**面内应力状态，`K_t` 不是一个常数，而是双轴比的函数。

## 1. 案例介绍（物理背景与参数）

无限大板，中心圆孔半径 `a`，孔边自由。远场为**主应力轴对齐的双轴拉伸**：

```
sigma_xx = T,   sigma_yy = l*T,   sigma_xy = 0      (l = 双轴比, l = sigma_yy/sigma_xx)
```

`l = 0` 即经典 Kirsch 单轴；`l = 1` 等双轴；`l = -1` 是主应力轴旋转 45° 的**纯剪切**状态
（`tau = T`，principal `+T`/`-T`）。

| 参数 | 取值 |
|---|---|
| 孔半径 `a` | 1.0 |
| 外边界 `b` | 10 a |
| 远场 `T` | 1.0（`sigma_yy = l`） |
| `E` / `nu` | 1.0 / 0.3（平面应力，`t = 1`；另验证平面应变等效常量路径） |
| 模型 | 四分之一环 `0 ≤ θ ≤ π/2`，Q4 渐变极坐标网格，`grading = 5` |
| 边界 | θ=0：`u_y = 0`；θ=π/2：`u_x = 0`（双轴对称）；r=a：自由；r=b：**精确**双轴面力 |
| 网格 | `n_θ = n_r ∈ {16, 24, 32, 48}`，`l ∈ {-1, 0, 0.25, 0.5, 1, 2}` |

**为什么四分之一模型对任意 `l` 都合法**：主轴对齐的双轴远场对 `x→-x` 与 `y→-y` 两次镜面反射
都保持不变（`sigma_xy = 0`），所以解满足两条对称线上的法向位移为零；这与 `l` 的符号无关，
`l = -1`（纯剪）也成立。

## 2. 怎么做的（方法与工具链）

1. **解析基准的推广**（`src/tensorfem/kirsch_hole.py`，新增 `lateral_ratio`，默认 0 完全向后兼容）：
   远场分解为各向同性部分 `T(1+l)/2` 与偏斜幅度 `T(1-l)/2` 的单轴场：
   ```
   sigma_rr = T/2(1+l)(1-a²/r²)   + T/2(1-l)(1-4a²/r²+3a⁴/r⁴) cos2θ
   sigma_tt = T/2(1+l)(1+a²/r²)   - T/2(1-l)(1+3a⁴/r⁴) cos2θ
   sigma_rt = -T/2(1-l)(1+2a²/r²-3a⁴/r⁴) sin2θ
   ```
   孔边 `sigma_tt(a,θ) = T[(1+l) - 2(1-l)cos2θ]`，即 `K_t(θ)` 解析可得。
   位移场取 **单轴闭式解 + 其 90° 旋转**（同一规范/同一支解），因此仍满足两条对称线条件。
2. **先证明基准本身没错**（程序化，见 `reference_checks`）：
   - 孔边自由：`|sigma_rr(a,θ)|`、`|sigma_rt(a,θ)|` 全部 **0.0**（6 个 `l` 全通过）；
   - 径向平衡（中心差分）残差 ≤ **9.5e-11**；
   - 位移数值微分 → 平面应力本构 → 复算应力，相对残差 ≤ **8.2e-10**；
   - 叠加构造与独立单轴对象（旋转 90°）对比 **≤ 8.0e-16**；
   - 孔边恒等式 `T[(1+l)-2(1-l)cos2θ]` 偏差 **0.0**；`l=1` 时孔边恒为 `2T`（偏差 0.0）且 `u_θ/Ta·E ≤ 8.9e-16`（纯径向）。
3. **生产路径原样调用**：`annulus_model()` → `tensorfem.continuum.ContinuumModel`（`plane='stress'`,
   `element_type='q4'`，双精度）+ `solve_continuum`（整刚稠密求解），未修改生产代码；外弧载荷由
   `consistent_arc_loads` 用与离散边界一致的弦上 Gauss 积分生成（因此载荷合力有 `O(Δθ²)` 的
   弦-弧差，`n=48` 时 3e-4，`n=16` 时 1.8e-3，已单列而不被吞掉）。
4. **点式应力恢复独立性**：模块自带 Q4 `B` 矩阵在固定物理点取样，并与生产存盘的单元中心应力
   交叉校验（`n=48` 最大 1.9e-13），保证比较口径不是自证。
5. 复现：`OMP_NUM_THREADS=1 PYTHONPATH=src python scripts/audit_kirsch_biaxial.py`
   → `benchmarks/kirsch_biaxial_reference.json` + 4 张 PNG（约 85 s，单核）。

工程结论：**`K_t` 不是常数**。相对较大主应力，`K_t = 3 - min(|l|,1/|l|)` 形态：

`l = 2` 时峰值挪到 `θ = 0`（较大主应力方向的孔边），若沿用单轴 `K_t = 3` 会**低估 40%**。

## 5. 注意点 / 局限

- **对称模型的适用范围**：主轴对齐的双轴远场可用四分之一模型；若远场含显式剪应力
  `sigma_xy ≠ 0`（主轴不在坐标轴上），需要把网格旋转到主轴或改用半/全域模型，本单未做，
  但解析场（`stress_polar`/`stress_cartesian`/`traction_on_arc`/`displacement_*`）对一般
  双轴主应力已经成立，可作为后续 FE 案件的边界数据。
- **孔边是多边形**：节点精确落在 `r = a`，单元边为弦，矢高 `O((π/2n)²)`；孔边 `K_t` 采用
  相邻单元节点值平均（后处理口径），点式误差只用单元内部采样点，二者分开列。
- **只覆盖平面应力 Q4 + 平面应变位移基准**，不涉及壳体、正交异性、塑性、接触、有限宽修正
  （有限宽见 `docs/finite-width-hole-howland.md`）。
- `l = 1` 时孔边应力场与 `θ` 无关，峰值位置无定义，报告中以 `theta_degrees = 0, uniform = True` 标注。
- `K_t` 的定义随双轴比而变，引用时必须写清「相对哪个主应力」；本文所有 `K_t` 均相对 `T = sigma_xx`。
  相对较大主应力换算：`K_t^rel = K_t^T / max(1, l)`。
