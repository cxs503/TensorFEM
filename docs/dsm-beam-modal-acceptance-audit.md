## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理背景**：Timoshenko 梁同时含剪切变形与转动惯量，波长越短（阶越高）两者越不可忽略。
位移型有限元对一个**等截面**构件的频率误差 = 插值误差（随加密下降）+ 求根误差（收敛后不下降）；
而等截面构件的方程有闭式通解，取出的精确动刚度矩阵使自然频率就是 `det K(ω)=0` 的根，
插值误差**结构性消失**。这正是"能给任意阶（≥3 节点）可信频率"的前提，也是 whipping/springing
共振裕度判级需要的高阶锚点。

| 算例 | 用途 | 几何 / 参数 |
|---|---|---|
| **A** 深梁 | (c)(d) 主力对拍 | 矩形 0.2×0.4 m、L=10 m（L/h=25）、E=2.06e11 Pa、ν=0.3、ρ=7850 kg/m³、κ=5/6 |
| **A′** 细长梁 | (a) Euler-Bernoulli 极限 | 0.001×0.001 m、L=10 m（L/h=10⁴，I/(A L²)=8.3e-10） |
| **C** 深梁 | (b) 剪切敏感的闭式对拍 | 0.4×1.0 m、L=5 m（L/h=5），简支；剪切使 1–5 阶相对 EB 降低 **6.03/18.52/30.81/40.94/48.96 %** |
| **B** 船体梁（m6117） | (e) 债务清算 | L=230 m、I=394.453 m⁴、有效剪切面积 A_s=1.52 m²、EI=8.12572e13 N·m²、κGA=1.00359e11 N、干质量 2.31873e5 kg/m、附加质量系数 C_W=0.5 |

> 算例 A′ 的选择本身是一个物理发现（§5.1）：m7170 用的 L/h=2000 细长梁在 3 阶仍有 **5.16e-06** 的
> Timoshenko 剪切余项——大于本节点 1e-6 的判据线，那是物理不是实现。判定 (a) 必须用 L/h≥5000
> （本单取 1e4，余项 2.07e-07）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 精确动刚度单元（`dsbeam.py`，m7170 已落地，本单只做审计）
无量纲 ξ=x/l、S=ρAω²l⁴/EI、R=I/(Al²)、γ²=κGAl²/EI、B=S/γ²，消元得
`λ⁴ + S(1/γ²+R)λ² + S(SR/γ²−1) = 0`；四个根实或纯虚，取复指数基（避免第二谱分支切换），
精确能量泛函在四个精确解张成空间上的 Gram 矩阵给出 `K(ω)=H⁻ᵀQH⁻¹`（4×4，节点自由度 w₁ψ₁w₂ψ₂），
双曲对按 1/cosh(u/2) 归一（超 15 阶不失精度）。**1 单元即精确**，装配多单元不改答案（§3.2）。

### 2.2 Wittrick-Williams 计数 + 二分/割线求根
`J(ω) = n·J₀(ω) + s{K(ω)} − 刚体数 − 谱阈值伪零`，其中 J₀ 是单元固端频率（元素动刚度的极点）。
求根全程用 `J` 的阶梯做括号（不可能跳到别的根），括号内用 **纯 Python 的 Brent** 精化，
接受前再用 J(ω∓) 复核（`J` 必须从 k−1 降到 k），失败即抛错而不是返回可疑值。

### 2.3 三个**互相独立**的对拍面
1. **闭式**：简支 Hu–Timoshenko 二次式；Euler-Bernoulli 超越根 (βL)²=22.3733/61.6728/120.9034。
2. **有限元加密 + Richardson**：本审计内自带两场（w,ψ）一致 Timoshenko 单元（Arnold–Falk 一点减缩
   积分防剪切锁死，一致质量含转动惯量），20/40/80/160 单元三点 Richardson 外推，观测阶 ≈2.00。
3. **独立根普查**：**不用 WW 机器**，直接对 `det K_red(ω)` 做稠密符号扫描 + 二分；每个括号用
   `|det|` 在该括号内**最小值**处的大小分类（零点使 |det| 塌陷、极点使 |det| 爆掉），因此能把
   *极点*（单元固端频率）与*零点*（真实自然频率）分开。

### 2.4 本单在 `dsbeam.py` 上的三处改动（全部先证缺陷、后修、有回退对照）
| # | 缺陷 | 证据（修前） | 修复 |
|---|---|---|---|
| 1 | **criterion (g) 被违反**：`_frequencies_below` 里 `from scipy.optimize import brentq` | 节点判据要求"只依赖 numpy.linalg 与 math"；scipy 被禁即 ImportError | 新写 `_brent_solve`（Brent–Dekker，纯 Python，括号内永不出界），删除 scipy 分支；36 条测试全绿，scipy 禁用下重算差 **0.0** |
| 2 | **WW 计数在极低频为负**：`signature_count` 的容差 `1e-12·‖K‖` 远大于 `eigvalsh` 的向后误差，恰好吞掉 ω²M 量级的两个刚体特征值 | `J(1e-6·f₁) = **−2**`（计数不可能为负） | 容差改为 `64·eps·‖K‖`（eigvalsh 向后误差界）；`_elastic_count` 末 `max(count, 0)`（J≥0 是定义，负数只能是刚体对被舍入吃掉）；新增 `_count_floor` 在 ω 低到基函数失去相对精度时直接返回 0（此时精确计数必为 0） |
| 3 | **元素极点处静默给错计数**：ω 落在单元固端频率上时 H 奇异、`K=H⁻ᵀQH⁻¹` 有极点，惯性无意义 | `J(pole)` 返回 0 而真值 1（静默错）；极点由稠密扫描定位精度 ~1e-6 相对 | 检测 ω 与任一 `J₀` 相对距离 ≤1e-5 时抛 `ValueError`（明确拒绝而不是给数）；`J₀` 扫描上限放宽 0.1 % 以看见略高于 ω 的极点 |
| + | **新能力**：两场模态振型 | `mode_shape` 只给 w，无法做 whipping/springing 的曲率/应力恢复，也无法核模态质量正交性 | 新增 `BeamModeShape` + `mode_shape_full`（返回 x, w, ψ, w′, ψ′，含 `mass_inner`/`strain_energy`/`rayleigh_quotient`） |

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 判据线本身可能因**物理**而非实现而失败
m7170 用 L/h=2000 作 Euler-Bernoulli 极限，3 阶仍有 5.16e-06 的 Timoshenko 剪切余项（∝(βL)²EI/(κGAL²)），
大于本节点 1e-6 判据。把判据当"实现精度"用之前必须先确认测试算例已在渐近区（本单 L/h=1e4 → 2.07e-07，
其中 ~2e-07 已是双精度 round-off 地板）。

### 5.2 动刚度矩阵**同时有零点和极点**，稠密扫描必须分类
`K = H⁻ᵀQH⁻¹` 在单元固端频率处有极点（H 奇异），极点同样让 `det K` 变号。朴素"变号=根"的扫描会
把极点当根（本审计在 100 组随机样本里遇到 6 例：极点处 |det| 只比邻点大 1 个量级，阈值 1.0 的自然对数
判据失效）。改用"括号内 |det| 的最小值 + 塌陷量"分类后全部正确。**这是本次审计最贵的一课**。

### 5.3 惯性（惯性指数）的容差不能拍脑袋
`1e-12·‖K‖` 是个常见但不安全的惯性容差：自由-自由 DSM 的两个刚体特征值量级是 ω²M，在
ω=1e-6·f₁ 时比 ‖K‖ 低 13 个数量级，被容差吞掉后 `J` 直接给 **−2**。正确做法是用 `eigvalsh` 的
向后误差界（~n·eps·‖K‖）作容差，并在定义层面保证 J≥0。

### 5.4 m6117 的转动惯量口径是**证据缺口**（WITHHELD），不是可以猜的参数
船体梁 ρI = (m/A)·I，而 m6117 记录只给了干质量 m、有效剪切面积 A_s=1.52 m² 与 I=394.453 m⁴，
**没有给截面面积 A**。把 1.52 m² 当 A（ρ=152548 kg/m³ 非物理）得 f₁=1.0651 Hz；按钢密度反推
A=29.538 m² 得 1.1505 Hz；ρI→0 得 1.1556 Hz。**三者在 8.5 % 带宽内**，故 ρI 一项判 WITHHELD，
不写成结论。这也解释了为什么"精确真值"必须先声明截面口径。

### 5.5 与前序单 m7170 的**数字冲突**（honest finding，不改写历史）
`docs/timoshenko-dsm-exact.md` 报"精确 DSM（ρI=0）= 1.22783 Hz、含 ρI = 1.19143 Hz、裁判 128 单元
= 1.19148 Hz"。本审计用同一组 EI/κGA/m 参数**无法复现**这两个数：ρI→0 的精确解上界是
**1.15557 Hz**（剪切只降不升，1.22783 与 1.19143 都要求更小的剪切柔度）；本审计的独立裁判
（两场一致 FEM 128 单元）得 1.15061 Hz，与自身 DSM 差 7.8e-04。因此 1.19/1.23 Hz 很可能来自
不同的 κGA 或不同的截面口径（记录未写）。**以本审计的可复现数字为准，m7170 的船体梁频率数字
应视为不可复现（WITHHELD），但其定性结论（"6.28 % 不是离散误差、闭式锚点过修正"）与本审计一致。**

### 5.6 适用范围
* 等截面、无轴力、无阻尼、平面内弯曲；变截面需装配（多单元）或改用 Riccati/传递矩阵。
* 第二谱（ω>√(κGA/ρI)）处基函数退化：模块在该阈值抛错，需移位求值；本审计的所有判据带都在阈值以下
  （脚本显式断言）。
* 计数/求根在 ω 落在单元极点 1e-5 相对邻域内时抛 `ValueError`（明确拒绝而非静默错）。
* 单元"固端频率"由稠密扫描 + 双重网格互验得到，定位精度约 1e-6 相对（极点附近 det 发散，扫描最不锐）。

## 6. 误差判定（逐项 vs 基准，显式回答"是否 <3%"）

| 关键量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| 自由-自由前 3 阶 (βL)²（L/h=1e4） | Euler-Bernoulli 常数 22.3733/61.6728/120.9034 | 2.07e-07 / 4.88e-09 / 1.50e-07 | 是（<0.0001 %） |
| 简支前 5 阶 ω（L/h=5，含剪切） | Hu–Timoshenko 闭式 | 最大 2.99e-13 | 是 |
| 自由-自由第 3/4/5 阶 ω（L/h=25） | FEM n=160 + Richardson | 1.37e-06 / 4.81e-06 / 1.17e-05 | 是 |
| J(ω) 计数（0–10 f₁，40 采样） | 独立 det K 根普查 | 0 点不一致 | 是（离散计数，0/0） |
| 100 组随机样本前 5 阶 ω | 简支闭式 | 最差 4.63e-13 | 是 |
| 100 组随机样本根数 | 闭式解析根数 | 0 漏 / 0 伪 | 是 |
| m6117 交付频率（ρI=0 口径） | 精确 DSM(ρI=0) | +0.0274 / +0.1406 / +0.3592 / +0.6677 %（1–4 阶） | 是 |
| m6117 交付频率（物理 ρI 口径） | 精确 DSM(物理 ρI, A=29.538 m²) | +0.47/0.70/0.88/1.13 %（1–4 阶） | 是 |
| m6117 闭式锚点 | 精确 DSM(ρI=0) | **−5.89 %** | **否（>3 %）**——这就是债务本体 |
| m6117 闭式锚点 | 精确 DSM(物理 ρI) | **−5.47 %** | **否（>3 %）** |
| 6.28 % 复现值 | m6117 报告的 6.28 % | 0.0027 个百分点 | 是 |
| 裁判 FEM 128 单元 vs DSM | 精确 DSM | 7.84e-04（物理口径）/ 7.89e-04（ρI=0） | 是 |

**结论**：DSM 自身对三个独立基准的误差全部 ≪3 %（实测 1e-13…1e-5 量级）；m6117 的**锚点**
相对精确解偏低 5.5–5.9 %，**超出 3 %**，且 m6117 的 6.28 % 恰好是"FEM(+0.03 %) − 锚点(−5.89 %)"
的差——债务的归属因此明确落在闭式近似上，而不是有限元或网格。
