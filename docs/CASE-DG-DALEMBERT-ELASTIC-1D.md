# CASE-DG-DALEMBERT-ELASTIC-1D — 一维弹性杆波传播 vs d'Alembert 精确解

锚点：`CASE-DG-DALEMBERT-ELASTIC-1D`（验收：应力波剖面 `sigma(x,t)` 与 d'Alembert 双行波解析解
误差 < 2 %；度量 = 无物理弥散）。参考文献：Graff, *Wave Motion in Elastic Solids* (1975) 一维杆极限。
实现仓：TensorFEM（2 节点线性杆单元 + 一致质量 + 中心差分显式积分）；
DG 侧算例池条目保持独立，本文件是该锚在 FEM 侧的实质增量与证据。

## ① 案例介绍

一维线弹性杆轴向运动满足波动方程 `u_tt = c^2 u_xx`，`c = sqrt(E/rho)`。杆在 t=0 静止、
给定局部速度脉冲 `v0(x) = A exp(-((x-x0)/w)^2)`，其**精确**解（d'Alembert 双行波）为

    u(x,t) = 1/(2c) * ∫_{x-ct}^{x+ct} ṽ0(s) ds ,   σ = E u_x = (ρc/2)[ṽ0(x+ct) - ṽ0(x-ct)]

其中 `ṽ0` 是 `v0` 按边界条件的周期镜像延拓：自由端（u_x = 0）取偶延拓，固支端（u = 0）取奇延拓
（method of images，反射被精确包含，**参考解不消耗任何有限元解**）。

一维杆**无物理弥散**：应力剖面是两个以 `c` 刚性平移的脉冲之和，形状不变（本文件的
`translation_error = 1.56e-15` 把它量化到机器精度）。因此 FE 解对剖面的任何偏差都是
**离散算子的数值弥散**，这正是本算例度量的对象。

| 参数 | 值 |
|---|---|
| 弹性模量 E | 2.100e+11 Pa（钢） |
| 密度 ρ | 7850 kg/m³ |
| 杆波速 c = sqrt(E/ρ) | 5172.19 m/s |
| 杆长 L | 16.0 m |
| 截面积 A | 1.0 m²（只定力量级，不影响 c） |
| 脉冲幅值 / 中心 / 半宽 | 1.0 m/s / 5.0 m / 0.50 m |
| 采样时刻 t* | 1.50 ms（c·t* = 7.76 m，左行波已反射） |

## ② 方法

1. `src/tensorfem/rod_wave_dalembert.py`：2 节点线性杆单元 `K_e = EA/L[[1,-1],[-1,1]]`、
   `M_e = ρAL/6[[2,1],[1,2]]`（一致质量），三对角装配后用带状直接解每步求解
   `M(u_{n+1} - 2u_n + u_{n-1}) = -dt² K u_n`。
2. 时间步不是取解析估计而是取**装配后** (K, M) 铅笔的最大特征频率（对 `M^-1K` 做幂迭代 +
   带状解，避开本机 OpenBLAS 上 `scipy.linalg.eigh` 广义问题段错误），`dt = 0.5·2/ω_max`，越界即 raise。
3. 固支端把端节点自由度**消去**（缩聚到内部自由度）再积分，不是解完自由系统后清零（见 ⑤ 坑 2）。
4. 应力取单元应变 `(u_{i+1}-u_i)/h` 与 d'Alembert 解在**同一单元中点**比较；
   指标：相对 L2（全杆）、相对 Linf（以精确峰值归一）、前导脉冲幅值比、峰位偏移（用抛物线亚网格细化）、
   反射瓣符号、机械能漂移。
5. 数值弥散用两条独立路径交叉验证：闭式离散弥散关系
   `ω² = (6c²/h²)(1-cosθ)/(2+cosθ)` vs 时域单模态频率测量（振型 `sin(mπx/L)` 的探针过零计数）。

## ⑤ 注意点（本单踩到的坑）

1. **快照/探针状态一步偏移**：初版在推进后记录，把 `u_{n+1}` 记到 `t_n` 名下，引入 O(dt) 的伪误差，
   使收敛阶看起来只有 ~1.1 阶；修正索引后 L2 误差恢复严格 ∝h²（1.98/2.00/2.00）。
   教训：收敛阶标定是发现"时间轴对齐 bug"的最灵敏探针。
2. **固支端不能"解完再清零"**：对自由装配系统求解后把端节点位移置零，会破坏端节点相邻行的
   （质量耦合）平衡，产生边界层伪解（首内点位移偏差 33 %，阶数掉到 ~1）。正确做法是**消去**端自由度
   （缩聚求解），修正后单模态位移误差 4.97e-7 → 1.24e-7 → 3.10e-8（二阶），能量漂移同步降 4×。
3. **镜像延拓只对局部化脉冲收敛**：`exact_rod_state(length=...)` 的镜像求和依赖脉冲衰减；若用
   `sin(πx/L)` 这类非衰减剖面求和截断会给出 ~13 倍偏差（发散级数）。该路径只用于局部脉冲；
   局部脉冲下与模态解析解一致到机器精度。
4. **数值弥散符号**：一致质量 `c_num/c = 1 + θ²/24`（比 c 快、到达偏早），集中质量
   `c_num/c = 1 − θ²/24`（偏慢）；二者一阶系数同量级反号，故"用集中质量更省更准"在本算例不成立。
5. 中心差分的时间离散误差与空间弥散误差符号相反、部分抵消：n=800 时 CFL 0.5/0.25/0.125 的
   误差为 4.34e-3/4.09e-3/4.03e-3（时间步缩小误差基本不变），说明该网格上空间误差主导。
6. 本算例是 1D 理想杆，不含横向惯性（Rayleigh/Love 修正）、材料阻尼与大变形；适用范围限于
   细长杆、弹性、小应变、波长 ≫ 截面尺寸。

## ⑥ 误差判定

| 关键量 | 基准 | 误差 | 是否 < 3 % |
|---|---|---|---|
| 应力剖面 σ(x,t*) 相对 L2（n=1600） | d'Alembert 精确解 | 0.109 % | **是** |
| 应力剖面相对 Linf/峰值（n=1600） | 同上 | 0.111 % | **是** |
| 前导脉冲幅值 | 同上 | 0.0085 % | **是** |
| 峰值到达时刻 | (x−x0)/c | 0.0108 % | **是** |
| 反射瓣幅值（自由/固支） | 镜像精确解 | 0.0085 % / 0.0085 % | **是** |
| 离散频率（时域测量 vs 闭式） | 闭式弥散关系 | 5.59e-05 | **是** |

验收判定：**PASS**（最小网格 0.109 % < 2 %，容差 2.0 %）；
同时给出反例：n=200（h=0.080 m）误差 6.87 % **判为 FAIL**，
说明判据不是恒真（`run_case(mesh_sequence=(100,200))` 亦返回 `verdict=fail`，诚实失败路径有测试覆盖）。
