# GAP-PP-5 ICE-STRUCT 板架极限 · Round 9：板格支的薄膜（大挠度）容量

> 本文数字全部由 `benchmarks/grillage_plate_membrane_reserve.py` 注入，无手抄；
> 机读结果 `docs/grillage_ice_ultimate/membrane_capacity.json`，
> 实现在 `src/tensorfem/grillage_plate_membrane.py`，
> 门禁 `tests/test_grillage_plate_membrane.py`（M1–M8，22 项）。

## 0. 为什么还要做这一轮

round 1–8 已把锚点的三条验收口径做实（板架模型、三档组合工况、
板格应力→极限载荷映射表 60 行机读），独立复核的处置是 approve with notes，
数值保真度到 0.02 %。但复核的**未做项**（not_run，不得当作通过）里有一条是
本锚点物理上的关键：三档工况的控制分支恒为 `plate_local_bending`，而该分支是
**线弹性小挠度**板场——峰值 Navier 弯矩对 `sigma_y t^2/4`，**不含薄膜效应**。
冰带板格的边界（纵骨 + 相邻板格连续）在面内是被约束的，大挠度下会张紧，
因此真实容量高于线弹性值。审稿人（Marine Structures）对“板格极限”的常规质疑正是这一点。
本轮把这条欠账闭合：**量化**薄膜储备、给出对边界约束的敏感性、并给出可引用的界。

## 1. 模型与方法

板格在两根纵骨之间的部分按**单位宽条带**建模：跨度为纵骨间距
0.350 m，厚 20 mm，
受冰压斑 + 静水头侧压。三档工况的压斑宽度均被夹到纵骨间距，即沿条带跨度方向
**满布**，故条带承担的峰值弯矩与二维板场同一量级（差异见 §3.2，实测给出）。

控制方程取 von Kármán 浅条带（中等转角、小应变）：

```
eps = u' + (1/2) w'^2 ,   N = EA eps ,   EI w'''' - N w'' = q
```

面内边界用约束刚度 `k_s` 参数化（单位边长、单位端点缩短的力）：

```
N L /(EA) + N / k_s = (1/2) ∫ w'^2 dx
```

`k_s → ∞` 为不可移边界（储备上界），`k_s = 0` 为自由边界（无薄膜，退化为
已交付的线弹性判据），中间的 1/4、1/2 倍 `EA/L` 代表部分约束。**真实结构落在其中，
故本轮报的是区间而不是一个数。**

三条互不共享代码的求解路线：

| 路线 | 方法 | 求解内容 |
| --- | --- | --- |
| `exact` | 给定 N 时 ODE 为常系数线性，`w` 闭式（`q x²/2N` + `A+Bx+C cosh kx + D sinh kx`），四条简支条件解析定 A–D | 对 N 的**标量**根求根；无级数、无网格、无场迭代 |
| `series` | Ritz/Galerkin，`w = Σ a_m sin(mπx/L)`（仅奇模态），膜能用端点缩短表示 | 约化非线性方程组，阻尼 Newton |
| `fe` | 共旋梁单元，复用 `beam_large_deflection._assemble` 的能量与 AD 精确切线；两端 u、v 全约束 | 载荷步 + Newton；**不使用**相容关系，N 由单元轴向拉伸能自然产生 |

`薄膜储备 = p_plastic / p_plastic,N=0`，分子分母用**同一**截面相互作用律
`M/M_p + η² = 1`、同一条带，唯一差别就是薄膜力，因此这一列单纯是薄膜效应；
`塑性/已交付` 一列另外混入了 `sqrt(1-η²)` 与抛物线相互作用律的差别，不作为薄膜结论引用。

自由边界一列恰好等于 1.0000（M6 门，1e-9）：无薄膜时两条判据必然重合，
这是整条链的自洽性检查。

### 3.2 一维条带归约本身的误差

条带 `p_nomembrane` 与已交付二维板场 `p_ult` 的差：

* light-ice + ballast head：-31.67 %（条带 2.2921 vs 二维 3.3546 MPa）
* design-ice + design head：-5.07 %（条带 2.2116 vs 二维 2.3298 MPa）
* severe-ice + tank head：+5.16 %（条带 2.0704 vs 二维 1.9688 MPa）

小压斑（0.35 m × 0.35 m）时条带显著**低估**（双向局部弯曲在二维解里叠加，条带只有单向），
故本轮**不用条带替代**二维板场——条带只用来在同一几何下比较“有/无薄膜”，
二维解仍由已交付的 Navier 板场给出。这条误差是本轮明确声明的局限。

## 4. 结论（含否证）

1. **薄膜储备是有界的小量**：不可移边界下 1.110–1.171 倍，部分约束（1/2、1/4 EA/L）下降到 1.039–1.051 倍。原因是能量学的：板格在 `w/t ≈ 0.13–0.17` 时就到达截面塑性相互作用极限，此时膜应力只有几十 MPa，薄膜来不及起作用。**“线弹性板场忽略薄膜 ⇒ 容量被低估很多”这一假说在本几何下被否证**（负结果，如实入账）。
2. **已交付的 `plate_local_bending` 判据是塑性极限状态，不是屈服校核**：一次屈服出现在已交付限值的 0.411–0.622 倍，即已交付判据隐含了 1.61–2.44 倍的一次屈服储备。论文中必须这样表述，不能把它当“屈服载荷”引用。
3. **对边界约束不敏感**：1/4 → 1/2 → 不可移，储备只从 1.039 变到 1.171，因此唯一未知量（面内约束刚度）不影响结论方向。
4. **映射表保持保守、可引用**：三档工况的已交付 p_ult 在部分约束与不可移边界下均落在“有薄膜的塑性极限”之下（自由边界时同一判据族给出 x0.893–0.989，差异来自 √(1−η²) 与抛物线相互作用律，已声明）；故 round-1..8 的映射表与安全裕度不需要修改，但薄膜储备应作为**已知且已量化**的余量声明，而不是未做项。

## 6. 注意点 / 局限

* 条带归约在**小压斑**工况（light-ice，0.35×0.35 m）低估 32 %，见 §3.2；
  结论只用同几何下“有/无薄膜”的比值，不跨几何引用。
* von Kármán 运动学（中等转角、小应变）在 `w/t ≲ 1` 有效；本轮所有判据点 `w/t ≤ 0.17`，
  远在有效域内，但这也意味着**没有**利用 `w = t` 之后才出现的大挠度储备
  （`w=t` 对应压力 14–58 MPa，被截面塑性先限制住，不构成可用容量）。
* 面内约束刚度 `k_s` 是参数而非实测值：本轮报 4 档区间，未做约束刚度的结构分析。
* 未做：温度/棘轮、循环冰压下的低周疲劳、焊缝热影响区材料不均匀、
  以及分类社规范的外部数据对标（沙箱内无外部算例数据，仍需外部输入）。
* 本轮**不改动**已交付的设计判据与映射表数值。
