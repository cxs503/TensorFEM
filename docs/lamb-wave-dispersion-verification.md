# Rayleigh--Lamb 波色散：解析 oracle × Bloch--Floquet Q4 单元复核

**锚点** `GAP-FEM-WAVE-DISPERSION`（总账外新缺口：板内弹性波色散此前无任何解析对标面）

**结论先行**：解析 Rayleigh--Lamb 频率方程与 Bloch--Floquet 有限元单元在 `kh=0.2`–`2` 上相位速度最大偏差 **0.069%**（门限 3%），细网格收敛阶 **1.75**（A0）/ **1.93**（S0）；9/9 门 9 PASS。

## 1 案例介绍（物理背景 / 几何 / 参数）

均匀各向同性弹性板中的导波（Lamb 波）是船体板架振动—噪声链、冰激振动和水弹性耦合的最底层传播通道。板厚 `2h`、平面应变（沿板宽方向无应变），上下表面无面力；对每个实数波数 `k`，两族模态满足精确超越方程：

$$\begin{aligned}
S_n:\quad &4k^2pq\,\sin(ph)\cos(qh)+(q^2-k^2)^2\cos(ph)\sin(qh)=0\\
A_n:\quad &4k^2pq\,\sin(qh)\cos(ph)+(q^2-k^2)^2\sin(ph)\cos(qh)=0
\end{aligned}$$

其中 `p^2=ω^2/cL^2-k^2`、`q^2=ω^2/cT^2-k^2`；`p`、`q` 在各自截止频率以下为纯虚数，实现时按 `tan(ix)=i·tanh(x)` 分三段写成实数算式（这正是本锚点踩到的坑，见 §5）。

| 参数 | 值 |
|---|---|
| 杨氏模量 E | 2.1e+11 Pa |
| 泊松比 ν | 0.3 |
| 密度 ρ | 7850 kg/m³ |
| 半板厚 h | 0.01 m（板厚 20 mm） |
| c_L | 6000.98 m/s（1.870829 c_T） |
| c_T | 3207.66 m/s |
| 板纵波速 c_p=√(E/(ρ(1-ν²))) | 5421.93 m/s（1.690309 c_T） |
| Rayleigh 波速 c_R（经典三次方程根） | 2974.82 m/s（0.927413 c_T） |

## 2 怎么做的

1. **解析侧**：`tensorfem.wave_dispersion.lamb_residual` 在三个频率区间（`ω>k c_L`、`k c_T<ω<k c_L`、`ω<k c_T`）用纯实数算术求值，以对数网格扫描 + 二分求根；残差按自身两项幅度归一化，门限无量纲。波速 `c_L`、`c_T`、`c_p`、`c_R` 全部闭式给出，其中 `c_R` 由经典三次方程 `z³-8z²+8z(3-2η)-16(1-η)=0` 的物理根 `z∈(0,1)` 取得。
2. **FEM 侧**：单胞长 `L=2π/(k·4)`（每波长 4 个单胞）、厚 `2h`，刚度用**生产单元** `continuum.q4_stiffness`（平面应变、2×2 Gauss），质量用一致质量阵 `q4_consistent_mass`（`ρt∫N_iN_j detJ`，2×2 Gauss 精确）。施加 Floquet 条件 `u(x+L)=e^{ikL}u(x)`，以复归约矩阵 `T^H K T`、`T^H M T` 解 Hermitian 广义特征值问题（`scipy.linalg.eigh`）。FEM 侧完全不知道解析根，解析侧完全不知道单元矩阵——两侧互不喂答案。
3. **网格梯**：`(n_x, n_y) = (8,4) / (16,8) / (32,16)`，`kh ∈ {0.2, 0.5, 1.0}`。
4. 全部数字由本脚本写盘（`result.json` / `gates_verified.json` / 本文件），零手抄；图由 matplotlib 现场生成。

## 5 注意点 / 踩过的坑（本单修复）

1. **Floquet 归约的自由度编号（本单修复的阻断性缺陷）**：归约矩阵 `T` 原先把同一节点的 `u_x`、`u_y` 两个分量写进**同一个**列号，`K_red = T^H K T` 把两分量的刚度/质量交叉项相加，归约后的系统不再是弹性体的 Bloch 问题；表现是最低支相位速度对 `k` 与网格都不敏感（≈1.247 c_T），而只保留 `u_x` 的同一套机器却能精确复现 `c_L`。修法：一个保留节点占 **两个** 列（`2*idx+d`）。修复后 A0/S0 两支立刻落回解析值 0.05%–0.66% / 0.001%–0.09%。
2. **单胞长度不能随 1/k 缩放**：原实现 `L = 2π/(4k)` 使 `kL≡π/2`，离散问题对 `k` 自相似，「色散曲线」退化为一条常相位速度直线。改为固定物理单胞 `L = 2h`（`kh≤1` 时 `kL<2`）。
3. **解析侧两个判据缺陷**：(a) `s0_plate_velocity_extrapolated` 把无量纲外推截距 `c/c_T` 直接除以有量纲的 `c_p`，判据恒报 99.97% 假误差；(b) `s0_longitudinal_limit` 以 `c_L` 为 S0 的高 `kh` 参考是**物理错误**——S0 与 A0 在 `kh→∞` 都趋于 `c_R`，S0 的极大值才是 `kh→0` 的 `c_p`（`c_p = 1.690 c_T < c_L = 1.871 c_T`）。两者均已改为可比/正确的参考。
4. **复数相位的陷阱**：最初直接把 `sin(ph)`、`cos(ph)` 用 `cmath` 求值再取实部，结果在 `ω<k c_T` 区间残差恒为 0（该项整体是纯虚数，实部为 0），根扫描把 A0 支完全漏掉、把 S1 截止频率当成 A0。改法：按三段区间用实数算术显式写 `tan`/`tanh`，残差才有符号可二分。
5. **扫描窗**：`ω_max` 必须同时覆盖截止频率阶梯 `(n+1)πc_T/(2h)` 与传播区 `3c_L k`；只用前者在 `kh≳5` 时会把 S0 丢掉。对数网格（每族 1500×(n+1) 点）同时覆盖 A0 的低频极小根与高频三角函数振荡。
6. **适用域**：本锚点只覆盖**均匀各向同性板、平面应变、线性弹性、无衰减**。不含流固耦合加载、层合板、粘弹阻尼、有限变形；这些由其它锚点各自负责，不得据此外推。
7. **FEM 侧精度被一致质量阵与 Q4 双线性插值限制**：低频 A0 需要足够的厚度方向单元（`n_y`）才能捕捉弯曲模态的厚度分布，细网格取 `n_y=16`；更粗网格的误差保留在表 3.2 中，未做平均或剔除。
8. 解析侧的对数扫描可能漏掉**重根**（本算例的支在 `kh≤20` 内均为单根，所有报出的根都用归一化残差逐一回代验证，见表 3.1 最后两列）。
