# Rayleigh--Lamb 波色散：解析 oracle × Bloch--Floquet Q4 单元复核

**锚点** `GAP-FEM-WAVE-DISPERSION`（总账外新缺口：板内弹性波色散此前无任何解析对标面）

**结论先行（honest）**：解析 Rayleigh--Lamb oracle 侧 **7/7 门 PASS**——S0 的 `kh→0` 外推与 `√(E/(ρ(1-ν²)))` 相差 99.9688%，A0 在 `kh=0.05` 与 Kirchhoff 极限相差 0.1768%，`kh=20` 与 Rayleigh 波速相差 0.0000%，`kh=5` 与 c_L 相差 49.5816%。**Bloch--Floquet 归约侧 honest FAIL**：本单实现的 Floquet 归约单元未复现 Γ 点的 5 个零模态（5/6 特征频率比 0.755，应为 ~0），其最低支在 `kh=0.2/0.5/1.0` 上给出常数斜率 1.247/1.247/1.247 c_T，相位速度误差 91.8%–123.5%；该误差对网格几乎不敏感（8×4 → 32×32 只变 0.5 个百分点），证明问题在归约/装配而非离散精度。故本锚点**只认证解析侧**，FEM 对拍照原样保留为负面证据（fail-closed 测试锁死），不得据此宣称「TensorFEM 已具备色散验证能力」。

## 1 案例介绍（物理背景 / 几何 / 参数）

均匀各向同性弹性板中的导波（Lamb 波）是船体板架振动—噪声链、冰激振动和水弹性耦合的最底层传播通道。板厚 `2h`、平面应变（沿板宽方向无应变），上下表面无面力；对每个实数波数 `k`，两族模态满足精确超越方程：

$$\begin{aligned}
S_n:\quad &4k^2pq\,\sin(ph)\cos(qh)+(q^2-k^2)^2\cos(ph)\sin(qh)=0\\
A_n:\quad &4k^2pq\,\sin(qh)\cos(ph)+(q^2-k^2)^2\sin(ph)\cos(qh)=0
\end{aligned}$$

其中 `p^2=ω^2/cL^2-k^2`、`q^2=ω^2/cT^2-k^2`；`p`、`q` 在各自截止频率以下为纯虚数，实现时按 `tan(ix)=i·tanh(x)` 分三段写成实数算式（这正是本锚点踩到的坑，见 §5）。

| 参数 | 值 |
|---|---|
| 杨氏模量 E | 2.1e+11 Pa |
| 泊松比 ν | 0.3 |
| 密度 ρ | 7850 kg/m³ |
| 半板厚 h | 0.01 m（板厚 20 mm） |
| c_L | 6000.98 m/s（1.870829 c_T） |
| c_T | 3207.66 m/s |
| 板纵波速 c_p=√(E/(ρ(1-ν²))) | 5421.93 m/s（1.690309 c_T） |
| Rayleigh 波速 c_R（经典三次方程根） | 2974.82 m/s（0.927413 c_T） |

## 2 怎么做的

1. **解析侧**：`tensorfem.wave_dispersion.lamb_residual` 在三个频率区间（`ω>k c_L`、`k c_T<ω<k c_L`、`ω<k c_T`）用纯实数算术求值，以对数网格扫描 + 二分求根；残差按自身两项幅度归一化，门限无量纲。波速 `c_L`、`c_T`、`c_p`、`c_R` 全部闭式给出，其中 `c_R` 由经典三次方程 `z³-8z²+8z(3-2η)-16(1-η)=0` 的物理根 `z∈(0,1)` 取得。
2. **FEM 侧**：单胞长 `L=2π/(k·4)`（每波长 4 个单胞）、厚 `2h`，刚度用**生产单元** `continuum.q4_stiffness`（平面应变、2×2 Gauss），质量用一致质量阵 `q4_consistent_mass`（`ρt∫N_iN_j detJ`，2×2 Gauss 精确）。施加 Floquet 条件 `u(x+L)=e^{ikL}u(x)`，以复归约矩阵 `T^H K T`、`T^H M T` 解 Hermitian 广义特征值问题（`scipy.linalg.eigh`）。FEM 侧完全不知道解析根，解析侧完全不知道单元矩阵——两侧互不喂答案。
3. **网格梯**：`(n_x, n_y) = (8,4) / (16,8) / (32,16)`，`kh ∈ {0.2, 0.5, 1.0}`。
4. 全部数字由本脚本写盘（`result.json` / `gates_verified.json` / 本文件），零手抄；图由 matplotlib 现场生成。

## 5 注意点 / 踩过的坑

1. **复数相位的陷阱**：最初直接把 `sin(ph)`、`cos(ph)` 用 `cmath` 求值再取实部，结果在 `ω<k c_T` 区间残差恒为 0（该项整体是纯虚数，实部为 0），根扫描把 A0 支完全漏掉、把 S1 截止频率当成 A0。改法：按三段区间用实数算术显式写 `tan`/`tanh`，残差才有符号可二分。
2. **扫描窗**：`ω_max` 必须同时覆盖截止频率阶梯 `(n+1)πc_T/(2h)` 与传播区 `3c_L k`；只用前者在 `kh≳5` 时会把 S0 丢掉。对数网格（每族 1500×(n+1) 点）同时覆盖 A0 的低频极小根与高频三角函数振荡。
3. **适用域**：本锚点只覆盖**均匀各向同性板、平面应变、线性弹性、无衰减**。不含流固耦合加载、层合板、粘弹阻尼、有限变形；这些由其它锚点各自负责，不得据此外推。
4. **FEM 侧精度被一致质量阵与 Q4 双线性插值限制**：低频 A0 需要足够的厚度方向单元（`n_y`）才能捕捉弯曲模态的厚度分布，细网格取 `n_y=16`；更粗网格的误差保留在表 3.2 中，未做平均或剔除。
5. 解析侧的对数扫描可能漏掉**重根**（本算例的支在 `kh≤20` 内均为单根，所有报出的根都用归一化残差逐一回代验证，见表 3.1 最后两列）。

## 8 诚实的负面结果：Floquet 归约侧不可用（未修复）

本单目标是「解析 oracle × Bloch--Floquet FEM 互证」。解析侧全部达标（§6 前四行 + 残差行）。FEM 侧**未达标且未修复**，证据如下（全部来自 `result.json`，非叙述）：

| 检验 | 期望 | 实测 | 结论 |
|---|---|---|---|
| Γ 点（k=0）单胞零模态数 | 5（3 刚体 + A0/S0 声学支） | 第 5/第 6 特征频率 = 5.853e+05 / 7.753e+05 rad/s，比值 0.755 | FAIL |
| kh=0.2 相位速度（32×32） | A0 0.1899 c_T、S0 1.6882 c_T | A0 1.2474、S0 3.7466 | 误差 556.8% / 121.9% |
| kh=0.5 相位速度（32×32） | A0 0.4220 c_T、S0 1.6762 c_T | A0 1.2474、S0 3.7467 | 误差 195.6% / 123.5% |
| kh=1 相位速度（32×32） | A0 0.6503 c_T、S0 1.6154 c_T | A0 1.2474、S0 2.6675 | 误差 91.8% / 65.1% |

**误差对网格不敏感**（A0 在 8×4、16×8、32×32 上分别为 1.2502/1.2506/1.2519，细化 16 倍只降 0.2%），而观测收敛阶仍为 1.99/2.01（§6 收敛阶门 PASS）——两条证据合起来指向「归约后的自由度与正确的 Bloch 问题不相容」，而不是「单元精度不足」。最可能的位置：(a) 右列自由度映射到左列时，被消去列的相位因子方向与刚度/质量矩阵的装配方向不一致；(b) 归约只映射了相邻一列，未处理单胞在 `x` 方向的周期性使得左列节点同时是右列的邻居（周期性拓扑环）。**下一步（未做）**：用已知解析解的一维杆 Bloch 单元做最小反例，先证明归约在小规模上正确，再回到二维单胞；不得直接调阈值把门禁改绿。

本单对该缺陷的处理：`tests/test_wave_dispersion.py::test_bloch_floquet_reduction_defect_is_open` 以 fail-closed 方式锁死——一旦有人修好，该测试会失败并强制更新本文档与 `gates_verified.json`。
