# Rayleigh--Lamb 波色散：解析 oracle × Bloch--Floquet Q4 单元复核

**锚点** `GAP-FEM-WAVE-DISPERSION`（板内弹性波色散解析对标面）

**结论先行**（全部数字由 `run_verification.py` 写盘，零手抄）：门禁 **11/11 PASS**（总判定 `passed=true`）；细网格（32×16）上 A0/S0 相位速度对解析 Rayleigh--Lamb 的最大相对误差 **0.334%**，**是** < 3%；观测收敛阶 A0 **1.97** / S0 **2.00**。

## 1 案例介绍（物理背景 / 几何 / 参数）

均匀各向同性弹性板中的导波（Lamb 波）是船体板架振动—噪声链、冰激振动与水弹性耦合的最底层传播通道。板厚 `2h`、平面应变、上下表面无面力；对每个实数波数 `k` 两族模态满足精确超越方程：

$$\begin{aligned}
S_n:\quad &4k^2pq\,\sin(ph)\cos(qh)+(q^2-k^2)^2\cos(ph)\sin(qh)=0\\
A_n:\quad &4k^2pq\,\sin(qh)\cos(ph)+(q^2-k^2)^2\sin(ph)\cos(qh)=0
\end{aligned}$$

其中 `p^2=ω^2/cL^2-k^2`、`q^2=ω^2/cT^2-k^2`，`p`、`q` 在各自截止频率以下为纯虚数，实现时按 `tan(ix)=i·tanh(x)` 分三段写成实数算式（见 §5 的坑）。

| 参数 | 值 |
|---|---|
| 杨氏模量 E | 2.1e+11 Pa |
| 泊松比 ν | 0.3 |
| 密度 ρ | 7850 kg/m³ |
| 半板厚 h | 0.01 m（板厚 20 mm） |
| c_L | 6000.98 m/s（1.870829 c_T） |
| c_T | 3207.66 m/s |
| 板纵波速 c_p=√(E/(ρ(1-ν²))) | 5421.93 m/s（1.690309 c_T） |
| Rayleigh 波速 c_R | 2974.82 m/s（0.927413 c_T） |

## 2 怎么做的

1. **解析侧**：`tensorfem.wave_dispersion.lamb_residual` 在三段频率区间用纯实数算术求值，对数网格扫描 + 二分求根，残差按自身两项幅度归一化；每个二分结果**复核归一化残差**（< 1e-6 才收录），因此 `tan`/`tanh` 极点处的符号跳变不会被当成根（见 §9）。`c_L`/`c_T`/`c_p`/`c_R` 全部闭式。
2. **FEM 侧**：单个周期单胞（长 `L=2π/(4k)`、厚 `2h`），刚度用生产单元 `continuum.q4_stiffness`（平面应变、2×2 Gauss），质量用一致质量阵 `q4_consistent_mass`；施加 Floquet 条件 `u(x+L)=e^{ikL}u(x)`，以复归约矩阵 `T^H K T`、`T^H M T` 解 Hermitian 广义特征值问题。**归约在自由度空间进行**：每个保留节点保留 `u_x`、`u_z` 两个未知量，归约后自由度 80 = 2×(45−5)（见 §8 修复的缺陷）。
3. **分支识别不看 oracle**：单胞本征模态按频率排序，而 S0 的序号随 `kh` 变化（`kh=0.2` 时 A1 支插在 A0 与 S0 之间，S0 落在第 3 个模态）。因此按**中面奇偶性**分类：S 族 `u_x` 偶 / `u_z` 奇，A 族反之。分类器只读模态形状，解析根只用于打分，不用于挑选。
4. **网格梯**：`(n_x, n_y) = 8,4 / 16,8 / 32,16`，`kh ∈ [0.2, 0.5, 1.0]`。
5. 全部数字由本脚本写盘（`result.json` / `gates_verified.json` / 本文件），零手抄；图由 matplotlib 现场生成。

## 5 注意点 / 踩过的坑

1. **复数相位的陷阱**：最初用 `cmath` 求 `sin(ph)`/`cos(ph)` 再取实部，在 `ω<k c_T` 区间残差恒为 0，A0 支被整体漏掉。改法：按三段区间用实数算术显式写 `tan`/`tanh`。
2. **按序号取模态是错的**：S0 在 `kh=0.2` 落在第 3 个模态（A1 支插入其间），取 `omega[1]` 会把 A1 当成 S0——修复前的锚点正是这样报出「S0 误差 122%」。现改为按中面奇偶性分类（§2 第 3 条），与 `kh` 无关。
3. **归约必须在自由度空间做**（§8）：按节点编号建变换矩阵会把不同节点的 `u_x`/`u_z` 混叠，结果看起来「有收敛阶」却是收敛到错误的算子。
4. **适用域**：均匀各向同性板、平面应变、线性弹性、无衰减；不含流固耦合加载、层合板、粘弹阻尼、有限变形。
5. **解析扫描的极点伪根（已修复，见 §9）**：`ω = k c_T`（`q=0`）使 A 族残差的一项恒为零，而 `tan`/`tanh` 极点的符号跳变也会被当成变号区间，修复前 `rayleigh_lamb_frequencies(n_roots>=2)` 的列表里会混入 `ω/k/c_T = 1.0` 的伪根与每个截止频率处的一个极点穿越（归一化残差 0.6–1.0）。现每个二分结果须 `|残差| < 1e-6` 才收录，`analytic` 表（只用最低根）数字不变，门禁 `higher_root_residual` 覆盖全部报告根。

## 8 已修复的缺陷：Floquet 归约建在节点空间（m16896）

修复前的锚点是**诚实的负面结果**：Γ 点零模态数不足、FEM 相位速度误差对网格不敏感，`tests/test_wave_dispersion.py::test_bloch_floquet_reduction_defect_is_open` 以 fail-closed 方式锁死。根因是本单定位的：`bloch_cell_matrices` 把约化变换矩阵的列索引取成**节点号**（`nred` = 保留节点数），而自由度是每节点 2 个，于是 `u_x` 与 `u_z` 被混叠进同一列——`kh=0.2`、`8×4` 时归约矩阵只有 40×40 而正确维数是 80×80。修复：按自由度建变换矩阵（列号 `2·node+d`），并在 `bloch_cell_modes` 中把模态还原到未归约自由度空间以便做中面奇偶分类。修复前后数字见 git 历史（`benchmarks/verified/fem_wave_dispersion/gates_verified.json` 的上一个版本），本文件与门禁文件由同一脚本重生成。

## 9 已修复的缺陷：多根扫描收录 tan 极点伪根（m16849 / 重开 847）

原 PR#847（m16849）交付的扫描器修复在 2026-11-05 随 PR 关闭而丢失，本单从当前 main 补回。缺陷：`lamb_residual` 在 `tan(qh)`/`tan(ph)` 极点两侧符号相反，对数网格扫描把极点穿越误判为变号区间，二分后得到一个归一化残差 O(0.1)..1 的「根」；`q=0`（`ω = k c_T`）处 `4k²pq` 项恒为零，A 族在 `ω/k/c_T = 1.0` 处必现伪根。锚点只打最低根的分，故 10 道门禁当时全部 PASS，缺陷由 fail-closed 测试 `test_higher_root_scan_defect_is_open` 锁死。修复：`rayleigh_lamb_frequencies` 对每个二分结果复核归一化残差，`< 1e-6` 才收录（窗口内真根不足时宁可少给，不给伪根）。验证：`kh ∈ {0.1, 0.5, 2.0}` 两族各 2 根、全部残差 < 1e-6（`tests/test_wave_dispersion.py::test_higher_roots_are_genuine`，由原 fail-closed 门翻转为正向回归门）；本锚点自己的 `kh` 网格、每族 3 根、共 54 个报告根的最大归一化残差 8.52e-14（门禁 `higher_root_residual`，修复前该值为 1.0）。A0/S0 最低根数字与全部既有门禁不变。
