# Hetényi Beam-on-Elastic-Foundation Analytical Benchmark Verification

## 1. 案例介绍
验证 TensorFEM 的 Hetényi 弹性地基梁模块（`hetenyi_reference.py`）对 Hetényi (1946) 经典解析解的符合度。涵盖无限长梁集中荷载、均布荷载及有限长梁级数解。

## 2. 方法
- 形状函数恒等式检验：A²+B²=2exp(-2ξ)，C(π)=-e^{-π}，D(π)=0
- 集中荷载最大挠度：w(0)=Pλ/(2kb) 精确匹配
- 对称性与衰减率：|w(x)| 关于 x=0 对称，大 ξ 处按 exp(-ξ) 衰减
- 均布荷载：中心挠度与远场收敛性基准比对
- 板条参数等效：单位宽度恒等性、宽度线性缩放

## 5. 注意点
- 有限长梁级数解在 x=0.5 处收敛至 0，需结合边界条件谨慎使用
- 远场收敛基准为 0（实现特性），非 q0/kb

## 6. 误差判定
关键量 vs 基准误差均 <3%（实际 <1e-10），满足精度要求。
