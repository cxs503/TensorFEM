# P97-N04: TensorFEM 结构动力学验证面

## ① 案例介绍

### 物理背景
本验证面覆盖 TensorFEM 从解析解到经典基准的结构动力学能力，涵盖静力/动力/稳定性三类问题。
验证对象包括 Euler-Bernoulli 梁、Timoshenko 深梁、Kirchhoff/Love 板、柱/板/壳屈曲、以及瞬态响应。

### 几何与参数

| 问题类型 | 几何参数 | 材料参数 |
|---------|---------|---------|
| EB梁 (简支/悬臂) | L=5-10m, b=0.1m, h=0.15-0.2m | E=210GPa, ρ=7800kg/m³ |
| Timoshenko深梁 | L=1m, h/L=0.2 | E=210GPa, ν=0.3, k_s=5/6 |
| 简支方板 | a=1m, t=0.01m | E=210GPa, ν=0.3, ρ=7800kg/m³ |
| 固支方板 | a=1m, t=0.01m | E=210GPa, ν=0.3 |
| 板屈曲 | a/b=1-10, t=0.01-0.012m | E=210GPa, ν=0.3 |
| 柱屈曲 | L=3-5m, 4种边界 | EI=1.2-1.5×10⁶ |
| 圆柱壳屈曲 | R=1m, L=1.2m, t=0.01m | E=200GPa, ν=0.3 |
| SDOF瞬态 | ω=5-10 rad/s | m=1kg, k=mω² |

## ② 方法

### 求解器链
- **梁振动**: `tensorfem.modal` — EB梁单元刚度+一致质量矩阵 → Cholesky约化 → 对称特征值
- **Timoshenko梁**: `tensorfem.advanced_beam` — 精确棱柱刚度矩阵，含剪切柔度 φ=12EI/(κGAL²)
- **板振动**: `tensorfem.plate_vibration` — Q4 Mindlin SRI单元 + 一致质量(含转动惯量) → 特征值
- **板静力**: `tensorfem.plate_uniform_load` → `tensorfem.plate_mindlin` — Q4 Mindlin + Winkler(退化为0)
- **屈曲**: `tensorfem.buckling` / `tensorfem.marine_plate_buckling` — 线性特征值屈曲 Kφ=λKgφ
- **瞬态**: `tensorfem.dynamics` — Newmark-β平均加速度法(β=1/4, γ=1/2, 无条件稳定)

### 解析参考
- EB梁频率: ω_n = (β_n L)² √(EI/ρA), β_n L 由边界条件特征方程给出
- Timoshenko挠度: δ = PL³/(3EI) + PL/(κGA)
- Navier板级数: w = 16q₀a⁴/(π⁶D) Σ sin(mπx/a)sin(nπy/a) / (mn(m²+n²)²)
- 板频率: ω_mn = π²√(D/ρh) [(m/a)² + (n/b)²]
- 板屈曲: σ_cr = kπ²E/(12(1-ν²)) (t/b)², k=4.0 (长板)
- 柱屈曲: P_cr = π²EI/(KL)²
- 圆柱壳: N_cr = Et²/(R√(3(1-ν²)))
- Duhamel积分: u(t) = F₀/k (1-cos ωt)

## ⑤ 注意点

1. **板振动高阶模态**: 10×10网格对(1,3)模态误差~10%，需更细网格。验证面仅保证前4阶<5%。
2. **圆柱壳屈曲**: 面片近似圆柱有O(sin²(π/n_θ))误差，粗网格可偏离50%+。库内有完整网格收敛研究。
3. **Mindlin板剪切锁定**: SRI(单点剪切积分)避免锁定但引入2个零能模式；MITC4无此问题但计算更贵。
4. **Newmark精度**: 平均加速度法(β=1/4)二阶精度、无条件稳定，但每周期需≥20步才能<1%误差。
5. **稠密代数瓶颈**: 板/壳特征值问题用稠密eigh，>24×24网格应换稀疏求解器。
