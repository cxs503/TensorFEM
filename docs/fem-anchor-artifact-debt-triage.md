## 1. What is being triaged

`tools/verified_anchor_audit.py` certifies an anchor when its `gates_verified.json` is self-consistent. A certificate that *names* an artifact which is not committed is a hard defect (`E_ARTIFACT_MISSING`): the gate verdicts may be recomputable, but a reader following the certificate gets a 404. The registry currently holds **33 anchors**: 7 certified, 17 contradicted, 9 uncertified, across 244 gates.

Of those, **17 anchors** carry a defect and **14 of them name at least one artifact that does not resolve** (48 names in total). The debt registry lists 26 anchors.

## 4. The recipe, proven on `fem_shell_modal`

`fem_shell_modal` was the one anchor whose defect made the *fail-closed* gate red: `tests/test_verified_anchor_certificates.py` rejected it as unregistered debt (`unregistered=['fem_shell_modal']`) because its certificate named `shell_modal_audit.png`, which no commit ever contained. The repair used the `rebuild_from_dump` class above:

1. the figure code was lifted out of the live run into `render_figures(...)`, a pure function of the numbers in `result.json`;
2. `--from-dump` re-renders the certificate figure (plus the three README panels) with **no eigensolve**, and stamps `figure_provenance.json` with the sha256 of the `result.json` it read and of every PNG it wrote;
3. the four PNGs and the stamp are committed, so `tests/test_shell_modal_anchor_certificate.py` can prove the PNG on disk is the render of the JSON on disk;
4. the debt registry was **not** touched — the anchor became certified instead of becoming registered debt, which is the only direction the shrink-only registry allows.

## 5. Limits of this triage

* `rebuild_from_dump_candidate` is a statement about *data availability*, not about effort: an anchor whose `result.json` stores only scalars cannot rebuild a field or mode-shape figure, and the honest remedy there is `fresh_run`.
* The triage re-runs no solver, so it cannot tell whether the *numbers* inside a present `result.json` are still reproducible; that is the audit's `W_` warning class and remains open.
* A rebuilt figure is provenance-stamped but not independently re-measured: it reproduces the *presentation* of the committed data, never new physics.
* "Zero solve" is a property of the *figure code*, not of the anchor: `fem_beam_static.make_figures`, for instance, re-solves its 10/20/40-element beams to draw the FE curves, so its `--from-dump` costs milliseconds rather than nothing. That is still three orders of magnitude below a re-run of the anchor's own ladder, but the class name is about the missing *ladder*, not about literal zero time.
* `fem_shell_modal` is the only anchor repaired here. The other `rebuild_from_dump_candidate` rows are *diagnosed*, not fixed: each needs its own renderer and its own provenance stamp before its certificate is honest.
