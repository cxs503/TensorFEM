# 平面应变 Q4 近不可压锁定：B-bar 元素与精确 Lamé 场验证

本报告结算 [near-incompressible-locking.md](near-incompressible-locking.md) §6 列出的**欠账第 1 项**：
「2D 平面应变 Q4 无 B-bar/EAS 对照实现，`nu >= 0.499` 时误差 14 %–155 %」。该项不是文档缺口，
而是**求解器能力缺口**——仓内 `tensorfem.continuum` 只有全积分位移 Q4 一条路径，`nu -> 1/2` 时锁定，
船舶结构里橡胶支座、近不可压涂层、复合基体试件都在这条路径上算。本次补上平均膨胀
（mean dilatation，B-bar）Q4，并用**精确解**而不是更细网格或自比较来判定。

交付物：`src/tensorfem/continuum_bbar.py`（元素）、`scripts/audit_plane_strain_bbar_locking.py`
（审计）、`benchmarks/plane_strain_bbar_locking.json`（机器可读证据）、
`tests/test_continuum_bbar.py`（10 个门禁）、`docs/assets/plane_strain_bbar_locking/*.png`（3 图）。

## 1 案例介绍（物理背景 / 几何 / 参数表）

受内压厚壁圆筒的平面应变截面。选它的理由是决定性的：该问题存在**与 Poisson 比无关的精确应力场**
与含 `(1-2nu)`、`(1+nu)` 的闭式位移场，

`sigma_r = A - B/r^2`, `sigma_theta = A + B/r^2`, `A = p a^2/(b^2-a^2)`, `B = p a^2 b^2/(b^2-a^2)`。

于是「体积过刚（锁定）」这一偏差会直接表现为**误差随 `nu` 单调恶化**；无锁定的格式该误差对 `nu` 平坦。
参考解本身由 `tensorfem.lame_reference.lame_state` 给出，只含几何与压力（平面应变），
并已由 `tests/test_lame_cylinder_plane_strain.py` 独立校验。

| 项 | 取值 |
|---|---|
| 几何 | 厚壁圆筒，内半径 `a = 0.5 m`、外半径 `b = 0.8 m`（`a/b = 0.625`，厚壁） |
| 材料 | `E = 210 GPa`，平面应变，厚度 1 m |
| 载荷 | 内表面均布压力 `p = 100 MPa`（一致节点载荷 `circular_pressure_loads`），外表面自由 |
| 参考解 | 平面应变 Lamé 闭式（`lame_state`） |
| 基准网格 | 周向 `n_theta = 16` × 径向 `n_radial = 8` = 128 Q4，306 DOF |
| 细分网格 | 8×4（90 DOF）、32×16（1122 DOF）、48×24（2450 DOF） |
| 边界 | 对称轴上 `symmetry_fixed_dofs` 去刚体，**不施加任何解析位移** |
| 对比格式 | 全积分位移 Q4（`solve_continuum`，仓内已合并） vs B-bar Q4（`solve_continuum_bbar`，本次新增） |

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 元素构造（`src/tensorfem/continuum_bbar.py`）

平面应变本构按体积/偏量拆开：`D = D_dev + kappa m m^T`，`m = [1,1,0]^T`，
`kappa = E/(3(1-2nu))` 为三维体积模量（平面应变的正确极限）。记 `b_theta = m^T B` 为膨胀行、
`b_bar_theta = (1/A) int b_theta dA` 为其单元平均值，则

`K = int B^T D_dev B dA + kappa A b_bar_theta^T b_bar_theta`。

偏量部分在 **2×2 高斯点**上积分（因此不引入沙漏模态），只有体积部分被平均。
应力在单元中心用 `B_bar = B - m b_theta/2 + m b_bar_theta/2` 恢复，与三维
`solid3d_bbar` 的投影同形，两族的数值可直接对照。`kappa` 不额外传参，而由平面应变矩阵恒等式
`kappa = D[0,1] + 2 D[2,2]/3` 精确反算（`D[0,1] = kappa - 2G/3`、`D[2,2] = G`）。

适用边界是硬判据而非注释：`plane="stress"` 与 `element_type != "q4"` 直接 `ValueError`
（平面应力的体积拆分不同，宁可拒绝也不静默返回另一个模型）。

### 2.2 打分流程

1. 元素级性质先验（不依赖精确解）：无沙漏零能模态、刚度对称半正定、常应变精确再现、刚体运动零应力；
2. 再用 `plane_strain_case` 对精确解打分，度量与 3D 报告**同一套**：位移 L2、径向/环向应力 L2、
   平均应力 L2（体积指标）、内表面位移相对误差，应力一律在单元中心恢复、与同坐标精确值比较；
3. 最后做 4 档网格细化的观测阶。

工具链：`pytest`（门禁）、`scripts/audit_plane_strain_bbar_locking.py`（出数+出图）、
`matplotlib`（PNG）、JSON 证据（数字全部由程序写入，无手抄）。

## 3 计算结果（数字表）

### 3.1 误差随 Poisson 比（基准网格 16×8，306 DOF，单位 %）

| `nu` | 位移 L2 标准 | 位移 L2 B-bar | 径向应力 L2 标准 | 径向应力 L2 B-bar | 平均应力 L2 标准 | 平均应力 L2 B-bar |
|---:|---:|---:|---:|---:|---:|---:|
| 0.30 | 0.1537 | 0.0984 | 0.7663 | 0.5981 | 0.0340 | 0.0130 |
| 0.45 | 0.4090 | 0.1162 | 1.3656 | 0.5993 | 0.1357 | 0.0165 |
| 0.49 | 1.6858 | 0.1221 | 4.5433 | 0.5998 | 0.6697 | 0.0178 |
| 0.499 | 14.0439 | 0.1235 | 35.4570 | 0.5999 | 5.8556 | 0.0181 |
| 0.4999 | 61.9144 | 0.1236 | 155.2219 | 0.5999 | 25.9452 | 0.0182 |

环向应力 L2 与内表面位移相对误差同表存于 JSON（`nu=0.4999`：标准 36.424 % / 61.918 %，
B-bar 0.1648 % / 0.1236 %）。

**读数**：全积分 Q4 的位移误差在 `nu: 0.30 -> 0.4999` 段涨了 403 倍、平均应力误差涨 763 倍，
这就是锁定；B-bar 的对应数字只从 0.0984 % 到 0.1236 %（1.26 倍）与 0.0130 % 到 0.0182 %（1.40 倍），
而位移里本来就含 `(1-2nu)` 因子，残余变化是物理的不是锁定。

### 3.2 `nu = 0.4999` 网格细化

| `n_theta × n_radial` | DOF | 位移 L2 标准 | 位移 L2 B-bar | 径向应力 L2 标准 | 径向应力 L2 B-bar |
|---|---:|---:|---:|---:|---:|
| 8×4 | 90 | 86.5693 | 0.4932 | 216.0242 | 2.4066 |
| 16×8 | 306 | 61.9144 | 0.1236 | 155.2219 | 0.5999 |
| 32×16 | 1122 | 28.9434 | 0.0309 | 72.6497 | 0.1499 |
| 48×24 | 2450 | 15.3339 | 0.0137 | 38.4977 | 0.0666 |

观测阶（末两网格、`h ∝ 1/n_theta`）：B-bar 位移 1.9997、径向应力 2.0004；
标准 Q4 1.567 / 1.566——**加密虽然收敛但常数极差**，2450 DOF 仍有 38.5 % 径向应力误差，
即锁定不能靠加密治，与 3D 报告里标准 HEX8 的结论一致。

## 4 误差判定（逐项回答是否 < 3 %）

| 关键量 | 基准 | 误差 | < 3 %? |
|---|---|---|---|
| B-bar 位移 L2，`nu=0.4999`，16×8（306 DOF） | 平面应变 Lamé 闭式 | 0.1236 % | **是** |
| B-bar 径向应力 L2，`nu=0.4999`，16×8 | 同上 | 0.5999 % | **是** |
| B-bar 环向应力 L2，`nu=0.4999`，16×8 | 同上 | 0.1648 % | **是** |
| B-bar 平均（体积）应力 L2，`nu=0.4999`，16×8 | 同上 | 0.0182 % | **是** |
| B-bar 内表面位移相对误差，`nu=0.4999` | 同上 | 0.1236 % | **是** |
| B-bar 径向应力 L2，最粗网格 8×4（90 DOF） | 同上 | 2.4066 % | **是** |
| B-bar 径向应力 L2 对 `nu` 的平坦度（0.30 -> 0.4999） | 自参照 | 0.5981 % -> 0.5999 %（变化 0.3 %） | **是** |
| 标准 Q4 位移 L2，`nu=0.4999`，16×8 | 同上 | 61.9144 % | **否**（锁定，fail-closed 锁死） |
| 标准 Q4 径向应力 L2，`nu=0.4999`，16×8 | 同上 | 155.2219 % | **否** |
| 标准 Q4 径向应力 L2，`nu=0.4999`，48×24（2450 DOF） | 同上 | 38.4977 % | **否**（加密不治） |

结论（限定范围）：**在这套精确 Lamé 基准上，2D 平面应变 Q4 的锁定被治愈**——所有声明的位移/应力
指标在基准网格上均 < 1 %，且误差对 `nu` 几乎不敏感（应力 0.5981 % vs 0.5999 %），
残余误差是纯离散误差并按二阶收敛。本报告**不**宣称 B-bar Q4 可用于平面应力、不可压大变形
（有限变形 `J` 约束另需 F-bar/混合格式）、材料非线性或三维壳路径——这些没有基准在这里。

## 5 注意点（坑 / 局限 / 适用范围）

- **有限转动不是小应变刚体运动**：刚体运动门禁用 `u = ω × x`（反对称梯度）。先用有限旋转矩阵
  `R` 写 `u = R x` 会带来 `(R-I)xx = cosθ - 1` 的**真实二阶应变**，在 `kappa ≈ 3.5e14 Pa` 下放大成
  6.5e14 Pa 的假应力——这不是元素缺陷，是测试写错。同理，小应变近不可压的 patch test
  必须用**等体积**仿射场，否则体积响应本身就把舍入误差放大成可见应力。
- **`kappa` 的量级**：`nu = 0.4999` 时 `kappa = 3.5e14 Pa`，任何相对 1e-16 的应变差都会变成
  ~0.1 Pa；因此所有门禁的相对容差按 `E·|u|/h` 的应力尺度定，而不是按应力绝对值定。
- **B-bar 修正的是体积项**，不改善弯曲/剪切锁定；薄壁平面应变构件仍应按 `h/l` 判断是否需要
  EAS 或减缩积分。观测阶 2 只在光滑解下成立。
- **未加稀疏装配**：`solve_continuum_bbar` 沿用仓内 `solve_continuum` 的稠密装配
  （`n_dofs^2`），2450 DOF 尚可，再上一档需 COO 路径，与 3D B-bar 的同类欠账一致。
- **数值会随参考实现漂移**：几何/载荷/约束来自 `tensorfem.lame_reference`，若其改动，本报告须重跑；
  全部标量在 `benchmarks/plane_strain_bbar_locking.json`。
- 全积分 Q4 的失败由 `tests/test_continuum_bbar.py`、
  `tests/test_incompressible_locking.py` 双侧 fail-closed 锁死，任何人不得把它算作通过。

## 6 由此暴露的未完成项（下次自找活的线索）

   （或在平面应力下判定不构成锁定并给出证据），当前只有 `ValueError`。
