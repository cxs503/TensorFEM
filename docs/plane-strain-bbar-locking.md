# 平面应变 Q4 体积锁定治理：平均膨胀（B-bar）单元与 Lamé 精确解对照

## 1. 案例介绍

`docs/near-incompressible-locking.md` 用三维 Lamé 球壳把 B-bar HEX8 的锁定问题结清，
并在其 §6「未完成项」第 1 条留下一条**功能性欠账**：

> 「2D 平面应变 Q4 无 B-bar/EAS/BF 对照实现，`nu >= 0.499` 时误差 14 %–155 %；
> 船舶结构里橡胶支座、近不可压涂层、复合基体都用平面应变/平面应力 Q4 路径求解。」

同文 §4 把这条欠账钉成一个数字：`nu = 0.4999`、16×8 Q4 环扇网格、径向应力 L2 误差
**155.2 %**，且加密不收敛。该文档同时声明「未治理」，即**当时没有可用格式**。

本单清偿这条欠账：在**已合并的生产二维路径**（`tensorfem.continuum.ContinuumModel` /
`q4_stiffness` / `solve_continuum` 的同一数据结构与约束语义）上新增平均膨胀 B-bar Q4 单元
（`src/tensorfem/plane_strain_bbar.py`），并用**存在闭式解**的平面应变 Lamé 厚壁筒逐项打分。
被验证对象不是新求解器，而是「同一网格、同一载荷、同一约束、只换单元格式」的对照。

物理背景：厚壁圆筒（内半径 `a`、外半径 `b`）受内压 `p`。平面应变下环向/径向应力由两个
面力边界条件唯一确定（Lamé 1852）：

```
sigma_r = A - B/r^2,   sigma_theta = A + B/r^2,
A = p a^2/(b^2-a^2),   B = p a^2 b^2/(b^2-a^2),
u_r = (1+nu)/E [ (1-2nu) A r + B/r ],   sigma_z = nu (sigma_r + sigma_theta)
```

关键性质（本单的判据基础）：**面内应力场与 `E`、`nu` 均无关**，只有位移随 `nu` 变化。
因此「应力误差随 `nu` 增大」只可能是格式误差（体积锁定），不可能是基准或离散本身的物理效应。

| 参数 | 取值 |
|---|---|
| 几何 | 四分之一厚壁圆筒环扇 `0 <= theta <= pi/2`，`a = 0.5 m`，`b = 0.8 m`（`b/a = 1.6`） |
| 材料 | `E = 210 GPa`，`nu in {0.30, 0.45, 0.49, 0.499, 0.4999}`，平面应变 |
| 载荷 | 内壁均布压力 `p = 100 MPa`，外壁自由（一致节点压力，`tensorfem.lame_reference`） |
| 边界 | 两条对称切向约束（`tensorfem.lame_reference.symmetry_fixed_dofs`），**不施加任何解析位移** |
| 网格 | 极坐标 Q4 环扇，`n_theta x n_radial = 16x8 / 24x12 / 32x16 / 40x20`（306–1722 DOF） |
| 对比格式 | 全积分 Q4（生产 `solve_continuum`） vs 平均膨胀 B-bar Q4（`solve_continuum_bbar`） |
| 求解 | 自由 DOF 稠密直接解，`float64` |

## 2. 怎么做的

1. **先验判据，后验格式**（`lame_plane_strain_self_check`）。用自动微分对闭式场做三条独立残差：
   - 径向平衡 `d sigma_r/d r + (sigma_r - sigma_theta)/r = 0`（相对残差 < 1e-15）；
   - 面力：`sigma_r(a) = -p`、`sigma_r(b) = 0`（0）；
   - 平面应变本构：由 `du/dr`、`u/r` 与 `lambda, mu` 反算 `sigma_r, sigma_theta`（< 1e-12），
     并核验 `eps_z = 0 <=> sigma_z = nu(sigma_r + sigma_theta)`（< 1e-16）；
   - 面内应力对 `nu` 的不变性（0）。
   这四条通过后，基准才有资格判生产码。
2. **B-bar 离散（Hughes 1980 平均膨胀）**。把 Q4 的应变位移算子拆成体积/偏量两部分：

   ```
   B(xi) = B_dev(xi) + s · div(xi)/2,      s = (1, 1, 0)^T
   div_bar = ∫ div dV / ∫ dV               (2x2 Gauss，对双线性映射精确)
   K_e = ∫ B_bar^T D B_bar dV,             B_bar = B_dev(xi) + s · div_bar/2
   ```

   偏量部分保持 2x2 全积分，因此**不引入沙漏模式**：`bbar_element_eigenvalues` 在**畸变**
   单元上给出 8 个特征值中恰好 3 个零模态（刚体）与 5 个变形模态，测试锁死。
   平面应变下 `eps_zz = 0`，故面内膨胀恰为 `eps_xx + eps_yy`，与上式 `div` 一致。
3. **一致性（patch）检验走生产求解路径**：把仿射位移 `u = G x` 强加在矩形网格整个边界上，
   用 `solve_continuum_bbar` 求内部自由 DOF，位移与解析值差 < 1e-15（与全积分结果逐位相同）。
   常数应变场下 `div_bar == div`，故该单元是完备的（不是「近似完备」）。
4. **同一网格、同一载荷、只换格式**：环扇网格、一致节点压力、对称约束均取自
   `tensorfem.lame_reference`，两种格式共用 `ContinuumModel`，差异只能来自单元。
5. **应力恢复与格式一致**：单元中心应变取偏量部分，体积部分用 `div_bar` 投影
   （`q4_bbar_centre_strain`），再 `sigma = D eps`；这与三维 `solid3d_bbar` 的取法一致，
   避免「刚度用 B-bar、应力用 B」的自相矛盾。

复现：

```bash
PYTHONPATH=src python3 benchmarks/plane_strain_bbar_locking.py
PYTHONPATH=src pytest tests/test_plane_strain_bbar.py -q     # 8 passed
```

| 0.49 | 1.686 | 0.111 | 4.543 | 0.574 | 0.670 | 0.013 |

B-bar 的应力误差在 `nu` 从 0.30 到 0.4999 之间只从 0.572 % 变到 0.574 %（+0.35 %），
而全积分元素涨了 203 倍。面内迹应力（正比于膨胀 `eps_r + eps_theta`）是最灵敏的锁定指标：
全积分从 0.034 % 涨到 25.945 %（763 倍），B-bar 只从 0.010 % 到 0.014 %。

## 5. 注意点与适用边界

- **只治理了体积锁定，不是万能单元**：本单验证的是**线性**平面应变。塑性不可压
  （`J2` 流动、`nu = 0.5` 的金属成形）、大变形 `F-bar`、近不可压接触均未覆盖；
  `near-incompressible-locking.md` 的结论（B-bar 只修体积项）同样适用。
- **平面应力不是本单的主张**：平面应力本不体积锁定，此处只做「不劣化」核验
  （`nu = 0.3` 平面应力径向应力 L2：B-bar 0.572 % vs 全积分 0.715 %，两者 < 1 %）。
- **条件数变差 6.7 倍**（`nu = 0.4999`：1.87e7 vs 2.77e6）。稠密直接解不受影响，
  但**迭代求解器必须先加预条件**（本仓 2D 路径只有稠密装配）；这一点是使用 B-bar 的真实代价，
  不能只看误差表。
- **应力恢复仍在单元中心**：B-bar 把体积部分投影为单元常数，因此单元内 `sigma_r` 不再线性分布；
  0.574 % 是 16×8 粗网格值，随 `h` 二阶收敛（§3.3），若要更严的逐点判据需节点恢复/外推。
- **环扇网格是从极坐标规则生成的**，单元是曲边四边形（映射后非平行四边形）；B-bar 的
  `div_bar` 用 2×2 Gauss 积分求平均，对这类网格仍是精确积分，patch 检验在矩形网格上逐位通过。
  极端畸变网格（长宽比 > 10）未做参数化扫描。
- **线性求解器线程数**：`benchmarks/plane_strain_bbar_locking.py` 内固定
  `torch.set_num_threads(4)`。在 128 核高负载机器上，稠密 `torch.linalg.solve` 走 128 线程
  会因调度抖动把整脚本拖到分钟级（本机实测触发过 120 s 超时），固定线程数后全程 < 10 s。
- **复用关系**：网格、一致压力载荷、对称约束全部来自 `tensorfem.lame_reference`；若该模块
  改动，本报告数值须重跑。

## 6. 误差判定（逐项回答是否 < 3 %）

| 关键量 | 基准 | 误差 | < 3 %? |
|---|---|---|---|
| B-bar 径向应力 L2，`nu=0.4999`，16×8（306 DOF） | 平面应变 Lamé 闭式 | 0.574 % | **是** |
| B-bar 位移 L2，`nu=0.4999`，16×8 | 平面应变 Lamé 闭式 | 0.113 % | **是** |
| B-bar 环向应力 L2，`nu=0.4999`，16×8 | 平面应变 Lamé 闭式 | 0.158 % | **是** |
| B-bar 面内迹应力 L2，`nu=0.4999`，16×8 | 平面应变 Lamé 闭式 | 0.014 % | **是** |
| B-bar 径向应力 L2，`nu=0.4999`，40×20（1722 DOF） | 平面应变 Lamé 闭式 | 0.092 % | **是** |
| 全积分径向应力 L2，`nu=0.4999`，16×8 | 平面应变 Lamé 闭式 | 155.222 % | **否**（锁定，fail-closed 测试锁死） |
| 全积分径向应力 L2，`nu=0.4999`，40×20 | 平面应变 Lamé 闭式 | 51.923 % | **否**（加密不收敛，阶 1.51 且常数巨大） |
| B-bar 应力误差对 `nu` 的平坦度（0.30 → 0.4999） | 自参照 | 0.572 % → 0.574 %（+0.35 %） | **是**（应力场本与 `nu` 无关，误差不变 = 无锁定偏置） |
| B-bar 位移误差对 `nu` 的平坦度 | 自参照 | 0.090 % → 0.113 %（+25 %） | 属物理：`u_r` 含 `(1-2nu)` 因子，位移随 `nu` 变属真解行为，非锁定 |
| 参考解自身（平衡/面力/本构/轴向/不变性） | 自身控制方程 | ≤ 6.0e-13（相对） | **是** |
| 全局平衡（压力合力 vs 对称面反力） | 静力平衡 | ≤ 4.6e-11（相对） | **是** |

结论（限定范围）：在这套精确 Lamé 基准上，平面应变 Q4 的体积锁定已被 B-bar 平均膨胀格式
**治愈**——`nu = 0.4999` 时径向应力误差从 155.2 % 降到 0.574 %（271 倍），位移从 61.9 % 降到
0.113 %，且误差对 `nu` 平坦、随 `h` 二阶收敛。未覆盖项见 §5，不做外推式宣称。
