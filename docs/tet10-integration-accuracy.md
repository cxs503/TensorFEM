# TET10 积分精度：Keast 五点规则的亏欠量化与高阶参考

本单清理一条被两处审计明确挂出的欠账
（[quadratic-solid-rank-audit.md](quadratic-solid-rank-audit.md) §5.4、
[element-rank-deficiency-audit.md](element-rank-deficiency-audit.md) 第 6 条）：

> 「TET10 的 Keast 五点规则只精确到 3 次，而曲边二次四面体的刚度被积函数次数高于 3，
> 因此存在系统性积分不足。本次只证明了它**不掉秩**，**没有**量化其精度损失：
> 独立高阶参考（Duffy 变换 + 高阶张量积规则）在本次预算内未完成自验证。」

本报告把这句话变成可复现的数字，并且把参考本身立成可审计的对象：先用闭式单项式积分
自验证参考，再让它去判生产规则。

---

## 1. 案例介绍（物理背景 / 几何 / 参数）

TET10 是 10 节点二次四面体，生产路径见 `src/tensorfem/quadratic_solid.py`：
`tet10_stiffness` 用五点 Keast 规则积分，`solve_tet10` 完成三维线弹性求解，
`cantilever_tet10_benchmark` 与 `cantilever_tet4_benchmark` 提供悬臂 A/B 基准。

问题不在「规则是否掉秩」（此前已证：零空间恰为 6 维刚体，装配后 6 维，无伪零能），
而在「规则是否算得够准」。Keast 五点规则**总次数 3 精确**，而二次等参单元的刚度被积函数
$\boldsymbol B^T\boldsymbol D\boldsymbol B\,\det\boldsymbol J$ 在几何离开仿射（直边）后，
$\boldsymbol B$ 随自然坐标变化，次数超过 3；一致质量阵 $N_iN_j\det\boldsymbol J$ 是四次，
**连直边单元都超次数**。

几何与参数（单位制为 SI，量级取船体结构钢）：

| 项 | 取值 |
|---|---|
| 材料 | $E=200$ GPa，$\nu=0.3$，$\rho=7850$ kg/m³ |
| 参考域 | 单位四面体 $\{r,s,t\ge 0,\ r+s+t\le 1\}$，体积 $1/6$ |
| 顶点集 | 规则单位直角四面体；畸变但良态四面体（体积 0.2527，$\det J\equiv1.516$） |
| 曲边度量 | 边中点沿固定单位方向、交替符号偏移 `curvature × 平均边长`（与 HEX20 审计同约定，故两族可比） |
| 随机 warp | 同顶点集，边中点伪随机方向偏移（固定种子），用于排除「手工挑波形」 |
| 门限 | 平台 3 % 验收门 |

## 2. 怎么做的（方法 / 工具链）

三层，逐层自证后再用：

1. **独立参考规则（Duffy 塌缩 + 张量积 Gauss–Legendre）**，`src/tensorfem/tet10_integration_audit.py`，
   纯 NumPy，与生产代码**不共用形函数、不共用权重**：
   $r=u(1-v),\ s=uv(1-w),\ t=uvw$，Jacobian $=u^2v$，三方向各 `order` 点 Gauss。
   参考值一律取 `order=24`（$24^3=13824$ 点/单元），并以 `order=12` 的差值报告参考自身的收敛尾巴。
2. **参考自验证**（先证明参考可信，再让它当基准）：
   与闭式 $\int r^a s^b t^c\,dV=a!b!c!/(a+b+c+3)!$ 逐项比对（总次数 ≤6），
   以及与生产 Keast 刚度在**直边几何**上的逐元素比对（此处被积函数为常数，两规则必须一致）。
3. **亏欠量化**：在 7 档曲率上比 Keast 与参考的刚度矩阵相对 Frobenius 误差、
   一致质量阵误差、仿射场应变能误差（隔离 $\det J$ 积分）与弯曲场应变能误差（隔离 $\boldsymbol B$ 变化）。

产物与复现：

```
OMP_NUM_THREADS=1 PYTHONPATH=src python3 scripts/audit_tet10_integration.py
OMP_NUM_THREADS=1 PYTHONPATH=src python3 -m pytest tests/test_tet10_integration_audit.py -q
```

证据 JSON：`docs/benchmarks/tutorials/tet10-integration-accuracy.json`；
图：`docs/assets/tet10_integration_error.png`、`tet10_integration_oracle.png`、
`tet10_integration_mass.png`。门禁 21 项，55 s 内跑完（单线程，84 个稠密 30×30 单元积分为主）。

### 参考自验证结果

| 检查 | 结果 | 判据 |
|---|---|---|
| 参考体积（order 6..16） | 相对误差 ≤ 5.0e−16 | <1e−14 **是** |
| 闭式单项式，总次数 ≤6，order 6/8/16 | 最大相对误差 5.0e−16 | <1e−14 **是** |
| 参考单调收敛阶 | order 2→1 次、3→3 次、4→5 次、≥6→6 次（受 `max_degree` 限制） | 与塌缩 Jacobian $u^2v$ 的阶数一致 **是** |
| Keast 五点与生产 `tet10_quadrature()` 逐位差 | 点 0.0，权 0.0 | 完全相同 **是** |
| 生产 torch 实现 vs 独立 NumPy oracle（5 种几何） | 相对 Frobenius 差 ≤ 2.7e−16 | <1e−12 **是** |

最后一行的意义：两套**独立实现**（torch 生产 / NumPy 审计）在直边与曲边几何上都给出同一
Keast 矩阵，误差量级只在舍入位。因此后文的曲边误差来自规则本身，而不是某一份代码写错了。

## 3. 计算结果

### 3.1 刚度：直边精确，曲边系统性偏低

| 曲率（中点偏移 / 边长） | Keast vs 参考（相对 Frobenius） | 参考自身尾巴（order12 vs 24） | $\det J_{\min}$ | 是否 <3 % |
|---:|---:|---:|---:|---|
| 0（直边，畸变顶点） | 3.64e−15 | 3.4e−15 | 1.516 | **是**（机器精度） |
| 0.02 | 6.90e−04 = 0.069 % | 3.3e−15 | 1.317 | **是** |
| 0.05 | 4.28e−03 = 0.428 % | 3.1e−15 | 1.019 | **是** |
| 0.08 | 1.16e−02 = 1.160 % | 3.6e−15 | 0.721 | **是** |
| 0.11 | 2.55e−02 = 2.551 % | 2.5e−11 | 0.422 | **是**（贴门限） |
| 0.12 | 3.29e−02 = 3.292 % | 4.9e−10 | 0.323 | **否**（首次破门限） |
| 0.15 | 7.97e−02 = 7.970 % | 8.4e−05 | 0.025 | **否**（近似翻转单元） |

随机 warp 复核（排除手工波形）：曲率 0.02 → 0.154 %，0.05 → 1.066 %，与交替波形同量级，
结论不依赖某一组偏移方向。

### 3.2 误差来源拆分：是 $\boldsymbol B$ 变化，不是 $\det J$ 积分

| 曲率 | 仿射场应变能相对误差（只剩 $\det J$） | 弯曲场应变能相对误差（$\boldsymbol B$ 变化） | 是否 <3 %（弯曲场） |
|---:|---:|---:|---|
| 0 | 5.2e−15 | 5.2e−15 | **是** |
| 0.05 | 3.1e−15 | 0.512 % | **是** |
| 0.08 | 8.4e−16 | 1.348 % | **是** |
| 0.11 | 1.5e−15 | 2.668 % | **是** |
| 0.15 | 1.8e−15 | 6.059 % | **否** |

即：五点 Keast 对 $\det J$ 的体积积分即使在大曲率下也精确到舍入位；亏欠全部来自五点上
对 $\boldsymbol B(\xi)$ 的低阶采样——这也是为什么「掉秩审计通过」与「积分精度合格」是两件事。

### 3.3 一致质量阵：现规则根本不能积（生产尚无 TET10 质量阵）

| 曲率 | 相对 Frobenius | 对角元最大相对误差 | 总质量相对误差 |
|---:|---:|---:|---:|
| 0（直边） | 19.677 % | 70.833 % | 1.5e−15 |
| 0.05 | 19.872 % | 76.444 % | 2.0e−15 |
| 0.11 | 20.554 % | 81.866 % | 1.5e−15 |

这是一条**前瞻性约束**而非现存缺陷：`tensorfem` 目前没有 TET10 质量阵（`solid3d_mass`/
`solid_mass` 只覆盖 HEX8/HEX20 路径），日后实现时**不能**直接复用五点 Keast——它会把
对角质量（转动惯量来源）低估 71 %–82 %。总质量仍精确，因为规则对 $\det J$ 是精确的。

### 3.4 高阶规则的 opt-in 通道已可用

`tet10_stiffness(x, d, rule=(points, weights))` 新增可选规则参数（默认路径逐位不变）：

| 曲率 | 默认（Keast）vs 参考 | `duffy_rule(6)`（216 点）vs 参考 |
|---:|---:|---:|
| 0（直边） | 3.6e−15 | 与默认逐位一致（≤1e−12） |
| 0.05 | 4.285e−03 | 2.3e−10 |
| 0.11 | 2.551e−02 | 3.1e−06 |

即 216 点参考规则把曲边误差压到 1e−06 量级，成本 216/5 ≈ 43 倍积分点。

### 3.5 既有基准是否受影响：不受影响（这是实测，不是断言）

`cantilever_tet10_benchmark` 的网格由结构化 HEX8 升级而来，边中点全在精确中点，因此每个
单元都是仿射的；实测 8 个单元的最坏刚度相对误差 **1.94e−15**。所以该基准
（悬臂尖端挠度 3.933e−04 vs Timoshenko 参考 4.031e−04，相对误差 2.44 %）的残差来自离散
（单单元截面、二次插值的横向分辨能力），**不是**积分不足。3 % 门内通过，与本单结论互不冲突。

## 4. 注意点与局限

1. **参考在重曲率处本身要打折**：曲率 0.15 时 $\det J_{\min}=0.025$（近似翻转单元），
   有理被积函数让 order 24 的参考仍带 8.4e−05 的尾巴。该行 7.97 % 的结论有两个数量级余量，
   可以用；但**不能**把该行的第 4 位有效数字当成精确值。0.11 行尾巴 2.5e−11，可以放心用。
2. **3 % 门限的破点落在曲率 0.12**（3.29 %，$\det J_{\min}=0.32$，仍是良态单元），
   不是 0.15。写结论时要区分「良态但曲率较大」与「近似翻转」两个区段。
3. **曲率度量是「中点偏移 / 平均边长」的合成量**，不是曲率半径。它沿用 HEX20 审计的约定以便两族
   可比，但换算到真实曲面网格（例如球面壳 $R/h$）需要另行标定；本报告不声称覆盖任意几何。
4. **同族对比**：同等曲率（0.06–0.11 边长达）下 HEX20 的 27 点规则误差为 0.179 %
   （[quadratic-solid-rank-audit.md](quadratic-solid-rank-audit.md)），TET10 的 5 点 Keast 为
   0.6 %–2.6 %，约差一个数量级。这是「点数差 5 倍 + 参考域塌缩」的直接后果，不是 TET10 形函数的缺陷。
5. **不覆盖**：非线性（几何精确/塑性切线）路径；TET4 质心规则（其刚度被积函数在仿射几何下常数，
   精确）；TET10 质量阵实现（尚不存在）；动力学时间积分。
6. **算力纪律**：全部是 30×30 稠密单元积分，但参考点 13824/单元，`torch.set_num_threads(1)` +
   纯 NumPy 单线程即可在 55 s 内跑完门禁；本机 load15 高时不要把这些审计并行播种。

## 5. 误差判定（逐项 vs 3 % 门限）

| 关键量 | 本工作取值 | 基准 | 相对误差 | 是否 <3 % |
|---|---:|---|---:|---|
| 直边 TET10 刚度（畸变顶点） | Keast 5 点 | Duffy order 24 | 3.64e−15 | **是**（机器精度） |
| 曲边 0.05 刚度 | Keast 5 点 | Duffy order 24 | 0.428 % | **是** |
| 曲边 0.11 刚度 | Keast 5 点 | Duffy order 24 | 2.551 % | **是** |
| 曲边 0.12 刚度 | Keast 5 点 | Duffy order 24 | 3.292 % | **否**（保留，不粉饰） |
| 曲边 0.15 刚度 | Keast 5 点 | Duffy order 24 | 7.970 % | **否**（近似翻转单元） |
| 曲边 0.11 弯曲场应变能 | Keast 5 点 | Duffy order 24 | 2.668 % | **是** |
| 曲边 0.15 弯曲场应变能 | Keast 5 点 | Duffy order 24 | 6.059 % | **否** |
| 仿射场应变能（全部曲率） | Keast 5 点 | Duffy order 24 | ≤3.1e−15 | **是** |
| 直边一致质量阵 | Keast 5 点 | Duffy order 24 | 19.677 % | **否**（前瞻约束） |
| 悬臂 TET10 尖端挠度 | 3.933e−04 | Timoshenko 4.031e−04 | 2.44 % | **是**（与积分无关，见 3.5） |

结论一句话：**直边网格上 Keast 是精确的、既有基准未被污染；曲边网格上 0.05–0.11 曲率段误差
0.43 %–2.6 %，在 3 % 门内但不可忽略；曲率超过 0.12 即破门，且一致质量阵必须换规则。**
`tet10_stiffness(..., rule=...)` 已提供 opt-in 通道，默认路径不变。
