# GAP-PP-3 · 3 网格矩阵：族可行性 + 收敛阶估计器修复（m22746）

锚点：`GAP-PP-3-ICE-STRUCT-PLASTIC-SET`（板格低温钢弹塑性 + 永久挠度）。
仓：TensorFEM，分支 `agent/m22746`。本文件所有数字由
`scripts/post_gap_pp3_mesh_family_report.py` 程序化注入。

## 0. 一句话

上一单（m22559）发布的「3 网格矩阵」从未真正跑成：所用族 `(8,4)(12,6)(16,8)`
在 12×6 上违反斑边对齐约束，驱动脚本在第一个网格之后 `ValueError` 退出
（compute 作业 cj4232，rc=1），而消费该文件的测试在文件缺失时只 `skip`，
于是「3 档网格收敛」以 `not_run` 状态被当作「排队中」。本轮修了三处：
族可行性（N6）、收敛阶/Richardson 估计器符号（N7）、以及把矩阵拆成单网格分片
（`--grids` + `gap_pp3_3grid_merge.py`）。

## 2. N6（阻塞级，族不可行）——3 网格矩阵从未跑成

`patch_plate_mesh` 要求斑的**两条边**都落在单元边上（否则集中斑载荷不守恒，
实测 9.6% 挠度偏差）。居中 0.5 m 斑 ⇒ x 边界在 0.75 / 1.25 m，y 边界在
0.25 / 0.75 m ⇒ `nx % 8 == 0` 且 `ny % 4 == 0`。

扫描范围 nx∈[4,40], ny∈[2,20]：可容许 **25** 组，被拒 **678** 组。

| 族 | 判定 |
|---|---|
| 8×4 | 可容许 |
| 16×8 | 可容许 |
| 24×12 | 可容许 |
| 12×6（旧族第二档） | **被拒**（x 斑边 0.75 m 不在单元边上，单元尺寸 0.1667 m）|

cj4232 的实际日志（原始证据）：

```
[8x4]  280.9s  bias=-0.1557  yield_err=+0.2970  limit=1424752.73  perm=0.02591
ValueError: patch edge must coincide with an element edge   (作业 rc=1)
```

**处置**：`GRIDS = (8,4)(16,8)(24,12)`（8→16 比例 2，16→24 比例 1.5），
并在任何求解之前用 `check_alignment()` 预检整族（毫秒级失败，而不是烧掉
第一个网格的 281 s）；矩阵拆成 `--grids 16x8` 单网格分片由
`scripts/gap_pp3_3grid_merge.py` 合并，缺片会被**报告**而不是补数。
为什么不用等比 2 的 `(8,4)(16,8)(32,16)`：32×16 = 512 单元约 16 倍粗网格代价，
超出本单算力；阶数由最后一对（比例 1.5）估计，并作为 `refinement_ratio` 报告。

## 3. N7（阻塞级，估计器符号错）——收敛阶与 Richardson 极限都错

m22559 的 `_rules()` 用 `ln(h_c/h_f)` 作分母（正确应为 `ln(h_f/h_c)`，两者
互为相反数），于是 `observed_order` 符号翻转、`extrapolated_error` 随之错。

h = [0.25, 0.125, 0.083333] m（= b/ny），对精确幂律 `e = h^p`：

| p（真值） | 修复后 order | 修复后极限 | 修复前 order | 修复前极限 |
|---|---|---|---|---|
| 0.5 | +0.500000 | -5.551e-17 | -0.500000 | +0.642229 |
| 1.0 | +1.000000 | -1.388e-17 | -1.000000 | +0.208333 |
| 1.5 | +1.500000 | +0.000e+00 | -1.500000 | +0.068250 |
| 2.0 | +2.000000 | -8.674e-19 | -2.000000 | +0.022569 |
| 3.0 | +3.000000 | -1.084e-19 | -3.000000 | +0.002532 |

修复前在 p=1.5 上给出 order=−1.5、极限 0.068 —— 即**精确收敛的序列会被判为
不收敛**（假 FAIL）；反过来，符号错也会让「恰好越过 5% 线」的序列给出无意义
的外推值。这是判据可测性的前提，必须修。

**处置**：分母改为 `ln(h_f/h_c)`；幂律序列上 order 与真值一致（本文件数值表），
极限回到 0（|<1e-12|）；误差变号或只有一个网格时不外推并给出原因，
`refinement_ratio` 显式报告。回归测试钉在
`tests/test_gap_pp3_3grid_mesh_family.py::TestMergeReproducesCriteria`。

## 4. 本轮矩阵的状态（honest）

修复后的三档单网格作业已递交调度：**cj4336 (8×4) / cj4337 (16×8) / cj4338 (24×12)**，
递交后 17 分钟仍在排队（队列 68 个在飞），因此本轮**没有**新的多网格数值。

| 验收判据 | 状态 |
|---|---|
| 弹→塑过渡 <5% | **未达**（唯一可用数值 8×4 原始误差 +29.70%，cj4232 原始日志） |
| 塑性极限 vs 上限解 <10% | **未达**（8×4 实测 1.4248 MPa vs 上限 2.0528 MPa，−30.6%；落在括号 [0.570, 2.053] MPa 内） |
| 3 档网格收敛 | **not_run**（族已修好并可跑，作业排队中；详见 §2） |
| 永久挠度后处理 | 达成（8×4：25.91 mm，卸载收敛，`permanent_set_valid=True`） |

值得记下的是**括号本身很宽**（可容许上限/下限 = 3.60×）：单一上限解 ±10% 对齐在这个
问题上不是可满足的判据；更诚实的判据是「下限 ≤ p_FE ≤ 上限 且相邻网格差 <10%」，
并同时报告层数 n（截面能力比 (n²−1)/n²）与实测极限定义的三类展布。
