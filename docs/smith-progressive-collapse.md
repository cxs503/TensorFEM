## 1. 案例介绍
研究对象是 IACS CSR 标准加筋板格（纵向加筋、单跨单筋距）：

| 量 | 值 |
|---|---|
| 跨距 a（框架间距） | 2.4000 m |
| 筋距 b | 0.8000 m |
| 板厚 t | 12.0000 mm |
| 筋条 | HP 200 x 10, idealised as equivalent tee web 200x9 + flange 55x10（A_s = 2350.0000 mm²） |
| 材料 | E = 206.0000 GPa，ν = 0.30，σ_y = 235.0000 MPa |
| 板柔度 β | 2.25169 |
| 长宽比 a/b | 3.000（屈曲系数 k = 4.000） |
| 弹性屈曲应力 σ_cr/σ_y | 0.7130 |
| 参考初始挠度 w₀/t = 0.1β² | 0.5070 |
| 参考残余应力 σ_rc/σ_y | 0.2 |

HP 200×10 球扁钢按等截面等效 T 型（腹板 200×9 + 翼板 55×10）理想化——原始型材表在本环境不可得，此处为**声明式等效**而非引用；该等效对板格极限的影响通过面积比（A_s/A_total 见下表）传导。

## 2. 怎么做的
**板条载荷-缩短曲线**（`PlateStrip`）：三段式。①弹性段 σ = Eε 到 ε₁ = min(σ_cr, σ_u)/E；②后屈曲 von Kármán 有效宽度段 σ = √(σ_cr E ε)（从 σ_cr 升到 σ_u）；③峰后线性软化到 0.4σ_u（经历 2ε_y）后平台。峰值锚定 Faulkner(1975) 曲线 2.25/β − 1.25/β²（本研究把它作为**参考状态**的锚，参考状态定义为 w₀/t = 0.1β²、σ_rc = 0.2σ_y），并乘两个显式因子：
- 初始缺陷因子 κ_w = 1 − c_w(w₀/t − 0.1β²)/(0.1β²)，c_w = 0.050；
- 残余应力因子 κ_r = 1 − c_r(σ_rc/σ_y − 0.2)(1 − σ_cr/σ_y)，c_r = 1.000；后屈曲占比 (1 − σ_cr/σ_y) 是物理权重——矮胖板先屈服后屈曲，残余应力对该通道不起作用。
两个系数在参考状态下恰为 1，因此参考状态下模型**就是** Faulkner，其对 β 的依赖来自精确屈曲系数 k(a/b) = min_m (m b/a + a/(m b))²。

**筋条载荷-缩短曲线**（`TeeStiffener`）：Perry–Robertson 柱曲线（Euler 应力 π²EI/(A a²) 配初始弯曲 w₀ₛ = a/750，η = w₀ₛA/W）与腹板局部屈曲（k=4.0，两纵边受约束）、翼板悬伸局部屈曲（k=0.425，一边自由）三者取最小值作为筋条极限，含屈服后软化到 0.3σ_u。扭转（tripping）屈曲本模块**不覆盖**，由 `tensorfem.marine_stiffener_failure` 承担。

**Smith 组合**（`SmithPanel`）：板条与筋条在同一平均应变下各自取应力，按面积加权并联，σ_panel(ε) = (A_p σ_p + A_s σ_s)/(A_p + A_s)，曲线峰值为板格极限强度。由于两个分量的曲线都是"升—峰—降"单峰形，组合曲线必然单峰且峰后不回升（判据 g 的结构性保证，测试断言验证）。

**交互面**（`panel_interaction` / `equal_biaxial_capacity`）：CSR 规则面 (σ_x/σ_xu)² + (σ_y/σ_yu)² − c·σ_xσ_y/(σ_xuσ_yu) + (τ/τ_u)² = 1（jockeying 系数 c 由调用方给，默认 0），以及平面应力 von Mises 屈服面 σ_x² − σ_xσ_y + σ_y² = σ_y²。剪切极限 τ_u = min(σ_y/√3, √(τ_cr σ_y/√3))，τ_cr 用 k_s = 5.35 + 4(b/a)²。

**规则面交叉校核**（`csr_format_panel_ultimate`）：与曲线法结构上不同的第二条路——按规则结构取"板场极限 / 整截面柱 / 腹板局部 / 翼板局部 / 屈服"的**最小值**（不加面积权重），两者之差即判据 (b)。注意：两条路共享同一筋条柱表达式，因此该判据检验的是**组合规则**（面积加权峰值 vs 最小支配）而非重复检验柱曲线——这一点在局限中明确写出。

## 5. 注意点 / 局限
1. **Gordo & Soares (1993) 关系式 WITHHELD**：原文在本环境不可得，故未逐字复现其三段式方程；实现的是等效宽度三段式 + 显式缺陷/残余应力因子，参考状态锚定 Faulkner。这不是原式的替代品，而是同构物理模型的独立实现——引用时必须如此表述。
2. **两个经验系数是工程假设，不是转写值**：c_w = 0.050（标定：标准缺陷翻倍约降 5%，取文献定性趋势的保守端）与 c_r = 1.000（标定：残余应力效应随后屈曲占比线性增长）。两者都是模块构造参数（可外部注入、敏感性在图 3 中给出），主源未核对。
3. **IACS CSR 条文不可得**：`csr_format_panel_ultimate` 复现的是规则**结构**（板场/柱/局部取最小 + 二次交互面），不是条文原式；任何规则系数（分项安全系数）由调用方给出，模块内不发明规范数字。判据 (b) 因此是两种方法学的交叉校核，而非"符合规范"的声明。
4. **判据 (c) 未完成**：Paik & Thayamballi (2003) 试验表不可得。已交付的是可注入的比对器 + JSON 模式 + 证据等级传播（未核实条目强制 `WITHHELD`，不会误升 REAL）与合成夹具回归测试；三试件结果缺失，按 honest-FAIL 记为 **WITHHELD**，不用记忆值填充。
5. **Perry–Robertson 在极矮胖柱上偏保守**：当 Euler 应力远高于屈服时，Perry 曲线渐近到 σ₀/(1+η)（本例 η = 0.1432 → 筋条极限 0.6894σ_y）。这是 Perry 曲线的已知特性（缺陷与柱长成比例时该惩罚随柱长消失，本例 a = 2.4 m 仍保留部分惩罚）；若用于设计，应与规范柱曲线（Johnson–Ostenfeld/CSR 曲线）对拍替换。
6. **不含扭转（tripping）、不含横向加筋、不含腐蚀/开孔**；板格被处理为单跨单筋距的孤立单元，未计相邻板格与横框架的约束（对板格极限通常偏保守）。
7. **von Mises 与 "1/√2" 的口径说明**：平面应力 von Mises 在等双压下给出 σ/σ_y = 1（不是 1/√2）；1/√2 来自**二次利用面**（容量归一化）。本报告按判据 (f) 的原意采用后者，并同时给出前者数值，避免把两种口径混为一谈。

## 6. 误差判定（对基准逐项，显式回答是否 <3%）

| 关键量 | 基准 | 相对误差 | <3%？ |
|---|---|---|---|
| 板条 σ_u/σ_y（β∈[1,3]） | Faulkner 2.25/β − 1.25/β² | +0.00% | 是（参考状态恒等） |
| 板格 σ_u_panel/σ_y | CSR 规则面（最小支配） | +6.22% | **否**（6.2%，门限 10%） |
| 等双压容量比 | 1/√2 | +0.00% | 是 |
| 等双压容量比（c = 0.2） | 1/√2 | +5.41% | **否**（5.4%，门限 10%） |
| 剪切极限 τ_u | σ_y/√3 | 0.00% | 是（屈服支配，恒等） |
| 曲线峰值 | 网格 601 vs 4801 点 | +0.17% | 是 |
| 板格极限 | Paik & Thayamballi 2003 实验 | — | 无基准（WITHHELD，见局限 4） |

结论：与**解析/规则面基准**可比的两项（板条 Faulkner、等双压 1/√2）在 3% 内；两项不同方法学的交叉量（判据 b、c=0.2 的交互）在 5-6%，均满足各自 10% 门限但**不**声称 <3%；实验对标无基准，判据 (c) 记 WITHHELD 而非通过。
