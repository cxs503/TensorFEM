# 偏置谐波接触热流沿Q4接触边的精确积分与验证

## ① 案例介绍（物理背景/几何/参数表）
本工作针对有限元热传导模型中**接触边（contact edge）上的周期性谐波热交换**问题。在交变温度场（phasor）叠加稳态温度分布（bias）的条件下，接触边上的热流方向会随时间发生翻转。传统数值积分难以精确捕捉热流过零点，导致正向（forward）与反向（reverse）热流计算存在系统误差。

**几何与离散**：
- 单元类型：Q4 四边形单元
- 接触边：由 `contact_edge_pairs` 定义的对边
- 温度场：复数幅值（phasor）$T_a$ 与实数稳态分布 $T_s$ 叠加
- 接触导纳：$g$（单位长度热导）

**关键参数**：
| 参数 | 符号 | 取值/说明 |
|------|------|-----------|
| 角频率 | $\omega$ | 2.5 rad/s |
| 时间区间 | $[t_{start}, t_{end}]$ | $[0.12, 0.93]$ |
| 求积阶数 | $N_q$ | 32 点 Gauss-Legendre |
| 接触导纳 | $g$ | 线性梯度分布 |
| 稳态温差 | $T_s$ | 节点值 $[0,1,2,3,4,5,6,7]$ |
| 谐波幅值 | $T_a$ | 复数 $[0.8+0.3j, -0.2+0.9j]$ |

## ② 怎么做的（方法/流程/关键设置/工具链）
**核心算法**：`thermal_contact_edge_biased_cycle_heat`
1. **端点插值**：在接触边参数 $s \in [start, end]$ 处，线性插值得到左右子边的稳态温度端点 $(b_l, b_r)$ 与谐波端点 $(a_l, a_r)$。
2. **过零点检测**：求解 $b + |a|\cos(t+\phi) = 0$ 的根，确定热流方向翻转的时刻。
3. **时间分割求积**：将 $[0, 2\pi]$ 按过零点分割为若干子区间，在每个子区间内使用 $N_q=32$ 阶 Gauss-Legendre 求积计算瞬时功率积分。
4. **方向分离**：利用 `clamp_min(0)` 分离正向与反向热流，避免正负抵消。
5. **验证基准**：使用 `scipy.integrate.quad` 进行高精度数值积分作为参考真值（exact），误差容限设为 $10^{-12}$。

**工具链**：PyTorch（张量计算）、NumPy（Legendre求积节点）、SciPy（参考积分）、pytest（测试框架）。

## ⑤ 注意点（踩过的坑/局限/适用范围）
1. **过零点分割逻辑**：当 $|b| \ge |a|$ 时热流方向不翻转，需特殊处理避免 `acos` 定义域溢出；
2. **复数相位处理**：谐波端点需统一转换为极坐标计算相位角，确保时间分割点连续；
3. **批量维度广播**：支持 batch 维度输入，但要求 `steady_temperature` 为实数张量；
4. **适用范围**：仅适用于线性温度历史叠加单一频率谐波的场景；多频叠加需叠加原理或时域步进。
