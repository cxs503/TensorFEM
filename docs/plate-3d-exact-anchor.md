# 厚板三维弹性精确解锚点：FSDT 与 HEX20 实体单元的独立标尺

Status: **新增能力 · 已验收（12/12 测试绿）** · 模块 `tensorfem.plate_3d_exact`
· 证据 `docs/assets/plate_3d_exact/evidence.json`（由 `benchmarks/plate_3d_exact_anchor.py`
程序化生成，全部数字零手抄）· 图 `docs/assets/plate_3d_exact/fig1..fig4*.png`
· 锚点建议 `GAP-FEM-PLATE-3D-EXACT`（见 §7）。

## 1. 案例介绍（欠账是什么）

| 现有参考 | 层级 | 缺口 |
|---|---|---|
| `plate_vibration` 对 Kirchhoff Navier | 薄板理论 | 只在 `a/h = 100` 有效，厚板无参考 |
| `plate_thick_reference` 对 FSDT 精确谱 | 一阶剪切理论 | 是**本仓自己的理论**，不是三维弹性 |
| `hex20` 悬臂基准（`cantilever_hex20_benchmark`） | Timoshenko 梁 | 只有梁，没有板的三维真解 |

也就是说：任何"厚板误差"都只能报**相对 FSDT/薄板**的偏差，无法区分
**离散误差**与**板理论误差**；实体单元（HEX20/TET10）从未对三维弹性标定过。
本单补上这一层：三维弹性精确解（Pagano 型，Pagano 1970）作独立标尺。

物理/几何/参数表：

| 项 | 取值 |
|---|---|
| 几何 | 正方形板 `a = b = 1.0 m`，厚度 `h = a/(a/h)`，方向 `0 ≤ x,y ≤ a`，`-h/2 ≤ z ≤ h/2` |
| 材料 | `E = 200 GPa`，`ν = 0.3`（各向同性线弹性，Lamé 形式） |
| 载荷 | 顶面双正弦压力 `p = q0 sin(πx/a) sin(πy/b)`，`q0 = 1.0 MPa`，向下（`-z`） |
| 边界（边） | `x = 0,a`：`u_y = u_z = 0`，`σ_xx = 0`；`y = 0,b`：`u_x = u_z = 0`，`σ_yy = 0`（剪切膜/SS1） |
| 边界（面） | `z = -h/2`：`σ_zz = τ_xz = τ_yz = 0`；`z = +h/2`：`σ_zz = -q0`，`τ = 0` |
| 厚度扫描 | `a/h = 100, 50, 20, 10, 8, 5` |
| 有限元 | HEX20 结构网格 `4×4×2`、`6×6×2`、`8×8×3`（`a/h = 10`），另 `a/h = 5, 20` 于 `6×6×2` |

**边界口径的关键点（诚实披露）**：双正弦是"剪切膜"边的精确解族——`σ_xx` 在
`x` 边上**恒等为零**（不是被施加的），而 `σ_xy` 在边上**不为零**，它是
`u_t = 0` 约束的支反力。有限元在同样的位置约束切向面内自由度，因此两者是同一个
边值问题；实测该支反力峰值 = **2.987·q0**（`edge_shear_over_applied_pressure`）。

## 2. 怎么做的（方法与工具链）

1. **精确解（闭式，scipy-free）**：把 `u_x = U(z)cos(αx)sin(βy)`、
   `u_y = V(z)sin(αx)cos(βy)`、`u_z = W(z)sin(αx)sin(βy)`（`α = mπ/a`, `β = nπ/b`）
   代入 Lamé 方程，得常系数 ODE 系统 `y' = A y`，`y = (U,V,W,U',V',W')`；
   六个面条件（底面无面力、顶面 `σ_zz = -q0`）化为 `y(-h/2)` 的 6×6 线性方程组。
   传播算子用 `torch.linalg.matrix_exp`（保持 torch-only、无 SciPy、可设备迁移）。
   `A` 的构成在中文推导下逐项对应，见模块 docstring 的推导链。
2. **两个板理论参考**：`kirchhoff_static_navier`（闭式）与
   `fsdt_static_navier`（半波 3×3 系统，`κ = 5/6`，无单元、无离散。
   若加单元就又会把离散误差混进"理论参考"）。
3. **HEX20 三维桥**：`solve_hex20_ss_plate` 用 `structured_hex20_mesh` +
   `hex20_stiffness`（3×3×3 精确阶规则）组装，顶面用 3×3 Gauss 一致节点载荷
   `∫ q N_i dA`（面 Jacobian 由形函数差分给出）；边界面按上面的剪切膜口径约束。
   `sparse=True` 走 SciPy 直接法（研究网格），`sparse=False` 走仓内 dense 路径（测试网格）。
4. **程序化证据**：`benchmarks/plate_3d_exact_anchor.py`（本次全量运行 **108.3 s**）
   写出 `evidence.json` + 4 张图；文档里的每个数字都从该 JSON 回读。
5. **测试**：`tests/test_plate_3d_exact.py`（12 项，12 passed，52.1 s）。

### 2.1 精确解自身的自检（先证参考，再用参考）

| 自检 | 做法 | 实测 |
|---|---|---|
| 平衡方程 | **自动微分**求 `div σ`（与 ODE 矩阵构造完全独立，σ 由应变式给出） | `max|div σ| = 0.670` Pa/m，相对应力梯度尺度 **3.34e-8** |
| 顶面应力 | `σ_zz(x,y,+h/2)` 对 `-q0 sin sin` | 相对误差 **5.59e-15** |
| 底面无面力 | `σ_zz(x,y,-h/2)` | **0.0**（精确零） |
| 面内剪切 | `τ_xz, τ_yz` 于 `z = ±h/2` | **1.62e-9 Pa**（对 `q0 = 1e6` 相对 1.6e-15） |
| 边条件 | `u_y,u_z`（x 边）、`u_x,u_z`（y 边）、`σ_xx`（x 边）、`σ_yy`（y 边） | 全部 **0.0** |
| 薄板极限 | `a/h = 12.5 / 25 / 100` 的 `w_3D/w_K - 1` | `2.575e-2 / 6.347e-3 / 3.949e-4`，相邻比 **4.057 / 16.07** → 二阶 `O((h/a)²)` ✓ |

## 3. 计算结果（数字表，零手抄，源 `evidence.json`）

### 3.1 中心挠度随厚度（归一化到 Kirchhoff）

| a/h | `w_3D / w_K` | `w_FSDT / w_K` | FSDT 相对 3-D 误差 |
|---:|---:|---:|---:|
| 100 | 1.000395 | 1.000564 | +0.02 % |
| 50 | 1.001581 | 1.002256 | +0.07 % |
| 20 | 1.009944 | 1.014099 | +0.41 % |
| 10 | 1.040666 | 1.056398 | +1.51 % |
| 8 | 1.064583 | — | +2.21 % |
| 5 | 1.176881 | 1.225591 | +4.14 % |

链路顺序恒定成立：`w_K < w_3D < w_FSDT`（`a/h = 5,10,20,50` 全部实测，测试固化）。

### 3.2 FSDT→Kirchhoff 的一阶关系得到闭式确认

`a/h = 1000` 时实测 `w_FSDT/w_K - 1 = 5.639781e-6`，与 `p = D R/(κGh) = 5.639774e-6`
在 `1e-9` 相对意义下一致——即 `w_FSDT/w_K = 1 + p`（**不是**常见的 `1/(1+p)`，
后者只在 `O(p²)` 内相同；测试把这一区别钉住）。

### 3.3 HEX20 实体单元对三维弹性（`a/h = 10`）

| 网格 | 自由度 | 单元 | `w_FE` [m] | 相对 3-D 精确 | 耗时 |
|---|---:|---:|---:|---:|---:|
| 4×4×2 | 735 | 32 | 1.440445e-4 | **−1.224 %** | 9.9 s |
| 6×6×2 | 1491 | 72 | 1.454043e-4 | **−0.291 %** | 19.7 s |
| 8×8×3 | 3429 | 192 | 1.457～e-4 | **−0.091 %** | 40.2 s |

另：`a/h = 5`（6×6×2）**−0.309 %**；`a/h = 20`（6×6×2）**−0.640 %**。
三档加密单调收敛到精确解，且 `8×8×3` 后残差已 < 0.1 %。

### 3.4 厚度方向应力：FSDT 不能表达的部分

中心点 `(a/2, b/2)` 处 `a/h = 10`：

* `σ_xx(z)` 相对"线性分布假设"的最大偏差（相对顶面幅值 **20.04 MPa**）= **1.18 %**；
* 中面 `σ_xx(0)/σ_xx(+h/2)` = **0.36 %**（不为零：载荷只加在顶面，三维解在 `z` 向并非严格反对称）；
* 顶/底奇偶性残差 `|σ_xx(-h/2) + σ_xx(+h/2)|/|σ_xx(+h/2)|` = **0.83 %**；
* FSDT 的横向剪切为常数 `τ_xz = 1.592e5 Pa`，而三维解在该点**解析为零**
  （`τ_xz ∝ cos(αx)`，`x = a/2` 处为零）——见 §5 局限。

## 5. 注意点（坑与局限）

1. **形函数索引坑（本单实际踩到）**：HEX20 的 20 个节点是 8 角点 + 12 边中点，
   边中点按 `_EDGES` 顺序：节点 **8–15 是水平棱中点、16–19 是竖直棱中点**。
   顶面 `t = +1` 的非零形函数是 `{4,5,6,7,12,13,14,15}`。第一版误写成
   `{4,5,6,7,16,17,18,19}`，载荷被加到竖直棱中点上 —— 结果收敛到一个**错误的多重网格
   稳态值**（−125 %、−130 %、−131 %，"随加密不改善"），这种"稳定地错"最容易骗过
   "看起来有收敛趋势"的检查；最终由总载荷 `Σ F_z` 与期望 `−q0·4a²/π²` 的对比暴露。
2. **三维解不是严格反对称的**（§3.4）：因为压力只作用在顶面，中面 `σ_xx ≠ 0`。
   任何"对称取半模型"的做法都必须把这一项作为已知偏差披露，不能默认对称。
3. **边上存在非零面内剪切支反力**（`2.987·q0`）：剪切膜口径的必然结果。若把该边换成
   自由或固支，双正弦不再精确，本锚点不适用。
4. **`τ_xz` 取样点选错**：证据脚本在板中心取 `τ_xz` 剖面，该点解析为零，因此
   `τ_xz_peak_over_q0` 字段（1.5e-16）**没有物理含义**，不能当作"三维剪切峰值"引用；
   正确取样点在 `x = 0`（或 `a`）的 `y = b/2` 边中点。列为未结项，见 §7。
5. **适用范围**：单层各向同性、线弹性、小变形、双正弦载荷、剪切膜边。
   叠层/热/大变形/局部载荷（需 Fourier 叠加，正交性丢失后边条件不再精确）不覆盖。
6. **`κ = 5/6` 是参考值口径**，不是"真值"；FSDT 误差随 `a/h` 下降到 0.02 %（`a/h = 100`），
   上升至 4.14 %（`a/h = 5`），任何用 FSDT 当"验收基准"的场合必须先看这一列。

## 7. 建议总账条目

`GAP-FEM-PLATE-3D-EXACT` — 厚板三维弹性锚点（域：TensorFEM / 板壳）。
量化验收：①3-D 精确解自检 `div σ` 相对 < 1e-6；②薄板极限 `O((h/a)²)`，相邻细化比 4±20 %；
③HEX20 于 `a/h = 10` 收敛到 < 0.5 %；④FSDT 相对 3-D 误差在 `a/h ∈ [5,100]` 单调有表；
⑤`τ_xz` 剖面对比改在边中点 `x = 0, y = b/2` 重采样（**已闭环，见 §8**：峰值 `2.3834 q0` @ `z=0`，`peak/(V_x/h)=1.4975`，抛物线 1.5 因子 0.166 %，`∫tau_xz dz=V_x` Richardson `1.0e-12`，中心负对照 `1.5e-16`，`tests/test_plate_3d_exact_shear_probe.py` fail-closed 锁死）。

## 8. 遗留项闭环：边中点横向剪切剖面（m16017）

§5.4 的取样点欠账已结。新脚本 `benchmarks/plate_3d_exact_shear_probe.py`
（数字程序化写入 `docs/assets/plate_3d_exact/shear_probe.json`，图
`docs/assets/plate_3d_exact/fig5_shear_section.png`）在**边中点** `(x=0, y=b/2)`
重采样，`a/b=1, a/h=10, q0=1e6 Pa`：

| 关键量 | 数值 | 基准 | 误差 | 是否 < 3 % |
|---|---|---:|---:|---|
| `tau_xz` 峰值 | `2.383374 q0` @ `z=0` | 板理论抛物线 `1.5·V_x/h` | `0.166 %` | **是** |
| 峰值位置 `z/h` | `0.0000` | 中面（抛物线顶点） | `0` | **是** |
| `∫ tau_xz dz` | `-1.591539e5 N/m` | `V_x = q0·alpha/(alpha²+beta²) = 1.591549e5` | `6.3e-6`（梯形）/ `1.0e-12`（Richardson） | **是** |
| 对偶剖面 `tau_yz` 峰值 | `2.3834 q0` | 同 `tau_xz`（方板） | 逐位相同 | **是** |
| 中心负对照 `|tau_xz|/q0` | `1.5e-16` | 0（解析恒零） | — | — |

旧 bundle 的 `tau_xz_peak_over_q0 = 1.5e-16` 由此定谳为**取样点伪值**：双正弦载荷的
剪应力 `tau_xz ∝ cos(alpha x) sin(beta y)` 在板中心恒零，极值在四边中点。

物理判定：三维剪应力沿厚度为**抛物线**、峰值在中面，板理论均值 `V_x/h` 比真峰值低
**33.2 %**（`1 - 1/1.4975`）。FSDT 的常值剪应力**不能**用于表面/界面剪切强度评估，
工程取值须乘 `3/2`（或改用三维/高阶剪切变形模型）。`∫tau_xz dz = V_x` 残差为舍入级，
说明该剖面在量纲与系数上没有自由度可调，不是拟合结果。

符号约定：本解 `tau_xz = -d psi_x/dz`，积分与 `+V_x` 反号；脚本同时记录带符号积分与
量值残差，避免用取绝对值掩盖符号错误。

### 8.1 注意点 / 未结项

- 取样点 `(0, b/2)`、`(a/2, 0)` 只对双正弦载荷成立；换成局部压力/点载后必须重算取样点；
- 本项只闭合**解析解自身的取样口径**，不评价 HEX20 离散误差（那是 §3 的位移口径）；
- 仍未结：`tau_xz` 逐点剖面的**有限元恢复**误差无独立对照（节点外推在中面附近因奇偶性
  丢失精度），需 Barlow/Gauss 外推恢复场，本次不做。
