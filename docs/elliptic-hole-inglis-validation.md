# 椭圆开孔应力集中（Inglis）：开孔欠账从「圆孔」推广到「椭圆孔」

**Status:** verification report（把已合并的平面应力生产路径对解析基准复核）
**Repository:** TensorFEM · **Module:** `tensorfem.elliptic_hole`（新）
**Evidence:** `benchmarks/elliptic_hole_reference.json`（脚本直出）、`tests/test_elliptic_hole_reference.py`（36 项）、
图 `docs/assets/elliptic_hole/*.png`（4 张）

## 1. 案例介绍（物理背景 / 几何 / 参数）

船体开孔绝大多数**不是圆孔**：舱口角隅、人孔、通海阀箱唇口、管系贯穿件常是椭圆/长圆
（obround/oval）。此前 TensorFEM 的开孔证据链只有两个口径：

* `docs/kirsch-hole-stress-concentration.md`：无限大板 + **圆孔**，`K_t = 3`；
* `docs/finite-width-hole-howland.md`：有限宽板 + **圆孔**，净截面 `K_tn`。

两份文档都在 §5 留下同一条欠账：「椭圆孔/正交异性板/裂纹孔未覆盖，`K_t = 3` 只对圆孔成立」。
这条欠账有直接的工程代价——同一净开孔面积下，长圆孔相对圆孔的峰值应力可以差 2–3 倍：

| `semi_y/semi_x`（横向半轴/纵向半轴） | 1 | 1.5 | 3 | 1/1.5 | 1/3 |
|---|---|---|---|---|---|
| 精确 `K_t = 1 + 2·semi_y/semi_x` | 3.0 | 4.0 | 7.0 | 2.333 | 1.667 |

沿用 `K_t = 3` 在 `semi_y/semi_x = 3` 时低估 **133%**，在 `1/3` 时高估 **80%**。

几何与参数（四分之一模型，孔心在原点，远场单轴拉伸 `T` 沿 `x`）：

| 参数 | 符号 | 取值 |
|---|---|---|
| 沿载荷半轴 / 横向半轴 | `semi_x` / `semi_y` | 算例 A `1.5 / 1.0`（`K_t=2.333`）、算例 B `0.5 / 1.5`（`K_t=7`）；扫掠 `m∈[-0.6,0.6]` |
| 远场拉应力 | `T` | 1.0（应力按 `T` 归一） |
| 弹性模量 / 泊松比 | `E`, `ν` | 1.0 / 0.30（平面应力） |
| 外部边界 | `\|ζ\| = ρ₀` | 共焦椭圆 `ρ₀ = 5`（**精确面力**，无截断误差） |
| 网格 | — | Q4 双线性，`(θ,ρ)` 结构网格：θ 两端 Chebyshev 加密（两个尖端必在节点上），ρ 向孔边指数加密 `grading=3` |
| 网格级 | `n_θ = n_ρ` | 24 / 32 / 40 / 48（自由度 1250 … 4802） |
| 对称条件 | — | `θ=0`（载荷轴）上 `u_y=0`；`θ=π/2`（横向轴）上 `u_x=0` |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**(A) 基准本身先自证：解析解是推导出来的，不是拟合的。**
用 Joukowski 型映射 `z = ω(ζ) = R(ζ + m/ζ)`（`|m|<1`，`ω'(ζ)=R(1-m/ζ²)` 在 `|ζ|>1` 无零点）
把单位圆外映成椭圆外：`semi_x = R(1+m)`、`semi_y = R(1-m)`，即
`R=(semi_x+semi_y)/2`、`m=(semi_x-semi_y)/(semi_x+semi_y)`。`m>0` = 沿载荷方向拉长，
`m<0` = 横向拉长（尖端在载荷轴上），`m=0` 退化为 Kirsch —— **一个公式族覆盖两个方向**。

Kolosov–Muskhelishvili 势取
```
phi(ζ) = (T R/4) [ ζ + (2-m)/ζ ]
psi(ζ) = (T R/4) [ 2/ζ - 2(1-m)² ζ - 2ζ³ ] / (ζ² - m)
```
系数**不是**从文献抄的：把无面力条件 `phi + ω·conj(phi')/conj(ω') + conj(psi) = 0` 乘上
`(1-mσ²)` 得到 Laurent 多项式恒等式，要求 `psi(1/σ)` 只带远场 `1/σ` 奇性（不出现 `σ⁻²` 及更深），
于是 `a₁ = 2-m` 被唯一确定，`psi` 随即可闭式解出。随后两条与 `m` 无关的恒等式把结果钉死：

1. 载荷轴尖点 `(±semi_x, 0)`：`σ_yy = -T`（**与 `m` 无关**，和圆孔同值）；
2. 横向尖点 `(0, ±semi_y)`：`σ_xx = T(1 + 2·semi_y/semi_x)`（经典 Inglis 因子）。

实测（`benchmarks/elliptic_hole_reference.json` → `analytic`）：
孔边最大面力 `2.6e-14·T`（`m∈{-0.6,-0.3,0,0.3,0.6}` 全部 ≤3e-14，共 721 点/工况）；
两个尖点恒等式残差 `<1e-12`；`m→0`（取 `m=-5e-7`）与 `tensorfem.kirsch_hole` 的
应力/位移差 `4.6e-06` / `2.6e-06`（同仓另一个已独立锚定的解析解）；
把位移数值微分后代入本构，与应力场差 `5.0e-10`（`×E/K_t`，无量纲化）。

**(B) 为什么这是「验证」而不是「FE 对 FE」。** 外部边界取**共焦椭圆** `|ζ|=ρ₀`，
其上面力由同一解析解给出；两条对称线上的约束也是精确解自身满足的。于是椭圆环域
`1≤|ζ|≤ρ₀` 的边值问题的唯一解就是该解析解——没有 `b=10a` 那种远场近似，误差只有有限元离散。

**(C) 生产路径原样调用。** `annulus_model()` 组装 `ContinuumModel(plane='stress', element_type='q4')`，
`solve_continuum` 稠密求解；一致节点载荷用 4 点 Gauss 沿边积分 `∫Nᵀ t ds`（边度量由映射精确给出）。
应力恢复是**独立第二实现**：模块内自写 Q4 `B` 矩阵，先与生产存盘单元中心应力交叉校验
（`5.2e-14`，48 级），再用 2×2 Gauss→节点双线性外推取尖点峰值（单元中心值会低读 ~10%）。
静力学检查：`Σ(施加 + 反力) = 1.0e-14`（相对）；`θ=π/2` 对称边上的 x 反力与精确面力合力差
`0.020%`（48 级）。

## 4. 误差判定（逐项回答「是否 < 3%」）

| 判定项 | 结果 | 是否 < 3% |
|---|---|---|
| **算例 A（`K_t`=2.333，长圆孔）尖点峰值** | `n`=40 → 2.74%；`n`=48 → 2.29%；Richardson → 0.000% | **是**（`n≥40` 起；`n`=24/32 为 4.55%/3.42%，粗网格失败项保留） |
| **算例 B（`K_t`=7，尖椭圆孔）尖点峰值** | `n`=48 → 8.87%，观测阶 0.95，Richardson → 0.000% | **否**（honest FAIL：4802 自由度内未达 3%，见 §5） |
| 载荷轴尖点 `σ_yy = -T` | `n`=48 → 0.66% | **是** |
| 位移场 | 最大相对误差 1.9e-04（A）/ 4.1e-04（B），二阶收敛 | **是** |
| 静力学 | 力平衡 1.0e-14；对称边合力 0.020% | **是** |
| 解析参考自身 | 孔边无面力 ≤3e-14；尖点恒等式 <1e-12；Kirsch 极限 4.6e-06；本构 5.0e-10 | **是**（机器精度级） |

结论口径：**生产 Q4 平面应力链路对长圆孔（`K_t ≲ 2.34`）已在可负担网格上进入 3% 门限**；
对**尖椭圆孔（`K_t`=7，尖点曲率半径 = `semi_x/3`）在 4802 自由度内不达标**，这不是实现缺陷，
是 Q4 全积分在一阶尖点边界层上的固有收敛率（观测阶 0.95，与 Howland 报告里 `L/W` 带宽、
Kirsch 报告里 `n≥24` 才进 3% 的经验同一量级）。因此本单把能力边界写成**显式门限**：
`(semi_x/semi_y ≥ 0.63)` 的常规长圆孔可用；更尖的开孔必须有局部加密/奇异单元，否则峰值不可引用。

## 5. 注意点 / 局限

- **口径**：`K_t = 1 + 2·semi_y/semi_x` 中 `semi_y` 是**垂直载荷**的半轴、`semi_x` 是**沿载荷**的半轴；
  反过来读会得到 `7` 而不是 `1.667`（`semi_x/semi_y=3`）。Howland 报告踩过同类的毛/净截面口径坑，
  本模块在 docstring、测试与 JSON 三处都把方向写死（`transverse_tip`/`load_axis_tip` 两个属性）。
- **尖点收敛慢是物理 + 数值双重原因**：`K_t`=7 时峰值为远场的 7 倍，边界层厚度 ~ `ρ_tip/2 = 0.083`，
  而 48 级第一层径向单元厚度 0.043、尖点切向单元 0.010 —— 只有 2 层单元跨越边界层，
  因此单元中心值低读、节点外推偏高，误差 8.87% 且一阶收敛。要点是**不要**用粗网格的峰值去校核结构强度。
- **只覆盖平面应力、小应变、各向同性、单轴远场**：不含壳体、塑性、接触、几何非线性；
  双轴/剪切远场、多孔干涉、含裂纹孔、正交异性板仍未覆盖（`m` 家族只覆盖单轴拉伸；双轴可由
  两个 `±m` 解叠加，但本单未验收该叠加的实现）。
- **外部边界是共焦椭圆而非矩形/直边**：这是为了让面力「零截断」；真实板格的直边 + 有限宽效应
  仍需 Howland 那一类净截面口径，两者互补而不是替代。
- **生产路径用稠密求解**：最大 4802 自由度（单次求解 ~1 s），不是稀疏求解器缩放测试。
- 本单未改动任何求解器代码（只新增参考解 + 案例 + 测试），因此**没有**重新认证任何工业能力，
  也不改变 `docs/benchmark-qualification-status.md` 里 `stress_accuracy_qualified` 的既有判定。
