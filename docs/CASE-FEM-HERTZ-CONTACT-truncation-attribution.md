# CASE-FEM-HERTZ-CONTACT — 压入深 δ 的 ~1% 平台值归因：有限域截断律 + 无接触算法复现

【锚点=CASE-FEM-HERTZ-CONTACT】【本页由 `benchmarks/verified/fem_hertz_contact_loadcontrol/make_attribution_doc.py` 从 `result.json` 与 `truncation_law.json` 程序化生成，数字零手抄】

## 1. 案例与问题

| 项 | 值 |
|---|---|
| 参考解 | Hertz 1882 J. reine angew. Math. 92:156; Johnson 1985 Contact Mechanics 4.2 DOI:10.1017/cbo9781139171731 |
| 解析式 | `a = (3 P R / (4 E*))^(1/3)`，`δ = a²/R`，`E* = E/(1-ν²)`（刚性抛物压头 / 弹性半空间）|
| 算例池判据 | a 与 δ 均 < 3% |
| 参数 | 无量纲：长度 /R，力 /(E R²)；SI 等效 R = 10 mm、E = 0 GPa、ν = 0.3 |
| 接受模型 | h/a = 0.0075，域深 96a，ALM ρ/(E/a) = 1 |

**留下的问题（本单要解的）**：既有证书里 δ 误差在加密下**不收敛**，停在 -1.0107%（h/a = 0.03 → 0.015 → 0.0075：-0.9957% 附近不动）。饱和的误差不是离散误差，原证书无法说明它是「网格不够」「接触算法没收敛」还是「模型定义差异」——而三者在工程上含义完全不同。

## 2. 做法

两条互相独立的代码路径：

1. **接触路径（原有）**：载荷控制 ALM 轴对称接触求解，把域深 D（以 a 计）当参数扫 24a / 48a / 96a / 144a / 192a，每个 D 记录 δ 与 a 的误差。
2. **静态路径（本单新增，`truncation_law.py`）**：**不加接触算法**——直接把赫兹解析面力 `p(r) = p₀√(1-(r/a)²)` 施加到同一套网格上，解一次线性系统 `K u = f`，读轴心挠度 `w(0)`，与 `δ = a²/R` 比。此路径没有任何 active set、没有 ALM、没有载荷迭代，若它复现同样的误差，则误差与接触算法无关。

分析模型：固定 h/a 时，误差对域深应当是 `err(D) = e_inf + c/D`（外边界固定造成的 O(1/D) 柔度扰动），`e_inf` 即无界半空间极限。用最小二乘拟合 (e_inf, c)，并把 D = 144a、192a 留作**样本外预测检验**。

## 3. 结果

### 3.1 截断律（接触路径，a/R = 0.05，h/a = 0.015）

| D/a | 单元数 | δ 误差 [%] | 1/D 律预测 [%] | 残差 [pp] |
|---:|---:|---:|---:|---:|
| 24 | 9040 | -2.8998 | -2.8989 | +0.0009 |
| 48 | 9040 | -1.6391 | -1.6408 | -0.0017 |
| 96 | 9040 | -1.0107 | -1.0118 | -0.0011 |
| 144 | 9040 | -0.8024 | -0.8021 | +0.0003 |
| 192 | 9040 | -0.6989 | -0.6973 | +0.0016 |

- 拟合结果：`err(D) = -0.3827% -60.3872%/D`，五点最大残差 **0.0017 pp**（判据 ≤ 0.01 pp）。
- **样本外检验**：只用 D = 24a/48a/96a 拟合，预测 144a、192a：D=144a 预测 -0.8002% vs 实测 -0.8024%；D=192a 预测 -0.6953% vs 实测 -0.6989%，最大偏差 **0.0036 pp**（判据 ≤ 0.05 pp）。

### 3.2 无界域外推与「−1%」的分解

- 外推到 D → ∞：**δ 误差 = -0.3827%**（判据 |e_inf| ≤ 1%，即 3% 算例池门的 2.6 倍余量内）。
- 接受模型（D = 96a）实测误差 -1.0107% 中，**-0.6290 pp 是有限域截断**（占比 62%），其余 -0.3827% 是离散/模型残差。
- 因此 D = 192a 的实测 -0.6989% 不是「变好了」，而是截断项从 -0.6290 pp 降到 -0.3145 pp。

### 3.3 残余量的性质：与网格、远场加密无关，且与接触算法无关

| 对比 | 值 [%] | 判定 |
|---|---:|---|
| δ 误差，h/a = 0.015，D = 192a | -0.6989 | — |
| δ 误差，h/a = 0.0075，D = 192a | -0.6981 | 加密 2 倍，差 0.0008 pp |
| δ 误差，远场 26 → 52 列，D = 192a | -0.6963 | 差 0.0026 pp |

**静态路径（无接触算法）**，同一网格、同一刚度矩阵，只施加解析赫兹面力：

| 0.015 | 96 | 9040 | 深度阶梯 | -1.3281 |
| 0.015 | 192 | 9040 | 网格阶梯 @ D=192a | -1.0163 |
| 0.015 | 192 | 9040 | 网格阶梯 @ D=192a | -1.0163 |
| 0.015 | 192 | 10080 | 远场加密 | -1.0137 |

- 静态路径独立得到 `err(D) = -0.6996% -60.4251%/D`（最大残差 0.0019 pp）。与接触路径的斜率 -60.3872%/D 相比差 0.0379 pp——**截断项与接触算法无关**。
- 结论：δ 的 ~1% 平台值 = 有限域截断（可建模、可外推、O(1/D)）+ 约 0.4% 的离散/模型残差；**接触算法（ALM + active set）在 δ 上没有可测误差**（e_contact(ALM) ≤ 载荷残差 1e-12 量级，且静态路径复现同一误差）。

## 5. 注意点 / 局限

1. **被否定的假设（诚实记录，未采用）**：曾想把压力场 `p² = c₀ + c₁r²` 最小二乘拟合的接触半径估计量升为主估计量——它在最细网格上给 a 误差 −0.046%（比线性零点法的 −1.75% 好 30 倍）。但同一次求解中 δ 误差仍是 -1.0098%（若场真是赫兹场，a 准到 0.05% 则 δ 只能差 0.1%），且 `p²` 拟合的**形状残差**高达 8.4%（实测于 scratch 探针）。二者矛盾说明该估计量是**边缘节点抖动的补偿性过拟合**，不是更准的 a；故主估计量仍是形状无关的线性零点法，拟合估计量只作旁证。
2. **样本外检验是二维的**：1/D 律只在 a/R = 0.05、h/a = 0.015 一带扫描并验证（另在 h/a = 0.0075、D = 192a 复算一次：-0.6981%，与律预测 -0.6973% 相差 0.0009 pp）。更大 a/R 未扫描，律的系数 c 可能是载荷相关的。
3. **e_inf 的物理来源仍未定名**：它是网格无关、远场无关的固定偏差，静态路径在 e_inf 层给出更负的值（网格趋势 h/a=0.03: -1.4559%、h/a=0.015: -1.3310%、h/a=0.0075: -1.2470%），说明接触场的压力分布形状部分补偿了离散柔度误差。本页只声明「已定位到边界/离散层面，不在接触算法」，不宣称知道它的最终成因。
4. **判据未改**：本单没有松动任何既有闸门阈值；新增闸门全部是本次归因的产物，阈值在任何求解之前写入 `CRITERIA`（3% 算例池、0.01 pp 律残差、0.05 pp 样本外、1% 外推、0.05 pp 网格/远场无关性）。
5. **证书自包含性修复**：原 `result.json` 的 `artifacts.raw_dump` 指向 `artifacts/contact_hertz_loadcontrol/results.json`，该文件既未提交也不在盘上，文档承诺的 `--from-dump` 零算力复算实际不可用。现已把原始 dump 提交到 `benchmarks/verified/fem_hertz_contact_loadcontrol/results_dump.json`，并由 `tests/test_case_fem_hertz_truncation.py` 离线重判全部闸门，验证与 `gates_verified.json` 逐条一致。
