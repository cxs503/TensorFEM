# 离心体力载荷（旋转盘）验证：TensorFEM 新增旋转体力通道对 Timoshenko 闭式解

本报告清偿的是一处**能力缺口**而不是一处精度缺口：在本单之前，TensorFEM 仓库中
`centrifugal` / `rotating` / `self_weight` 关键字出现次数为 **0**，二维连续体求解器
`tensorfem.continuum` 只接受**节点力**，任何旋转部件的算例都只能手工拼装载荷向量，
且没有任何解析锚。本单新增 `tensorfem.rotating_disk`（一致离心体力向量 + 极性 Q4
网格 + Timoshenko 闭式解 oracle + 组装式基准），并用该闭式解在四个网格上复核求解器。
所有数字由 `scripts/verify_rotating_disk.py` 程序化生成，落盘于
`docs/benchmarks/tutorials/rotating-disk-verification.json`，无一手抄。

---

## 1. 案例介绍

### 1.1 物理背景

旋转部件（螺旋桨轴系、飞轮、涡轮盘、离心式分离机转鼓）的应力由**离心体力**主导：
单位体积体力 `b = ρ ω² x` 随半径线性增长，指向转轴。船海结构侧对应的是轴系与
旋转机械的强度/疲劳评估，而求解器侧它是一条独立的载荷通道——它不属于压力边载，
也不属于节点力，必须由形函数一致积分得到，否则（例如用质量集中折算）会引入
与网格无关的系统性偏差（本报告 §3.2 给出量化）。

薄圆盘（端面自由）是**平面应力**问题，长圆柱（轴向应变被约束）是**平面应变**问题；
两者都有 20 世纪 30 年代以来的闭式解，因此天然适合做验证锚。

### 1.2 几何与参数表

| 项目 | 取值 |
|---|---|
| 内半径 a | 0.25 m（主算例）；近实心盘 0.025 m |
| 外半径 b | 0.50 m |
| 厚 t | 0.02 m |
| 密度 ρ | 7850 kg/m³（钢） |
| 角速度 ω | 100 rad/s（955 rpm） |
| 弹性模量 E | 200 GPa |
| 泊松比 ν | 0.30 |
| 单元 | 全积分 Q4（2×2 Gauss），四分之一模型 + 两条对称轴（`u_y=0` @ y=0，`u_x=0` @ x=0） |
| 网格 | 径向 × 环向 = 4×24 / 8×48 / 12×72 / 16×96（近实心盘 8/12/16 × 6n，径向几何分级 1.15） |

**闭式解**（Timoshenko & Goodier, *Theory of Elasticity*, 3rd ed.,「Rotating disks」；
Timoshenko, *Strength of Materials*, Part II）。令
`C = (3+ν)/8 · ρω²`、`k = (1+3ν)/(3+ν)`（平面应力）：

```
σ_r(r)     = C (b² + a² − a²b²/r² − r²)
σ_θ(r)     = C (b² + a² + a²b²/r² − k r²)
u_r(r)     = r (σ_θ − ν σ_r) / E
```

平面应变（长圆柱，ε_z=0）同结构，`C = (3−2ν)/(8(1−ν)) · ρω²`、`k = (1+2ν)/(3−2ν)`，
位移内需计入被抑制的轴向应力 `σ_z = ν(σ_r+σ_θ)`。

## 2. 怎么做的

### 2.1 oracle 先自证，再当裁判

闭式解本身先被三条**互相独立、且唯一确定解**的命题反查（`tests/test_rotating_disk.py`，
三种泊松比 ν∈{0, 0.3, 0.45} × 两种平面假设）：

1. **径向平衡** `dσ_r/dr + (σ_r − σ_θ)/r + ρω² r = 0`：中心差分残差 /(ρω²b) ≤ 7.5e-11；
2. **应变协调** `du_r/dr = ε_r`：以 2001 点细网格中心差分复核，相对偏差 4.5e-7（差分截断）；
3. **自由边界** `σ_r(a) = σ_r(b) = 0`：逐位为 0。

三条同时成立 + 边界条件即可唯一确定该边值问题，故它不能"迁就"有限元结果。

### 2.2 载荷向量与求解

* 一致体力：`f_e = ∫ Nᵀ ρω² x dV`。Q4 上被积函数是二次多项式，**2×2 Gauss 精确**；
  `tests` 里用任意畸变四边形验证「单元节点力之和 = ρω²·A·x̄」到 1e-12，其中面积与
  形心用独立的多边形公式（shoelace），不使用模块自身的积分。
* 四分之一模型的两条对称轴与精确解**兼容**（精确位移纯径向，对称轴上分量恰为 0），
  因此可以直接逐自由度比较位移，不存在"夹持点与真解冲突"的伪误差。
* 后处理：单元中心笛卡尔应力旋转到 (r, θ) 方向后再与闭式解在同半径处比较。

### 2.3 判据（先于动手）

* 残差判据：`< 3%`（相对 L2，单元中心场）、峰值逐点 `< 3%`、位移 `< 3%`；
* 附加独立闸门：外力功 = 应变能（1e-12）、整体平衡残差（1e-12）、对称面反力与解析
  合力 `ρω²t(b³−a³)/3` 的一致性（< 0.5%），以及与闭式解无关的**收敛阶**检查；
* **闸门有牙**：两个"看似合理"的错误实现必须被同一判据打穿（见 §3.2）。

## 3. 计算结果

### 3.1 主算例（平面应力，a/b=0.5）

| 网格 | 单元 | σ 相对 L2 误差 | 峰值 σ_θ 误差 | 位移相对 L2 误差 | u_r 峰值误差 |
|---|---:|---:|---:|---:|---:|
| 4×24 | 96 | 0.4242% | 0.3324% | 0.2915% | 0.3810% |
| 8×48 | 384 | 0.1072% | 0.0814% | 0.0737% | 0.0991% |
| 12×72 | 864 | 0.0477% | 0.0358% | 0.0327% | — |
| 16×96 | 1536 | **0.0269%** | **0.0200%** | **0.0184%** | 0.0250% |

观测量级（16×96）：闭式峰值 `σ_θ,max = 17.049 MPa`（位于 r=a，自由内缘）、
`σ_r,max = 2.024 MPa`（r≈0.35 m）、`u_r,max = 21.31 μm`；有限元单元中心场峰值
`σ_θ = 16.495 MPa`。单元中心采样天然到不了 r=a 的自由缘，故比解析峰值低 3.24%——
这是**采样口径**而非求解误差，报告不把中心场峰值当作边缘峰值认证（边缘峰值需外推，
本单未认证）。

独立闸门（16×96）：外力功与应变能相对差 4.9e-15；整体平衡残差 2.2e-14；
对称面反力 vs 解析合力 0.007%；载荷向量合力 vs 解析积分 0.007%。

### 3.2 负控（闸门牙齿）

| 变体（同一代码路径，16×96 或 8×48） | σ 相对误差 | 结论 |
|---|---:|---|
| 一致体力（接受态） | 0.0269%（16×96） | 通过 |
| 质量集中折算载荷（`lumped=True`） | **48.04%** | 被打穿：一致积分不可省 |
| 载荷 ω 与参考 ω 不匹配 5% | **10.19%** | 被打穿：判据对 5% 量级失配敏感 |
| ω=0 | 0（应力与位移逐位为 0） | 平凡情形一致 |

收敛阶：由 12×72 与 16×96 两点反算 **p = 1.997**（Q4 位移型单元理论二阶），说明误差
在渐近区、不是偶然对上的。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

1. **平面假设必须显式传参**：第一版 `solve_rotating_disk(plane="strain")` 忘了把
   `plane` 透传给 `ContinuumModel`，于是拿平面应力解去对平面应变解，位移误差
   12.6%、应力 2.3%——看上去"几乎通过"，实则口径错。修正后为 0.029%。这类"半对"
   结果最容易被误判为精度不足，必须查口径而不是查网格。
2. **集中载荷不可用于体力**：质量集中等价于把体力按节点质量一次性投到 4 个角点，
   对随半径线性增长的载荷直接引入 48% 误差；一致积分（2×2 Gauss，对本被积函数精确）
   是唯一可接受路径。
3. **四分之一模型的对称面反力不是零**：对称面上的反力恰好等于该四分之一区域的净离心
   力（+x 方向 5.72e4 N）。最初把"反力应≈0"写成判据是错的，正确判据是反力与解析
   合力 `ρω²t(b³−a³)/3` 一致（0.007%）。
4. **单元中心采样不含自由缘峰值**：内缘 σ_θ 峰值需外推，本单只认证中心场与位移。
5. **不覆盖**：三维离心体力（HEX8/TET）未实现；旋转软化（离心预应力几何刚度）未计入，
   即本模块是**单次线性**分析，不能用于临界转速/失稳判定；温度相关的 E、塑性、蠕变、
   陀螺效应（非轴对称旋转）均不在范围内。
6. **算力纪律**：本机 load15 ≈ 122/128 核，故整单只用 2D 稠密求解（最大 16×96 → 3281
   节点、6562 自由度），未起三维网格。

## 5. 误差判定（逐项 vs 基准，显式回答「是否 < 3%」）

| 关键量 | 基准 | 最细网格误差 | 是否 < 3% |
|---|---|---:|---|
| 环向应力 σ_θ(r) 全域（单元中心，相对 L2） | Timoshenko 闭式解 | 0.0269% | **是** |
| 径向应力 σ_r(r) 全域（同上） | 同上 | 含于上述 0.0269%（合并范数）；逐个峰值 0.0200% | **是** |
| 环向应力峰值（单元中心场） | 同上 | 0.0200% | **是** |
| 径向位移 u_r 全节点（相对 L2） | 同上 | 0.0184% | **是** |
| 平面应变 σ 场 | 长圆柱闭式解 | 0.0291% | **是** |
| 近实心盘 σ 场（a/b=0.05） | 同上（含 a 的闭式解） | 0.327% | **是** |
| 外力功 vs 应变能 | 能量守恒（与闭式解无关） | 4.9e-15 | **是** |
| 对称面反力 vs 解析合力 | `ρω²t(b³−a³)/3` | 0.007% | **是** |
| 收敛阶 | 理论 p=2 | 1.997（相对偏差 0.16%） | **是** |

结论：新增的离心体力通道在二维 Q4 路径上对 Timoshenko 闭式解的全部可观测物理量都
**< 3%**（实际 < 0.05%），并以负控证明该判据不是空门。**未认证**：三维离心体力、
旋转软化预应力、自由缘应力峰值的网格外推。
