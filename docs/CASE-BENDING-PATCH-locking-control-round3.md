# CASE-BENDING-PATCH, round 3 — the locking control becomes a law, not a number

Decision record for round 3 of the `fem_bending_patch` anchor. Generated by
`gen_bending_patch_round3_note.py` from `result.json` / `gates_verified.json`; no
number below is hand-typed.

## 1. What was wrong with round 2

Round 2 repaired the Poisson cross-check and left this negative control in place:

> `locking_control_patch` = 0.0211 against the threshold 0.02 (`>=`, PASS) — a 5.5 % margin.

Two structural problems:

1. **The regime is the friendly one.** Every graded patch case runs at `t/L = 1`,
   i.e. `h/t = 0.25`. Bilinear-plate locking scales as `(h/t)^2`, so a thick plate
   is exactly where the effect is *weakest*: the control clears its threshold only
   because it is applied where locking is small.
2. **A single number cannot separate mechanisms.** 2.1 % could be a small
   interpolation error (a defect) or weak locking (a real property). A control that
   is one marginal number is not falsifiable in any useful sense.

## 2. Decision, alternatives, hypothesis

* **Decision**: leave the round-2 gate unchanged (never re-tune an existing
  threshold) and add a **thin-limit ladder** that grades the locking *law* with
  predeclared, physics-derived thresholds, plus the honest scope statement that
  follows from it.
* **Alternatives considered**
  - *(A) leave it alone*: cheapest, but leaves a 5 %-margin control as the only
    evidence that the gate set is discriminating.
  - *(B) tighten the round-2 threshold* (e.g. to 3 %): rejected — tuning after
    seeing the outcome, and it adds no evidence about the element.
  - *(C) replace it with the law-based ladder*: rejected as the *sole* basis — it
    would drop a graded quantity that already exists.
  - *(B+C, chosen)*: additive. The single-point control stays; the ladder pins the
    mechanism.
* **Hypothesis**: the spurious transverse-shear energy of the bilinear patch scales
  as `(h/t)^2`, so a locking element (2x2 shear integration) shows log-log slope 2
  and amplification `20^2 = 400` when the plate is thinned 20x at constant `h`, while
  a shear-robust element stays at round-off.
* **Metric / unit of analysis**: relative strain-energy error
  `|U_h - U_exact| / U_exact` of one patch case (`U_h = 1/2 u^T K u`) for one mesh
  family and one thickness. Graded mesh `n = 4`; replication `n = 8`.
* **Baseline / control**: the affine mesh family (its interpolant *is* shear-free,
  so any thickness dependence there would be a defect, not locking) and the 2x2
  `full` variant as the deliberate locking element.

## 5. What the ladder shows

* **Full (2x2) shear integration locks exactly as the law says.** Affine family:
  amplification 400.0, slope 2.0000 — the pure `(h/t)^2` law with *no fitted constant*, on two independent meshes. The negative control is now a
  prediction that could have failed.
* **MITC4 is shear-free in the thin limit**: 5.89e-13 at the thinnest plate, versus 6.3 for the locking element on the same mesh.
* **SRI is distortion-limited — a genuine limitation, recorded not hidden.** Exact
  on affine meshes at every thickness (1.0e-14), but on the distorted family its error follows the same law (slope 1.948) and reaches 26.144 % at `h/t = 5`. SRI cuts the constant by 24x relative to full integration; it does not remove the thin-plate
  limit on a general mesh.

## 6. Interpretation limits (and one honest FAIL)

* The graded quantity is the **relative strain-energy error**, which contains the
  spurious transverse-shear energy. It is a locking *indicator*, not a bound on the
  displacement error: the same SRI cases keep a field-displacement error of a few
  percent (`result.json`, `locking_scaling_summary.series`). No claim is made that
  the thin-plate displacement is 26 % wrong.
* **Honest FAIL, scoped**: the anchor's 2 % certification does *not* transfer to
  `h/t > 0.25`. At `h/t = 5` on a distorted mesh SRI is 26.144 % off in energy. This is now a `limitations`
  entry in `gates_verified.json`; the element recommendation for thin distorted
  plates is MITC4.
* `h` is *not* refined here. A thickness ladder at fixed `h` measures the locking
  exponent; it does not replace an `h`-convergence study (§5 covers that), and a
  combined `h`/`t` study at fixed `h/t` would be needed for asymptotic rates in the
  thin limit — outside this anchor.
* Round-off amplification: at the thinnest plate the exact energy is `(1/20)^3` of
  the thick-plate value, so a round-off-level relative energy error is ~`1e-13`,
  not `1e-16`. The declared floor (1e-10) is four orders above that, so
  `thin_limit_sri_affine` cannot pass by floating-point luck.
* One state is swept (the general `kappa = (1.0, 0.6, 0.4)e-3`). The pure-twist
  state carries no `kappa_y` and is thickness-insensitive by construction; it is not
  a substitute for the general state used here.
