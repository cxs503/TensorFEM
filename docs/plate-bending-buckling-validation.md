# 非均匀预屈曲应力下的板格屈曲：纯面内弯曲 k_b = 23.9 的独立验证

本单清偿 `docs/benchmark-qualification-status.md`「尚未闭环的工作」中明确列出的
**非均匀预屈曲应力**一项。此前 `tensorfem.plate_shear_buckling` 的已验证 Galerkin 引擎
只能表达**均匀**应力场（`K_x = ∫w,x²`、`K_xy = ∫2w,xw,y`），闭合案例仅有单轴压缩
（k = 4）与均匀剪切（k_s = 9.34 / 5.34）。本单新增 `src/tensorfem/plate_bending_buckling.py`，
把几何刚度推广到任意 `σ(y)` 剖面，并用文献值、独立离散与解析积分三重锚点判定其精度。

## 1. 案例与物理背景（①）

船体舷侧板格与甲板板格在中和轴附近同时承受总纵弯曲的拉/压两侧：沿板宽方向
（纵向加强材间距 b）的膜应力**线性变化**，且合力为零。该剖面正是纯面内弯曲：

| 参数 | 值 |
|---|---|
| 弹性模量 E | 2.1000e+11 Pa |
| 泊松比 ν | 0.3000 |
| 板厚 t | 0.0120 m |
| 板宽 b（加载边） | 1.0000 m |
| 弯曲刚度 D = Et³/12(1−ν²) | 3.32308e+04 N·m |
| 长细比 a/b 扫描 | 0.5 / 1.0 / 2.0 / 4.0 / 6.0 / 10.0 |
| 预屈曲应力 | σ_x(y) = σ_edge (1 − 2y/b)，σ_edge>0 为 y=0 边受压 |

对照基准：简支长板纯弯曲系数 **k_b = 23.9**（Timoshenko & Gere, *Theory of Elastic
Stability*, 2nd ed., §9.2；Bulson, *The Stability of Flat Plates*, 1970），
定义为 `N_x,edge,cr = k_b π²D/b²`；同一条带的均匀压缩仅 k = 4。二者 6 倍之差**全部**来自
预屈曲应力的非均匀性，因此若求解器把 σ(y) 悄悄换成宽度平均值，在这里会低估 6 倍且
现有任何锚点都发现不了。

## 2. 方法（②）

**(a) Galerkin（双正弦基，本仓已验引擎的推广）** 总势能
`Π(c) = cᵀK_b c − N cᵀK_σ c`，其中新增几何矩阵

`K_σ[(m,n),(p,q)] = δ_mp α_m (2/b) ∫₀^b σ(y) sin(nπy/b) sin(qπy/b) dy`

的 x 积分解析（`∫cos cos = a/2 δ_mp`），y 积分用复合 Gauss–Legendre 并按收敛加倍。
对线性剖面给出闭式

`∫₀^b (1−2y/b) sin sin dy = −(2b/π²)[((−1)^{n−q}−1)/(n−q)² − ((−1)^{n+q}−1)/(n+q)²]`（n≠q）、`0`（n=q），

对角线恒为零（零均值剖面的直接推论）。广义特征值问题 `K_b φ = N K_σ φ` 用共享的
不定铅笔求解器，入屈曲载荷取最小正特征值倒数。

**(b) 独立参考：无限长板 + y 向 C1 Hermite 单元** 本单另建一条**不共享代码路径**的参考：
取 a→∞、模态 `w = W(y) sin(kx)`，PDE 化为变系数 ODE，其能量泛函

`Π(W) = D∫(W''−k²W)²dy − k²∫σ(y)W²dy`

用三次 Hermite 单元在 y 向离散（`W = W'' = 0` 分别为本质/自然边界），无量纲化后为
`(Kb + 2K²Ka + K⁴Mc)W = Σ K² G W`，`Σ = σb²/D = k_b π²`；对半波长做黄金分割搜索取最小。
该泛函是真正的二次能量，离散刚度**天然正定**。

## 4. 注意点（⑤）

1. **基函数必须分辨屈曲波形**：临界半波长约 0.67 b，x 向基阶需约 `2a/b + 4` 项。
   `a/b=10` 而 `basis_x=10` 时结果被截断为 27.114（高估 13.6 %），
   `basis_x=16` 才回到 23.8818。该陷阱已被
   `test_long_panel_basis_must_resolve_the_buckle` 锁死，限定用脚本按 `max(basis, ⌈2a/b⌉+4)` 自动取基阶。
2. **本单发现的共享求解器缺陷（已修）**：`plate_shear_buckling._smallest_positive_from_symmetric_indefinite`
   原实现构造的是 `L⁻ᵀGL⁻ᵀ` 而非同余变换 `L⁻¹GL⁻ᵀ`。当弯曲矩阵 `K_b` 为对角阵
   （各向同性/正交异性且 D16=D26=0，即该模块交付过的全部算例）且 L 为对角阵时两者重合，
   故历史结论（k=4、k_s=9.34/5.34）不受影响，实测复跑未变（k_s 方板 9.3247、长板 5.4797）；
   但任何非对角刚度的铅笔都会解错。现改为正确形式并回归验证，同时新增
   `test_shared_pencil_solver_handles_a_non_diagonal_stiffness`（3×3 非对角铅笔的解析答案）。
   **这是"验证欠账"的典型形态：锚点选在被掩盖的参数域上，缺陷可以长期隐性存在。**
3. **1D 差分参考不可用（已弃用）**：最初用四点差分配点法写无限长参考，得到均匀压缩
   k=10（真值 4）并随加密发散——判据落点处第四差分的奇异模态使 `A` 近奇异。
   变分（Hermite）形式天然正定，是可靠路线。保留此记录以免后来者重复。
4. **适用域**：本结论限于四边简支、等厚、各向同性、弹性、线性预屈曲、均匀温度。
   不覆盖：加筋板的板-筋相互作用、弹塑性屈曲、面内剪切与弯曲组合、
   **壳体/板单元的几何刚度矩阵**（本单验证的是 Galerkin 能量引擎，而非 FE 初始应力矩阵）、
   残余应力与焊接缺陷。
5. 纯弯曲剖面零均值，几何矩阵对角为零且谱对称，最小正特征值需用不定铅笔求；若误用
   「最大特征值」路径会得到无意义结果。

## 5. 误差判定（⑥）

| 关键量 | 本文 | 基准 | 相对误差 | 是否 < 3 % |
|---|---|---|---|---|
| 长板纯弯曲 k_b（Galerkin, a/b=10） | 23.881813 | 23.9（Timoshenko & Gere） | 7.61e-4（0.076 %） | **是** |
| 长板纯弯曲 k_b（独立 Hermite） | 23.880627 | 23.9 | 7.94e-4（0.079 %） | **是** |
| 两法交叉（Galerkin vs 独立参考） | 23.881813 | 23.880627 | 4.97e-5 | **是** |
| 均匀压缩极限（Galerkin） | 4.000000 | 4.0 | 0（≤2.2e-16） | **是** |
| 均匀压缩极限（独立参考） | 4.000000 | 4.0 | <1e-8 | **是** |
| 闭式 vs 数值积分几何矩阵 | — | — | ≤1e-12 | **是** |
| 常数剖面 vs 已验单轴矩阵 | — | — | ≤1e-12 | **是** |
| a/b=1（非适用域，仅参照） | 25.52835 | 25.6（同文献） | 2.8e-3（0.28 %） | 是（但不作为判据） |

**负控**（证明锚点能失败）：把线性剖面替换为宽度平均的均匀应力，
得 k=4.000 vs 23.9（相对差 83.3 %），远超 3 % 门限——即"均匀化"错误必被本门捕获；
把 x 向基阶截断到 10 时 k=27.114（13.5 % 偏高）同样被拒。

## 7. 结论与边界

简支矩形板在**线性变化**面内应力下的屈曲已闭合到 0.08 % 量级，且有两条独立路径互相
印证（双正弦 Galerkin 与 Hermite C1 参考），均匀压缩极限精确回零。据此，
`benchmark-qualification-status.md` 中"非均匀预屈曲应力"一项可以标为**已验证（Galerkin 能量引擎）**；
但**壳单元几何刚度**在非均匀预应力下的场级验证仍未完成，不得据此外推 FE 壳路径。
