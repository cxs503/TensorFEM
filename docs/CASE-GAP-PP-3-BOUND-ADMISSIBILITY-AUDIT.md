## 2. 怎么做的：把「上界」按定义审一遍

刚塑性极限分析的上界定理：任一 **运动学可容**（满足位移边界与流动法则）的速度场
`w`，其外功率 = 内耗散给出 `p_ub >= p_exact`。所以每个上界必须满足两条：
(a) 可容；(b) 逐点耗散用**完整**的屈服面支撑函数算，不能漏掉耗散通道。

薄板 Johansen/Neville 屈服面 = 任意方向的弯矩 `|M(θ)| ≤ m_p`。它的支撑函数（耗散函数）
是**主曲率**形式：

```
D(κ) = m_p (|κ_I| + |κ_II|),   κ_I,II = (κ1+κ2)/2 ± sqrt(((κ1−κ2)/2)² + κxy²)
```

漏掉 `κxy`（扭率）的经典写法 `m_p(|κ1|+|κ2|)` 只在 `|κxy| ≤ min(|κ1|,|κ2|)` 时才对；
对**光滑**（非折线）机制，`κxy` 与被积曲率同量级，漏掉它必然少算内耗散。

### 2.1 硬反例（决定性）

全板均布载荷的简支方板有精确解 `p_c = 24 m_p/a²`（Johansen 屈服线解，教科书值）。
任何上界必须 ≥ 它。现有 `ilyushin_sine_upper_bound` 给出

```
2 π² m_p/a² = 19.74 m_p/a²  <  24 m_p/a²
```

**低于已知精确解 ⇒ 非上界**。原因正是它用的是 `m_p(|κ1|+|κ2|)`：`w = sin(πx/a) sin(πy/b)`
的扭率 `κxy = (π²/a²) cos cos` 与弯曲曲率同量级，被整段丢掉。
`tests/test_plate_patch_plastic_bounds.py::test_uniform_square_plate_recovers_two_pi_squared_mp_over_a2`
把 19.74 这个值本身冻结成了断言（注释里拿它和 *梁* 的 8 m_p/a² 比较，比较对象选错了），
所以这个缺陷此前被测试「保护」着。

### 2.2 修正实现

新增 `tensorfem.plate_patch_plastic_limit.johansen_twist_upper_bound`：
同一族机制（双正弦，简支边界上 `w=0`，故可容），但耗散用上面的主曲率形式（含 `κxy`），
中点数值积分（`quadrature` 默认 256，测试用加倍验证收敛）。只接受在斑区**不变号**的模态
（单侧压力不做负功），返回族内最小值——每个返回数本身都是合法上界。
`plastic_bound_bracket` 增列 `upper_johansen_twist` / `tightest_admissible_upper` /
`admissible_bracket_width_ratio`；`tightest_upper` 保留历史语义但在文档里显式标注不可采。

## 5. 注意点 / 局限

* 新上界**偏保守**（全板 +29 %、长条 +25 %）：单模态双正弦机制比最优折线机制浪费，
  所以它只把「不合法的紧界」换成「合法但略松的界」，区间宽度比从 1.85 恶化到 2.25。
  更紧的合法界需要折线/扇形机制族的最优化（未做，见 §6）。
* 耗散形式 `m_p(|κ_I|+|κ_II|)` 对应 Johansen/Neville 面（各向弯矩受 m_p 限），
  **不是**分层 von Mises 截面的精确面；两者的差异在双轴等弯状态为零（`κ1=κ2, κxy=0` 时
  两式都给 `2 m_p κ`），在纯扭状态为 `2/√3` 因子。因此「FE vs Johansen 界」的对标
  在纯扭主导的机制上仍带材料面差异，须明写，不能当成纯离散误差。
* 数值积分是中点法则（被积函数有 `|·|` 折点），故收敛性靠「加倍网格不变」实测，不靠假设。
* 未做：折线/扇形机制族最优化、可采界的 Mises 面版本（留给后续单，见 §6）。
