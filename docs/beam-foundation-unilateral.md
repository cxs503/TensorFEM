# Beam and plate elements on a Winkler foundation with unilateral contact

TensorFEM capability node IN70-N02.  Module: `tensorfem.beam_foundation`.  Evidence: `artifacts/beam_foundation_unilateral/evidence.json` (generated by `benchmarks/beam_foundation_unilateral.py`).  This document is rendered from that JSON by `scripts/beam_foundation_unilateral_report.py`.

## 1. Physics background and scope

A beam on a Winkler foundation obeys `EI w'''' + k w = q`, whose character-istic wavenumber is `beta = (k/4EI)^(1/4)` and whose decay length `1/beta` sets the mesh scale (Hetenyi 1946).  Two capabilities are added here for the *beam* level (the plate level already had a bilateral consistent matrix in `tensorfem.winkler_foundation`):

1. consistent foundation stiffness `k_e = integral k(x) N^T N dx` for the cubic Hermite Euler-Bernoulli element (closed form) and for the two-node Timoshenko element, plus the consistent nodal loads of a uniform load;
2. unilateral (compression-only) contact: a *tensionless* elastic foundation (lift-off) and a *rigid bed* (Signorini) solver, both exposing the pointwise complementarity data `(R_i, y_i)`.

Sign convention: `w` positive downward, `theta = dw/dx`; a node is in contact when `w_i > g_i` (initial gap `g`), the bed reaction is `R_i = k_i (w_i-g_i)^+ >= 0` and the separation `y_i = max(g_i - w_i, 0) >= 0`, so that `R_i y_i = 0` pointwise.  The rigid bed imposes `w_i <= g_i` instead.

## 2. Method

- **Bilateral solve**: `(K_b + K_f) w = f` with `K_f = sum_e int k N^T N dx`; dense Cholesky on the free DOFs (a non-positive-definite reduced system is reported instead of silently returning garbage).
- **Tensionless (lift-off)**: the one-sided model uses the tributary lumped springs `k_i = sum_e k_e L_e / 2` (`sum_i k_i = int k dx`, so the reaction resultant is conserved) and iterates the classical no-tension active set: engage the nodes that penetrate, solve, repeat until the KKT residual is below tolerance.  Convergence is accelerated by warm-starting from the previous solution (`init_active`) along a `k` ladder.
- **Rigid bed (Signorini)**: solved *dually*.  With the flexibility `A = S K^-1 S^T` of the bed transverse DOFs the reaction solves the non-negative QP `min 1/2 lam^T A lam - b^T lam, lam >= 0`, minimised by an accelerated projected-gradient (FISTA) iteration; its support identifies the contact set, and one primal equality solve on that set yields the exact solution, polished by single active-set flips.
- **Reference solutions**: (i) the Hetenyi closed form for an infinite beam under a point load, `w(0) = P beta/(2k)`; (ii) a semi-analytic lift-off length for an infinite beam under a uniform load `q` plus a central uplift `P`, obtained from continuity of `w, w', M, V` at the reattachment point.

## 4. Notes, pitfalls and limitations

1. **Load DOF indexing.** In a `(w, theta)` layout a nodal *force* must be written to the even DOF; writing it to the odd DOF silently applies a moment and produces a spurious rigid rotation (this bit the first draft of the `k -> 0` study).
2. **Mesh grading hurts.** An aggressively graded mesh (h from 1e-3 to 10 in the same solve) raised the condition number and poisoned the point deflection to ~1e-5 relative, whereas a *uniform* mesh on the decay-length domain reached 4e-8 with a third of the elements.
3. **Consistent vs lumped foundation.** The one-sided model needs per-node springs; row-sum lumping of the Hermite matrix is not defined (the moment shape functions break the partition of unity), so the tributary lumping `k L_e/2` is used.  It conserves the resultant but differs from the consistent matrix by ~6e-7 relative in the deflection of a fully contacted beam.
4. **Active-set robustness.** The naive 'engage every penetrating node' iteration cycles for stiff foundations; the cure implemented here is (i) a solvable 'no-spring' predictor with a full-contact fallback, (ii) warm starts along a `k` ladder, and (iii) a KKT-based convergence test instead of set equality.  All production paths stay at <= 10 active-set iterations.
5. **Rigid-bed contact is grazing in the pier geometry used here** (one contact node): the discrete LCP solution is verified by its KKT residuals and by agreement with the large-`k` elastic solution, but this particular geometry is not a demanding contact-patch benchmark.
6. **Plate one-sided path is not qualified.** The historical SRI Q4 element leaves rank-3 hourglass modes in `w` that a partially engaged one-sided foundation cannot suppress (singular system); the MITC variant runs but the plate strip has not been matched to a plate-contact reference.  The unilateral plate entry point is therefore shipped as experimental.
7. **Not modelled**: friction, large deflection (the beam stays small-displacement), layered/Kerr foundations (see `kerr_foundation.py`), and wall/drilling effects at a contact edge.
