## 1. 案例介绍

冰带板格（论文算例：0.8 m × 0.7 m × 22 mm，E = 206 GPa，ν = 0.3，1 MPa 压力补丁 8 cm × 70 cm）
的边界既非简支也非固支，而由纵骨与横框架提供**有限转动刚度**。此前四张单
（`docs/GAP-PP-4-ICE-STRUCT-ELASTIC-RESTRAINT.md` §9–§10、`CASE-FEM-ELASTIC-RESTRAINT-TRIBUTARY`、
`CASE-FEM-ELASTIC-RESTRAINT-LEVY-VERIFICATION`）已经把 **给定 β** 的求解器验到：β=0 与论文
Navier N=401 基准差 0.065 %、β 带内部与精确 Levy 解差 <0.08 %、节点弹簧网格无关。

**剩下唯一的洞**（原文档 §9.5 自陈）是：β 本身是**人为旋钮**——`ζ=β/(1-β)` 只是把
`c_r = ζD/a` 重新参数化，没有任何东西把 β 与真实板格的纵骨/框架尺寸连起来。于是论文只能写
「SSSS 是上限」，写不出「本船 β≈0.13–0.45，因此应力介于 −1 % 与 −10 % 之间」。

本单正是补这一环：**由构件尺寸 → 扭转梁模型 → 分布转动弹簧 c_r → ζ → β**，并用两套独立参考复核。

| 参数 | 数值 |
|---|---|
| 板格 x（横框架间距） | 0.8 m |
| 板格 y（纵骨间距） | 0.7 m |
| 板厚 t | 22 mm |
| 材料 | E = 206 GPa，ν = 0.3（G = 79.23 GPa） |
| 弯曲刚度 D | 2.00869×10⁵ N·m |
| 补丁压力 / 尺寸 | 1 MPa / 0.08 m × 0.70 m（全宽，板心） |
| 纵骨（上界/下界） | HP220×10 理想化 T（腹板 210×10 + 球缘 40×22）/ 扁钢 FB200×12 |
| 框架 | T400×12 + 100×18 |

## 2. 怎么做的

### 2.1 物理模型（扭转梁 → Winkler 型转动约束）

转动约束由上覆构件**绕连接线的 St. Venant 扭转**提供。板边给构件施加分布扭矩强度
`m [N·m/m]`，构件在跨长 L 内按 `GJ θ'' = -m` 变形，两端由其所交构件的转动刚度 K₀、K₁ 约束：

```
T(0) = K₀θ(0)，  T(L) = -K₁θ(L)，  T = GJ θ'
θ(x) = -m x²/(2GJ) + C₁x + C₀
```

闭式解出 θ(x) 后，按**均转角等价** `c_r = m/θ̄` 均质化为分布转动弹簧；同时给出**能量等价**
`c_r = m²L/(2U)` 作为第二定义（对称端固时两者严格相等，非对称时构成定义不确定度带）。
K→∞ 按解析极限处理，得到两条可与教科书对照的参考值：

* 两端扭转固支：`c_r = 12GJ/L²`
* 一端固支一端自由：`c_r = 3GJ/L²`

再接回求解器自己的映射（**不允许重新拟合**）：
`ζ = c_r·a/D`，`β = ζ/(1+ζ)`，`a` = 边缘法向板跨（与 `solve_restrained_panel` 内部一致）。
几何口径：y 边（法向 y）由纵骨约束（纵骨跨 = 框架间距 0.8 m），x 边（法向 x）由横框架约束
（框架在纵骨之间受扭，跨 = 纵骨间距 0.7 m，或整跨 = 舷侧桁材间距 3.2 m）。

### 2.2 复核链（全部独立于被验对象）

1. **闭式解 vs 独立有限差分解**：同一 ODE 用中心差分 + 虚节点离散，对该二次解离散误差为零，
   与闭式解符合到 1e-9（含 K₀=∞、K₁=0、双弹性端）。
2. **解析极限**：12GJ/L² 与 3GJ/L² 逐位一致（1e-12）。
3. **扭转常数 J**：与库内独立实现 `open_section_torsion.section_properties`（薄壁积分 + 每壁
   0.63 修正，其自身已由 3D HEX8 `fem_torsion_constant` 验过）比：扁钢 FB200×12 相对差 2×10⁻⁵。
4. **映射一致性**：`beta_from_k_rot(k_rot_from_beta(β)) = β`（1e-10），并与
   `plate_elastic_restraint.beta_to_zeta` 比（仅差该函数的 ε=1e-6 正则化）。
5. **端到端**：标定出的 `c_r` 直接喂进**精确** Kirchhoff Levy 解
   （`levy_restrained_plate`，弹簧在 x 边）与 Mindlin 板 FEM 比：`w` 差 <1 %。
6. **板级三方对照**：同一标定 β 分别用 Mindlin Q4 FEM（nx=120）与
   Kirchhoff 四边弹簧 Rayleigh–Ritz（`ritz_restrained_plate`，40×40 模态，补丁积分精确）算，
   逐项报差。
7. **回归护栏未动**：β=0 仍复现论文 Navier N=401 基准（见 §4 第 1 行）。

### 2.3 工具链与设置

本地单线程（torch `set_num_threads(1)`，OMP=1）跑 `benchmarks/plate_restraint_calibration.py --nx 120`，
81 s；重算作业 `cj3180`（nx=160）已递交集群但排队未完成，故本文所有数字为 **nx=120**，
网格误差见 §4 第 1 行（−0.12 %，容差 0.5 %）。1D 差分/Levy/Ritz 均与网格无关的解析/变分解。

## 3. 计算结果

### 3.1 构件扭转常数与其理想化不确定度

| 构件 | J 修正值 [m⁴] | J 薄壁 l t³/3 [m⁴] | 差 | GJ 修正值 [N·m²] |
|---|---|---|---|---|
| 纵骨 HP220×10（缘板整块 40×22） | 1.6068×10⁻⁷ | 2.1197×10⁻⁷ | +31.9 % | 1.2731×10⁴ |
| 纵骨 HP220×10（缘板按库内树模型拆两半） | 1.1803×10⁻⁷ | — | −26.6 % | 9.35×10³ |
| 纵骨 FB200×12 | 1.10845×10⁻⁷ | 1.1520×10⁻⁷ | +3.9 % | 8.7824×10³ |
| 框架 T400×12+100×18 | 3.9840×10⁻⁷ | 4.2480×10⁻⁷ | +6.6 % | 3.1566×10⁴ |

**厚缘板的 0.63 修正是必须的**：船体骨材缘板 t/b 常在 0.3 以上，裸 `l t³/3` 高估 J 达 30 %，
直接高估嵌固度。膨球缘的理想化（整块 vs 拆半）另有约 26 % 不确定度，已作为 β 带的一条边。

### 3.2 标定结果（假设矩阵 → β）

| 变体 | 假设 | ζ_x | ζ_y | **β_x** | **β_y** |
|---|---|---|---|---|---|
| `upper` | HP 纵骨 + 框架在每根纵骨处受扭，两端固支 | 3.079 | 0.832 | 0.755 | 0.454 |
| `mid_frame_global` | 同上，但框架按整跨（3.2 m 桁材间距）受扭 | 0.147 | 0.832 | **0.128** | 0.454 |
| `lower` | FB200×12 纵骨一端自由、框架整跨且一端自由 | 0.037 | 0.143 | **0.036** | **0.126** |
| `lower_thinwall_J` | 同上但用裸薄壁 J | 0.039 | 0.149 | 0.038 | 0.130 |

**结论（给论文 §4.2 的定量口径）**：冰带板格真实嵌固系数 **β_y ≈ 0.13–0.45（纵骨边）**、
**β_x ≈ 0.04–0.76（框架边）**。框架边的跨度口径是主导不确定度：横框架在每根纵骨处受扭
（局部口径）时 ζ_x = 3.1，而按整跨桁材间距受扭（全局口径）时 ζ_x = 0.15，相差 20 倍。
保守取值用全局口径 + 一端自由。

## 4. 误差判定（逐项，且显式回答「是否 <3 %」）

| 检查 | 误差 | 容差 | <3 %？ |
|---|---|---|---|
| FE β=0 中心 σ_vM vs 论文 Navier N=401（73.3710 MPa） | **−0.12 %** | 0.5 % | ✅ 是 |
| 标定 `upper`：FEM vs 精确 Ritz（σ_vM / w） | −0.53 % / +0.87 % | 5 % | ✅ 是 |
| 标定 `mid_frame_global`：FEM vs Ritz | −0.24 % / +0.67 % | 5 % | ✅ 是 |
| 标定 `lower`：FEM vs Ritz | −0.11 % / +0.59 % | 5 % | ✅ 是 |
| 闭式扭转梁 vs 独立 1D 差分（4 组端条件） | ≤1×10⁻⁹ | 1e-6 | ✅ 是 |
| FB200×12 的 J vs 库内独立实现 | 2×10⁻⁵ | 1e-3 | ✅ 是 |
| Ritz 模态收敛（40 vs 60） | 0.005 % | 1 % | ✅ 是 |
| β 映射往返 `k_rot→β→k_rot` | 1e-10 | 1e-6 | ✅ 是 |

**没有 3 % 以上未解释的误差项。** 但必须声明两条**模型层**不确定度（不是数值误差）：
(1) 框架扭转跨度口径（局部 0.7 m vs 全局 3.2 m）使 β_x 变动 6 倍，是本单最大的物理不确定度；
(2) 膨球缘整块/拆半使 J 变动 ±26 %，进而 β_y 变动约 ±0.05。
另外 St. Venant 模型忽略翘曲（E C_w）：对 `L/h > 10` 的开口截面该近似误差在几个百分点量级，
本算例纵骨 L/h = 0.8/0.21 = 3.8，属于翘曲不可忽略的短跨情形——这是模型**已知偏保守方向**
（忽略翘曲 → 低估扭转刚度 → 低估嵌固度 → 应力偏高）之外还需说明的一点：短跨时翘曲实际
*降低*约束，故 12GJ/L² 在此偏不保守。**下一单应做的正是纵横骨-板壳三维单元实体标定。**

## 5. 注意点（踩过的坑）

1. **不要直接用 `l t³/3`**：船体缘板厚宽比大，30 % 量级高估 J；已默认用每壁精确矩形级数。
2. **β 不等于「嵌固百分比」**：β=0.454 只对应 σ 降 5.5 %，而 β=1 对应 35.6 %；论文必须报
   「β–响应」曲线，不能把 β 读成线性嵌固度。
3. **框架边的扭转跨度必须写清**：同一套尺寸，跨度从 0.7 m 换成 3.2 m，β_x 从 0.755 掉到 0.128。
   论文口径建议报区间而不是单值。
4. **Ritz 中心弯矩在补丁载荷下收敛慢**，20/30 模态非单调；至少 40 模态。
5. **保留两位有效数字**：标定的输入本身（缘板理想化、端部固支假设）不确定度远大于 1 %，
   β 不应报成 0.7548 这种精度。
6. 数值网格：nx=120 时 β=0 相对论文基准 −0.12 %；nx=160 为 −0.065 %（历史数据）。
   集群作业 `cj3180`（nx=160 版）递交时队列排队 >15 min 未完成，本报告全部数字取 nx=120。

## 6. 局限与下一步

* 线性弹性、小挠度；无塑性/屈曲/接触。
* St. Venant 扭转 + 忽略翘曲；对短跨骨材需 3D 实体或 Vlasov 扭转复核（**推荐的下一单**）。
* 板边按刚性线（w=0）处理，未含骨材自身弯曲变形引起的板边位移相容。
* 端部固支 / 一端自由两种极端已覆盖，未含横框架真实端部转动刚度（需框架-纵骨节点细化模型）。
