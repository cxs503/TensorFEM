# 板自由振动验证：Mindlin Q4 + 一致质量矩阵 vs 解析/文献基准（验证欠账清零）

## 1. 案例介绍（why this case exists）

在加入本模块之前，TensorFEM 具备板**弯曲**能力（`tensorfem.plate`、
`tensorfem.plate_mindlin`，含 Winkler 地基）与**梁**振动能力
（`tensorfem.modal`），但没有任何板/壳特征值能力。船体板格的首阶固有频率是
振动噪声评估、砰击/颤振筛选与疲劳谱分析的入口量，这一空白卡住的是学科而不是
单个 benchmark，故本单按「验证欠账 + 功能补全」处理。

物理背景：船底/舷侧板格在均布脉动压力下的首阶弯曲振动。取标定算例为
1 m × 1 m × 10 mm 钢板（a/h = 100，薄板极限，便于与 Kirchhoff 解析解对标），
并分别考察简支、固支、矩形 a/b = 2 选阶以及 Winkler 弹性地基（板格在纵桁/
肋骨上的等效支承）四种工况。

| 参数 | 符号 | 取值 |
|---|---|---|
| 板长 / 板宽 | a, b | 1.0 m / 1.0 m（另一工况 a/b = 2，a = 2.0 m） |
| 板厚 | h | 0.01 m（a/h = 100） |
| 弹性模量 | E | 200 GPa |
| 泊松比 | ν | 0.30 |
| 密度 | ρ | 7850 kg/m³ |
| 抗弯刚度 | D = Eh³/(12(1−ν²)) | 1.8315×10⁴ N·m |
| 面密度 | ρh | 78.5 kg/m² |
| 边界 | — | 硬简支（SS1）/ 全固支 |
| 地基模量 | k_w | 0 / 0.5 / 2 / 8 GN/m³ |
| 网格 | — | 6×6 … 16×16 Q4（最细 512 单元，867 自由度） |

## 2. 怎么做的（方法/流程/工具链）

**单元与质量矩阵**。复用既有四节点选择性减缩积分（SRI）Mindlin 板单元刚度
`plate.q4_mindlin_stiffness`，只新增一致质量矩阵

    M_e = ∫ [ ρh NᵀN (w–w) + (ρh³/12) NᵀN (θ–θ) ] dΩ

转动惯量块不是修饰：仅含平动块时 M 在 θ 自由度上奇异，Cholesky 归约直接失败
（见 §5 坑 1）。对 a/h = 100 转动惯量块对频率的影响 < 0.05%，保留它是为了
良态性，而不是声称已覆盖厚板。

**求解流程**。装配 K = K_plate + k_w·K_foundation（`plate_mindlin.q4_winkler_foundation_stiffness`）
与 M → 消去固定自由度 → 用 M 的 Cholesky 因子 L 做标准对称化
(L⁻¹KL⁻ᵀ)φ = λφ → `torch.linalg.eigh` → ω = √λ，f = ω/2π。
全部为 float64，最细网格 16×16 单次求解 4.6 s（128 核机器，8 线程）。

边界约定与既有弯曲算例保持一致，避免同一物理工况出现两套 BC：`simple` 为
硬简支，全边界 w = 0，y 边约束 θ_x、x 边约束 θ_y；`clamped` 全边界 w = θ_x = θ_y = 0。

**独立基准（无一条来自本模块输出）**

| 基准 | 出处 | 形式 |
|---|---|---|
| 简支矩形板 Navier 双正弦解 | 经典板理论 | ω_mn = π²√(D/ρh)[(m/a)²+(n/b)²] |
| 简支板 + 均匀 Winkler 地基 | 正弦模态是地基算子的精确特征函数 | ω² = (D R² + k_w)/(ρh)，R = (mπ/a)²+(nπ/b)² |
| 固支方板基频系数 | Leissa, *Vibration of Plates*, NASA SP-160 (1969) | ω₁ = (λ₁/a²)√(D/ρh)，λ₁ = 35.9853 |
| 薄板基准的剪切偏置 | 一阶剪切修正 | ω² = ω_K²/[1 + D R²/(κGh)] |

工具链：`benchmarks/plate_vibration.py` 一次跑完四个工况，写出
`benchmarks/plate_vibration_evidence.json` 与三张图；下表由该脚本直接打印，
不经手抄。

```bash
OMP_NUM_THREADS=8 PYTHONPATH=src python benchmarks/plate_vibration.py
OMP_NUM_THREADS=8 PYTHONPATH=src python -m pytest -q tests/test_plate_vibration.py
```

## 3. 计算结果（数字表）

### 3.1 简支方板（最细 16×16，512 单元，867 自由度）

| 模态 | 计算 f [Hz] | Navier 解析 f [Hz] | 相对误差 | 判定 |
|---|---:|---:|---:|---|
| (1,1) | 48.1757 | 47.9865 | 0.394% | PASS |
| (1,2)/(2,1) | 121.7450 | 119.9662 | 1.483% | PASS |
| (2,2) | 194.9953 | 191.9458 | 1.589% | PASS |

(1,2) 与 (2,1) 数值相等（差 < 1e-6），方板二重简并被 FE 结果自动复现，测试
`test_simply_supported_square_first_four_modes_below_three_percent` 锁定该性质。

### 3.2 固支方板与 Winkler 地基

| 工况 | 计算 f₁ [Hz] | 基准 f₁ [Hz] | 相对误差 | 判定 |
|---|---:|---:|---:|---|
| 固支方板 16×16（Leissa λ₁=35.9853） | 88.2677 | 87.4811 | 0.899% | PASS |
| 简支 + k_w = 0（8×8，纯弯曲对照） | 48.8038 | 47.9865 | 1.7032% | PASS |
| 简支 + k_w = 0.5 GN/m³（8×8） | 404.5912 | 404.5271 | 0.0159% | PASS |
| 简支 + k_w = 2 GN/m³（8×8） | 804.7552 | 804.7736 | 0.0023% | PASS |
| 简支 + k_w = 8 GN/m³（8×8） | 1607.2890 | 1607.3998 | 0.0069% | PASS |

地基模量越大误差越小是符合预期的：地基刚度项被一致积分精确表达，频率由
地基项主导后，弯曲项的离散误差被 diluted（8×8 网格弯曲误差 1.7% 仍高于门限
的 1/17）。这不构成「地基算例比纯弯算例更准」的能力声明。

### 3.3 矩形板 a/b = 2（12×12）：选阶与误差

| 模态标签 | 计算 [Hz] | 解析 [Hz] | 相对误差 |
|---|---:|---:|---:|
| (1,1) | 30.225 | 29.994 | 0.78% |
| (2,1) | 48.904 | 47.987 | 1.91% |
| (3,1) | 82.227 | 77.982 | 5.45% |
| (1,2) | 105.263 | 101.972 | 3.23% |

长板首阶按 (m,1) 序列选阶（m = 1, 2, 3…），与 Navier 理论一致；第 3、4 阶
（5.45% / 3.23%）在 12×12 网格上**未达 3%**，本报告只声明前两阶通过，见 §6。

### 3.4 收敛性与质量守恒

| 检查项 | 结果 |
|---|---|
| 网格 6→8→10→12 首阶误差单调下降 | 6.79% → 1.70% → 1.05% → 0.73% |
| 观测收敛阶（12/10 两级，带符号误差） | 2.097（二阶，SRI Q4 的预期阶） |
| 一致质量矩阵质量守恒 1ᵀM_ww1 / ρh·A | 1 − 1e-12 内（精确到舍入） |

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **质量矩阵必须含转动惯量块**。只装配平动量矩阵时，约化质量矩阵在 θ 自由度
   上奇异，`torch.linalg.cholesky` 报「leading minor of order 1 is not
   positive-definite」。这不是数值小毛病，而是「板有转动自由度、就得有转动惯量」
   的物理约束；`rotary_inertia=False` 路径现在显式抛 ValueError，并被测试锁定。
2. **在 SRI Q4 上做自由振动没有出现沙漏模态污染**。16×16 网格前 4 阶全部落在
   Navier 谱上、无非物理近零特征值；但这是经验结论，不能外推到粗网格或自由边界
   板——模块对「保留集仍含机构」有显式护栏（特征值 ≤ 0 直接报错），自由边界工况
   本身未做验证。
3. **薄板基准只到 0.03% 精度水平**。Mindlin 的一阶剪切修正给出 ω/ω_K − 1 =
   −2.82×10⁻⁴；把 FE 误差做 Richardson 外推（8/16 两级，比 4.3 ≈ 2²）得到极限值
   约 −0.04%，与该解析偏置同量级。因此「与 Kirchhoff 解析解对齐到 1e-4」既做不到
   也不该作为验收口径；本报告的 3% 门限远宽于此偏置，判定不受影响。
4. **简支约定是硬简支（SS1）**。与 `plate.solve_simply_supported_sine_square`
   共用同一套边界消元，使弯曲与振动两处结论可互相引用；换软简支（M_n = 0 自然
   边界）频率会不同，不可混用。
5. **稠密代数上限**。模块用稠密 K、M 与稠密 Cholesky，代价 O(ndof³)：6×6 约
   0.7 s，16×16 约 4.6 s，24×24 已接近分钟级。工程板格（数十万自由度）必须换
   稀疏特征值求解器，本模块不含。
6. **不覆盖的内容**（明确不声明）：预应力和流固耦合（附加质量）、阻尼、几何
   缺陷、层合/各向异性、壳体特征值、屈曲-振动耦合。`tensorfem.added_mass` 与
   `tensorfem.shell4_buckling` 的存在不等于这两个能力已与本模块耦合。

Winkler 精确特征值、固支 vs Leissa 且固支必须高于简支、质量守恒、边界自由度
被完全约束且基频无内部节线、奇异质量矩阵与非法输入的显式报错。
