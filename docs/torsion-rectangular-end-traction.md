## 1. 案例介绍（物理背景 / 几何 / 参数表）

开口薄壁梁、船体梁、螺旋桨叶根、加筋板的扭转刚度全部落在同一个矩形级数上，而真实截面几乎都是
`a ≠ b`。`a/b = 3` 的 3-D 棱柱在上一份报告中被判「扭转率随加密单调变差（0.911 % → 2.026 % →
2.568 % → 2.871 %）」，并归因为「`0.25L–0.75L` 窗口整体落在 Saint-Venant 端部影响区（衰减长度
`~ a`）内」。该归因若成立，必须满足两个可证伪推论：**(i)** 换成长度更长的杆（窗口远离两端）误差必须
变小；**(ii)** 换成精确端部面力（无自平衡端部扰动）误差必须消失且与窗口无关。本单逐条检验。

| 项 | 取值 |
|---|---|
| 截面 | `b × a` = `1 × {1.5, 2, 3}`（`x` 跨短边，`y` 跨长边） |
| 杆长 | `L = 4`（原工况）/ `6` / `9`；壁面回收用 `L = 6` |
| 材料 | `E = 1 GPa`，`ν = 0.3` ⇒ `G = 3.8462e8 Pa` |
| 载荷 | 端面纯扭矩 `T = 1 N·m`（两种分布：`linear` = 原环向线性面力；`exact` = Saint-Venant 面力） |
| 单元 | HEX8，立方单元 `nz = round(L·n/b)`，面内 `n_short × n_long = n × round(n·a/b)` |
| 扭转率 | 各 `z` 平面环向转角最小二乘斜率，窗口 `0.25L–0.75L`（另有 `0.30–0.70`、`0.35–0.65`） |
| 参考 | `J = c1 a b³`、`τ_max = T/(c2 a b²)` 闭式级数（401 项）+ 独立 Prandtl 差分 PDE（既有） |

## 2. 怎么做的（方法 / 流程 / 关键设置）

1. **精确端部面力通道**：把整体求解抽成 `_twist_prism()`，其中 `end_traction="exact"` 用
   `(τ_zx, τ_zy) = Gθ(∂ψ/∂y, −∂ψ/∂x)` 在端面 **2×2 Gauss** 积分成一致节点力（原 `A_e/4` 规则只对
   线性面力精确）。`θ = T/(GJ)` 取闭式值，因此该工况**就是** Saint-Venant 问题本身；积分残差
   （扭矩复现误差）实测 `1.1e-3 → 2.3e-4`（`n = 3…5`），随网格二阶下降，未被归一化掩盖
   （`end_traction_residual` 入结果字段）。默认 `"linear"` 路径数值**逐位不变**。
2. **窗口复用**：`_PrismSolve.twist_rate_in(window)` 让一个解支持多窗口回归，避免重复求解。
3. **壁面峰值回收** `surface_peak_shear()`：同一位移场的三种口径——`direct`（壁面节点上取应变算子，
   相邻单元平均）、`gauss`（壁邻单元两个 Gauss 站位线性外推到壁面）、`centroid`（壁内半个单元的
   单元形心值，严格内部下界）。参考值用 **FE 自身解出的扭转率**乘闭式梯度，故扭转率误差不会伪装成
   应力回收误差。
4. **验证矩阵**：`a/b = 3` × `n ∈ {3,4,5}` × 两种端部载荷 × 三个窗口；长度研究 `L ∈ {4,6,9}`；
   壁面回收 `a/b ∈ {1.5,2,3}` × `n ∈ {4,6}`。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **原 §5.1 的归因被推翻，不是被"修补"**。若端部影响区是主因，`L = 4 → 6 → 9`（`a/L` 0.75 → 0.33）
   误差应显著下降；实测 linear 工况反而 0.911 → 1.286 → 2.104 %（**上升**）。同时 exact 工况的误差
   对 `L` 完全不敏感（2.322/2.331/2.336 %），对窗口**逐位不敏感**。故 `a/b = 3` 的"不收敛"来自
   **环向线性面力不是 Saint-Venant 面力**这一载荷模型偏差（其自平衡分量随截面加密改变符号贡献），
   与端部衰减长度、与截面细长比都无关。
2. **exact 工况仍不是"零误差"**：`n = 3/4/5` 误差 2.32/1.35/0.88 %，观测阶约 0.7（亚二阶），
   是 HEX8 对翘曲函数 `ψ` 的表示能力所限（薄长截面 `ψ` 沿短边方向变化剧烈）。即：`a/b = 3` 若要
   <1 % 仍需 `n ≥ 5`（6048 自由度）。
3. **`direct` 口径在长边中点异常准（<0.7 %）、在短边中点偏保守（2.2 %–2.5 %）**：短边中点附近
   `ψ` 的梯度方向与网格对齐差，节点导数平均有系统低估；引用短边峰值时须给误差或加密。
4. **`centroid` 口径不能当壁面峰值**：壁内半个单元的形心值系统偏低 17 %–27 %，这正是原报告
   §5.2「形心 L2 误差停在 1.7–2.5 %，不能当作峰值精度」的定量确认。
5. **exact 面力需要先用闭式 `J` 求 `θ`**：它是"给定解析场的能量一致载荷"，用于**归因与控制**，
   而非替代可测工况；工程预报仍应以 linear（物理）工况为准，并按第 1 条给出载荷分布不确定度。
6. **范围**：单连通实心矩形、各向同性均值弹性、小应变、自由翘曲；不含闭口薄壁、Vlasov 约束翘曲、
   变截面、塑性，也不含 `a/b > 3`（本次仅到 3）。

## 6. 误差判定（关键量 vs 基准，逐项显式回答「是否 <3%」）

| 关键量 | 基准 | 最细网格误差 | < 3 % ? |
|---|---|---|---|
| `a/b = 3` 扭转率（exact 端部面力，`n = 5`） | 闭式级数 `J = c1 a b³` | 0.87 % | **是** |
| `a/b = 3` 扭转率（exact，`n = 4`） | 同上 | 1.33 % | **是** |
| `a/b = 3` 扭转率（linear 物理工况，`n = 3…5`） | 同上 | 0.91 / 2.03 / 2.57 %（非单调递增） | **否（fail-closed 保留）** |
| 长边中点壁面峰值（`a/b = 1.5/2/3`，`n = 6`） | 闭式边界峰值 `|∇ψ|Gθ` | 0.21 / 0.03 / 0.06 % | **是** |
| 短边中点壁面峰值（`n = 6`） | 同上 | 2.20 / 2.47 / 2.53 % | **是（边界上，`n = 4` 时 5.1–5.6 % 否）** |
| `τ_L/τ_S` 比值（`a/b = 3`，`n = 6`） | 闭式 1.328 | 2.6 % | **是** |
| 端面扭矩复现（exact，Gauss 积分） | `T = 1` | 2.3e-4（相对） | **是** |

结论：**§5.1 的失败被定性为载荷模型缺陷并给出可用工况（exact 端部面力 `n ≥ 4` 进 3 % 门）；
§5.2 的矩形壁面峰值回收闭环（长边中点稳定 <0.7 %，短边中点需 `n ≥ 6`）**。物理线性工况的
fail-closed 记录不撤销。
