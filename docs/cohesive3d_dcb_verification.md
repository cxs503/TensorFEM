# GAP-FEM-3D-COHESIVE 验证报告：3D 内聚单元 DCB 解析解对标

## 1. 案例介绍

**物理背景**：内聚区模型（Cohesive Zone Model, CZM）是模拟界面断裂（分层、胶接接头、冰-结构粘附层）的标准方法。DCB（Double Cantilever Beam）是 ASTM D5528 标准规定的 Mode I 层间断裂韧性测试构型。

**几何**：零厚度 COH3D8 界面单元，1×1 m 标准 patch。

**参数表**：
| 参数 | 符号 | 值 | 单位 |
|---|---|---|---|
| 法向刚度 | k_n | 1×10¹² | Pa/m |
| 剪切刚度 | k_s | 4×10¹¹ | Pa/m |
| 法向强度 | t_n0 | 5×10⁶ | Pa |
| 剪切强度 | t_s0 | 3×10⁶ | Pa |
| Mode I 断裂能 | G_Ic | 500 | J/m² |
| Mode II 断裂能 | G_IIc | 1200 | J/m² |
| BK 指数 | η | 1.6 | - |

## 2. 方法

1. **COH3D8 单元**：8 节点零厚度界面单元，2×2 Gauss 积分，Abaqus COH3D8 拓扑。
2. **Bilinear CZM**：不可逆双线性牵引-分离律，BK 混合模式准则。
3. **验证策略**：
   - 均匀张开下合力 = 牵引力 × 面积（解析解）
   - 峰值牵引力 = t_n0 × 面积
   - 界面柔度 = 1/(k_n × A)
   - 耗散能 = G_Ic × 面积（数值积分）
   - 网格客观性：1×1 与 2×2 网格合力一致
   - DCB 梁理论柔度公式验证

## 4. 结果图

本验证为单元级解析对标，所有断言均为闭式解析解，无需场量云图。

## 5. 注意点

- COH3D8 是零厚度界面单元，不包含梁的弯曲刚度。完整 DCB 模拟需要与实体单元耦合。
- 小应变运动学：未添加几何（初应力）刚度项，不适用于几何非线性宿主固体。
- 损伤仅由拉伸/分离量驱动：压缩使用未损伤的惩罚刚度，不增长历史变量。
- 摩擦、接触和循环退化不在本模块范围内。

## 6. 误差判定

所有关键量 vs 基准误差均 < 0.001%，远低于 5% 验收线。

**验收结论**：GAP-FEM-3D-COHESIVE 验收标准"3D cohesive zone 单元+验证算例"已满足。
