# 圆孔应力集中（Kirsch）解析验证：生产 Q4 平面应力路径的独立基准

## 1. 案例介绍

船体开孔（舱口角隅、人孔、管系贯穿件、舷侧开孔）的强度评估依赖应力集中系数
`K_t`。TensorFEM 此前**没有任何圆孔/开孔应力集中基准**（`grep -ri kirsch` 全仓为空），
`docs/benchmark-qualification-status.md`「尚未闭环的工作」一节把「局部板屈曲、Hertz 接触及
其他经典壳体案例」列为缺完整场验证；本单补的正是其中「开孔应力集中」这一类解析基准，
对象是已经合并的生产平面应力路径（`tensorfem.continuum.ContinuumModel` /
`q4_stiffness` / `solve_continuum`），而不是新写一个求解器。

物理背景：无限大板受单轴拉伸 `T`（沿 x），中心圆孔半径 `a`，孔边自由。
Kirsch (1898) 精确解（Timoshenko & Goodier, *Theory of Elasticity*, 3rd ed., §39）：

```
sigma_rr = T/2 (1 - a²/r²) + T/2 (1 - 4a²/r² + 3a⁴/r⁴) cos2θ
sigma_tt = T/2 (1 + a²/r²) - T/2 (1 + 3a⁴/r⁴) cos2θ
sigma_rt = -T/2 (1 + 2a²/r² - 3a⁴/r⁴) sin2θ
```

孔边：`sigma_tt(a, π/2) = 3T`（即 `K_t = 3`），`sigma_tt(a, 0) = -T`。

| 参数 | 取值 |
|---|---|
| 孔半径 `a` | 1.0 |
| 外边界 `b` | 10 a |
| 远场拉应力 `T` | 1.0 |
| `E` / `ν` | 1.0 / 0.3（平面应力，`t = 1`）|
| 模型 | 四分之一环 `0 ≤ θ ≤ π/2`，`a ≤ r ≤ b` |
| 网格 | 渐变极坐标 Q4，径向向孔边加密 `grading = 5`，`n_θ = n_r ∈ {16, 24, 32, 48}` |
| 边界 | θ=0：`u_y = 0`；θ=π/2：`u_x = 0`（对称）；r=a：自由；r=b：Kirsch 精确面力的一致节点载荷 |

## 2. 怎么做的

1. **精确解自校验（先证明基准本身没错，再拿它判生产码）**：
   - 径向平衡 `dσ_rr/dr + (1/r)dσ_rt/dθ + (σ_rr-σ_tt)/r = 0` 用中心差分复核（残差 < 1e-7）；
   - 孔边自由：`σ_rr(a,θ) = σ_rt(a,θ) = 0`（< 1e-12）；
   - 位移场按 `E,ν` 直接推得的闭式（本文档模块 docstring 给出，`κ` 形式被消去），
     对 `r,θ` 数值微分后必须复现由应力反算的应变（平面应力与平面应变各一组，残差 < 1e-7）；
   - 平面应变的一致性：用 `E→E/(1-ν²)`、`ν→ν/(1-ν)` 的等效常量与三维柔度
     `ε_rr = [σ_rr - ν(σ_tt+σ_zz)]/E`（`σ_zz = ν(σ_rr+σ_tt)`）逐点对照。
2. **为什么这是"验证"而不是"FE 对 FE"**：四分之一环的每一条边界数据（两条对称线的
   法向位移为零、孔边零面力、外弧上的面力）都是 Kirsch 场自身满足的，因此**Kirsch 场就是该
   环域边值问题的唯一精确解**；外边界不是"远处近似"，而是精确面力，`b = 10a` 不引入截断误差
   （载荷合力校验见 §3）。
3. **生产路径原样调用**：`annulus_model()` 组装 `ContinuumModel`（`plane='stress'`，
   `element_type='q4'`，双精度），`solve_continuum` 用**整刚稠密求解**，不修改生产代码。
4. **点式应力恢复独立性**：模块内自写 Q4 `B` 矩阵（`_q4_b`）在固定物理点取样，先用
   `element_centre_cross_check` 证明它与生产存盘的单元中心应力一致（`≤ 3.3e-13`），
   再用它做点式比较——恢复路径未通过时点式误差不得发布（这是 Cook 膜审计踩过的坑）。
5. 复现：`OMP_NUM_THREADS=1 MPLBACKEND=Agg PYTHONPATH=src python scripts/audit_kirsch_hole.py`
   → `benchmarks/kirsch_hole_reference.json` + `docs/assets/kirsch/*.png`；
   测试：`PYTHONPATH=src python -m pytest tests/test_kirsch_hole_reference.py -q`（61 项）。

## 4. 误差判定（逐项回答"是否 < 3%"）

| 关键量 | 基准 | 最细网格误差 | 粗网格最差误差 | 是否 < 3% |
|---|---|---:|---:|---|
| 孔边 `K_t = σ_θθ(a,π/2)/T` | 3（Kirsch 精确） | 0.10%（3.0030） | 0.15%（n=16，2.9955） | **是** |
| 点式环向应力峰值区 `r/a = 1.02…2.0` | Kirsch 精确 | 0.19% | 1.23%（n=16） | **是** |
| 节点位移 L2 | Kirsch 位移闭式 | 3.8e-4 | 3.2e-3 | **是** |
| 载荷合力 | 精确弧面力积分（200 点 Gauss） | 4.6e-5 | 4.1e-4 | **是** |
| 点式恢复 vs 生产存盘应力 | 生产 `solve_continuum` | 3.3e-13 | — | **是** |

结论：**生产 Q4 平面应力路径在开孔应力集中问题上通过 3% 门限**，即使最粗的 578 自由度
网格（n=16）也已在 1.24% 内，`K_t` 在 0.15% 内。这一条此前在 TensorFEM 中是空缺。

## 5. 注意点 / 局限

- **孔边是正多边形**：节点精确落在 `r=a`，单元边为弦，矢高 `O((π/2n)²)`（n=16 时 0.107%）。
  它随网格细化消失，但**不能**把某一级的 `K_t` 当作"圆孔"的精确 FE 值；本文的 3% 判定在
  最细网格上不受此限制。
- **点式取样点都在单元内部**（`inside=True` 由测试锚定），不给孔边节点的外推值作误差量；
  孔边节点的 `K_t` 是相邻单元节点值的平均，属于后处理口径，报告里与点式误差分开列。
- **只覆盖平面应力 Q4 + 平面应变位移基准**：壳体（Shell4）在球壳内压下已单独记录为
  1006% 失败（`docs/sphere-membrane-validation.md`），本单**不**改善壳体族；
  正交异性板、含裂纹孔仍未覆盖，`K_t = 3` 只对无限大板成立；**有限宽板（Howland 修正）
  已在 `docs/finite-width-hole-howland.md` 单独清偿**（`tensorfem.finite_width_hole`，
  净截面 `K_tn` 对 Heywood/Peterson 表误差 ≤0.98%，Richardson 外推后 ≤0.18%，
  `d/W→0` 极限把 `K_t=3` 复现到 0.05%）。
- 该基准验证的是**装配/求解/应力恢复链路**，不涉及几何非线性、塑性、接触。
- 生产路径用稠密求解，本基准最大 4802 自由度（单次求解数秒），不是稀疏求解器缩放测试。
