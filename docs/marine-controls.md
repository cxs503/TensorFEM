# 曲面压头、半球壳同面应力与辐射记忆核对照

## 曲面压头与弹性平板

刚性抛物面压在四边固支的弹性钢板上。板宽 1 m、厚 20 mm、压头曲率半径 3 m，最大压入 4 mm。法向界面刚度取 1 GPa/m，仅传递压力。板采用 MITC 剪切处理的 Mindlin Q4；单独的中点积分网格覆盖板面，用同一组形函数传递位移、按转置分配压力。压头在 0.1 s 内按对称三角行程加载和卸载。模型求解一系列准静态平衡，表中冲量为沿这条指定时间路径的力积分。钢板弹性且无惯性，压头无断裂。

| 单因素对照 | 峰值力 / kN | 中心等效应力 / MPa | 冲量 / N·s |
|---|---|---|---|
| 板网格 15 / 31 / 47，接触积分每边 120 点 | 54.160 / 53.349 / 53.206 | 135.135 / 139.785 / 140.664 | 2144.04 / 2113.76 / 2108.39 |
| 接触积分每边 60 / 120 / 240 点，板网格 31 | 53.362 / 53.349 / 53.345 | 139.655 / 139.785 / 139.830 | 2114.31 / 2113.76 / 2113.12 |
| 界面刚度 0.5 / 1 / 2 GPa/m | 38.550 / 53.349 / 67.443 | 96.482 / 139.785 / 186.574 | 1455.63 / 2113.76 / 2802.39 |
| 每半行程 8 / 16 个采样区间 | 53.349 / 53.349 | 139.785 / 139.785 | 2113.76 / 2105.67 |

中心应力在各奇数网格的同一单元中心读取。基准接触面积 0.04778 m²；积分加密至每边 240 点后为 0.04771 m²。刚板极限另有解析参照，$F=\\pi kR d^2$、$A=2\\pi R d$、界面能 $U=Fd/3$。提高板模量到 $10^{17}$ Pa 后，计算 / 解析力为 150.784 / 150.796 kN，面积为 0.075313 / 0.075398 m²。有限柔度板还检验支承合力和储能对压入深度的导数。用于实物冰载荷时，仍缺可独立测定的界面刚度、压头破碎规律及动态参照。[逐工况与刚板对照](../artifacts/marine_controls/curved_panel.json)

## 18° 开孔半球壳

旧评分取平面壳两面中较大的 von Mises 应力，与最近的实体外表面单元比较。现依据外向法线分别对比两面，在实体采样点围成的角度范围内做双线性插值。每一区域记录所请求和实际覆盖的站点数。在原存盘壳位移和转角上测试两种恢复（平面法向、球面节点径向），并重新执行五个独立 HEX20 实体解。外表面和内表面均按各自的切平面计算。这批控制重新计算了壳应力恢复，壳平衡解来自原存盘场。

| 固定 40×40 壳网格、平面法向恢复 | 内部外表面平均 / 最大误差 | 内部内表面平均 / 最大误差 |
|---|---|---|
| 实体 20×24×1 | 16.01% / 21.79% | 3.26% / 7.18% |
| 实体 28×36×1 | 6.60% / 8.90% | 2.54% / 4.66% |
| 实体 34×42×1 | 4.60% / 6.18% | 1.87% / 3.46% |
| 实体 24×24×1 → 24×24×2 | 12.75% / 17.81% → 12.74% / 17.79% | 2.92% / 6.63% → 2.93% / 6.62% |

在 34×42×1 实体上，内部 702/702 个站点可比，孔边为 156/182，赤道载荷带为 200/240。径向恢复使内部外面误差降为平均 4.37%、最大 5.95%，内面降为平均 1.69%、最大 3.28%。两面的局部误差均超过 3%。实体的面内分辨率也显著影响差值，继续判定局部应力需要更细实体或另一套局部应力参照。保留原壳默认恢复和未认证状态。[含壳 24、32、40 网格及两种恢复的全部对照](../artifacts/marine_controls/hemisphere_faces.json)

## 辐射记忆核

对解析单极点 $K(t)=2e^{-1.5t}$，在 0.01–50 rad/s 的 2001 个频点上固定带宽、时间窗和积分规则。仅用带内阻尼时，阻尼往返变换的最大误差占阻尼峰值的 9.4645%；提供解析端点 $B(0)=2/1.5$ 后为 0.04479%。同一输入下附加质量重建误差为动态范围的 0.516%，带内 KK 残差为 0.00135%。有限带宽和有限记忆窗仍有误差。程序只在调用方提供端点时补上低频区间。

时域更新以两端载荷做梯形动量积分，有限记忆窗首末端使用半权重。无阻尼振子的能量、单频耗散以及解析核的三个弱阻尼自由衰减频点均有独立对照；自由衰减相对弱阻尼公式的偏差为 2.43%–3.18%。这组输入是解析系数，未使用实船水动力系数或水池试验。[数值记录](radiation_memory_results.json) · [核与变换](fig_radiation_memory_kernel.png) · [因果关系和自由衰减](fig_radiation_memory_gate.png) · [频带分辨率](fig_radiation_memory_convergence.png)

## 复现

从仓库根目录执行。半球脚本在独立进程中依次求解各实体网格，以释放稀疏分解的内存。

```bash
export OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=src
python benchmarks/curved_panel_controls.py --output artifacts/marine_controls/curved_panel.json
python scripts/hemisphere_face_controls.py --output artifacts/marine_controls/hemisphere_faces.json
python benchmarks/radiation_memory_kk_case.py
python -m pytest -q tests/test_curved_panel_controls.py tests/test_hemisphere_face_controls.py tests/test_hemisphere_hex20_oracle.py tests/test_radiation_memory.py
```
