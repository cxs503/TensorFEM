## ① 案例（物理背景 / 几何 / 参数）

悬臂实体梁 `L/h` 阶梯，矩形截面 `b × h = 10 mm × 10 mm`，HEX20 三线性/二次实体单元，
全夹持根部，两种载荷：

| 工况 | 载荷 | 参照（闭式） |
|---|---|---|
| 力（force） | 端面横向合力 `P = 5 N` | `δ_EB = PL³/(3EI)`；`δ_TI = δ_EB + PL/(κGA)`，`κ = 5/6` |
| 纯弯（moment） | 端面线性拉压 `σ_x = M(z−h/2)/I`，`M = 0.2 N·m` | `θ = M L/(E I)` |

`E = 200 GPa`，`ν = 0.3`，`G = E/(2(1+ν))`，`I = b h³/12`，`GAP ≡ E/(4κG) = 0.78`
（即 `(δ_TI−δ_EB)/δ_EB = GAP (h/L)²`）。被复核的问题是：能否从力工况的挠度里**辨识**剪切修正
`κ_eff`（候选 `5/6 = 0.8333` 能量、`0.8496` Cowper、`2/3 = 0.6667` 截面中心）。

## ② 怎么做（方法 / 独立性 / 关键设置）

复核者**重写**了探针，而不是重跑上游脚本：

1. **载荷向量自建**：端面 Q8 形函数（自实现）+ 3×3 Gauss 一致载荷；力工况另保留上游的「端面节点均分」
   作为载荷施加方式对照（St. Venant 敏感性）。
2. **斜率估计量自建**：端面全部节点上 `u_x(z)` 的最小二乘斜率（上游用上/下缘之差），并同时计算上游定义，
   从而把「测量定义敏感性」与物理误差分开。
3. **R1 复现**：在与上游逐位相同的网格/载荷上重解两工况（8 个 `L/h` 阶梯）。
4. **R2 上游点名要做的实验**：定长细比族（每高度 2 单元，`L/h = 4…40`）+ 截面网格 `2x2 → 3x3 → 4x4`，
   用三参数设计 `e = (a−1) + c1 (h/L) + GAP (b−1)(h/L)²` 与上游设计 `(a−1) + B(h/L)² + C(h/L)³`
   在同一数据上对比（AIC + 残差），并由 `a` 的独立纯弯钉子给出受钉版本。
5. **容量纪律**：控制面 `load15 ≈ 190–220`（nproc=128），全程单进程 4 线程；4x4 截面族在 `L/h=10`
   处被负载拖住，**只做到 `L/h = 4,6,8`**（3 点 3 参数=插值不是辨识，其系数不用来报 κ）。此限制显式登记。

## ③ 计算结果（数字表，程序化注入）

### 3.1 R1 复现（证明上游数字不是手抄）

| 复现项 | 量 | 最大偏差 | 判定 |
|---|---|---:|---|
| 力工况 8 个 `L/h` 阶梯 | `e = δ_FE/δ_EB − 1` | **3.9e-16** | 逐位一致 |
| 纯弯 8 个 `L/h` 阶梯（自建载荷+自建斜率） | `e_θ = θ_FE/θ_exact − 1` | **3.9e-15** | 逐位一致 |
| 斜率估计量（LS vs 上/下缘差） | `e_θ` 差 | ≤ 1.8e-11 | 两种定义等价 |

纯弯载荷纯度：净轴力 `7.1e-16`（相对），施加弯矩相对误差 `2.8e-16`，根部反力矩闭合 `4.4e-9`。

### 3.2 载荷施加方式敏感性（本单新增，关键）

| 工况 | 一致载荷（`σ_x = M(z−h/2)/I`） | 静力等效节点力偶 | 差 |
|---|---:|---:|---:|
| `e_θ`（`L/h=10`） | −0.346 % | **+2.551 %** | **2.90 百分点** |
| `e`（力工况，`L/h=10`） | −0.279 % | −0.270 % | 9.4e-5 |

纯弯的斜率误差**强烈依赖端面载荷的局部分布**（角点/局部奇异，St. Venant 边界层），
而力工况几乎不敏感。上游把 `a` 钉到 `σ_a = 8.8e-5` 用于后续拟合——这个不确定度比载荷施加方式的
不确定性小 **约 300 倍**。

### 3.3 R2：把「力工况未收敛」这个假设当靶子打

| 截面网格 | `L/h` 阶梯 | 1/L 模型系数 `(c0, c1, c2)` | 最大残差 | 上游 `(a−1,B,C)` 设计最大残差 | AIC（1/L vs 上游） |
|---|---|---|---:|---:|---:|
| 2x2 | 4…30（8 点） | (−4e-6, **−0.10370**, **0.75838**) | **1.1e-6** | 7.74e-4 | −223.4 vs −117.6 |
| 3x3 | 4…20（7 点） | (−0, −0.09746, **0.76724**) | 5.6e-8 | 4.12e-4 | −235.5 vs −108.6 |
| 4x4 | 4,6,8（3 点，仅插值） | (0, −0.09438, 0.76983) | 1.0e-17 | 6.1e-16 | −229.8 vs −204.2 |

截面细化把 `c2` 从 `0.75838` 移到 `0.76724`（**相对散布 1.16 %**），`c2` 的**符号与量级不变**。
由 `c2 = GAP (b−1)`，`κ_eff = κ/b`：

| 截面网格 | `b` | `κ_eff` | vs `5/6` | vs `2/3` |
|---|---:|---:|---:|---:|
| 2x2 | 1.9723 | **0.4225** | −49.3 % | −36.6 % |
| 3x3 | 1.9836 | **0.4201** | −49.6 % | −37.0 % |
| 4x4 | 1.9869 | 0.4194 | −49.7 % | −37.1 % |

纯弯族的根部层系数（本单族，`L/h=4…40`，10 点）：`e_θ = (0.0 ± 1e-6) − 0.03461 (h/L)`，最大残差 `1.8e-8`，
条件数 `15.4`。上游族（轴向 `max(24,2s)` 下限）给 `d = −0.02468` —— 同一个量的族依赖版本。

## ⑤ 注意点 / 局限

1. **不是求解器复核**：R1 复用同一份 `tensorfem.hex20` 内核（我只读不改）。能抓「数字不可复现 / 结论过度 /
   门禁失效 / 设计错设」，抓不到「HEX20 内核本身错」——后者由纯弯载荷纯度（7e-16）与反力闭合（4.4e-9）部分兜底。
2. **4x4 族不完整**（3 点）：受控制面负载限制（`load15 ≈ 200`），未做 `L/h = 10,12`；其系数只作趋势证据。
3. **`κ_eff` 的统计不确定度不能当真**：LS 协方差给 `σ(κ_eff)/κ_eff ≈ 4e-5`，那是**模型残差**噪声，
   不是模型形式误差；真不确定度由 3.2 的载荷施加敏感性与 3.3 的族依赖主导。本页不据此宣称「测到 κ」。
4. `c1`（1/L 根部层）在力工况与纯弯工况**不相等**（−0.104 vs −0.0346）：根部层与载荷类型相关，
   不能把纯弯的 `d` 当作力工况的 `d` 直接代入。
5. 范围：线性弹性、小变形、各向同性、静力；未做塑性/接触/大变形；未做时间步或模态。
