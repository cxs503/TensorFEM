# 实际流体—刚体运动反馈

本轮将 Q4 载体返回的实际速度送入 LBM 下一步，并用壁面及节点转换冲量更新 5 kg 刚体。局部边界不使用全域质量缩放；另保留全域修正的对照案例。

这是二维周期域内圆盘的自由平动验证。四节点载体只承载刚体平动，尚未包含柔性 SUBOFF 壳体、转动、自由液面或冰破坏。

## 执行和证据

使用 TensorFEM 虚拟环境，并将 TensorLBM 的 src 加入 PYTHONPATH，运行 `scripts/run_live_rigid_feedback.py --audit`。原始 population、逐步运动和冲量、完整重启及源文件 SHA256 位于 [原始证据](assets/live-rigid-feedback/study.json)。10 项接口和重启测试通过；三例实际重放均通过。

## 验收结果

| 检查 | 结果 |
|---|---|
| 局部边界总动量最大误差 | 2.53e-14 N·s |
| 实际速度反馈、力矩/功率映射、完整重启 | 通过 |
| 时间步减半后的冲量变化 | **46.3372%，失败** |
| 无外驱动的总动能变化，原时间步 | **+0.000457793 J，失败** |
| 无外驱动的总动能变化，时间步减半 | **+0.022764812 J，失败** |

初始刚体动能为 0.00225 J。时间步减半同时改变格子声速，因此该比较包含时间与可压缩性影响。当前局部节点转换与显式交错反馈存在严重能量增长，不能认定为可信湿态碰撞模型。

刚体中点冲量功等于刚体动能增量是代数恒等式，不能证明流体与刚体总能量守恒。逐步记录另行保留使用旧速度交换时的功缺陷；两个局部案例最大分别为 0.000634504 J 和 0.003986064 J。

下一阶段应先修复局部扫掠体积转换的共速伪冲量，并验证交换的能量耗散和时间收敛，再推广三维带附体 SUBOFF。
