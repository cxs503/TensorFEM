# 疲劳谱域验证：rainflow + Miner 对 Rayleigh 窄带律、计数恒等式与 Paris 幂律支

本单补的是 `docs/marine-fatigue-advanced-qualification.md` 留下的**谱域验证欠账**。该文件
声明的四个独立判据里，rainflow 只对一个三角波（单区间）核对计数总量、Miner 只对一个
已知 S-N 寿命的点乘、Paris 只验了 `m = 2` 的**指数支**。也就是说：

* 合并进 main 的 `rainflow_cycles` 的**幅值分布行为**从未被任何基准检验过——单区间算例
  在循环幅值分布错误、半循环记账错误、采样丢失这几种缺陷下都会照样通过；
* `paris_crack_growth` 的 `m != 2` **幂律支**（`a^(1-m/2)` 递推）完全没有覆盖。

本文件用**独立数学**（不是第二个 FE，也不是第二个自研计数器）把这四类对象重算一遍：
窄带 Rayleigh 闭式损伤律、ASTM E1049 计数恒等式、Paris 常量几何闭式积分，以及对采样率与
记录起点这两类"实现无关但会毁掉结论"的敏感性做定量标定。

## 1) 案例与判据

| 项目 | 取值 |
|---|---|
| S-N 曲线 | `N = N_ref (S_ref / S)^m`，`S_ref = 100 MPa`，`N_ref = 2e6`，`m = 3`（单斜率，无截止） |
| 应力过程 | 平稳带限高斯，RMS `sigma = 40 MPa`，中心频率 `f0 = 1 Hz`，谱为 `M = 101` 条等幅余弦的平带 |
| 谱宽 | `eps = sqrt(1 - m1^2/(m0 m2))`，由实际离散分量矩**精确算出**，不作假设 |
| 记录长度 | 每个谱宽算例 20000 个名义循环 |
| 采样 | 每循环 40 点（40 x f0），另做 4/6/8/12/20/40 点扫描 |

窄带（Rayleigh）闭式律：窄带高斯过程的应力幅服从 Rayleigh 分布，**应力范围** `S = 2a`
服从 `p(S) = S/(4 sigma^2) exp(-S^2/(8 sigma^2))`，于是单循环期望损伤

```
E[S^m] / C = (2 sqrt(2) sigma)^m Gamma(1 + m/2) / C ,   C = N_ref S_ref^m
```

这就是 DNV-RP-C203 附录 B 的窄带公式（原始统计见 Bendat 1964 / Rice 1944），
本模块 `narrow_band_damage_per_cycle` 直接实现它。两种归一化都报，因为它们回答不同问题：

* `damage_ratio` = 数值损伤 / 以**实际计得循环数**取的 Rayleigh 参考 → 只检验**范围分布**；
* `damage_rate_ratio` = 数值损伤 / 以**谱上穿率** `nu_up T` 取的参考 → 检验**物理损伤率**，
  这才是窄带公式的本义（窄带假设把 `nu_up T` 与计得循环数视为同一件事）。

## 2) 怎么做的

1. `src/tensorfem/rainflow_spectrum_reference.py`：带限高斯过程生成器（返回精确谱矩）、
   Rayleigh 密度/矩、窄带损伤、采样亏损前导估计 `(1 - pi^2/(6N^2))^m`、
   Paris 幂律闭式、ASTM 计数恒等式检查、算例封装。全部 float64，无随机隐状态（种子固定）。
2. `scripts/audit_marine_fatigue_spectrum.py`：跑四项研究并把**脚本回读**的数字写入
   `benchmarks/marine_fatigue_spectrum_evidence.json`（零手抄），同时生成 4 张图。
3. 被测对象是 main 上的生产函数：`marine_fatigue_advanced.rainflow_cycles` /
   `spectrum_miner_damage` / `paris_crack_growth`，未修改它们一行。
4. 复现：`OMP_NUM_THREADS=1 PYTHONPATH=src python scripts/audit_marine_fatigue_spectrum.py`；
   fail-closed 判据锁在 `tests/test_marine_fatigue_spectrum_reference.py`（11 项全绿）。

## 3) 计算结果（脚本回读）

### 3.1 谱宽扫描（每循环 40 点，20000 循环）

| `eps` | 计得循环数 | `damage_ratio` | `damage_rate_ratio` | 计数率偏差 | 相对 Rayleigh 误差 |
|---:|---:|---:|---:|---:|---:|
| 0.1158 | 20880 | 0.96700 | **1.00278** | +3.70% | 3.300% |
| 0.0582 | 20320 | 0.99521 | **1.00945** | +1.43% | 0.479% |
| 0.0291 | 20120 | 1.00618 | **1.01181** | +0.56% | 0.618% |
| 0.0146 | 20060 | 1.00946 | **1.01241** | +0.29% | 0.946% |

读数：最窄带（`eps = 0.0146`）的逐循环范围分布与 Rayleigh 律差 **0.95% < 3%**；
`eps` 变宽时**计数率**先偏离上穿率（+3.70%），使逐循环归一化比值被拉低到 0.967
（即最宽带的逐循环口径 3.30% > 3%，**如实记为不通过**），但物理损伤率始终
`>= 1.00`——与"有限带宽下 rainflow 损伤不低于窄带估计"的理论方向一致。

### 3.2 采样率敏感性（`eps = 0.0146`）

| 每循环采样点数 | 4 | 6 | 8 | 12 | 20 | 40 |
|---|---:|---:|---:|---:|---:|---:|
| 实测 `damage_ratio` | 0.77117 | 0.89213 | 0.94220 | 0.98030 | 1.00061 | 1.00946 |
| 前导估计 `(1-pi^2/6N^2)^3` | 0.72220 | 0.86909 | 0.92486 | 0.96612 | 0.98771 | 0.99692 |

离散采样把每个极值向内拉，范围按 `1 - pi^2/(6N^2)` 缩短、损伤按 `m` 次幂放大缺失：
**每循环 6 点会丢 11% 损伤，4 点丢 23%**。这是本次审计发现的最实用的一条工程告警：
用应力时程喂 rainflow 时，采样率不足的偏差比大多数建模误差都大，且方向永远是**低估**。

### 3.3 记录起点与残差记账

| 记录长度 | 起点偏移 0 / 5% / 20% / 50% 的损伤比 | 计得循环数 |
|---|---|---|
| 20000 循环 | 1.000000 / 1.000015 / 1.000000 / 1.000000 | 20060.0–20060.5 |
| 200 循环 | 1.000000 / 1.001204 / 1.000996 / 1.001232 | 202.5（四点全同） |

### 3.4 ASTM E1049 计数恒等式

300 组随机闭合历程（`h = [v0, v1.., v0]`）：`sum(count) = (n_rev - 1)/2` **违例 0/300**，
绝对缺陷 0.0（双精度零）。即每个极值区间恰好被记账一次，既没丢也没重复计。

### 3.5 Paris 幂律支（常量几何）

| 算例 | 指数 `m` | 生产 `a_f (m)` | 闭式 `a_f (m)` | 相对误差 |
|---|---:|---:|---:|---:|
| `m2_exponential`（既有覆盖） | 2.0 | 1.0034e-02 | 同 | 0.000e+00 |
| `m2p5_power` | 2.5 | 1.6411e-02 | 同 | 0.000e+00 |
| `m3_power` | 3.0 | 1.0021e-02 | 同 | 0.000e+00 |
| `m4_power` | 4.0 | 1.0004e-02 | 同 | 0.000e+00 |

`m > 2` 时括号项可以被推过零，生产代码抛 `ValueError("... unbounded")`；本模块闭式返回
`inf`，测试同时锁住两条行为（fail-closed 一致）。

## 5) 注意点（踩过的坑 / 适用范围）

1. **采样亏损是这个链条里最容易被忽略的误差源**：6 点/循环 → −11% 损伤，方向固定为低估。
   仓库此前没有任何文档记录这一点，本文件把它变成可测判据（测试里锁 `< 0.93`）。
2. **两种归一化不能混用**。用"计得循环数"归一化时，宽带信号会因为多出许多小幅振荡而
   把比值压到 1 以下（`eps = 0.1158` 时 0.967），此时若宣称"rainflow 低于解析律"就错了：
   物理损伤率是 1.0028。本文件把 `damage_rate_ratio` 作为主判据，并同时公布两者。
3. **起点只动残差分解，不动总量**：开放式长记录的残差半循环随起点偏移变化，但损伤变化
   `<= 0.002%`（20000 循环）/ `<= 0.13%`（200 循环）。短记录、跨边界的大循环会被记成残差
   半循环，因此该类算例必须显式声明起点，或把记录头尾闭合。这是 ASTM 约定本身的性质，不是缺陷。
4. **生成过程的局限**：等幅余弦和的平带谱并非任何船级社波浪谱；它只用于比较分布。
   宽带的 Wirsching 修正因子没有实现，本文件也不给宽带损伤的外推结论。
5. Rayleigh 参考只对 `sigma` 与 `m` 成立；`m` 变化会放大分布尾部权重，尾部样本量不足时
   统计涨落随 `m` 增大（本例 `m = 3`、20000 循环下损伤的相对标准差约 1.1%）。

## 6) 误差判定（逐项，是否 < 3%）

| 关键量 | 基准 | 误差 | < 3% ? |
|---|---|---:|---|
| 窄带（`eps = 0.0146`）逐循环损伤 | Rayleigh 闭式 `E[S^3]/C` | 0.946% | **是** |
| 窄带（`eps = 0.0291`）逐循环损伤 | 同上 | 0.618% | **是** |
| 中带（`eps = 0.0582`）逐循环损伤 | 同上 | 0.479% | **是** |
| 宽带（`eps = 0.1158`）逐循环损伤 | 同上 | 3.300% | **否**（带宽外，见注意点 2） |
| 全部谱宽物理损伤率 | 窄带损伤率 `nu_up T` | `+0.28% ~ +1.24%`（恒 `>= 1`） | **是** |
| 窄带计数率 | 谱上穿率 `sqrt(m2/m0)` | 0.29% | **是** |
| ASTM 计数恒等式（300 组闭合历程） | `(n_rev-1)/2` | 0.0（精确） | **是** |
| Paris `m = 2 / 2.5 / 3 / 4` 终裂纹 | 闭式积分 | 0.000e+00（双精度） | **是** |
| 采样敏感性标定 | 前导估计 `(1-pi^2/6N^2)^m` | 定性一致、量级一致（见 3.2） | 不适用（该量是偏差本身） |

结论：合并功能在**窄带到中等带宽**与谱域解析律一致（< 1%），Paris 幂律支与闭式逐位相同；
最宽带（`eps = 0.1158`）的逐循环口径 3.30% **未过** 3% 门限，原因已定位且未粉饰。

## 7) 范围与未做

* 不涉及船级社规范符合性、细节类别选取、平均应力修正、检验周期；
* 未实现 Wirsching 宽带修正、雨流矩阵/马尔可夫链、非高斯（Weibull）过程；
* 未做变幅块谱的载荷顺序效应（Miner 本身无序，本文件不检顺序相关模型）；
* `damage` 只对单斜率、无截止的 S-N 曲线成立；双斜率/截止段需另建参考。
