# CASE-FEM-ELASTIC-RESTRAINT-TWO-WAY-PEAK — 双向弹性嵌固带的独立基准与峰值应力口径

**锚点**：`GAP-PP-4-ICE-STRUCT-ELASTIC-RESTRAINT`（JOUR-ICE-STRUCT §4.2 边界口径）
**模块**：`src/tensorfem/plate_elastic_restraint.py`、`src/tensorfem/plate_levy_restraint.py`
**探针**：`scratch/probe_two_way_peak.py`　**测试**：`tests/test_plate_restraint_two_way.py`
**图**：`docs/figures/elastic_restraint_two_way_peak.png`

## 1. 案例介绍

冰带板格由纵骨（一对边）与横框架（另一对边）提供**有限**转动刚度。既有工作
（`docs/CASE-FEM-ELASTIC-RESTRAINT-TRIBUTARY.md`）验证了**单向**嵌固带（β_x 扫描、β_y=0），
但论文工况是**四条边同时嵌固**。该双向带此前只有「FEM 对 FEM」，且其峰值应力用的是
Gauss→节点外推口径。本单补：(1) 双向带的独立基准；(2) 峰值应力口径审计与修复；
(3) 顺带发现并修复压力块载荷积分缺陷。

| 项目 | 数值 |
|---|---|
| 论文板格 | 0.8 m × 0.7 m × 22 mm |
| 材料 | E = 206 GPa, ν = 0.3 |
| 载荷 | 全宽 10 %L 压力块 p = 1 MPa（论文工况）；均布 p 用于基准对照 |
| 验证板 | 1 m × 1 m × 10 mm, E = 200 GPa, ν = 0.3, q = 1 kPa（剪切误差 ~0.03 %） |
| 嵌固律 | ζ = β/(1-β)，c_r = ζD/a，M_n = c_r θ_n |

## 2. 怎么做的

1. `ritz_restrained_plate` 增加**精确模态载荷积分**（`_modal_integral`），压力块工况也有无 FE 基准；
   先在 β_y=0 处对**精确 Levý 解**标定基准自身误差：w 相对误差 2e-5 / 1e-4 / 3.4e-3，
   M_n 相对误差 1.2e-3 / 4.3e-3 / 1.16e-2（β = 0.2 / 0.5 / 0.8，40×40 模态）。
2. FE 弹簧口径 `edge_spring_stress`（M_n = c_r θ_n）与精确 Levý / Ritz 对比，同时对照旧的外推值
   `moments_at_nodes`。
3. `peak_bending_stress` 新增 `peak_von_mises_consistent`：内部节点用外推 von Mises，受限边用
   弹簧口径，按 SS2 边运动学 M_t = νM_n、M_nt = 0 ⇒ σ_vm = (6|M_n|/t²)·√(1-ν+ν²) = 0.8890·σ_n。
   旧键全部保留（向后兼容）。
4. `rect_patch_pressure` 携带 `patch_bounds/intensity`，面板求解器在**单元∩压力块**矩形上做
   2×2 Gauss（双线性形函数在该矩形上积分精确）。

## 5. 注意点（坑与局限）

1. **压力块载荷积分缺陷（本轮发现并修复）**：原实现的 2×2 Gauss 作用在**整个单元**上。
   压力块宽 0.08 m 与 L/8=0.1 m、L/16=0.05 m 同量级时，压力块只在 Gauss 点上被采样，
   施加总载荷随网格振荡：nx = 8/12/16/24 时 `w_centre` = 0.830 / 0.582 / 0.872 / 0.587 mm，
   而无网格收敛趋势。修复后 `test_patch_load_integration_is_exact`（已通过）断言
   `Σfe = q·c·S` 到机器精度（nx = 8…24）。
2. **只在细网格验收会漏掉它**：nx=160（论文验收点）时单元尺寸 5 mm ≪ 80 mm，误差很小；
   工程网格（nx≤32）才是暴露区。这与从属边长缺陷同源，都是「网格相关性」错误。
3. **受限边不能用外推弯矩**：nx=16 时外推 `M_n` 只有弹簧值的 ~17 %（薄板方形）、
   β=0.8 论文板格仅 ~50 %；角点上外推更是伪峰（见 §3.3 β=0）。
4. **β→1 的正则化**：ζ=1/ε=1e6 逼近固支，极细网格（h/a<1e-4）失效，此时用 `boundary="clamped"`。
5. **基准水平**：Ritz 是变分解（位移自上方收敛），β=0.8 的 M_n 自身误差 ~1 %。

## 6. 误差判定（是否 <3 %）

| 关键量 | 基准 | 误差 | <3 %？ |
|---|---|---|---|
| 单向 β=0.8 边弯矩（nx=16，弹簧口径） | 精确 Levý | −0.18 % | 是 |
| 单向 β=0.8 边弯矩（nx=16，外推口径） | 精确 Levý | ≈ −83 % | **否（缺陷，已换口径）** |
| 双向 β=0.8 中心位移（nx=24） | 独立 Ritz | +0.48 % | 是 |
| 双向 β=0.8 边弯矩（nx=24，弹簧口径） | 独立 Ritz | ≤1 % 量级（基准自身 ~1 %） | 是（限基准分辨率） |
