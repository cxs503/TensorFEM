# 自由板振动：MITC4 假定剪应变消除 SRI 沙漏模态（能力从"有保留"升为"无保留"）

**Status:** capability extension + verification report
**Repository:** TensorFEM · **Module:** `tensorfem.plate_vibration`（新增 `shear_treatment` 选项）、复用 `tensorfem.plate.q4_mindlin_stiffness`
**Evidence:** `benchmarks/free_plate_mitc_vibration.py`、`benchmarks/free_plate_mitc_vibration_evidence.json`、`tests/test_plate_vibration_mitc.py`（17 项）
**锚点：** `NEW:自由板 SRI 沙漏模态致自由边界振动能力带保留，MITC4 清偿`

## ① 案例介绍（物理背景/几何/参数）

船底板格、舷侧板格在无支承边（大开孔、自由边、弱加筋边）处的振动模态与简支/固支完全不同。
`docs/free-plate-vibration-validation.md` 把自由边界路径纳入验证的同时，明确留下一条**能力保留**：

> **SRI Q4 在自由边界下多出 1 个零能量（沙漏）模态**：自由板物理上应有 3 个刚体模态，
> 实测每个网格都是 4 个零能量模态。……要把自由边界升格为无保留能力，需要 MITC4 或沙漏控制，本单未做。

本单清偿该条：把仓库里**已存在但未接入振动路径**的 MITC4（Dvorkin–Bathe 假定自然剪应变）
交给 `solve_plate_vibration` 使用，并用三层证据证明它确实消灭了沙漏、且不污染已认证的支撑边界工况。

| 参数 | 符号 | 取值 |
|---|---|---|
| 板长 / 板宽 | a, b | 1.0 m / 1.0 m（方形） |
| 板厚 | h | 0.01 m（a/h = 100，薄板） |
| 弹性模量 / 泊松比 | E, ν | 200 GPa / 0.30 |
| 密度 | ρ | 7850 kg/m³ |
| 抗弯刚度 | D = Eh³/12(1−ν²) | 1.8315×10⁴ N·m |
| 边界 | — | 完全自由（主工况）；简支/固支（回归对照） |
| 单元 | — | Q4 Mindlin 板，弯曲 2×2；剪切 `sri`（1 点）/`mitc`（MITC4）/`full` |

## ② 怎么做的（方法/流程/关键设置/工具链）

**代码改动（最小增量，默认路径逐位不变）**：`solve_plate_vibration` 新增关键字
`shear_treatment`（`"sri"` 默认 / `"mitc"` / `"full"`，非法值抛 `ValueError`），透传给
`q4_mindlin_stiffness`，并写回结果 `PlateVibrationResult.shear_treatment`。
默认值仍是历史 SRI，因此**既有调用行为零变化**（测试用 `torch.equal` 逐位锁定默认路径）。
`shear_correction` 显式传入模块常量 `5/6`，与历史调用等价。

**三层证据（互不自我指涉）**：

1. **刚度零空间（单元级，非特征值挑选）**：直接组装自由板总刚 `K`，数 `|λ| ≤ 1e-9·|λ|max` 的
   零特征值个数。同时用三个**精确刚体位移**（w=1；w=x, θx=−1；w=−y, θy=+1，对应单元剪应变
   口径 γ = w,∇ + θ）检验 `‖Ku‖/(‖K‖‖u‖)`。
2. **沙漏模态的定性与定量隔离**：零空间是 4 维时，`eigh` 给出的是任意基。把某个零向量对
   三个刚体位移张成的子空间做欧氏投影，得到唯一方向 `h`；刚体位移在两种剪应变规则下能量
   都是 0，所以判据是 **`h` 在 MITC4 刚度下的能量**：若显著非零，则 `h` 不是刚体位移，而是
   只有 SRI 单点采样"看不见"的伪机构。
3. **频率对独立参考**：`tensorfem.plate_ritz_reference`（全局 Rayleigh–Ritz，Kirchhoff，
   与 FE 不共享单元/积分/自由度布局）给自由板无量纲频率；该参考自身先对文献 Leissa SP-160
   钉住（13.468 / 19.596 / 24.272）。

**回归面**：简支/固支工况 `sri` vs `mitc` 逐阶对比（差 ≤0.01 %），固支对 Leissa 35.9853；
自由板 + 均匀 Winkler 地基的**精确**平移模态 ω² = k_w/(ρh)。

工具链：
```bash
OMP_NUM_THREADS=8 PYTHONPATH=src python benchmarks/free_plate_mitc_vibration.py
OMP_NUM_THREADS=8 PYTHONPATH=src python -m pytest -q tests/test_plate_vibration_mitc.py
```

|---:|---:|---:|---|
| 6 | **4** | **3** | 3.2e−17 / 4.7e−17 |
| 8 | **4** | **3** | 1.2e−17 / 5.2e−17 |

## ⑤ 注意点（踩过的坑/局限/适用范围）

1. **零空间里的本征向量是任意的**：4 维零空间上 `eigh` 返回的是任意基，直接取第 4 个向量
   做"沙漏形态"会得到刚体与沙漏的混合（本单第一版实测 ‖θ‖/‖w‖ = 0.45，看起来完全不像沙漏）。
   必须先对刚体子空间投影再定性，否则结论不可复现。
2. **刚体位移口径**：单元剪应变为 `γ = w,∇ + θ`（代码口径），因此刚体转动的转角自由度为
   `θx = −1`（w = x）、`θy = +1`（w = −y）；若沿用薄板教材的 `θ = +w,∇`，残差会假性非零。
3. **自由度布局是交错的**（节点 i → 3i, 3i+1, 3i+2），按"全部 w 再全部 θ"拼接会得到 0.23 的
   假残差；本单第二版即踩此坑。
4. **MITC4 在粗网格下略刚**：同一网格 MITC4 的高阶模态误差比 SRI 大 0.3–0.9 个百分点
   （λ₄：n=8 时 2.219 % vs 1.389 %）。原因是 SRI 的沙漏污染使结构"偏软"而部分抵消了离散刚化；
   两者都单调收敛到 Ritz 参考，**MITC4 的误差是可信误差，SRI 的偏小误差不可信**。
   这是本单诚实记录的反直觉现象，禁止把"SRI 误差更小"当作选择 SRI 的理由。
5. **n=6 第 3 阶两侧都超 3 %**（3.94 % / 3.99 %）：粗网格下不宣称 3 % 达标，见 ⑥。
6. **适用范围**：均匀厚度、各向同性、小应变、线性弹性、无预紧/附加质量/阻尼/流固耦合；
   稠密代数，24×24 以上应换稀疏特征值求解器。MITC4 只改剪切块，弯曲块与 SRI 同一个 2×2 规则。

## ⑥ 误差判定（逐项对基准，显式回答是否 <3 %）

| 关键量 | 基准 | 本次结果 | 是否 <3 % |
|---|---|---|---|
| 自由板 λ₁ @n=12（MITC4） | Rayleigh–Ritz（自身对 Leissa 0.0015 %） | +0.461 % | **是** |
| 自由板 λ₂ @n=12（MITC4） | 同上 | +1.291 % | **是** |
| 自由板 λ₃ @n=12（MITC4） | 同上 | +2.083 % | **是** |
| 自由板 λ₁..λ₃ @n=16（MITC4） | 同上 | +0.382 / +1.094 / +1.809 % | **是** |
| 自由板 λ₃ @n=6（MITC4 与 SRI） | 同上 | +3.989 % / +3.941 % | **否（honest FAIL，粗网格）** |
| 零能模态数（自由板，n=6…16） | 物理上必须为 3 | MITC4 恒为 3；SRI 恒为 4 | **是（MITC4）** |
| 多余模态的伪机构性 | 刚体位移两规则同为零能量 | `E_SRI/E_MITC ≈ 1e−18`，θ≡0 | 判定为伪机构（非刚体） |
| 支撑边界 λ₁（固支）@n=12 两规则差 | 互相（同一单元族） | ≤0.01 % | **是** |
| 固支 λ₁ @n=12 | Leissa 35.9853 | +2.914 %（MITC4） / +2.908 %（SRI） | **是** |
| 自由板 + 地基平移模态 ω² | 闭式 k_w/(ρh) | 相对偏差 5.9e−9 | **是** |

**结论**：自由板振动的"1 个多余零能模态"这一保留项在 MITC4 路径上**已消灭**（能力升格为无保留，
`rigid_body_modes` 恒为 3），频率在 n≥12 时三阶以内全部 <3 %；粗网格 n=6 第 3 阶 3.99 % 保留为
honest FAIL。默认 SRI 路径逐位不变，历史报告结论不受影响。
