## ① 案例介绍（物理背景 / 几何 / 参数表）

冰与船体外板的相互作用中，接触压力在冰缘与板面之间分布**不均匀**：局部碎冰/挤压形成高压斑（high-pressure patch），其空间分布由冰-结构界面（可压碎、可损伤的薄层）与板格刚度的**局部竞争**决定，而不是一个给定的均匀压力。本用例补上这一环：

* **接触侧**：`CrushInterfaceLaw`——压缩侧可损伤界面律（弹性→线性软化→残余平台），在**非匹配**接触网格上给出法向压力场 `p(x_i, y_i)`；
* **传递层**：`patch_from_contact()` 把压力场投影成板格载荷阵列 `f = Cᵀ(w·p)`；
* **结构侧**：`PlateModel`（Q4 Mindlin，选择性缩减积分，`plate.q4_mindlin_stiffness`）；
* **双向反馈**：`δ_i = d − g_i − (Cu)_i`，板的变形反过来降低侵入量，直到不动点收敛。

## ② 方法与实现

### 传递算子（本节点新增能力）

```
w_points = C u                     # 板面变形投影到接触点（冰看到的板面）
f        = Cᵀ (w ∘ p)             # 压力场投影成板格载荷阵列（一致载荷）
δ        = clamp(d − g − w_points, 0)   # 侵入量（双向反馈）
p        = law.envelope(δ)        # 压缩侧可损伤界面律
K u = f  →  M = +D_b κ  →  σ = 6|M|/t²
```

* `C` 是板的 Q4 双线性形函数在接触点处的行（`plate_contact_interpolation`），**同一算子同时用于正反两向**，故 `p·(Cu) = f·u`（功共轭）且 `Σf = Σ w_i p_i`（力守恒）——两条恒等式在测试中以机器精度断言，不是容差。
* 单元刚度直接复用 `plate.q4_mindlin_stiffness`（SRI），未引入新单元格式；`PlateModel` 只做一次性装配+Cholesky 分解+向量化 Gauss 点弯矩恢复。
* 弯矩约定：该单元转角自由度满足 `θ_x = −w,x`（其横向剪应为 `γ_x = w,x − θ_x`），故下挠为正时**下凹弯矩** `M = +D_b κ`，与 Navier 级数同一支。
* 收敛判据：`max|w_new − w_old| ≤ 1e-6·max(1, max|w|)`，欠松弛 0.6，迭代历史与 `converged` 标志原样入工件（不假设收敛）。

### 基准出处（external anchor）

* **Timoshenko & Woinowsky-Krieger, Theory of Plates and Shells (1959), Table 8 / Art. 30**：均布简支方板 ν=0.3，`w_max = 0.00406235 q a⁴/D`，`M_max = 0.0479 q a²`。
* **Navier 双正弦级数**：对任意可积压力场 `p(x,y)` 的简支矩形板精确解（本模块内实现，含 Reissner 横向剪切挠度项）；载荷系数用 48 点 Gauss 积分精确求出，级数取 ['199', '299'] 项做收敛对照。

## ⑥ 失败模式与工件

* **工件**：`artifacts/contact_patch_load/study.json`（全部数值+恒等式残差）、图：`pressure_fields.png`、`amplification_sweep.png`、`ridge_moment_profile.png`
* **一键复现**：`python benchmarks/contact_patch_load_ice.py`（约 67 s，单机 4 线程；>10 min 的规模应走集群队列）
* **单元测试**：`pytest tests/test_contact_patch_load.py -q`（10 项，覆盖传递恒等式、文献系数、级数单模态精确性、非均匀场对照、界面律分支、耦合收敛与守恒）
* **恒等式残差（每个耦合算例）**：力守恒与功共轭为机器精度；反力平衡 ~1e-9；应变能与外力功差为机器精度。

### 失败模式 / 局限

1. 界面律是**一维可损伤压缩律**（弹性-软化-残余平台），不是率/温度相关的海冰本构；残余平台是对持续压碎与挤出的均质化替代。峰值强度与软化比是**输入参数**。
2. 板为线弹性 Mindlin 小挠度；板惯性与附连水质量不在环内，耦合为准静态。
3. 接触点必须落在板格内（越界抛 `ValueError`），冰覆盖超出板格的情形未建模。
4. 峰值应力位于固支边，网格收敛慢（见 5.1），故绝对应力值应带 GCI 不确定度读；**放大系数与传递恒等式**是稳健的可交付量。
5. 冰缘缺陷用正弦轮廓参数化；真实冰缘几何/碎冰粒径分布未纳入。

### 是否 <3%（逐项显式回答）

* 文献系数：w_c +0.038%、M_max -0.090% → **<3% ✔**
* Navier 级数（均布，24×24）：M_peak -0.231% → **<3% ✔**
* Navier 级数（中心斑，24×24）：M_peak +0.388% → **<3% ✔**
* Navier 级数（脊形斑，24×24）：M_peak -0.810% → **<3% ✔**
* 耦合算例的峰值应力：无独立解析基准（固支边+非线性界面），以 GCI 给出不确定度（见 5.1），不宣称 <3%；其**传递恒等式**为机器精度、**刚冰 vs 双向**的差值由同一网格两次求解得到（差值与网格误差无关）。
