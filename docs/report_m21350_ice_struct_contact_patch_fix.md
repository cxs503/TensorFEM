# GAP-PP-1-ICE-STRUCT-CONTACT-PATCH: uniform-patch force-bias defect fixed

**Mission:** 21350 · **Branch:** agent/m21350 · **Commit:** 580c3b32

## 1. Case (physical background / geometry / parameters)

Ice-sheet contact on a ship-hull ice-belt panel produces a **non-uniform** contact
pressure (high-pressure core + lower-pressure periphery). The JOUR-ICE-STRUCT
baseline (`panel_patch_load_results.json`) idealises it as a **uniform** patch
pressure `p_ref` over a rectangular footprint. The two-way CZM-contact → plate
chain (`tensorfem.ice_panel_patch_contact`) must compare the non-uniform patch
against a uniform patch **at the same total force and same footprint**, so the
peak-stress delta is attributable to pressure non-uniformity alone.

Panel: 0.8 m × 0.7 m, t = 22 mm, E = 206 GPa, ν = 0.3, reference local pressure
1 MPa (JOUR-ICE-STRUCT design point). Total normal force 40 kN over a ~0.2 m
footprint (mean ~1 MPa).

## 2. How it was done (method / key setting / tool chain)

`uniform_patch_pressure` builds a uniform `p0 = total_force/area` over a
rectangular footprint `[x0,x1]×[y0,y1]`. **Defect found:** its pressure grid
spanned the *whole plate* `[0,a]×[0,b]` (with the patch edges added as grid
points), so the **bilinear interpolant** used by `patch_from_contact`'s exact
sub-cell overlap integration left `0→p0` boundary ramps on the *interior* patch
edges. The exact integral of those ramps **overestimated the applied force by
~6 %** (42366.7 N vs the true 40000 N at 40 kN).

This biased:
- the **non-uniform-vs-uniform** comparison (a flat ice edge, which must
  collapse onto the uniform reference, disagreed by ~4 % in peak stress), and
- the **design-point calibration** against the JOUR-ICE-STRUCT baseline.

**Fix:** the grid now spans only the loaded footprint `[x0,x1]×[y0,y1]` (clamped
to the plate), so the field is a **true step function** and `patch_from_contact`'s
`outside_zero` projection conserves `p0·area` to machine precision. The flat-edge
self-check tolerance was relaxed from `1e-9` to `1e-6` (the two patches are built
on different grids and agree to ~1e-7, not exactly).

## 5. Notes / limitations

- The two patches (CZM contact grid vs uniform `_grid`) are built on different
  grids, so they agree to ~1e-7, not exactly — hence the `1e-6` tolerance.
- Small-deflection Mindlin plate; no plasticity/buckling (declared model limit).
- The fix only affects the *uniform reference* construction; the CZM contact
  solve and the exact-conservative projection are unchanged.

## 6. Error judgement

Key quantity: **uniform-patch applied force vs `p0·area`**.
- Before fix: **+5.9 %** (42366/40000) — this was the material defect.
- After fix: **0** (machine precision, 6.5e-16).

Secondary: `fem_vs_navier` = **−0.648 %**, same order of magnitude as the
0.339 % H3-ICE-PLATE-FEM anchor (both < 1 %). **Is it < 3 %? Yes.**

**Disposition:** defect fixed; the non-uniform-vs-uniform comparison and the
design-point calibration are now at the correct (same-force) caliber.
