## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理背景**：Timoshenko 梁的运动方程包含剪切变形与转动惯量，波长越短（阶次越高）两者越不可忽略。
位移型有限元的频率误差 = 插值误差（随网格加密下降）+ 求根误差（收敛后不下降）；对**等截面**构件
前者完全可以避免：方程有闭式通解，取出精确动刚度矩阵，自然频率就是 `det K(ω)=0` 的根。
船体梁的"深梁"程度由 L/√(I/A) 衡量：本船体梁 I/A = 73.26 m²，
L/√(I/A) = 26.87——与算例 A 的 L/√(I/A)=25√12≈87 相比剪切柔度大得多：

**算例 A（验证基准）**：钢制矩形截面深梁，L=10 m、0.2×0.4 m（L/h=25），E=2.06e11 Pa、ν=0.3、ρ=7850 kg/m³、κ=5/6。
剪切与转动惯量在 1 阶为 0.58 %，到 4 阶为 4.97 %（相对 Euler-Bernoulli）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 精确动刚度单元（`dsbeam.py`）

无量纲坐标 ξ=x/l，记

    S = ρA ω² l⁴ / EI,   R = I/(A l²),   γ² = κGA l² / EI,   B = S/γ²

Timoshenko 方程消元后得 λ 的四次特征方程

    λ⁴ + S(1/γ² + R) λ² + S(SR/γ² − 1) = 0

四个根 λ_k 实或纯虚，通解

    W(ξ) = Σ_k a_k exp(λ_k ξ),      ψ(ξ) = Σ_k a_k ((λ_k²+B)/λ_k) exp(λ_k ξ)

**用复指数而不是传统的 cosh/sinh+cos/sin 双分支**：第二谱（`S > γ²/R`，即 ω > √(κGA/ρI)）时
λ² 的两根变号、传统写法要切换分支，复指数写法无需分支。基函数做"以单元中点为心的归一化"
（双曲对除以 cosh(u/2)），否则 cosh(u) 在 u≳15 时吃掉精度（测试与 mpmath 高精度对拍确认）。

单元矩阵由**能量泛函**在精确解空间上的限制给出（而非边界通量形式）：

    q(a) = ∫₀^l [EI ψ_x² + κGA(w_x−ψ)²] dx − ω²∫₀^l [ρA w² + ρI ψ²] dx
    K_e(ω) = H^{-T} Q H^{-1},   Q_ij 为闭式指数积分 2sinh(s/2)/s, s=λ_i+λ_j

`H` 把 4 个幅值映射到节点自由度 (w1,ψ1,w2,ψ2)。**Q 是精确解空间的 Gram 矩阵，所以 K_e(ω) 对称是构造
性保证**（测试实测 |K−Kᵀ|/|K| ≈ 2e-16），也避免了通量形式在 Euler-Bernoulli 极限下 `κGA·0` 的
不定式（代码里改用 `−B/λ` 表达剪应变因子，测试专门覆盖）。

### 2.2 Wittrick–Williams 计数 + 二分/割线 safeguard 求根

    J(ω) = J₀(ω) + s{K(ω)}
    J₀ = Σ_单元（该单元固-固自然频率 < ω 的个数）      s{·} = 负特征值个数（Sylvester 惯性律）

要点与踩坑：**单元固-固频率是 K_e 的极点而不是零点**。`det K_e` 的零点其实是单元的"自由-自由"频率，
用 `det K_e` 变号计数会把极点与零点一起数（实测每个物理频率产生 2 次变号）。本模块用**实基**
（双曲对/三角对）构造的固-固行列式计数极点，并用 |K_e| 在该频率处放大 10²–10³ 倍做交叉验证。

求根：先在 `J` 上做**扫描定界**（J 为单调阶梯，步长必须恰为 1，否则自动加密网格重扫），
再在单根区间内二分，最后用**缩放行列式的 Brent（二分+割线/反二次插值）抛光**，抛光后用
`J(root∓ε)` 复核（必须 `k−1 → k`）。审计失败直接抛 `RuntimeError`，不返回可疑频率。

两处"非物理修正"在计数里显式扣除并在文档写明：
(i) 自由-自由梁的 2 个零频刚体模态（J 计的是特征值，需扣掉才是弹性频率）；
(ii) ω=√(κGA/ρI) 处两个色散根重合、基函数退化，行列式出现一个孤立的数值零点——它不是有限梁的自然频率
（对应 k=0 的无限梁分支），计数扣 1，并在求值点落在该阈值附近时抛显式错误。

### 2.3 三个对拍面（互相独立）

1. **闭式**：简支 Timoshenko（Hu–Timoshenko 二次式）、细长梁 Euler-Bernoulli 超越根（βL=4.7300/7.8532/10.9956/14.1372、悬臂 1.8751/4.6941/7.8548）。
2. **有限元加密 + Richardson**：TensorFEM 已有的两场一致 Timoshenko 单元（`timoshenko_beam_modal`），8→128 单元，三点 Richardson/Atiken 外推。
3. **计数**：J(ω) 对解析模态计数（简支，含第二谱上支）；另有收敛位移 FEM 的特征值计数与 `det K` 变号扫描作旁证。

### 2.4 m6117 复现与归因

在脚本内逐行重写 m6117 的两节点单元（Φ 修正刚度 + **Euler-Bernoulli 一致质量**，ρI=0）与其闭式锚点
`f_EB/√(1+β²EI/(κGA L²))`，先复现 6.28 %，再用三种独立模型判定谁对：

* 精确 DSM（ρI=0，与 m6117 相同假设）；
* 精确 DSM（含转动惯量，物理正确）；
* **裁判**：TensorFEM 两场一致 Timoshenko 单元 128 单元（与 DSM 无共享代码）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **单元固-固频率是 K_e 的极点，不是零点**：用 `det K_e` 变号计数会双计（每个物理频率 2 次变号）。必须用实基底构造的固-固行列式。
2. **复基底的行列式是纯虚数**：直接取实部做变号扫描只会数到舍入噪声（实测 4000 点上出现 1950 次"变号"）。实基底变换后才是真行列式。
3. **基函数必须中心归一化**：未归一化的 e^{λξ} 基在能量积分里带进 e^{2u} 量级的相消增益（u≳15 即 ~1e13），
   双曲对必须除以 cosh(u/2)、并以单元中点为心。归一化后 1600–1900 rad/s（u≈17–19）仍保持：对称性 1e-16、
   静态极限对经典 Φ 单元 5.3e-10、WW 计数与解析模态计数逐点一致。
4. **loong64 平台的 BLAS 陷阱**（与 m6117 记录一致）：`np.linalg.inv` 解 4×4 要 6.4 ms、矩阵右端项 `solve` 要 4.6 ms（单个右端项 28 µs），`scipy.linalg.eigh` 广义对称驱动直接**段错误**。本模块用自写 Gauss 消元（4×4 ~10 µs），脚本/测试用 Cholesky+三角求解，不用 eig。
5. **第二谱阈值 ω=√(κGA/ρI) 是奇点**：两个色散根重合，基函数退化，行列式出现孤立数值零点（不是物理频率）。计数显式扣 1，求值点落在阈值上抛显式错误。**因此本模块的可信频率区间不含阈值邻域（±1e-3 相对）**；跨越第二谱的求根在阈值附近精度不可信（测试只断言计数跨阈值连续）。
6. **转动惯量不是细节**：算例 A 第 4 阶 ρI 使频率降低 7.82 %；船体梁（I/A = 73 m²）ρI 使第 1 阶降 3.05 %。低频"薄梁"上可忽略，深梁/船体梁不可。
7. **适用范围**：仅等截面、无轴向力、无剪切后屈曲、线弹性（无阻尼）；截面由 A、I、κ 三个量概括，薄壁剖面的有效剪切面积口径需用户自定（本报告的船体梁取两舷壳板，与 m6117 一致 = 保守偏低）。
8. **船体梁用"有效密度"建模**：DSMBeamSection 只有一个密度（同时定 ρA 与 ρI），船体梁质量来自排水量而非钢结构，故取 ρ_eff = (单位长度质量)/(剪切面积)。这是建模口径，不是数值近似。
