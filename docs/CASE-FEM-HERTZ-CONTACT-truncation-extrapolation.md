# CASE-FEM-HERTZ-CONTACT — 加深截断边界：把 −1.01% 压入深平台分解为「截断误差 vs 模型偏差」

【锚点=CASE-FEM-HERTZ-CONTACT】｜仓=TensorFEM｜证据分级：REAL（解析基准 + 证书化闸门 + 可离线复算）
| 前序：`docs/CASE-FEM-HERTZ-CONTACT-verification.md`（载荷控制 Hertz 接触，14 闸门 PASS，F2 遗留问题）

## ① 案例介绍

算例池 `FEM-HERTZ-CONTACT`（id 104）：刚性球形压头压入弹性半空间，**载荷 P 给定**，求接触半径 `a` 与压入深 `δ`，
对标 Hertz 1882（*J. reine angew. Math.* 92:156）/ Johnson 1985 *Contact Mechanics* §4.2
（DOI:10.1017/cbo9781139171731）：`a=(3PR/4E*)^{1/3}`、`δ=a²/R`、`p0=3P/(2πa²)`，`E*=E/(1−ν²)`。

| 参数 | 值 |
|---|---|
| 无量纲工作集 | R=10、E=1e5、ν=0.3（长度 /R，力 /(ER²)；SI 等价 R=10 mm、E=100 GPa） |
| 载荷 | a/R=0.05（P=1831.50）、a/R=0.10（P=14652.0），Hertz 反算 |
| 表面网格 | h/a=0.015（主）；h/a=0.03（鲁棒性复核） |
| 域深/外径阶梯 | 96a → 192a → 384a → 768a（**近场网格不动，只把截断边界外推**；单元数恒为 9040） |
| 判据（算例池） | `<3%`，指标 a 与 δ |

**为什么做这一单**：前序证书发现 F2——δ 误差在三档表面网格上恒为 **−1.010%**，不随 h→0 下降。
该记录把它称作「网格无关系统偏差」，但没确定它**是什么**。两种物理上不同的解释都符合同一批网格数据：

* **H_trunc**：真实半空间被有限斑块（深 96a、外径 96a，底部/外缘运动学约束）替代，**刚度偏高约 1%**，
  属未收敛的**截断误差**——预测：边界越远误差越小；
* **H_bias**：偏差在无限域仍在（例如 Q4 表面用弦代替抛物面型面），属**模型偏差**——预测：出现非零平台。

## ② 怎么做的

1. 复用前序驱动 `benchmarks/verified/fem_hertz_contact_loadcontrol/run.py::run_case`（ALM 单边接触 + 外载控制），
   新增 `truncation_extrapolation.py`：在同一 `h/a` 下只改 `depth_factor`（远场拉伸而非加密，
   故单元数/近场分辨率完全一致 → 干净隔离截断），跑 96a/192a/384a/768a。
2. **阈值先于运行写死**（`CRITERIA`）：残差界 0.5%（把「截断收敛掉」与「模型偏差」分开的那条线）、
   观测阶带 [0.5, 3]、近场量不敏感界 0.05 pp、算例池 3%；假设陈述 `HYPOTHESIS`/`ALTERNATIVE` 同时写入工件。
3. 外推用**仓内共用算术** `benchmarks/verified/_harness.py::richardson`（三点观测阶 + Richardson 极限），
   不另造公式；序列非单调/饱和/与截断无关时**一律不外推**，只记为 `blocked` 并在报告里说清原因。
4. 决策规则双侧：`|e_inf(δ)| ≤ 0.5%` ∧ 幅值单调 ∧ 阶在带内 ⇒ `H_trunc`；否则 `H_bias`。两种结果都是产出。
5. 闸门并入锚点证书（`run.py::truncation_gates()` 读兄弟文件 `gates_truncation.json`，证书 14 → 20 闸门，
   全部是可离线复算的数），并用 `run.py --from-dump result.json` 零算力重生成证书。

## ③ 计算结果（全部程序化来自 `truncation_extrapolation.json`）

压入深 δ 误差 vs 域深（a/R=0.05，h/a=0.015）：

| 域深/a | δ 误差 | a 误差 | p0 误差 |
|---:|---:|---:|---:|
| 96 | −1.0107% | −0.5316% | +0.5880% |
| 192 | −0.6989% | −0.5316% | +0.5880% |
| 384 | −0.5472% | −0.5319% | +0.5882% |
| 768 | −0.4804% | −0.5326% | +0.5885% |
| **外推 depth→∞** | **−0.4278%**（阶 1.18） | 不外推（截断无关） | 不外推（截断无关） |

* 外推灵敏度（换用不同三点）：96/192/384 → −0.4036%（阶 1.04）；192/384/768 → −0.4278%（阶 1.18）；
  两者差 **0.024 pp** ⇒ 极限本身的不确定度约 ±0.03 pp。
* **截断解释掉平台的 57.7%**（1.011 pp 中的 0.583 pp），余下 **0.428%** 为残余模型偏差。
* 第二个载荷 a/R=0.10 的阶梯：−1.0109 / −0.6991 / −0.5475（外推 −0.4039%），与 a/R=0.05 **逐点重合**，
  平台在两载荷间散布仅 **0.0002 pp**——这正是它此前被误读为「与网格/载荷无关」的原因：
  域深以 `a` 为单位，两载荷的 `depth/a` 阶梯是同一个无量纲问题。
* 深域网格无关性复核：域深 768a 处 h/a=0.03 给 −0.4654%、h/a=0.015 给 −0.4804%，**散布 0.015 pp**
  ⇒ 残余 0.43% 不是网格伪影，是网格无关的**模型偏差**（约为 3% 判据带的 1/7）。
* 近场量**与截断无关**：`a` 的误差在 8 倍域深变化下总散布 **0.0010 pp**，p0 为 **0.0005 pp**
  ⇒ 前序证书里 a 的 −0.53%（h/a=0.015）是**纯网格**误差，δ 的平台则是「截断 + 模型偏差」的叠加。

## ⑤ 注意点 / 局限

1. **判据改换披露**：外推假设单幂律 `e(depth)=e_inf+C·depth^{-p}`；四个域深点只能支持一阶项，
   故给出「换三点」灵敏度（±0.03 pp）而不是单一数字。
2. **H_trunc 被判「成立」，但不是「截断解释一切」**：按预先写死的规则（残差 ≤0.5%）成立，
   同时如实记录 42% 的平台（0.428%）是网格无关的模型偏差，未定位其机理（候选：Q4 表面弦替代抛物型面、
   δ 提取方式）。这是本单**未解决**的部分，不粉饰。
3. 远场是**拉伸**不是加密：单元数恒定意味着远场离散变粗，因此这是截断研究不是网格研究；
   网格效应由前序证书的 h 阶梯单独覆盖，二者在此交叉验证（深域散布 0.015 pp）。
4. 仅轴对称 Q4、线性弹性、小变形、无摩擦；未涉可变形双体（E* 组合）推广。
5. **顺手修掉的缺陷 D1**：`run.py --from-dump` 对提交的 `result.json` 抛 `KeyError: 'probe'`
   （原始 dump 用 `probe`，证书自身写 `probe_low_load`），即文档承诺的「零算力重生成证书」实际不可用。
   兼容两键后 `--from-dump result.json` 通过，20/20 闸门 PASS（本单所有证书数字均由该路径重生成）。

## ⑥ 误差判定（关键量 vs 基准，逐项回答是否 <3%）

| 关键量 | 基准 | 误差 | <3%? |
|---|---|---:|---|
| δ（无限域外推，a/R=0.05） | `δ=a²/R` | −0.428% | **是** |
| δ（96a 接受模型，h/a=0.015） | 同上 | −1.011% | 是（其中 0.583 pp 为截断、0.428 pp 为模型偏差） |
| δ（无限域外推，a/R=0.10） | 同上 | −0.404% | **是** |
| a（h/a=0.015，96a） | `a=(3PR/4E*)^{1/3}` | −0.446%（证书最细网格） | **是** |
| a（域深 96a→768a 散布） | — | 0.0010 pp | 是（截断无关，量级可忽略） |
| p0（h/a=0.015） | `3P/(2πa²)` | +0.588% | 是（判据 5%） |

**结论**：δ 的「网格无关平台」已被定量分解——**截断 58% + 模型偏差 42%**，二者都在 3% 判据带内；
前序 F2 的「未知系统偏差」不再是未知量，而是一个带误差棒的已知量。残余 0.43% 的机理待后续（建议新条目见下）。
