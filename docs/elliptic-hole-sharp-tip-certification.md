## 1. 案例介绍（物理背景 / 几何 / 参数）

船体开孔常为长圆/椭圆：同一净开孔面积下，横向拉长的孔（`semi_y > semi_x`）峰值应力可比圆孔高
一倍以上。Inglis 精确解给出 `K_t = 1 + 2·semi_y/semi_x`，且尖端曲率半径
`ρ_t = semi_x²/semi_y` 是该处应力场唯一的长度尺度。

上一份报告（m7524）已把开孔证据链从圆孔推广到椭圆孔，并留下一条**诚实 FAIL**：

| 算例 | `semi_x / semi_y` | `K_t` | `ρ_t` | 旧阶梯 `grading=3, n=48` 峰值误差 | 判定 |
|---|---|---|---|---|---|
| A 横向短椭圆 | 1.5 / 1.0 | 2.333 | 2.250 | 2.288 % | 进 3 % 门限 |
| B 横向尖椭圆 | 0.5 / 1.5 | **7.000** | **0.1667** | **8.872 %** | **honest FAIL** |

本报告把 B 的 3 % 门限欠账变成可判定的量化结论：**是哪个离散参数在限制它，需要多少。**

几何与参数（与上一份报告完全一致，四分之一模型、孔心原点、远场单轴拉伸 `T` 沿 `x`）：

| 参数 | 符号 | 取值 |
|---|---|---|
| 半轴 | `semi_x` / `semi_y` | A `1.5 / 1.0`；B `0.5 / 1.5` |
| 远场拉应力 | `T` | 1.0（应力按 `T` 归一） |
| 弹性模量 / 泊松比 | `E`, `ν` | 1.0 / 0.30（平面应力） |
| 外边界 | `\|ζ\| = ρ₀` | 共焦椭圆 `ρ₀ = 5`，面力取精确解（**零截断误差**：这是验证而非 FE 对 FE） |
| 网格 | — | Q4 双线性，`(θ, ρ)` 结构网格；θ 两端 Chebyshev 加密（尖端必有节点）；ρ 向孔边指数加密，强度 `grading` |
| 本次扫掠 | `grading` × `n` | `grading ∈ {3, 5, 6, 9}` × `n ∈ {24, 32, 48}`（`n_θ = n_ρ`） |
| 对称条件 | — | `θ=0` 上 `u_y=0`；`θ=π/2` 上 `u_x=0`（精确解自身满足） |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**(A) 把「离散误差」拆到一个可解释的长度尺度上。** 尖端位于参数网格角点 `(θ=π/2, ρ=1)`，
该点上两个方向的度量因子**相同**：`|dz/dθ| = |dz/dρ| = R(1+m)`（`m` 为 Joukowski 映射参数）。
于是可以定义无量纲尖端分辨率

```
δ_r = h_r/ρ_t ，  δ_θ = h_θ/ρ_t ，  aspect = h_θ/h_r
```

其中 `h_r`、`h_θ` 是尖端第一个单元的径向/切向物理尺寸。这三个量由新增的
`tensorfem.elliptic_hole.tip_resolution()` 解析给出（不依赖求解），`solve_case()` 的返回体里也
直接带上了 `tip_resolution` 字段，**任何后续报告都能自查尖端是否被分辨**。

**(B) 先问「旧公式族为什么不收敛」。** 旧阶梯固定在 `grading=3`、只升 `n`。实测该族
`n=24→64`：误差 17.104 % → 6.734 %，拟合观测阶 **0.947**（≈1，一阶），且
`δ_r` 仅从 8.372 % 降到 3.017 %——**ρ 方向首层厚度是 `∝1/n`，永远追不上 3 %**。按该族拟合律外推，
3 % 需要 `n ≈ 151`（≈ 4.6×10⁴ 自由度，稠密求解不可行）。结论：限制项是 **径向加密强度**（grading），
不是网格级数 `n`。

**(C) 再把 grading 当离散参数扫。** `grading` 从 3 提到 5/6，在**同一或更低自由度**下
`δ_r` 掉一个量级，误差随之进 3 % 门限；而更强的 `grading=9` 虽然 `δ_r` 更小，却在粗网格上
反而变差（尖端单元被压成扁平条，`aspect → 0.02`，双线性 Gauss→节点外推的各向异性误差占优）。
这条非单调性被如实记录，并转成一条**平衡加密**建议。

**(D) 全局一致性同轮核验。** 每次求解都同时输出：节点位移场相对误差、力平衡残差
（施加 + 反力）、`θ=π/2` 对称边 x 反力 vs 精确面力合力、以及生产存盘单元中心应力与独立
自写 `B` 矩阵的交叉校验。判定峰值误差不是靠「力平衡过了」这种弱证据，而是靠**解析基准本身**
（见 §5 的两条与 `m` 无关的恒等式）。

### 判定：通过的定量条件（本次 16 组合全部符合）

| 条件 | 组合数 | 结果 |
|---|---:|---|
| `δ_r ≤ 1 %` 且 `δ_θ ≤ 1 %`（平衡加密） | 13 | **全部 < 3 %**，最差 2.288 %（A, grading=3, n=48），最好 0.033 % |

`δ_r ≥ 3 %` 时分母里没有 `ρ_t` 的信息，峰值不可引用。** 该判据在 `n=24…64`、`grading=3…9`、
两个 `K_t`（2.333 / 7）上都成立，不是单点拟合。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

* **旧 `grading=3` 全族保持 FAIL**，本报告没有把 8.872 % 的旧结果「重跑成通过」；认证来自**换加密切口**
  （`grading`），并且以 `tests/test_elliptic_hole_sharp_tip.py::test_legacy_grading_family_still_fails_the_gate`
  锁死——若生产路径将来改变导致该族意外通过，测试会报错要求重跑审计而非静默升级结论。
* **过加密会反噬**：`grading=9` 的 `δ_r` 只有 `ρ_t` 的 0.02 %，但尖端单元 aspect 达 13–30，
  粗网格误差反而 0.53–2.45 %，不优于 `grading=6`。所以判据是「`δ ≤ 1 %` **且平衡**」，
  不能读成「越密越好」。误差随 `n` 非单调（相消），本报告因此不拟合收敛阶。
* **只覆盖单轴远场、平面应力、小应变、各向同性、单一峰值点**。双轴/剪切远场、多孔干涉、
  裂纹（`ρ_t → 0` 真奇异）不在内：真奇异需要奇异单元/自适应，`δ_r ≤ 1 %` 的判据**不适用**。
* 峰值口径是 `tip_nodal_stress`（Gauss→节点外推）而非单元中心值：后者对尖端低读约 10 %，
  上一份报告已定；两口径不可混引。
* 稠密求解上限：本单最大 8450 自由度（~22 s/解）；`grading` 加密在高 `n` 上会增加条件数，
  但本轮扫掠（`n ≤ 48` 全 24 组合）的独立 `B` 矩阵交叉校验都在 1e-13 级，未观察到病态。

结论：**尖锐椭圆孔（`K_t = 7`）峰值应力的 3 % 验证欠账在 `δ_r ≤ 1 %` 的平衡加密网格上已清偿**

`δ_r ≥ 3 %` 时峰值不得引用。旧 `grading=3` 阶梯的 FAIL 原样保留。
