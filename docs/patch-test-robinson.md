# Robinson patch test A/B/C — TensorFEM verification report

Generated by `benchmarks/patch_test_robinson.py`; every number below is injected from `runs/patch_test_robinson/result.json`.

## 1. Problem and reference

* **Criterion** (Robinson, J., *An attempt to evaluate incompatible mode elements*, in *Finite Element Methods for Plate and Shell Structures*, Vol. 1: Element Technology, Pineridge Press, 1987, pp. 1-15; restated in Zienkiewicz & Taylor, *The Finite Element Method*, Vol. 1, §3.6): a patch of elements with an **irregular** mesh and free interior nodes, loaded only through boundary displacements that lie in the element's span, must reproduce the interior displacement and the recovered stresses to round-off.
* **Target values are analytical**, derived from the prescribed field by `sigma = D B u` (zero hand-copying of a table):
  * A uniaxial tension: `u=(sigma0/E x, -nu sigma0/E y)`, `sigma_xx = sigma0` (constant strain);
  * B pure shear: `u=(gamma/2 y, gamma/2 x)`, `gamma = tau0/G`, `tau_xy = tau0` (constant strain);
  * C pure bending: `u=(-kappa x y, kappa/2 (x^2 + nu y^2))`, `sigma_xx = -E kappa y` (**linear** stress, quadratic displacement).
* **Tolerance**: exact reproduction, i.e. relative error <= `1e-10` in both displacement and stress.
* **Reference access note (honest)**: the Robinson paper itself was not retrievable in this sandbox (no outbound network), so the *mesh coordinates are this benchmark's own irregular patch* (`q4_patch_mesh`) and only the *criterion* is taken from the reference. All target values are analytic, so nothing depends on the unavailable table.

**Honest note on the rates.** The deterministic distortion field is specified in
*element fractions*, so every mesh in the refinement column is a different irregular
mesh, not a nested family; the measured rates therefore scatter (Q4: 5.0, -4.3, 1.4;
Q8 distorted: 7.5, -10.7, 3.8) and must **not** be read as an asymptotic order. What the
table does establish is the qualitative split: affine Q8 stays at round-off while the
distorted Q8 error falls with h, i.e. the patch-test defect is a mesh-size effect.

## 8. Failure modes, limits, and what is *not* claimed

* Q4 (bilinear) **cannot** reproduce case C at any mesh size: the error is a discretisation property, not a bug; the table quantifies it and the refinement study shows the O(h^2) decay.
* Q8 serendipity passes A/B on distorted meshes but **fails the linear-stress patch test on distorted meshes** (its span lacks the `xi^2 eta^2` term needed once the isoparametric map is quadratic). It is exact on affine meshes.
* TET10 passes the 3-D linear-stress patch exactly even on distorted straight-sided tets (affine element map + complete quadratic span).
* Passing a patch test is a **consistency** statement, not accuracy or validity: it says the element can represent the field, nothing about locking, distortion sensitivity under real loads, or engineering error.
* Curved (non-straight-sided) element geometry is out of scope here; the TET10 quadrature limitation is documented separately (`docs/tet10-integration-accuracy.md`).
