## 2. 方法：独立推导 + 只复用有限元

`scripts/adjudicate_gap_pp3_plastic_set.py` 中所有基准量**重新推导**，不调用模块的解析函数：
Navier 双级数（载荷展开 `4 q0 Δcosx Δcosy /(π²mn)`）、首次屈服栅格扫描、
四三角锥屈服线机构（4 条脊线各自耗散 `m_p w0 (a/b + b/a)`）、
Ilyushin 双正弦机构（`W_int = 4 m_p a b w0 (1/a²+1/b²)`）、双向条带下界（`8m_p/(u(2a−u))` 等）。
FE 侧仅调用库内核 `run_patch_plastic_path`。

`scripts/validate_plastic_limit_strip.py` 提供**精确**极限载荷基准（既有证据缺的一环）：
窄条板（b/a = 0.2）单向机构 `p_exact = 8 m_p / a²`，位移型 FE 应从**上方**收敛。

- 弹性场偏差（同网格 vs Navier）：挠度 **+2.60%**，表面 Mises **−5.62%**。
- 首次屈服 FE = 0.852 MPa vs 解析 0.804 MPa → **原始误差 +6.0%**。
- 载荷升到 3.10 MPa（1.82× 最紧上限）仍"收敛"，挠度达 0.56 m：这是分层单元在粗网格下

  的几何刚度默认关闭（`geometric=False`），膜张力并未参与，故这一支路无物理意义。

## 4. 发现的缺陷（本单已修，最小改动）

1. **永久挠度可被伪造成峰值挠度**（严重，已修）：卸载首步 Newton 失败时，旧代码把占位点
   写成"残差 = 峰值挠度"并当作 permanent set 返回（本次 4×4 实测返回 558.7 mm，
   即峰值本身）。现在：失败不写入点，记录 `unload_failure`/`unload_converged_steps`，
   `permanent_deflection` 在零步收敛时返回 `None`，新增 `permanent_set_valid`；
   `plate_capacity_summary` 在卸载未收敛时把证据改写为 "permanent set WITHHELD"。
2. **极限载荷来源不可分辨**（严重，已修）：`plate_capacity_summary["collapse_factor"]`
   原先把"载荷表末端"与"失去平衡的极限载荷"混为一谈。现补 `collapse_is_limit_point`、
   `ramp_completed`，路径对象补 `limit_point_searched`。
3. **表面应力外推在屈服后高报 ~50%**（中，已加告警）：3 层时外推按弹性线性分布，
   外层刚屈服即得 `1.5 σ_y`（实测 533 MPa vs 355 MPa）。仅用于首次屈服定位，文档已
   加 `.. warning::`。
4. **既有"网格收敛"测试恒真**（中，未改其断言，仅在本文件记录并新增独立门）：
   硬化 2e10 + 载荷表末端的 `collapse` 使 `<=` 单调断言无信息量。

## 5. 注意点 / 局限

- 位移型 FE 的极限载荷应**从上方**收敛到精确解，既有断言方向（向上单调逼近上限）与
  极限分析理论相反——需要精确基准（本单新增的窄条板 `8m_p/a²`）才能判定，扫描已递交。
- 复核脚本的栅格扫描子例程（`first_yield_pressure_independent`）返回 0.887 MPa，而中心
  级数与模块扫描一致给出 0.804 MPa：该子例程存在偏差（max 低于中心值，逻辑上不可能），
  已定位为待修**已知缺陷**，因此本次**不引用**栅格扫描值，仅用中心级数。
- 平台报告未出图：图 pipeline（`scripts/plot_gap_pp3_adjudication.py`）已入库并可从 JSON
  程序化生成 4 张图（载荷-挠度、网格收敛、卸载残差、弹性偏差），但所需八组扫描
