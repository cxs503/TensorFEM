# 平面应变 Q4 锁定治理：B-bar 体应变投影 + 精确 Lamé 圆柱基准

本报告**关闭** `docs/near-incompressible-locking.md` 第 6 节列出的欠账 1
（"2D 平面应变 Q4 无 B-bar/EAS 对照实现，`nu >= 0.499` 时误差 14 %–155 %"）。
做法不是再量化一次欠账，而是给二维 Q4 补上锁定治理并对照**闭式 Lamé 解**证明治理生效。

## 1 案例与离散

| 项 | 取值 |

| 材料 | `E = 210 GPa`，`nu` 扫描 0.3 → 0.4999 |

## 2 方法

**B-bar**：把应变-位移矩阵的体积分量替换为单元体积平均、偏量分量保持 2x2 全积分。
平面应变下体积应变 `eps_x + eps_y = m^T eps`，`m = [1,1,0]`，

```
B_dil = m (m^T B) / (m^T m),   B_dev = B - B_dil,
B_bar = B_dev + (1/V) ∫ B_dil dV,
K_e   = Σ_gp w_gp B_bar^T D B_bar
```

体积项变为单元常数后不可压约束不再逐点强制（那是锁定的来源），而偏量项仍全积分，
**不引入沙漏模态**（单元零能模态数仍为 3，见测试）。

**SRI**：偏量 2x2 全积分、体积项单元中心 1 点积分。数学上与 B-bar 对 Q4 等价：
对双线性等参四边形有 `(1/V)∫∇N_i dV = ∇N_i(中心)`；本仓用一条刻意畸变的四边形
（`[[0,0],[2.3,0.1],[2.6,1.7],[-0.2,1.1]]`）实测 `max|K_bbar - K_sri| / max|K| = 5.4e-16`。
**因此二者不是相互独立的交叉验证**，报告不这样宣称；独立证据是 patch test + 网格收敛阶。

**参考解自检**（先验判据，不靠自述；`reference_self_check`）：

| `nu` | 平衡残差 | 面力残差 | 本构残差 | 体积应变/应变尺度 |
|---:|---:|---:|---:|---:|
| 0.3 | 2.39e-10 | 0.0 | 1.85e-16 | 2.703e-01 |
| 0.45 | 2.39e-10 | 0.0 | 1.84e-16 | 7.519e-02 |
| 0.499 | 2.39e-10 | 0.0 | 3.70e-16 | 1.561e-03 |
| 0.4999 | 2.39e-10 | 0.0 | 2.77e-16 | **1.562e-04** |

第三行末列是关键：`nu -> 1/2` 时参考状态本身趋于**不可压**（体积应变比 0.4999 时比 0.3 时小 3 个量级），
所以这条基准确实在考"不可压极限"，不是文字游戏。

误差为**无加权点式 RMS 相对误差**（与 `docs/near-incompressible-locking.md` 的二维欠账表同口径，
可直接对比），应力在单元中心由极坐标变换取得。

观测阶（末两档网格，`h ∝ 1/n_radial`）：B-bar 位移 **2.000**、`sigma_r` **2.000**、平均应力 1.994；
标准 Q4 位移 1.646、`sigma_r` 1.646。

**与三维 HEX8 结论的差别（如实记录）**：三维报告称标准 HEX8 "加密不收敛"（阶 0.19–0.32）；
二维标准 Q4 在这里其实**会收敛但极慢**（阶 1.65），`nu=0.4999` 时 4290 DOF 仍有 9.25 %。
两者不矛盾：Q4 是协调单元、在 `h -> 0` 极限必须收敛，只是锁定常数量级巨大；
三维那次的判据只有三档网格，观测阶样本太短。本报告不沿用"不收敛"的措辞。

### 3.3 对 `nu` 的平坦度（max/min，16 x 8）

| 量 | 标准 Q4 | B-bar |
|---|---:|---:|
| 位移 L2 | 402.74 | **1.25** |
| `sigma_r` L2 | 202.57 | **1.00** |

`sigma_r` 的精确场**与 `nu` 无关**，所以"误差对 `nu` 完全平坦"（1.00）就是不锁定的直接证据：
B-bar 的残余误差是纯离散误差，不是体积过刚。

## 5 注意点与适用边界

- **默认 dtype 陷阱（本单实测踩到）**：`torch.tensor(0.4999)` 是 **float32**，而 `nu -> 1/2` 时
  体积模量 `K ∝ 1/(1-2nu)`；float32 的 `nu` 舍入（`0.4999000132083893`）被放大成
  **1.3e-4 的相对应力误差**（140140 vs 140121 MPa），在近不可压算例里足以冒充"格式误差"。
  本模块的求解与期望值一律显式 `float64`。凡做 `nu >= 0.499` 的验证，输入常数必须 float64。
- **B-bar 与 SRI 对 Q4 恒等**（5e-16），二者不能当两条独立证据；本报告只用 patch test + 收敛阶做独立验证。
- 单元中心取样（`B_bar` 中心值）**不是**超收敛点；应力要用 Barlow 点或外推才可能进一步降误差。
  本案例中 B-bar 的 `sigma_r` 误差在 8x4 时 2.30 %，已低于 3 %，无需应力恢复。
- 锁定治理对 Q4 **只在 `plane` 与 `thickness` 都常数的线性 Q4 上验证过**；`cst` 与
  非均匀厚度会被 `ContinuumModel.__post_init__` 拒绝（fail-closed）。
- 三维路径未改动：`solve_solid` / `solve_solid_bbar` 与 `docs/near-incompressible-locking.md`
  的全部数值不受本单影响。
- 载荷路径采用既有 `circular_pressure_loads` 的一致弧压；其对解析边界功的 `O(dtheta^2)`
  再分配（1.6e-3）已单列，不混进格式误差。
- 求解为稠密装配（`ContinuumModel` 既有方式）；4290 DOF 以上需稀疏路径，本单未做。

| B-bar 位移 L2，`nu=0.4999`，64x32（4290 DOF） | 同上 | 0.0071 % | **是** |
| B-bar `sigma_r` L2，`nu=0.4999`，8x4 | 同上 | 2.3043 % | **是** |
| B-bar `sigma_r` L2，`nu=0.4999`，64x32 | 同上 | 0.0358 % | **是** |
| B-bar 平均应力 L2，`nu=0.4999`，8x4 | 同上 | 0.0513 % | **是** |
| B-bar 内孔位移，`nu=0.4999`，16x8 | 同上 | 0.1128 % | **是** |
| B-bar 位移误差对 `nu` 平坦度（0.3→0.4999） | 自参照 | 0.0899 % → 0.1128 %（比值 1.25，位移含 `(1-2nu)` 项属物理） | **是** |
| B-bar `sigma_r` 误差对 `nu` 平坦度 | 自参照 | 0.5738 % vs 0.5725 %（比值 **1.00**） | **是**（应力场与 `nu` 无关，误差不变 = 无锁定偏置） |
| B-bar 收敛阶（位移/`sigma_r`） | 自参照 | 2.000 / 2.000 | **是**（≥ 2 即无锁定退化） |
| 标准 Q4 位移 L2，`nu=0.4999`，16x8 | 平面应变 Lamé 闭式 | 61.9144 % | **否**（锁定） |
| 标准 Q4 `sigma_r` L2，`nu=0.4999`，16x8 | 同上 | 155.2219 % | **否** |
| 标准 Q4 位移 L2，`nu=0.4999`，64x32（4290 DOF） | 同上 | 9.2468 % | **否**（按阶 1.65 外推需约 2.0 倍网格/4 倍 DOF 才到 3 %） |
| 参考解自检（平衡/面力/本构） | 解析残差 | 2.4e-10 / 0.0 / 3e-16 | **是** |

结论（限定范围）：**二维平面应变 Q4 的近不可压锁定在本基准上被治愈**——B-bar 在最粗的
90 DOF 网格上位移 0.45 %、`sigma_r` 2.30 %，在 4290 DOF 上分别 0.0071 % / 0.0358 %，
误差随 `h` 以二阶收敛，且 `sigma_r` 误差对 `nu` 完全平坦。
`standard` 路径被 fail-closed 测试锁死（`> 50 %` 位移误差、`> 1.0` 应力误差，
且要求逐位复现 61.9175 % / 155.2296 %），任何人不得把它算作通过。

## 7 由此暴露的未完成项（下次自找活的线索）

1. **三维 B-bar 只有稠密装配**（`solve_solid_bbar` 直接建 `n_dofs^2` 稠密矩阵）——要先有
   `assemble_coo` 稀疏路径，才能上 64x64x6 级认证网格。二维同理（本单上限 4290 DOF）。
2. **平面应力路径未做锁定基准**：`plane="stress"` 下 `nu -> 1/2` 不产生真锁定（`eps_z` 自由），
   但薄板弯曲仍会剪切锁定，那是另一个欠账（Mindlin 板 vs 三维）。
3. **EAS（增强假定应变）对照缺失**：B-bar 与 SRI 恒等，若需要真正第二条独立路线，
   需实现 Q4-EAS（Simo–Rifai）或不相容模态 Q6，用同一 Lamé 基准交叉。
4. **轴对称（ring）单元**：船舶厚壁壳/法兰多用 CAX4，其体积投影与平面应变不同
   （`eps_theta = u_r/r` 进入体积项），值得单独一单。
