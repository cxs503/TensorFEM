# 矩形（`a ≠ b`）Saint-Venant 扭转：形状因子与长/短边峰值剪应力的清偿

Status: **形状因子（`a ≠ b`）欠账已清偿**；**细长比 `a/b = 3` 的 3D 扭转率仍为未结项**（§6 如实记录）。
Library: `TensorFEM`。模块: `tensorfem.torsion_rectangular`。基准脚本:
`benchmarks/torsion_rectangular_section.py` → `docs/assets/torsion_rectangular_section/rectangular_evidence.json`。

## 1. 欠账是什么（案例介绍）

`docs/torsion-boundary-stress.md` §5 第 3 条明确写下：

> 监测点是**单个**对称等价点……也没有覆盖矩形（非方）截面的长边/短边两侧差异；
> `a≠b` 的形状因子未验证。

`tensorfem.torsion_bar` 的闭式级数本来就是为一般 `a × b` 截面写的
（`rectangular_torsion_constant(a, b)`，要求 `a ≥ b`），但**已发表的每一次复核**
（`docs/saint-vanant-torsion.md`、`docs/torsion-boundary-stress.md`）都在 `a = b`
上取值，3D 驱动 `solve_torsion_bar` 更是只把 `side` 传两遍、内部参考值也写成
`rectangular_torsion_constant(side, side)`。也就是说：

* 「扭转常数随截面细长比如何变化」没有任何独立证据；
* 「峰值剪应力在长边中点还是短边中点、差多少」没有数字；
* 一般矩形的 **3D 单元路径**（不是级数）从未跑过。

这一处欠账影响面很宽：船体梁、开口/闭口薄壁梁、螺旋桨叶根、加筋板的扭转刚度与
剪应力峰值都用同一个级数，而真实截面几乎都是 `a ≠ b`。

## 2. 怎么做的（方法 / 流程 / 关键设置）

新增 `src/tensorfem/torsion_rectangular.py`，给出三条**互不共享代码**的证据流，
外加一个**真正的矩形 3D 驱动**。归一化统一为手册形式，便于逐项对表：

| 量 | 归一化 | 含义 |
| --- | --- | --- |
| `c1` | `J = c1 · a · b³` | 扭转常数形状因子（`a` 为长边） |
| `c2` | `τ_max = T / (c2 · a · b²)` | 峰值剪应力形状因子 |

| 证据流 | 实现 | 与级数的独立性 |
| --- | --- | --- |
| ① 闭式级数 | `torsion_bar.rectangular_torsion_constant` + `torsion_shear_stress` 在边界点 `(b/2, 0)` 取值（`shape_factors`） | 被检对象 |
| ② 手册系数表 | `classical_rectangle_coefficients()`：Timoshenko & Goodier / Roark「矩形截面」表，`a/b = 1.0…10` | 文献，非本仓代码 |
| ③ 独立 PDE 数值解 | `prandtl_finite_difference(a, b)`：直接解**定义方程** `∇²ψ = −2`、边界 `ψ = 0`，二阶五点格式；`J = 2∫ψ dA`，`|∇ψ|` 用二阶单侧差在边界中点取值；两级网格 + Richardson 外推 | 只共享 PDE，不共享级数（符号/归一化/双曲比错误无法互相抵消） |
| ④ 3D 有限元 | `rectangular_torsion_bar(a, b, ...)`：HEX8 棱柱，端面一致牵引、`0.25L–0.75L` 最小二乘扭转率，逐单元面面积给一致节点权 | 与级数只通过「同一个物理问题」相连 |

关键数值设置：

* FD 网格 `nx = n_short`（短边）、`ny = round(n_short·a/b)`（长边），
  `hx = b/nx`、`hy = a/ny` **分开取**，使离散区域精确等于 `a × b`
  （早期版本令 `hx = hy`，`a/b = 1.2` 时域长偏差 0.38 %，把 FD 与级数的差
  伪造到 0.46 %；改正后差降到 5×10⁻⁵ %）。这一点是本单踩到的坑，写在 §7。
* 3D 单元取**立方单元**：`nz = round(L·n_short/b)`，与方截面驱动
  `nz = 4·segments`（`L = 4b`）完全一致。
* 端面牵引按逐单元面面积 `A_e/4` 组装，并断言合力矩等于施加扭矩（机器精度）。

## 5. 注意点 / 局限（含未结项）

1. **`a/b = 3` 的 3D 扭转率不收敛，本单不予认证**。误差随网格加密**单调上升**
   （0.911 % → 2.026 % → 2.568 % → 2.871 %），与 `a/b = 1.5 / 2.0` 的干净二阶收敛
   形成对照。原因不是截面细长比：`L = 4` 时 `a/L = 0.75`，0.25L–0.75L 的扭转率
   窗口整体落在 3 m 长边的 Saint-Venant 端部影响区（衰减长度 ~ `a`）内。
   长度研究（`segments_short = 4`，立方单元，故 `nz` 随 L 增长）：`L = 4` → 2.026 %、
   `L = 6` → 0.192 %、`L = 8` → 0.946 %，即长度一改误差就掉一个量级，
   支持「窗口/端部效应」而非「截面形状」归因；但 `L = 6 → 8` 又不单调，
   说明现有证据还不足以下最终结论。该失败已用 fail-closed 测试
   （`test_slender_section_twist_rate_does_not_converge_monotonically`）锁住，
   任何后续改动若把它悄悄变成"通过"都会红。
2. **形心剪应力的 L2 误差不是评审过门限的量**。3D 应力比较在形心（`L/2` slab）进行，
   形心永远到不了边界，故细网格上 L2 误差停在 1.7–2.5 %，不能当作峰值精度。
   边界峰值需用 `docs/torsion-boundary-stress.md` 的表面回收流程（方截面已做，
   矩形尚未做，仍为开放项）。
3. **手册表只有三位小数**，`c1 = 0.141` 的舍入即 ±0.35 %，所以「级数 vs 手册」
   的 0.3 % 是本底，不是模型误差；判据必须靠 FD 的 1e-5 级对照。
4. **FD 参考的适用范围**：只覆盖单连通实心矩形、弹性均值材料；不覆盖闭口薄壁
   （`tube_torsional_constant` 另有报告）、翘曲约束（Vlasov）、变截面、塑性。
5. **`solve_torsion_bar`（方截面）未被改动**，仍走原路径；矩形驱动是新函数
   `rectangular_torsion_bar`，两者共用装配/求解/扭转率提取的做法，但独立实现，
   以避免破坏既有方截面 golden 数值。

## 7. 踩过的坑（留给后来者）

* **FD 网格各向异性**：先令 `hx = hy = b/nx` 再按 `ny = round(nx·a/b)` 取点数，
  离散域长边变成 `ny·hx ≠ a`（`a/b = 1.2` 时偏 0.38 %），足以把"独立参考"
  伪造成 0.46 % 的模型误差。必须 `hy = a/ny`。改正后 FD 与级数差 5×10⁻⁵ %。
* **`nz` 取法会伪造趋势**：早期用 `nz = 4·max(n_short, n_long)`，长度从 4 加到 8
  时轴向越来越粗，误差"随长度增长"其实来自轴向离散，而非端部效应。
  改为立方单元 `nz = round(L·n_short/b)` 后趋势才有物理意义。
* **`pytest.approx(rel=1e-12)` 不适用于级数对称性**：方截面长/短两侧中点由级数的
  `cosh` 比与截断决定，两侧相等只到 ~1e-8，不是机器精度。
