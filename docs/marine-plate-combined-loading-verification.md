## 1. 缺口与本次增量

`tensorfem.marine_plate_buckling` 只覆盖**单向压缩**，且其数值侧利用可分离性把二阶中心差分算子的特征值写成
`4 sin²(m pi / 2(n+1)) / h²` 的闭式。船体板格在规范筛查中从来不是单向受载：纵向压缩、横向压缩与面内剪切同时作用，
而剪切项 `-2 N_xy w_,xy` 引入混合导数，把每个 `(m, n)` 耦合成整体系，闭式捷径随即失效。

本次补上三段：

1. **双向压缩精确解（Navier）**——双正弦仍是本征函数，临界纵向线载荷取

   `N_x(m,n) = [Dx α⁴ + 2 H α²β² + Dy β⁴] / (α² + r β²)`，`α = mπ/a`，`β = nπ/b`，`r = N_y/N_x`；
2. **不可分离有限差分数值核**——显式 Kronecker 组装 `K = Dx(Sx²⊗I) + 2H(Sx⊗Sy) + Dy(I⊗Sy²)`，
   几何算子 `lx Sx⊗I + ty I⊗Sy + 2 sxy D1x⊗D1y`，经 `K` 的 Cholesky 因子化为 `L⁻¹GL⁻ᵀ μ = (1/N) μ`；
3. **经典剪切系数** `k_s = 5.34 + 4(b/a)²`（Timoshenko & Gere，*Theory of Elastic Stability* 2nd ed., Art. 9.3）
   作为剪切分支的文献锚点。

参数：E=210 GPa，ν=0.3，t=12 mm，D = Et³/12(1−ν²) = 3.3230e4 N·m = 33.23 kN·m。

## 2. 方法链（三独立层级互为对照）

| 层级 | 对象 | 判据 |
|---|---|---|
| A 精确解 | 双向压缩 Navier | 等双轴方板 `N_x = 2π²D/b²`（舍入精度）；`r=0` 必须逐位等于既有单向 oracle |
| B 可分离数值 | 既有 `finite_difference_uniaxial_buckling` | 新组装核在单向载荷下必须与之**逐位一致**（相对差 <1e-10） |
| C 不可分离数值 | 一般 `(N_x, N_y, N_xy)` | 对标 A（双向）；对标文献 k_s（剪切）；网格细化单调且 Richardson 外推 |

`r=0` 与单向解的一致性（实测相对差 0）与 `(1,1)` 模态的闭式离散误差恒等式（下表）是两条最强锚点：
它们把「新代码是否只是把旧代码抄了一遍」变成一个可机器裁决的问题。

## 3. 计算结果

### 3.1 资格门（`run_combined_panel_buckling_qualification`，全部 fail-closed）

| 门 | 实测 | 基准 | 相对误差 | 判定 |
|---|---|---|---|---|
| 等双轴方板精确解 | 6.5595e5 N/m | `2π²D/b²` = 6.5595e5 N/m | 0.0 | 通过 |
| `r=0` 退化为单向 oracle | 与 `navier_uniaxial_buckling_load` 完全相等 | 同左 | 0.0 | 通过 |
| 组装核 vs 可分离核（16×16） | 与闭式 sin² 特征值一致 | 同左 | 3.7e-13 | 通过 |
| 双向 r=0.5、a/b=2，8/16/32 | 6.76370e5 → 6.81338e5 → 6.82764e5 N/m | Navier 6.83280e5 N/m | 1.011% → 0.284% → 0.0755% | 通过（<3%，单调） |

### 3.2 双向压缩：`(1,1)` 模态的闭式离散误差恒等式

方网格（`grid_x = grid_y = N`）下 `(1,1)` 模态的离散临界载荷恰为连续解的 `s(N)` 倍：

`s(N) = 4(N+1)² sin²(π / 2(N+1)) / π²`，相对误差 ≡ `s(N) − 1`。

| N | 预测 `s−1` | 实测相对误差 | 一致 |
|---:|---:|---:|---|
| 8 | −1.011276e−2 | 1.011276e−2 | 逐位 |
| 16 | −2.84267e−3 | 2.84267e−3 | 逐位 |
| 32 | −7.5502e−4 | 7.5502e−4 | 逐位 |
| 48 | −3.4250e−4 | 3.4250e−4 | 逐位 |

该恒等式对任意长宽比与任意双轴比都成立（a/b = 1 / 1.5 / 2 三例误差逐位相同），
因为它只依赖 `κx/κy = (a/b)² β²/α²` 这一比例；因此三例不构成三次独立证据，报告中如实说明。
高阶模态（a/b=3、r=0.1，模态 (3,1)）走出该恒等式，误差 1.610% → 0.480% → 0.130% → 0.0590%，
观测阶 1.89，外推 0.033%——这是一条真正独立的网格细化证据。

### 3.3 纯剪切：与文献系数 `k_s` 的逐长宽比比较

`k = N_xy,cr / (π²D/b²)`，网格沿 b 向加密（`grid_y ≈ grid_x · a/b`）。

| a/b | 拟合 `k_s` | 最细网格实测 k | 对拟合偏差 | Richardson 外推后偏差 |
|---:|---:|---:|---:|---:|
| 1.0 | 9.340 | 9.3521（40×40） | 0.130% | **−0.007%** |
| 1.5 | 7.1178 | 7.0879（40×60） | 0.420% | 0.276% |
| 2.0 | 6.340 | 6.5653（40×80） | 3.55% | 1.80%（观测阶仅 0.13） |
| 3.0 | 5.7844 | 5.8887（32×96） | 1.80% | 0.930% |

a/b=1 一列是关键：外推极限与经典 9.34 相差 0.007%，说明剪切分支的数值核本身没有系统偏差。

### 3.4 轴压+剪切相互作用（a/b=2，24×24）

按各自纯载荷临界值归一化 `(N_x/N_x,cr, N_xy/N_xy,cr)`：

| shear_share | N_x/N_x,cr | N_xy/N_xy,cr | 线性和 | 平方和 |
|---:|---:|---:|---:|---:|
| 0.0 | 1.000 | 0.000 | 1.000 | 1.000 |
| 0.3 | 0.970 | 0.176 | 1.145 | 0.972 |
| 0.6 | 0.896 | 0.325 | 1.220 | 0.909 |
| 1.0 | 0.779 | 0.471 | 1.250 | 0.828 |
| 2.0 | 0.553 | 0.669 | 1.223 | 0.753 |
| 4.0 | 0.337 | 0.816 | 1.153 | 0.779 |

相互作用曲线单调外凸，夹在「线性叠加」（和=1）与「椭圆」（平方和=1）两条规范常用包络之间；
最大线性和 1.250 出现在 `N_xy/N_xy,cr ≈ 0.47` 附近。测试 `test_combined_loading_lowers_the_load_below_either_branch`
即锁定该夹逼关系，避免将来改动悄悄把曲线推到包络之外。

## 4. 注意点（局限与适用范围）

1. **薄板特征值问题，不含壳单元预屈曲应力**：与 `marine_plate_buckling` 的边界一致。本模块不宣称
   Shell4 预屈曲/后屈曲能力，也不给出极限强度。
2. **简支边界**：四边 `w = 0` 且法向弯矩为零。固支、弹性约束、加筋离散梁不在范围内。
3. **`k_s = 5.34 + 4(b/a)²` 是渐近拟合，不是精确解**（**已结清，见
   [shear-buckling-spectral-reference.md](shear-buckling-spectral-reference.md)**）：a/b≈2 处实测超差 3.55%，
   其中约 3.25 个百分点来自拟合式本身、约 0.5 个百分点来自求解器。现已用双正弦 Galerkin 收敛参考
   （`tensorfem.plate_shear_buckling_spectral`，`a/b=2` 时 `k_s=6.5460`，残差 3.1e-06）复核：求解器在该分支
   为 +0.456%（<3%，合格），拟合式为 +3.25%（超门限）。第 6 道门
   `pure_shear_aspect_two_spectral_reference` 以 fail-closed 方式锁死此结论；a/b=1 的文献门与 9.34 锚点保留。
4. **一次未收拢的交叉检验（已定性）**：时间盒内的双正弦 Rayleigh–Ritz 在 a/b=1 给出 k≈9.03，与有限差外推
   9.346 差 3.4%。现由收敛参考定谳：真值 9.3245（残差 1e-6 量级），有限差外推 9.346 只偏高 0.3%，而 9.03
   **低于**收敛参考、违反 Ritz 上界性质，故判定该次 Ritz 实现未良置（欠收敛或归一化错误），不能作参考。
   剪切问题的几何算子虽不定，但 `K - N G` 在完备正弦基上的 Galerkin 截断仍是上界序列——原文「Ritz 上界
   性质不成立」一语过强，此处更正。
5. **剪切分支的符号**：`shear_share` 取 ±1 给出相同临界载荷（实测相对差 1e-13），符合纯剪的对称性；
   纯拉伸（`longitudinal_share < 0 且 transverse_share ≤ 0`）直接报错，不给「无限临界载荷」这种伪结果。
6. **横向受拉**：`biaxial_ratio < 0` 允许，但会使部分模态中性化；若全部模态被排除则显式报错。

## 5. 误差判定（逐项 vs 基准，是否 <3%）

| 关键量 | 基准 | 实测误差 | <3%？ |
|---|---|---:|---|
| 等双轴方板 N_x | `2π²D/b²`（解析） | 0.0 | 是 |
| 双向 r=0.5、a/b=2，32×32 | Navier 解析 | 0.0755% | 是 |
| 双向高阶模态 (3,1)，48×48 | Navier 解析 | 0.0590% | 是 |
| 双向全部工况 Richardson 外推 | Navier 解析 | 0.019%–0.033% | 是 |
| 纯剪切 a/b=1，40×40 | k_s = 9.34（文献） | 0.130%（外推 −0.007%） | 是 |
| 纯剪切 a/b=1.5，40×60 | 渐近拟合 7.1178 | 0.420% | 是（但拟合本身非精确解，见注意点 3） |
| 纯剪切 a/b=2，40×80 | 渐近拟合 6.340 | **3.55%** | **否**（不认证，见注意点 3） |
| 纯剪切 a/b=3，32×96 | 渐近拟合 5.7844 | 1.80% | 是（同上，拟合非精确解） |

结论：可解析对标的两条分支（双向压缩、a/b=1 纯剪）全部 <3%，其中 a/b=1 纯剪外推后与经典值相差 0.007%；
唯一超 3% 的是 a/b≈2 的剪切分支对渐近拟合的比较，该分支按 fail-closed 处理，不作认证。

## 6. 遗留问题的后续复核（谱参考解，2026-11-04）

§4.3 的「`a/b≈2` 未认证」与 §4.4 的「Ritz 未能对账」两条遗留，已由
[简支板纯剪屈曲：闭式谱参考解](shear-plate-spectral-reference.md) 复核，结论与本节原记录并存：

| 遗留 | 复核结论 |
|---|---|
| `a/b≈2` 实测比拟合式高 3.55% | 是**拟合式**偏低 3.15%，不是求解器误差：谱参考 `k_s(2) = 6.54601`，本模块有限差分 6.5653，偏差 0.295%。拟合式在该点超出 3% 门限，不可作基准 |
| Ritz `k≈9.03` vs 有限差分外推 9.346 | 同一双正弦基在 `M=2` 给 11.10、`M=4` 给 9.40，逐级收敛到 `9.32454`；`9.03` 是截断不足的产物。方板经典值 9.34 与谱解相差 0.166% |
| 方板外推 9.346（对 9.34 偏差 −0.007%） | 该外推其实高于谱极限 0.23%，说明 `−0.007%` 是「外推值偏高」与「拟合式偏高」互相抵消的结果，不宜作为精度证据 |
| `a/b≈2` 观测阶仅 0.13 | 该处前两阶剪切屈曲载荷近简并（`6.54604` vs `6.57281`，差 0.41%），低分辨率无法分开这对模态 |

谱参考解由 `src/tensorfem/shear_plate_spectral.py` 提供（双正弦 Galerkin、闭式矩阵元、13 项测试全绿），
证据见 `benchmarks/shear_plate_spectral.json`。本节的失败记录、未认证结论与误差数字**不做修改**。
