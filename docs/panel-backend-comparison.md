# 平面应力面板的串行与双进程对照

同一块 4 m × 1 m、厚 0.1 m 的 Q4 悬臂面板，弹性模量 7 GPa，泊松比 0.3。左侧固支，右侧向下施加合力 1000 N 的一致边载荷。稠密法直接累加到稠密矩阵。稀疏法组装 COO 并转为 CSR。双进程法将网格沿长度分成两条子域，各自在独立 Python 进程中组装和凝聚内部自由度，主进程求解界面位移并回代。

在一台 AMD EPYC 9V74 主机上，每种方式、每种规模独立启动三次，每个进程的 BLAS 线程数为一。下表为各指标的中位数。双进程的组装列包含进程启动、局部稀疏分解、凝聚与关闭；求解列仅含主进程的界面求解和回代。总时间自进入求解器起算，内存取每 50 ms 采样到的整棵进程树的比例常驻内存之和。主机同时执行回归，计时用于描述本次运行环境。[18 组原始时长、内存和数值误差](../artifacts/panel_backend_comparison.json)

| 网格 | 方法 | 组装（s） | 求解（s） | 总时间（s） | 峰值 PSS（MiB） |
|---|---|---:|---:|---:|---:|
| 32×8 | 稠密 | 0.0400 | 0.0390 | 0.0794 | 187.3 |
| 32×8 | 稀疏 | 0.0145 | 0.0018 | 0.0254 | 179.7 |
| 32×8 | 双进程 | 12.2348 | 0.0003 | 12.2356 | 536.5 |
| 80×16 | 稠密 | 0.0812 | 1.1301 | 1.2119 | 296.5 |
| 80×16 | 稀疏 | 0.0463 | 0.0161 | 0.0629 | 176.9 |
| 80×16 | 双进程 | 13.5561 | 0.0004 | 13.5571 | 536.5 |

逐节点比较位移、外载荷和反力，逐单元比较中心应力三分量。各场取最大绝对差，除以稠密参考该场的最大绝对值。应变能通过积分单元刚度计算，并与半外力功单独核对。18/18 组通过 (10^{-7}) 门限，最大场量或能量相对差为 (3.06\times10^{-12}) 以内。两种规模下，串行稀疏法耗时最短，双进程的启动和凝聚占据了主要时间。本结果只覆盖单机平面应力模型。

复算需要 Linux、项目 dev 依赖及 psutil。从仓库根目录运行：

```bash
python -m pip install 'psutil>=5.9'
PYTHONPATH=src python benchmarks/panel_backend_comparison.py
python -m pytest -q tests/test_structural_coupon_paths.py
```
