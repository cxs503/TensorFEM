# CASE-FEM-HEAT-L2 收敛率的度量缺陷：节点 RMS 伪范数把 2 阶压低到 1.88（m20995）

**锚点** CASE-FEM-HEAT-L2 ｜ **性质** 对抗性复核（adversarial review）+ 缺陷修复 ｜
**判据** 收敛率 ≥ 2 阶（ref: manufactured solution）

**一句话**：算例池该项的 PASS 长期建立在 `sqrt(mean(e²))` 这个**节点 RMS 采样伪范数**上，
它比真实 L₂ 范数系统性偏高收敛率下限、并且门禁阈值被放宽到 `≥1.8`；换回理论所依据的
**域积分 L₂ 范数**后，同一份内核（未改一行装配/求解代码）给出
1.99225 / 1.99776 / 1.99942 / 1.99985，
2 阶判据成立且带域积分/积分阶次/独立码三重交叉验证。

## 2. 发现的缺陷（按严重度排序）

**F1（阻断级，度量）** `l2_rel = sqrt(mean_nodal(e²)) / sqrt(mean_nodal(T²))` 是节点采样伪范数，
不是判据所指的 L₂ 范数：

* Dirichlet 边界节点的误差**恒等于零**，于是采样集合把"内部 O(h²) 误差"和"零误差边界层"混在一起，
  伪范数/真范数的比值随 h 漂移（下表"伪/真 比值"列：0.51 → 0.67），沿阶梯偷走 0.03–0.19 阶；
* 观测到 1.81/1.88/1.94 被判读为"趋向 2 但未到"，实际是**度量伪影**：同一内核用真范数是 1.992/1.998/1.999。

**F2（阻断级，声明）** 门禁 `convergence_order_ge_1p8`（阈值 1.8）与验收"收敛率 ≥ 2 阶"**不对应**：
证书 `passed:true` 不能支持验收结论（这是"声明超出证据"的典型形态）。

**F3（中，数值卫生）** 误差范数的后处理积分阶次未受控：粗网格 4 点规则的积分差达
4.9e-06（相对），
足以在 1e-2 量级污染阶次。仓内已有"积分不充分导致伪 2 阶"的前科。

**F4（低，阶梯长度）** 阶梯止于 32×32，最细段仍在前渐近区，而"接近 2"的判读无外推残差佐证。

## 3. 修复（最小、可验证）

1. `src/tensorfem/heat_conduction_l2.py`：新增 `integral_error_norms()`（自有形函数 + Jacobian + Gauss，
   **不复用装配内核**）给出域积分 L₂ / H₁ 相对误差；`l2_relative` 改为门禁量，
   旧的节点 RMS 保留为 `l2_nodal_rms_relative`（**无门禁**，供历史记录对照）。
2. 门禁重定：`ORDER_GATE=1.95`（2 阶的 2.5% 带）、`QUADRATURE_GATE=1e-6`、`QUADRATURE_ORDER_GATE=1e-3`、
   `H1_ORDER_GATE=0.9`、`HEAT_BALANCE_GATE=1e-10`；`run_heat_conduction_l2()` 返回逐门禁字典。
3. `benchmarks/verified/fem_heat_conduction_l2/run.py`：阶梯延长到 64×64；门禁从 3 条扩到 8 条
   （含 Roache 幂律残差、积分阶次稳定性、独立码一致性）；图件同时画真范数与伪范数两条阶梯，
   让度量缺陷在图上直接可见。
4. `independent_sparse.py`：从零写的 numpy/scipy Q4 求解器，逐层复核 L₂ 与节点场。
5. 测试：`tests/test_heat_conduction_l2.py` 从"跑一遍"升级为**不变式断言**
   （阶次带、逐对门禁、积分阶次不变性、伪范数必须比真范数低 >0.02 的回归断言——一旦有人把度量改回去就红）。

## 5. 误差判定（逐项回答"是否 < 3%"）

| 关键量 | 值 | 基准 | 相对偏差 | 是否 <3% |
|---|---|---|---|---|
| 最细网格 (64×64) L₂ 域积分误差 | 1.755209e-04 | 解析制造解（同网格精确场积分） | 即误差本身 | **是**（0.0176%） |
| 最细段观测阶 | 1.99985 | 2.0（仓内先验表） | 0.007% | **是** |
| 最粗段观测阶（8×8→16×16） | 1.99776 | 2.0 | 0.112% | **是** |
| H₁ 最细段观测阶 | 0.99998 | 1.0 | 0.002% | **是** |
| 旧伪范数最细段观测阶（已废弃） | 1.9657 | 2.0 | 1.71% | **否**（正是本单修掉的度量伪影） |

**结论**：验收"稳态热传导 L2 收敛率 ≥ 2 阶"在域积分范数下**成立**（最细段 1.99985，误差带宽内），
且不再是"接近 2"的含糊表述；旧口径下"未达 2"的结论是度量缺陷造成的**假阴性**。
本单不涉及诚实 FAIL 的覆盖：旧 PASS 结论本身不假（误差量级与热平衡残差都是真的），
假的是它对"阶次"的支持强度与门禁阈值。

## 6. 注意点与适用范围

* 只覆盖均匀矩形网格、常数热导 k=1、无内热源（制造解严格调和），Q4/2×2 Gauss；
  扭曲网格、变热导、三维四面体、瞬态 θ 法**未验证**，不得外推。
* 两份实现共享同一离散格式，交叉验证只覆盖装配/求解/后处理，不覆盖离散格式选择本身；
  格式阶次的锚是仓内先验表行 + H₁ 阶次 1.0 + 幂律残差三重独立证据。
* 伪范数偏低的机制是"边界节点误差恒零 + 采样权重随 h 变化"，对**零误差边界**的算例才成立；
  纯 Neumann 算例不会有同样的偏差，不得把 0.03–0.19 的偏差当作通用常数。
* 64×64 是稠密装配上限（4225 未知量、143 MB 电导阵）；更细网格需先给 `thermal` 稀疏路径，
  本单未动内核。
