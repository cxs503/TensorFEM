# Stiffener-calibration figures (GAP-PP-4)

GitHub mirror of the three figure artifacts of the m21055 / PR #1226
deliverable ("calibrate the ice-belt panel edge restraint `beta` from real
scantlings", anchor `GAP-PP-4-ICE-STRUCT-ELASTIC-RESTRAINT`).

| file | content |
|------|---------|
| `beta_stiffener_calibration_band.png` | `beta` and mobilised moment fixity vs the spacing of the fixing members; ice-belt design point |
| `beta_stiffener_calibration_field.png` | von Mises bending-stress field at the calibrated restraint (uniform 1 MPa) |
| `beta_stiffener_calibration_stress_band.png` | centre stress vs `beta`: Mindlin FE band, exact Kirchhoff-Levy anchors, calibrated design point |

## Provenance

* Data source: `benchmarks/artifacts/beta_stiffener_calibration.json`
  (committed, git sha + versions recorded inside).
* Generated by `gen_stiffener_calibration_figures.py` (reads the JSON only,
  no recomputation) and then downscaled (0.7x, 128-colour palette) so the
  three PNGs stay under the merge-governor 200 KB artifact cap. The full
  resolution originals live in the record area
  `benchmarks/artifacts/beta_stiffener_calibration_{band,field,stress_band}.png`
  (regenerate with `python gen_stiffener_calibration_figures.py`).
* These copies live under `docs/` because the push gate only lets delivery
  figures through `docs/` (v5.8 F3); the `benchmarks/artifacts/` originals are
  the record-area master and are not pushed.

Landed by mission m24649 (re-open of TensorFEM#1226, 管到底 round 1): the eight
text deliverables of m21055 are already in main (merged via #1020); the three
PNGs were the only part filtered by the gate and never landed.
