# 曲面壳几何刚度复核（Shell4 面元柱壳外压屈曲）：否定定谳

`docs/shell4-prestress-buckling-qualification.md` 的 capability boundary 一直写着
「does not yet qualify … curved-shell geometric stiffness」。本文把这条验证欠账
放进一个**有闭式解、只考算子**的工况里复核，结论是**不通过**，并以 fail-closed 测试锁死现状。

可复现入口：


## 1 案例与基准

薄壁圆柱壳受均匀外压的经典失稳是 **n = 2 不可伸长（椭圆化）环向模态**：

```
p_cr(n) = (n^2 - 1) E t^3 / (12 R^3 (1 - nu^2)),      p_cr(2) = E t^3 / (4 R^3 (1 - nu^2))
```

n = 2 值与船级社/教科书的长壳弹压形式 `2 E / (1 - nu^2) (t/D)^3`（D = 2R）代数恒等；
本次运行实测两者相对差 0.0e+00，`(n^2-1)/3` 波数比
{'2': 1.0, '3': 2.666667, '4': 5.0, '5': 8.0} 亦在测试中逐项断言。

工况：R = 1.0 m，t = 0.01 m（R/t = 100），
L = 8.0 m（L/R = 8），E = 2.1e+11 Pa，nu = 0.3，
参考 p_cr = **57692.3 Pa**。壳内薄膜状态精确且均匀（`N_theta = p R`，开口壳 `N_x = 0`），
所以本案例只考查**面元算子 + 局部基旋转 + 组装边界条件**，不掺入载荷积分或应力恢复路径。

## 2 方法

1. 网格：闭合无缝隙的平面四边形面元柱壳；每个面元跨两条母线因此严格共面
   （`shell4_local_frame` 要求共面），测试逐边验证内部边均被两个面元共享。
2. 算子：弹性阵用生产 `shell4_stiffness`，几何阵用生产 `shell4_geometric_stiffness`；
   每个面元按自身局部基把环向/轴向合力落到局部 x/y 轴（**数值判定**局部轴与环向/轴向的对齐，
   不依赖节点排序）。压缩为正（`K - lambda Kg`）。
3. 特征求解 `generalized_buckling_load_factor`：按 `|Kg|` 列范数分 active/passive，对 `K`
   做静力凝聚（与已验收平板路径同一套处理），再把 `Ga` 白化后对角化；低于
   `1e-9 max(lambda)` 的因子作为数值机构剔除，但**不剔除携带有限失稳功的面元尺度近机构**——
   那正是本审计要报告的物理事实。
4. 求解器先自证：同一求解器在**已验收的平板 Navier 路径**上复算，相对差
   1.7e-13（`757259.2749` vs 生产平板路径
   `757259.2749`，Navier `759200.3385`；该量随 BLAS 线程数为 1e-14–1e-13 量级）。
5. 闭合柱壳自检：整体绕轴刚体运动对 K 与 Kg 的能量均为 ~0（相对最刚方向 1e-10）；压缩预应力
   Kg 半正定；**拉伸预应力必须无法给出有限屈曲因子**（否则报错，测试覆盖）。

## 4 误差判定

| 关键量 | 参考值 [Pa] | 本次结果 [Pa] | 相对误差 | 是否 < 3% |
|---|---:|---:|---:|---|
| 求解器交叉验证（平板 8×8 vs Navier） | 759200 | 757259 | 0.256 % | 是 |
| 求解器交叉验证（vs 已验收生产平板路径） | 757259 | 757259 | 1.7e-11 % | 是 |
| 参考式自洽（环向式 vs 船级社式） | 57692.3 | 57692.3 | 0.0e+00 % | 是 |
| 柱壳最低屈曲压力 n_circ=16 | 57692.3 | 2.159e+06 | +3641.6 % | **否** |
| 柱壳最低屈曲压力 n_circ=32 | 57692.3 | 1.303e+05 | +125.8 % | **否** |
| 柱壳最低屈曲压力 n_circ=48 | 57692.3 | 2.555e+04 | -55.7 % | **否** |
| 柱壳最低屈曲压力 n_circ=64 | 57692.3 | 8065 | -86.0 % | **否** |

结论：求解器与参考公式本身达标（1.9e-14 / 0.0），**被审计能力（曲面壳几何刚度）逐项均不满足 3%**，
最细网格反而更差（-86.0 %）。故 `passed = False`，
`verdict = curved-shell-geometric-stiffness-unqualified`，不认证曲面几何刚度、不提升任何验收状态。

## 5 根因与适用范围

* **根因**：bilinear 平面面元的横向位移是 C0 双线性，无法表达不可伸长弯曲（椭圆化）；在环向压缩下
  面元尺度的锯齿模态弹性刚度趋零而失稳功有限，于是 λ 随加密而衰减。这与
  [sphere-membrane-validation.md](sphere-membrane-validation.md) 记录的"薄 + 曲面 + 压力"平面面元膜力
  误差约 1000% 同源：面元族在**不可伸长/膜态主导**的曲面工况上不可信。
* **不覆盖**：载荷跟随（pressure follower）刚度项、非线性预屈曲求解、缺陷敏感性、后屈曲；
  也**不覆盖轴向压缩**（该工况模态含显著膜伸缩，faceted 表现可能不同，需独立复核）。
  本文结论不外推到上述工况。
* **工程含义**：薄壁曲面壳的屈曲评估不要直接采用 faceted Shell4 的初始应力特征值结果；需要一致壳单元
  （MITC/退化壳）、含曲率项的几何刚度公式，或至少做面元尺度模态过滤并在报告中写明。
* **后续修法线索**：(a) 在壳单元几何刚度中加入曲率/压力跟随项并把标志位暴露给求解器；
  (b) 以 Fourier 限制子空间求 n = 2 模态因子，得到"光滑模态"下的收敛证据；
  (c) 用 MITC4/一致壳单元复算同一工况。
