## 1. Case Introduction

This verification suite validates the Mindlin-Reissner plate bending element in TensorFEM against two independent analytical solutions:
- **Static**: Timoshenko plate theory (Navier solution for simply supported rectangular plate under uniform load)

## 2. Methodology

### Element Formulation
The Q4 Mindlin-Reissner element uses:
- **Bending**: 2×2 Gauss integration (full)
- **Transverse shear**: Selective reduced integration (1-point rule at element center)
- **Degrees of freedom**: (w, θ_x, θ_y) per node
- **Shear locking prevention**: SRI technique

### Analytical References

#### Timoshenko Plate Theory (Static)
For a simply supported rectangular plate under uniform load q:

$$w(x,y) = \sum_{m,n \text{ odd}} W_{mn} \sin\left(\frac{m\pi x}{a}\right) \sin\left(\frac{n\pi y}{b}\right)$$

where:
$$W_{mn} = \frac{q_{mn}}{D R_{mn}^2} \left(1 + \frac{D R_{mn}}{\kappa G h}\right)$$
$$q_{mn} = \frac{16q}{\pi^2 m n}, \quad R_{mn} = \left(\frac{m\pi}{a}\right)^2 + \left(\frac{n\pi}{b}\right)^2$$
$$D = \frac{Eh^3}{12(1-\nu^2)}, \quad G = \frac{E}{2(1+\nu)}$$

The factor $(1 + D R_{mn}/(\kappa G h))$ is the shear deformation correction. For thin plates (a/h → ∞), this approaches 1 and recovers the Kirchhoff solution.

**Reference**: Timoshenko & Woinowsky-Krieger, *Theory of Plates and Shells*, §33.

#### Navier/Leissa Frequencies (Vibration)
For a simply supported square plate:

$$\omega_{mn} = \pi^2 \sqrt{\frac{D}{\rho h}} \left[\left(\frac{m}{a}\right)^2 + \left(\frac{n}{a}\right)^2\right]$$

First 5 modes for square plate (a=b):
1. (1,1): ω = 2π²√(D/(ρh))/a²
2. (1,2): ω = 5π²√(D/(ρh))/a² (degenerate with (2,1))
3. (2,1): ω = 5π²√(D/(ρh))/a²
4. (2,2): ω = 8π²√(D/(ρh))/a²
5. (1,3): ω = 10π²√(D/(ρh))/a² (degenerate with (3,1))

**Reference**: Leissa, NASA SP-160 (1969); Timoshenko & Woinowsky-Krieger §54.

## 5. Observations & Limitations

### Strengths
1. **Independent references**: Both analytical solutions are closed-form and independent of the FE implementation
2. **Comprehensive coverage**: Static + vibration + convergence + negative controls
3. **Physical consistency**: Shear correction factor properly accounts for Mindlin vs Kirchhoff difference
4. **Mesh convergence**: Demonstrates O(h²) convergence as expected for Q4 elements

### Limitations
1. **Computational cost**: Dense eigensolve limits mesh sizes to ~16×16 on control node
2. **Thin plate regime**: For a/h=100, shear deformation is negligible (<0.1%), so Mindlin and Kirchhoff give nearly identical results
3. **Boundary conditions**: Only simply supported (SS1) is verified; clamped and free edges require separate validation
4. **Cluster queue**: Execution delayed by resource constraints; framework is ready but results pending

### Applicability
- **Valid for**: Thin to moderately thick plates (a/h ≥ 20), isotropic materials, small deflections
- **Not validated for**: Thick plates (a/h < 10), large deflections, composite laminates, dynamic loading
