# 厚壁圆筒稳态热应力验证：平面应变热应变通道 vs Timoshenko 精确解

## 1. 案例介绍（为什么是这个算例）

在加入本单之前，TensorFEM 的**热弹性**能力只到一维杆
（`thermal.solve_thermoelastic_bar`，自由膨胀 / 全约束两种工况），二维/三维
温度梯度引起的热应力场（船体板格受焊后残余温度场、主机基座与液舱隔热层两侧
温差、管路与压力容器壁厚温差）没有任何独立基准。热应力与外力应力的失效模式
不同：它的"载荷"由温度场自身的非均匀性产生，边界力为零，**约束完全来自材料
内部相容性**，因此它对有限元实现的三处细节极其敏感——

1. 等效热载荷向量 `f_e = ∫ Bᵀ D ε_th t dA` 的相容性；
2. 平面应变下热应变的有效取值（见 §5 坑 1，差一个 `(1+ν)` 因子）；
3. 应力恢复时必须从总应变中扣除热应变。

本单把这三处一次性钉在**有闭式解**的厚壁圆筒算例上。

物理背景：内壁热、外壁冷、内外表面均无面力的无内热源圆筒，稳态径向导热

    T(r) = T_i + (T_o - T_i) ln(r/r_i) / ln(r_o/r_i)

由此产生的环向应力在内壁为压、在外壁附近转拉，是热应力场的经典态。

| 参数 | 符号 | 取值 |
|---|---|---|
| 内半径 / 外半径 | r_i, r_o | 0.5 m / 0.8 m（壁厚/内径 = 0.6） |
| 内壁 / 外壁温度 | T_i, T_o | 500 K / 100 K（ΔT = 400 K） |
| 弹性模量 / 泊松比 | E, ν | 210 GPa / 0.30 |
| 线膨胀系数 | α | 12×10⁻⁶ 1/K |
| 参考温度 | T_ref | 0 K（应力按 α(T−T_ref) 计） |
| 边界 | — | 内外表面**均自由**（无面力）；θ=0 与 θ=π/2 两切面轴对称约束 |
| 应变假设 | — | 平面应变（ε_z = 0，广义平面应变） |
| 网格 | — | 四分之一扇区 Q4：n_θ × n_r = 8×4 … 12×24（最细 288 单元 / 650 自由度） |
| 闭式解峰值 | — | σ_θ 833.7 MPa（压）、σ_r 83.6 MPa、σ_z 1511.3 MPa |

## 2. 怎么做的（方法 / 流程 / 工具链）

**闭式参考解**（`src/tensorfem/thermoelastic_annulus.py`）。从轴对称平衡的位移形式

    (λ + 2μ) d/dr[ (1/r) d(r u)/dr ] = (3λ + 2μ) α dT/dr

出发，取特解 `u_p = (1+ν) α r (T − K/2) / (2(1−ν))`（`K = (T_o−T_i)/ln(r_o/r_i)`，
即 `∫ rT dr` 的闭式），叠加齐次解 `A r + B/r`；两个常数由**双面自由**条件
`σ_r(r_i) = σ_r(r_o) = 0` 定出。`σ_r` 对 (A,B) 是仿射的，故用三点线性探针精确求解
这两个常数（不做手工代数化简，避免公式抄错）。应力由 `σ = D(ε − ε_th)` 用**与有限元
完全相同的 D 矩阵**给出，参考解与离散解之间只可能存在离散误差。

**等效热载荷**。`thermal_strain_loads` 逐单元 2×2 高斯积分 `∫ Bᵀ D ε_th t dA`，
单元内温度用双线性形函数插值（与评分时所用的温度场一致）。**相容性由测试机器精度
锁定**：均匀升温时 `f_th = K u_free`，实测残差 < 1e-10 × ‖f‖。

**有限元路径**（`solve_annulus_thermoelasticity`）。四分之一扇区 Q4 网格
（`lame_reference.sector_q4_mesh`）+ 轴对称约束（`symmetry_fixed_dofs`）→ 稠密求解
→ 每个单元 2×2 高斯点上恢复 `ε = B u`、`σ = D(ε − ε_th)` 并旋转到极坐标
（`lame_reference.cartesian_to_polar_stress`）。

**参考解自身的独立校验**（均为测试，不依赖有限元结果）：位移形式平衡 ODE 的有限差
残差 < 1e-4 × 应力尺度；双面 `|σ_r| < 1e-9 × σ_θ峰值`；均匀温度极限下**面内**应力
严格为零、轴向应力严格等于约束应力 `−EαT`；`σ_z = ν(σ_r+σ_θ) − αET` 恒等式逐点成立。

**单元映射的补丁测试**。该模块自带形函数导数（`_shape_derivatives`），在**强畸变**
扇区单元上用任意线性位移场检验 `ε = B u` 复现常应变，最差绝对误差 7.6×10⁻¹⁹。

工具链：`benchmarks/thermoelastic_annulus.py` 一次跑完 5 组网格，写
`benchmarks/thermoelastic_annulus_evidence.json` 与
`docs/assets/thermoelastic_annulus_stress.png`；下表由脚本直接打印，不经手抄。

## 3. 计算结果（程序化注入）

误差一律按**被比较场自身的峰值**归一化（σ_θ 峰值 = 833.68 MPa）。

| 网格 (n_θ × n_r) | 单元 | 自由度 | 内壁 σ_θ FE / 解析 (MPa) | 内壁 σ_θ 误差 | σ_θ 全场最大误差 | σ_r 全场最大误差 | σ_z 全场最大误差 |
|---|---|---|---|---|---|---|---|
| 8 × 4 (grad 1.0) | 32 | 90 | −823.60 / −723.96 | 13.764% | 15.916% | 325.545% | 7.643% |
| 8 × 8 (grad 1.0) | 64 | 162 | −830.43 / −782.81 | 6.083% | 8.739% | 172.188% | 4.434% |
| 8 × 16 (grad 1.0) | 128 | 306 | −831.78 / −812.99 | 2.310% | 5.115% | 90.677% | 2.609% |
| 8 × 32 (grad 1.0) | 256 | 594 | −831.94 / −828.29 | 0.441% | 3.278% | 48.267% | 1.633% |
| 12 × 24 (grad 1.6) | 288 | 650 | −830.92 / −833.68 | **0.331%** | **2.348%** | **43.090%** | **1.279%** |

内壁环向应力在 8×4 → 8×8 → 8×16 上为 13.8% → 6.1% → 2.3%，逼近速率约 O(h^1.4)；
径向加密（grad 1.6，向内壁聚拢）进一步压到 0.33%。σ_r 的绝对误差随径向加密近似减半
（O(h)），但其**自身峰值只有 83.6 MPa**（σ_θ 峰值的 1/10），因此按自身尺度仍在 43%。

结果图见 `docs/assets/thermoelastic_annulus_stress.png`
（左：环向应力 vs 解析曲线；右：径向应力 vs 解析曲线；均为最细网格 12×24 的高斯点值）。

## 4. 误差判定（逐项，显式回答是否 < 3%）

| 关键量 | 基准 | 最细网格误差 | 是否 < 3% |
|---|---|---|---|
| 内壁环向应力 σ_θ(r_i) | Timoshenko 闭式解 −833.68 MPa | 0.331%（8×16 时 2.31%） | **是** |
| 环向应力全场（高斯点最大偏差） | 闭式解，按 σ_θ 峰值归一 | 2.348% | **是** |
| 轴向应力 σ_z 全场 | 闭式解，按 σ_z 峰值归一 | 1.279% | **是** |
| 径向应力 σ_r 全场（按自身峰值归一） | 闭式解，峰值 83.57 MPa | 43.09% | **否（honest FAIL）** |
| 径向应力 σ_r 全场（按 σ_θ 峰值归一） | 同上 | 4.32% | **否（honest FAIL）** |

**结论：工程关键量（内壁环向应力、环向应力场、轴向应力场）全部 < 3%，最差项 2.35%；
径向应力场在两种归一化下均超 3%（4.3% / 43%），本单**不**宣称 σ_r 达到 3% 门限**，
并把这个事实写成测试 `test_radial_stress_error_is_reported_against_its_own_peak` 锁住，
防止后续报告把 σ_r 混进"全部 < 3%"里。σ_r 是差分型小量（与 σ_θ 峰值差一个量级），
Q4 高斯点应力的低阶性使它只能按 O(h) 收敛；要按自身尺度达到 3% 需要单元应力恢复
（如 SPR/超收敛片恢复）或更高阶单元，本单未做。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **平面应变的热应变不是 `α·T`，而是 `(1+ν)·α·T`**。这是本单最大的坑，也是唯一
   值得单独立项的价值点。三维胡克律在 `ε_z = 0` 下给出面内应力 `− (3λ+2μ) αT`；
   而平面应变 D 矩阵乘 `αT[1,1,0]` 只得到 `−(2λ+2μ) αT = −(3λ+2μ)αT/(1+ν)`，即**所有
   热应力被系统性低估 (1+ν) 倍**（ν=0.3 时低估 23.08%）。正确做法：等效热应变取
   `ε_th = (1+ν)αT[1,1,0]`（等价于平面应变→平面应力的经典映射
   `E/(1−ν²), ν/(1−ν), α(1+ν)`）。本单第一版就是漏了这个因子，导致闭式"参考解"自身
   不满足平衡（平衡残差 1.2 GPa/m vs 应力尺度 0.8 GPa），**是平衡残差检验把参考解抓出来
   的**——凡热应力参考解，先做平衡残差检验再谈误差。测试
   `test_effective_plane_strain_thermal_strain_reproduces_three_dimensional_term` 与
   `test_naive_plane_strain_thermal_strain_breaks_the_gate` 锁定该因子（后者证明漏因子的
   误差恰为 ν/(1+ν) = 23.08%）。
2. **均匀升温在平面应变下不是零应力**：面内应力为零，但轴向应力为 `−EαT`
   （ε_z=0 的约束应力）。本单 v1 测试按"全零"写，被实测打回；已改为分别断言面内零 +
   轴向 `−EαT`。
3. **形函数导数的转置陷阱**：本模块的映射导数用 `natural @ inv(J)ᵀ`（J 的行是
   `∂x/∂ξ_a`）。写成 `natural @ inv(J)` 在**轴对齐**单元上看不出差别（J 对角），
   在**畸变**单元上直接错（常应变补丁测试误差 O(1)），而环向扇区单元全部是畸变单元。
   `test_shape_derivatives_reproduce_an_arbitrary_linear_field_on_a_skew_element`
   用最畸变的扇区单元锁定。
4. **温度场离散是算例的一部分**：单元内温度按双线性插值，故误差含"温度场插值误差"，
   不只是位移插值误差。这也是 σ_r 收敛慢于 σ_θ 的原因之一；若把温度场也做超收敛
   处理，另需基准，本单未做。
5. **不覆盖**：温度相关材料参数（α(E,T)）、瞬态热冲击（热波/惯性效应）、塑性热应力、
   内热源、对流/辐射边界、三维（本单只做平面应变；平面应力分支留给同一 D 矩阵接口，
   测试只锁定其热应变因子，未做全场验证）、各向异性/层合材料。
6. **算例池是单点标定**：只取 r_o/r_i = 1.6 一组；壁厚比 → 1（薄壁）时 σ_z 与 σ_θ 的
   量级比会变，σ_r 的相对重要性下降，3% 判定应重新标定。
