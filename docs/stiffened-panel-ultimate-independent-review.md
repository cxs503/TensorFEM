# Independent review of `stiffened_panel_ultimate` (verifier seat, TensorFEM)

Status: **independent re-verification, two defects fixed, one limitation quantified**.
Evidence generated by `scripts/verify_stiffened_panel_ultimate_independent.py`
into `artifacts/stiffened_panel_ultimate_review/verification.json`
(schema `stiffened-panel-ultimate-review/1`); every number below is rendered
from that JSON, none is transcribed by hand. Regression tests:
`tests/test_stiffened_panel_ultimate_independent_review.py`.

## 1. Case: what was re-verified and why

`tensorfem.stiffened_panel_ultimate` is the closed-form screening chain of the
ship stiffened-panel workflow: plate field under pressure (Navier series),
rigid-plastic plate capacity (yield lines), Faulkner effective width,
Johnson--Ostenfeld column curve, flange/tripping limits and the area-weighted
panel ultimate. Its acceptance tests restate the formulas the module
implements, so they can only prove self-consistency: a unit or convention
error passes every one of them.

The review therefore re-derived the same quantities on **independent** paths
and audited the conventions against the section geometry used elsewhere in the
same class. Reviewed parameters (the benchmark panel of
`docs/stiffened-panel-ultimate-strength.md`):

| item | value |
|---|---|
| span a (frame spacing) | 2.40 m |
| stiffener spacing b | 0.80 m |
| plate thickness | 20 mm |
| web / flange | 200x10 mm / 80x12 mm |
| material | E = 206 GPa, nu = 0.3, sigma_y = 235 MPa |

## 2. Method (why these paths are independent)

1. **Plate field** -- a finite-difference Kirchhoff solver: two Dirichlet
   Poisson solves, `grad^2 M = -p` (M = 0 on the simply supported edges) and
   `grad^2 w = -M/D` (w = 0), then centre moments from second differences with
   Richardson extrapolation over two grids. The only shared input with the
   module is the plate equation itself; no series coefficient is reused.
2. **Yield-line capacity** -- the virtual work of the pyramid and strip
   mechanisms is integrated *numerically*: area quadrature for the external
   work, sampled gradient jumps across the hinge lines for the internal work.
3. **Component limits** -- Faulkner, Johnson--Ostenfeld and the one-edge-free
   outstand buckling are re-implemented from their definitions and swept
   against the module over a parameter grid; the outstand convention is
   checked against `_section_geometry`, which builds the flange area as
   `flange_width * flange_thickness` (that is, the **total** flange width).

Toolchain: Python 3.11, numpy 2.4.6, scipy 1.16.0 (sparse Poisson solves),
matplotlib 3.10.8. Runtime of the whole evidence run: a few seconds (CPU),
no cluster job needed.

### 3.2 Defect 1 -- deflection returned `E` times too large

The series carried `D/E = t^3/(12(1-nu^2))` into the deflection sum and never
multiplied `E` back, so `centre_deflection` (also returned by
`plate_pressure_bending_stress`) was unphysical in SI units:

| quantity | value |
|---|---|
| legacy returned deflection at a/b = 3, b = 1 m, t = 20 mm, p = 1 Pa | 1.6698e+04 m |
| independent FD deflection, same case | 8.1057e-08 m |
| ratio | 205999976272.5 |
| ratio / E (E = 2e+11 Pa) | 0.999999885 |

The bending moments are unaffected (D cancels), which is why the shipped
evidence never noticed: the benchmark only quoted stresses. **Fix**: the
series takes a `young` argument, `D = E t^3/(12(1-nu^2))` is the physical
rigidity and `plate_rigidity` is returned as `D`; `plate_pressure_bending_stress`
forwards `young`. After the fix the module and the FD solution agree to
2.1e-08.

### 3.4 Defect 2 -- flange outstand convention

`flange_width` is the total flange width (the section geometry, area and the
warping constant `t_f^3 b_f^3/144` all assume that). The local-buckling screen,
however, used `flange_width/flange_thickness` as the slenderness of a
one-edge-free plate, although the outstand is only
`(flange_width - web_thickness)/2`. `sigma_cr` is proportional to `1/(b/t)^2`,
so the screen under-predicted it by a factor `(b_f/outstand)^2` -- about four.

The defect only bites fabricated flanges with `b_f/t_f` between about 18 and
37, where the pre-fix screen under-predicted the panel ultimate by up to
20.0 %.

## 5. Notes, limitations, things not verified

* **Yield-line selector step (quantified, not fixed).** The selector uses the
  pyramid for `a/b <= 1.5` and the strip for `a/b >= 2`. Because the pyramid
  value is always larger than the strip value, the "transition" branch
  `min(fan, strip)` always returns the strip value, so the screened capacity
  drops by **53.8 %** at `a/b = 1.5`
  (17.33 -> 8.00 in
  `p_u b^2/M_p`). The step is conservative (the strip mechanism has the smaller
  admissible capacity), but the module's own comment states that the strip
  mechanism is *not* kinematically admissible for `a/b < 2`, and the classical
  capacity curve is continuous. Closing this needs a combined mechanism family
  (central trough plus corner fans) that is out of scope for one session; it is
  filed as a gap instead of being papered over with an interpolation.
  Recorded in `tests/test_stiffened_panel_ultimate_independent_review.py`.
* **Tripping screen not verified.** The St Venant torsion-only tripping stress
  is not a rule clause and is excluded from the default limiting stress; this
  review does not certify it (WITHHELD). Its exclusion is documented in the
  module and is arithmetically consistent (torsion constant, warping constant
  and polar moment are evaluated about the plate line).
* **No experimental anchor for panel ultimate.** The Smith (1977) series is not
  available in this environment, so the panel-level strength remains verified
  only against its own component definitions and against the elasto-plastic
  shell unit cell of the original benchmark (6.81 % difference, reported
  there). This review does not change that status.
* **Pre-existing test failure, not caused by this change.**
  `tests/test_stiffened_panel_unit_fe.py::test_plastic_collapse_path_has_a_limit_point`
  (marked `slow`) fails on the unmodified module as well: the 14-step path
  reaches only 0.170 sigma_y, below the asserted 0.2. Reproduced by stashing
  the fix; reported here rather than fixed (the arc-length step size, not this
  review's scope).
* The Poisson split used by the FD solver assumes the exact simply supported
  boundary condition `M = 0` on the edges, which holds for `w = w_nn = 0`;
  clamped edges are not covered by this review.

## 7. Disposition

* **Request changes -> changes applied** for the two defects (deflection units,
  flange outstand convention); both are minimal, documented and covered by new
  regression tests.
* **Approve with notes** for the rest of the chain: the Navier series, the
  pyramid mechanism and all component limits are confirmed on independent
  paths within 1e-4.
* **Escalate** the yield-line selector step as a quantified gap rather than a
  silent limitation; the module's own comment and the measured 53.8 % step
  disagree, and the fix requires a mechanism family this session did not build.
