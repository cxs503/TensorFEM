# 加筋板架在冰压斑+侧压组合下的*局部*失稳极限状态：腹板局部屈曲与纵骨倾覆

锚点 `GAP-PP-5-ICE-STRUCT-GRILLAGE-ULTIMATE` 的自声明局限（`grillage_ice_ultimate` 模块文档串、
`CASE-GAP-PP-5-...-round6` §5 注 2）写着："纵骨腹板局部屈曲/倾覆和框架倾覆未建模"。也就是说，冰压斑 +
静水侧压 + 船体梁轴压组合链上的判据全是*板*判据或*梁柱*判据；深瘦腹板在局部冰压斑下恰恰可能先绕它与
板的连接线转动（倾覆），或腹板先局部屈曲，这两种状态此前一个都没有。本单补齐这两个极限状态，全部由
第一性原理推导（不抄规范系数），并与独立数值解法设门对照。

## 1. 案例介绍（物理背景 / 几何 / 参数）

冰级船冰带板架：板厚 20 mm；纵骨 T 250×10+80×12，肋距（纵骨跨距）2.10 m、纵骨间距 0.35 m；
横框架 T 550×10+120×14，跨距 2.80 m；EH36，σ_Y = 355 MPa。该几何即锚点 case study 几何
（`tensorfem.grillage_ice_ultimate.case_study_geometry()`），因此本单数字可直接与锚点已合并的 21 个 gate 对照。

## 2. 方法（怎么做的）

**截面**：倾覆截面取*裸 T 形*（腹板+翼板）。连续板**不**计入截面刚度，只作为约束介质（阻塞连接线横向平动、
提供转动弹簧 k_θ）。理由：把板算进截面会重复计入约束——对 20 mm 板 / 0.35 m 间距，板的 `b t³/3` 约为 T 形
自身 J 的 7 倍，会使倾覆应力虚高。

**能量泛函**（绕连接线转动 φ，横向平动被板约束）：

    U = 0.5 ∫(GJ φ'² + EI_w φ''² + k_θ φ²) dx,    W = (P/2) ∫(I_p/A + d²) φ'² dx

d 为形心到连接线距离，I_p = I_lat + I_strong，J = Σ b t³/3，I_w = ∫(ω−ω̄)² dA（极点取在连接线：腹板与
板中线 ω = 0，翼板 ω = h_e y）。正弦基 φ = sin(mπx/L) 下本征值闭式：

    σ_tr(m) = (GJ k² + EI_w k⁴ + k_θ) / (A (I_p/A + d²) k²),   k = mπ/L

**板转动弹簧**由板条自身弯曲导出（非规范系数）：宽 b_s/2 板条，远端为跨中对称面（转角 = 0），近端随纵骨转 θ，
梁解 k_θ = c D/(b_s/2)，c = 4（远端固支）/ 3（远端简支），D = E t_p³/(12(1−ν²))。

**腹板局部屈曲**：长板条 σ_w = k π² D_w/(t_w h_w²)；已知跨距时 k 取精确长宽比系数 k = min_m (m h/a + a/(m h))²
（≥ 4），并给出 k = 6.97（一边固支）上界。

**独立核定门**（`benchmarks/grillage_local_instability.py`，T14a–T14h，共 23 项，程序化断言）：
Hermite 有限元本征解（与模块正弦 Ritz 不同离散）、Hermite 梁 FE 求板弹簧、warping 常数数值积分 vs 闭式、
模态叠加、k_θ→∞ 抑制、量纲与长宽比标度、单调性。**23/23 通过。**

## 3. 计算结果（程序化注入）

**锚点纵骨（T 250×10+80×12，跨距 2.1 m，板转动约束 = 0 的下界）**

| 量 | 值 [MPa] | /σ_Y |
| --- | --- | --- |
| 梁柱极限（已合并链，JO/PR 包络） | 329.9 | 0.929 |
| 腹板局部屈曲 | 1194.4 | 3.365 |
| 倾覆（k_θ = 0，闭式，精确） | 222.6 | 0.627 |
| 倾覆（单模态 Ritz，全约束，*上界*） | 13562.6 | — |
| 倾覆（收敛 Hermite FE，全约束） | 2775.7 | — |
| 倾覆（自由平动横向-扭转，仅对照） | 56.2 | — |
| **局部极限状态（下界）** | **222.6** | **0.627** |

局部极限 / 梁柱极限 = **0.675**：在"板完全不提供转动约束"的下界上，倾覆比已合并链的梁柱极限低
32.5 %。

**需要多少板转动约束才让梁柱极限重新控制**：闭式线性解给出 η = 0.804 % × k_θ,max
（k_θ,max = 3.450e+06 N，而扭转刚度 GJ k² + EI_w k⁴ = 5.756e+04 N·m²）。
用收敛 FE 在同一点复核得 552.5 MPa > 梁柱极限 329.9 MPa，结论方向不变：
板只要还剩百分之几的转动约束，倾覆就不会控制。

**横框架（T 550×10+120×14，跨距 2.8 m，板转动约束下界）**

| 量 | 值 [MPa] |
| --- | --- |
| 腹板局部屈曲 | 246.3 |
| 倾覆（k_θ = 0） | 172.0 |
| 倾覆（单模态 Ritz，全约束，上界） | 595.7 |
| **局部极限状态** | **172.0**（控制：tripping） |

**参数扫描**（168 组：t_p ∈ 6–20 mm × b_s ∈ 0.35–1.20 m × 7 种腹板，跨距 2.8 m）：无转动约束下界上
48 组由腹板局部屈曲控制、120 组由倾覆控制；局部极限状态最低 0.245 σ_Y、最高 0.850 σ_Y。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **单模态正弦 Ritz 在 k_θ > 0 时是非保守上界**：板弹簧存在后扭转方程出现长度 (EI_w/k_θ)^(1/4) 的端部边界层，
   全局正弦基表达不了，倾覆被高估（全约束下 Ritz 13562.6 MPa vs 收敛 FE 2775.7 MPa，
   FE/Ritz = 0.205）。因此**容量判据只用 k_θ = 0 的闭式值（无边界层、精确）**，约束端数值一律标注
   `single_mode_ritz` 并在证据包里以 FE 值复核。
2. 横框架的板转动约束用 b_s = 肋距 2.1 m（约束来自两侧板格），纵骨用 0.35 m，两者量级差别很大，不可混用。
3. 弹性分岔极限状态，**不是倒塌载荷**：无塑性、无后屈曲储备、与梁柱/板屈曲的相互作用未建模；与已合并的刚塑性
   倒塌模块属不同极限状态，不可互校。
4. 端部按简支 + 自由翘曲；横框架对翘曲有部分约束，故倾覆值偏保守。
5. "自由平动"的横向-扭转状态（本例 56.2 MPa）**不是**焊接在连续板上纵骨能到达的状态（板膜刚度阻塞平动），只作对照。
6. 未做：规范（CSR/IACS）条文对照——沙箱内无规范文本，仓内锚点 `iacs-csr-w22.json` 状态为 `NOT_OBTAINED`，不得伪造；塑性-倾覆耦合；温度/棘轮路径。

## 6. 误差判定（逐项，是否 <3 %）

| 关键量 | 基准 | 误差 | <3 % ? |
| --- | --- | --- | --- |
| 倾覆（k_θ = 0） | 独立 Hermite FE 本征解（16 单元） | 1.9e-5 相对 | **是** |
| 倾覆（自由平动耦合） | 独立 Hermite FE（24 单元） | ≤1e-5 相对 | **是** |
| 倾覆（弱约束 1 % k_θ,max） | 独立 Hermite FE（24 单元） | <2 % | **是** |
| 板转动弹簧 k_θ | 独立 Hermite 梁 FE（2 单元） | <1e-9 相对 | **是** |
| warping 常数 I_w | 闭式 h_e² t_f b_f³/12 | 0.024 %（64 采样） | **是** |
| 腹板屈曲标度 | σ ∝ t²、σ ∝ 1/h² 精确关系 | <1e-12 | **是** |
| 屈曲系数 k | 长宽比精确解 min_m(mh/a+a/(mh))² | <1e-12 | **是** |
| 单模态 Ritz（k_θ > 0，全约束） | 收敛 FE | **+388.6 %** | **否** |

**显式回答**：除最后一项外全部关键量相对独立基准误差 <3 %。最后一项是**已知且已量化**的非保守偏差
（单模态正弦基的边界层缺陷），已在模块文档串、`restrained_bias_note` 字段与本表三处同时披露，且**不进入
容量判据**（容量判据只用 k_θ = 0 的精确闭式），因此本单结论不依赖该项。
