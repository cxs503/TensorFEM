## 1. 案例介绍

**物理背景**：船体板格在总纵弯曲与波浪剪流共同作用下，纯剪分支常常先于单向压缩分支控制板厚。规范/筛
查层面通用的纯剪屈曲系数是 `k_s = 5.34 + 4(b/a)²`（`τ_cr = k_s π² D /(b² t)`），简支板 `a/b = 1` 时
给出 9.34，与 Timoshenko & Gere 的经典值一致。这个式子本身**不是**特征值问题的解，而是对数值结果的
渐近拟合。

**几何与参数**（无量纲化，只影响归一化不影响 `k_s`）：

| 参数 | 取值 |
|---|---|
| 板 | 矩形薄板，边 `a`（x，纵向）、`b`（y，横向），`a/b ∈ [1, 8]` |
| 边界 | 四边简支：`w = 0`、`M_n = 0` |
| 弯刚 | `D_x = D_y = H = D = 1`（各向同性），厚度 `t = 0.012` 仅用于报应力 |
| 载荷 | 纯面内剪切 `N_xy = τ t`，`N_x = N_y = 0` |
| 归一化 | `k_s = N_xy,cr · b² / (π² D)` |

**要回答的问题**：`docs/marine-plate-combined-loading-verification.md` 第 3、4 条注意点留下两笔欠账——
(a) `a/b≈2` 的剪切分支只与渐近拟合比对、超差 3.55%，因此不认证；(b) 时间盒内写的双正弦 Rayleigh–Ritz
给出 `k≈9.03`，与有限差外推 9.346 差 3.4%，两侧都没法判对错（剪切问题几何算子不定，Ritz 的「上界」性质
被认为不成立，因而无法定谳）。

## 2. 怎么做的

**为什么需要一个独立参考**：拟合式不是解，两个数值方法互相不一致时无从判决。简支板在 `w = 0`、`M_n = 0`
下的 Kirschhoff 屈曲问题

```
D_x w,xxxx + 2H w,xxyy + D_y w,yyyy = N_x w,xx + N_y w,yy + 2 N_xy w,xy
```

的容许空间有一组**完备**基：`φ_mn = sin(mπx/a) sin(nπy/b)`（每个基函数本身就满足两条边界条件）。于是在
这个基上做 Galerkin 就是「在真解所在的完备空间里截断」，截断值是真特征值的 Ritz 上界，随基扩大单调
下降收敛。退化项只剩扭转项把 `(m,n)` 与 `(i,j)` 耦合：

```
g_ij,mn = - m n i j χ_mi χ_nj / ((m²-i²)(n²-j²)),   χ = 1 - (-1)^(m+i) ∈ {0, 2}
K_ij,mn = (ab/4)[D_x kx⁴ + 2H kx²ky² + D_y ky⁴] δ
G_ij,mn = (ab/4)[N_x kx² + N_y ky²] δ + N_xy · 2 g_ij,mn
```

`G` 对纯剪是不定的，所以屈曲载荷**不是**最小代数本征值，而是使 `K - N G` 奇异的最小正 `N`，即
`1 / max{正本征值}`，用 Cholesky 同余 `L⁻¹ G L⁻ᵀ` 求解。

**先给参考本身造判据（否则又是自述）**：参考实现必须先复现存在闭式的情形，才有资格去判别人。

| 参考自检 | 基准 | 结果 |
|---|---|---|
| 扭转块闭式 vs 64 点 Gauss–Legendre 二重积分 | 恒等式检验 | 最大偏差 **2.66e-14** |
| 单向压缩方板 `k_x` | Navier 精确 `4π²D/b²`（`k=4`） | 误差 **0.00e+00** |
| 等双轴方板 | Navier 精确 `2π²D/b²`（`k=2`） | 误差 **0.00e+00** |
| 方板纯剪 `k_s` | 经典表列值 9.34 | **−0.17%** |
| 长板极限（`a/b = 8`） | 经典渐近 5.34 | 5.4148（单调趋近） |

**两个真实踩到的坑**（都写进模块文档并做成机检）：

1. 宇称因子 `χ = 1-(-1)^(m+i)` 是 **0 或 2**，不是 0/1 指示函数。写成 1 会把整个扭转块缩小 4 倍，
   方板 `k_s` 从 9.3245 变成 **37.298**——一个完全收敛、光滑、稳定、但错了 4 倍的答案。闭式 vs 求积
   自检就是为了挡住这一类。
2. 纯剪时 `G` 不定，`K⁻¹G` **非对称**；`numpy.linalg.eigvalsh` 会静默只读一个三角，返回的谱连主子块
   的值都不包含（实测给出 37.3，而两模子块解析解是 11.1，违反上界性质）。必须走 Cholesky 同余。

**对比协议**：解算核 `panel_buckling_load`（`longitudinal_share=0, shear_share=1`）在相同长宽比下与收敛
参考比；同时把拟合式与收敛参考也作同一口径比较，于是「谁超差」变成两个可比数字。

## 3. 计算结果

**收敛参考的 `k_s`（截断预算 8→24，末两级相对差即残差）**

| a/b | 收敛参考 k_s | 残差 | 拟合式 `5.34+4(b/a)²` | 拟合式误差 |
|---:|---:|---:|---:|---:|
| 1.0 | 9.324542 | 3.3e-06 | 9.3400 | −0.17% |
| 1.5 | 7.069988 | 3.8e-06 | 7.1178 | −0.67% |
| 2.0 | 6.546044 | 3.1e-06 | 6.3400 | **+3.25%** |
| 3.0 | 5.840187 | 7.3e-06 | 5.7844 | +0.96% |
| 4.0 | 5.624627 | 1.8e-05 | 5.6250 | +0.62% |
| 6.0 | 5.478928 | 3.8e-05 | 5.4511 | +0.51% |
| 8.0 | 5.414756 | 2.6e-05 | 5.4025 | +0.23% |

（拟合式误差列按 `k_s,fit / k_s,ref − 1` 的绝对值口径记录；正号表示拟合式偏保守或偏小由表中正负号给出。）

**求解器 vs 收敛参考（同长宽比、纯剪）**

| a/b | 网格 | 求解器 k | 参考 k_s | 求解器误差 | 对拟合式误差 |
|---:|---|---:|---:|---:|---:|
| 1.0 | 24×24 | 9.39935 | 9.324542 | +0.802% | +0.635% |
| 1.5 | 24×36 | 7.11859 | 7.069988 | +0.687% | +0.011% |
| 2.0 | 32×64 | 6.57590 | 6.546044 | **+0.456%** | +3.721% |
| 3.0 | 20×60 | 5.96150 | 5.840187 | +2.077% | +3.061% |

`a/b = 2` 的三级加密（16×32 → 24×48 → 32×64）末级误差 +0.456%，观测阶约 1.13——说明该长宽比的长板方向
网格仍未进渐近区，这也解释了旧报告里 `a/b = 2` 网格观测阶只有 0.13 的异常：那是拟合式本身在 `a/b≈2`
偏离，把真实（正的、光滑的）插值阶淹没了。

**归一化核对**：`a/b = 2` 的求解器 +0.456% 与旧报告「对拟合 3.55%」在同一量级上并不矛盾——
`(1.000456)(1.0325) ≈ 1.033`，即旧报告的 3.55% 里约 3.25 个百分点来自拟合式、约 0.5 个百分点来自求解器。

## 5. 注意点（踩过的坑 / 局限）

1. **适用范围**：薄板线化屈曲、四边简支、各向同性（或正交各向异性只需给 `D_x, D_y, H`）。固支、弹性
   约束、加筋离散梁、塑性、后屈曲、三维壳应力全部不在范围内。
2. **结论方向被反转，但失败面保留**：旧报告的 3.55% 记录不删；本页只是把它重新归因，并把归因做成机检
   门禁（第 6 道门在拟合式重新变「准」时会失败，防止结论被悄悄改回去）。
3. **`a/b = 3` 的求解器误差 +2.08% 已在门限边缘**：该点用 20×60 网格，允许但不宜引用；要用得更准应加密
   （本页未做，属未完成项）。
4. **参考自身在 `a/b` 大时残差上升**（8.0 处 2.6e-05），是模数预算固定 (8..24) 所致；仍远小于任何门限。
5. **经典值 9.34 与本文参考 9.3245 差 0.17%**：9.34 是历史数值解（Timoshenko & Gere 表列，四位有效数字），
   本文参考是可复算的收敛值。判据仍锚在 9.34 上（更保守），但 0.17% 的差异需要读者知道。
6. **旧 Ritz 的 9.03 定性**：9.03 低于收敛参考 9.3245，违反 Ritz 上界性质，因此那次实现只能判定为
   「实现未良置（欠收敛或归一化错误）」，不能作为参考；本页不对其细节做进一步考古。

## 6. 误差判定（逐项 vs 基准，是否 <3%）

| 关键量 | 基准 | 实测误差 | <3%？ |
|---|---|---:|---|
| 扭转块闭式积分 | 64 点 Gauss–Legendre 求积 | 2.66e-14（绝对） | 是 |
| 单向压缩方板 `k_x` | Navier `4π²D/b²` | 0.00e+00 | 是 |
| 等双轴方板 | Navier `2π²D/b²` | 0.00e+00 | 是 |
| 方板纯剪 `k_s` | 9.34（文献表列） | −0.17% | 是 |
| 长板极限 `k_s(a/b=8)` | 5.34（渐近） | +1.40%（未在渐近区） | 是 |
| 求解器 `a/b=1`，24×24 | Galerkin 收敛参考 | +0.802% | 是 |
| 求解器 `a/b=1.5`，24×36 | Galerkin 收敛参考 | +0.687% | 是 |
| 求解器 `a/b=2`，32×64 | Galerkin 收敛参考 | +0.456% | 是 |
| 求解器 `a/b=3`，20×60 | Galerkin 收敛参考 | +2.077% | 是（边缘，见注意点 3） |
| **拟合式 `a/b=2`** | **Galerkin 收敛参考** | **+3.25%** | **否**（拟合式不合格，求解器合格） |

结论：求解器在全部四个长宽比上 <3%，`a/b≈2` 的欠账判给渐近拟合式；这是本仓 `k_s` 判据口径的一次
**参考侧**纠正，求解器实现不需要改动。
