# Kirsch 逐点径向应力 FAIL 行的归因与复测

Status：**已发表判据与其 6 行 FAIL 原样保留**；本条补上归因（探针压在单元界面上 + 分母近零）与同一位移解上的良置复测。TensorFEM 0.45.0，2026-11-09T00:15:03.378930+00:00。全部数字由 `benchmarks/kirsch_pointwise_conditioning_audit.py` 写入 `benchmarks/kirsch_pointwise_conditioning_audit.json` 后程序化注入，无手抄。

## 1. 案例与欠账（案例介绍）

`docs/structural-certification-materials.md` 的 Kirsch 四分之一圆环算例（孔半径 `a=1`、外半径 `R=10`、远场拉伸 `T=1`、`nu=0.3`、平面应力、Q4、径向渐变 `grading=5`）在两条射线 `theta=90°/0°` 上各留下 3 行 `FAIL`，**全部是径向应力**（`r/a=1.02 / 1.05 / 1.25`），判据是相对量 `|fe-ref|/|ref| <= 3 %`。本条不改判据、不改这 6 行，只回答三个问题：探针落在哪里、误差在绝对量纲上有多大、把同一位移解换成单值的取样算子后还剩多少。

| 项 | 值 |
| --- | --- |
| 网格阶梯（沿用已发表阶梯） | 24, 32, 48, 64 |
| 每级单元/自由度 | n=24: 576/1250, n=32: 1024/2178, n=48: 2304/4802, n=64: 4096/8450 |
| 探针 | 2 条射线 × 6 个 `r/a` × 3 分量 = 48 行/级 |
| 判据 | 相对 3 %（原判据，未改）；同时报 `|Δ|/T` 绝对口径 |
| 弃权下限（继承） | |ref| < 1 %·T → `WITHHELD` |
| 病态边界（本条声明） | |ref| < 5 %·T → 相对判据失去分辨力，标 `ill_conditioned` |

## 2. 方法（怎么做的）

三项观测全部在**生产解**上完成，不重算、不改求解器、不动判据：

| 观测 | 实现 | 回答什么 |
| --- | --- | --- |
| ① 探针位置 | `stress_recovery.locate_point` 的 `on_boundary`/`containing_elements` 与原始协议的 `edge_distance = 1-max(|xi|,|eta|)` | 探针是否压在单元界面上（Q4 应力在界面双值） |
| ② 界面跳变 | 同一物理探针在界面两侧各取 `theta ± 1e-7` rad，比较原始协议返回值 | 原始协议在双值场里丢了多大一跳 |
| ③ 良置复测 | `q4_gauss_stresses` → `recover_nodal_stress`（Barlow 外推 + 面积加权节点平均）→ `interpolate_nodal_field` | 同一解、同一探针，换成单值恢复场后的误差 |

非空转对照两项：①常应力场恢复必须精确到舍入；②恢复场整体乘 1.05 后门禁必须拒收。另以粗网格级仍 FAIL 作第三重对照。

## 5. 注意点与适用范围

1. **这 6 行 FAIL 的责任在测点协议，不在求解器。**探针全压在对称边界上，原始协议取单侧值；同一解换成恢复场后，良置行的最差径向误差从 13.43 % 降到 7.68 %。
2. **未良置的邻域仍然不给通过。**`theta=0°, r/a=1.25` 处 `|σ_rr|` 只有约 1.4 % 的应力尺度（处于零点附近），两个口径都记为 `ill_conditioned`，既不算 PASS 也不改判。
3. **恢复场的精度是「解 + 恢复」的联合性质。**本报告不改变 `structural-certification-materials`的任何 PASS/FAIL；它给出的是一条可复现的替代口径与它的非空转证据。
4. **适用范围**：四分之一圆环 `R/a=10` 的线弹性平面应力 Q4 路径、`grading=5`、无边界层/接触/非线性；不外推到壳体、三维实体或自适应网格。
5. **顺带修掉一个潜伏缺陷（本条副产物）。**复算时发现 `kirsch_hole.solve_case` 的直角→极坐标剪应力旋转写成了 `tau_rt = (sigma_rr - sigma_tt) cos sin + sxy cos2theta`，正确式是 `tau_rt = (sigma_yy - sigma_xx) cos sin + sxy cos2theta`（Mohr 圆）。两者只在 `sin2theta = 0`（即 `theta = 0/90°`）处重合，而全部规范探针正好只在两条射线上，所以已发表数字**逐位不变**（`tests/test_kirsch_pointwise_conditioning.py` 以 `sin2theta = 0`的恒等性锁死这一点）。离轴探针此前会拿到错误剪切：`theta = 45°`、单轴应力 `(1,0,0)` 时旧式给 0，正确值 −0.500。修复形式为模块级 `polar_from_cartesian`，并按定义`sigma_ab = e_a·sigma·e_b` 在 8 个角度 × 4 个张量上锁到 1e-14。
