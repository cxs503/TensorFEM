# 船舶加筋板纵向承载真实有限元标模

## 摘要

本研究报告以等效加筋板为对象，验证 TensorFEM Q4 连续体单元的纵向位移、应力场、端部反力和网格收敛。模型采用板厚与纵向加筋等效厚度，施加均匀轴向载荷；该案例用于验证船舶结构基础 FE 计算链，不等同于板屈曲或极限强度认证。

## 1. 问题与理论解

长度 `L=2 m`、宽度 `H=1 m`，板厚 `10 mm`，纵向加筋等效厚度 `6 mm`，有效厚度 `t_eff=16 mm`。左端固支，右端施加总轴向力 `P=1 MN`。均匀理论解为：

`sigma_x=P/(H*t_eff)=62.5 MPa`，`u_x=PL/(E H t_eff)=0.595238 mm`。

## 2. 计算条件

| 项目 | 数值 |
|---|---:|
| 单位制 | SI |
| `E`, `nu` | 210 GPa, 0.3 |
| 网格 | Q4：10×5、20×10、40×20 |
| 载荷 | 右端总轴力 1 MN |
| 验收 | 位移相对误差 < 3% |

## 3. 运行

```bash
PYTHONPATH=src .venv/bin/python scripts/run_stiffened_panel_fe_benchmark.py \
  --output results/stiffened-panel-fe.json
```

脚本执行真实 Q4 组装、约束、线性求解、应变/应力恢复、反力计算和三组网格误差统计。JSON 中保存全部节点位移和单元应力字段，可直接生成后处理云图。

## 4. 结果与误差

运行后报告包含每个网格的节点数、单元数、端部位移、理论值、相对误差、左端反力、`sigma_x/sigma_y/tau_xy/von_mises` 场。验收器只允许误差小于 3% 的网格标为 `qualified`；缺少场数据或反力平衡时必须 `blocked`。

理论上该均匀应变标模在所有规则网格上应达到机器精度，反力应为 `-1 MN`（符号取决于约束反力约定）。

## 5. 结果解释与边界

位移云图应沿长度方向单调增加，轴向应力云图在板宽方向近似均匀，von Mises 云图应与轴向应力一致。该报告验证的是材料、网格、边界和场恢复链；真实船舶加筋板屈曲/后屈曲还需单独的几何缺陷、壳弯曲自由度和非线性弧长案例，不能由本标模替代。

## 6. 结论

本案例具备可复现真实 FE 结果、三网格误差、位移/应力场和反力闭环，适合作为船海 benchmark 的基础回归案例。
