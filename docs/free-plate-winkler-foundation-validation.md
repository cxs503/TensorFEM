# 自由边界板 + Winkler 弹性地基：用三条精确参考清偿「无特征函数即无参考」的欠账

**Status:** verification report（自由边界 + 弹性地基本单清偿；细网格与软地基使用边界如实记录）
**Repository:** TensorFEM · **Module:** `tensorfem.plate_vibration`（新增 `winkler_translation_angular_frequency`）、`tensorfem.plate_ritz_reference`（新增 `foundation_energy_matrix`、`winkler_parameter`）
**Evidence:** `benchmarks/free_plate_winkler_foundation.py`、`benchmarks/free_plate_winkler_foundation_evidence.json`、`tests/test_free_plate_winkler_foundation.py`（19 项）
**Figures:** `docs/assets/free_plate_winkler_foundation/{foundation_branches,mesh_convergence}.png`

## 1. 案例介绍（物理背景 / 几何 / 参数）

船底板格、双层底与基座板格在**自由边**（大开孔、弱加筋边）与**弹性地基**（垫木、阻尼层、
土/水弹性支撑的等效 Winkler 床）同时出现的工况下，其振动频率既不能套简支口径，也不能套
自由板口径。`docs/free-plate-vibration-validation.md` §5.5 已明确写下这是未验证项，理由是
「Winkler 项对自由边没有精确特征函数，无法直接得到参考解」。

本单要回答的问题因此很具体：**在自由边界上，`winkler_k > 0` 这条代码路径对不对、误差多少、
能力边界在哪里**。

| 参数 | 符号 | 取值 |
|---|---|---|
| 板长 / 板宽（方形） | a / b | 1.0 m / 1.0 m |
| 板长 / 板宽（2:1） | a / b | 1.0 m / 0.5 m |
| 板厚 | h | 0.01 m（a/h = 100，薄板） |
| 弹性模量 / 泊松比 | E, ν | 200 GPa / 0.30 |
| 密度 / 面密度 | ρ, ρh | 7850 kg/m³ / 78.5 kg/m² |
| 抗弯刚度 | D | 1.8315×10⁴ N·m |
| 地基系数 | k_w | 1×10⁵ … 1×10⁸ N/m³（另做 10⁴…10¹⁰ 扫描） |
| 边界 | — | 完全自由（无位移/转动约束） |
| 单元 | — | Q4 选择性减缩积分（SRI）Mindlin 板 + 含转动惯量的**一致**质量阵 |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

关键认识：**自由边不缺参考解，缺的是换一个提法**。均匀 Winkler 床只增加势能
`k_w/2 ∫w² dA`，在无量纲 Kirchhoff 模型（D = ρh = 1）里它就是质量算子的 κ 倍
（κ = k_w a⁴ / D）。于是：

* 任意边界、任意模态都有**精确位移恒等式** `ω²(k_w) = ω²(0) + k_w/(ρh)`，模态不变；
* 平移模态 `w = const, θx = θy = 0` 是**闭式精确特征对** `ω² = k_w/(ρh)`，与边界、弯曲刚度、
  平面形状全都无关；
* 一致 Q4 单元的地基刚度阵与平动一致质量阵共用同一组形函数乘积，所以**离散**层面该恒等式
  也应在机器精度内成立——这使它成为对「装配」而不是对「网格」的锚点。

三条互不共享代码的参考（无一由 FE 求解器生成）：

| 参考 | 实现 | 独立性 |
|---|---|---|
| ① 平移闭式解 | `winkler_translation_angular_frequency`：`sqrt(k_w/(ρh))` | 解析，任何边界成立 |
| ② 装配恒等式 | 地基阵行和 = k_w × 精确汇水面积（内部 ab/(nx·ny)，边半、角四分之一） | 单元阵的解析性质 |
| ③ 平移后的自由板 Ritz 谱 | `plate_ritz_reference` 新增 `winkler_parameter`：Legendre 张量积基 + 2(order+1) 点 Gauss 积分装配 Winkler 算子 `W`，与 Kronecker 质量算子**用不同积分阶**，`foundation_check` 报告两者差异；`κ>0` 时不再投影掉刚体模态（三个刚体模态此刻恰是特征值 κ 的精确模态，投掉就把锚点投掉了） | 全局谱方法，无单元、无共享积分 |

被检对象：`solve_plate_vibration(boundary="free", winkler_k>0)`，网格 6×6 → 12×12（方形）、
8×4 → 16×8（2:1），模态数 10，刚性模态阈值用默认 1e-9（另测 1e-12）。

工具链：`OMP_NUM_THREADS=4 PYTHONPATH=src python benchmarks/free_plate_winkler_foundation.py`
（一键重生成 JSON + 两张图，全脚本数字均程序化产出、零手抄）。

### 3.3 被地基抬升的四个近机构模态

`k_w > 0` 后 `rigid_body_modes` 由 4（3 刚体 + 1 沙漏）降为 **0**，四个近机构模态被抬到
`k_w/(ρh)` 附近：

| 量 | 方形 | 2:1 |
|---|---|---|
| 平移型两模态 `ω²/(k_w/ρh) − 1` | ≤ 1.5×10⁻⁹（求解器舍入） | ≤ 3.5×10⁻⁹ |
| 转动惯量型两模态 `ω²/(k_w/ρh) − 1` | **−1.000×10⁻⁴** | **−4.000×10⁻⁴** |
| 上述亏欠的网格依赖性（6×6 vs 12×12；8×4 vs 12×6） | ≤ 2.7×10⁻⁹ | ≤ 2.7×10⁻⁹ |

亏欠为负且与网格无关 ⇒ 它来自一致质量阵的转动惯量块（`ρh³/12`）而非离散误差：转动型模态的
质量分母多了 `ρh³/12 ∫θ²` 项，频率必然低于 `k_w/(ρh)`。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

1. **大 k_w 会稀释相对误差（本单最重要的坑）**：位移恒等式是精确的，所以弯曲分支的**相对**误差
   被 `λ₀²/(λ₀²+κ)` 稀释。12×12 方形 mode 3 的误差从 k_w = 0 的 2.51% 降到 k_w = 10⁸ 的 0.21%，
   这不是网格变好，而是分母变大。因此本单同时报告**去位移误差**（减去 k_w/(ρh) 后再比）：
   12×12 方形在 k_w = 10⁵ 与 10⁶ 下去位移误差之差 ≤ 1×10⁻³，且与 k_w = 0 的同网格误差一致
   （`test_de_shifted_bending_error_is_independent_of_the_foundation`）。
2. **软地基 + 自由边界会被机构计数器静默吞掉**：`solve_plate_vibration` 的刚性/机构计数用的是
   「相对最大特征值的容差」（默认 1e-9）。当 `k_w/(ρh)` 低于该阈值时，被地基抬升的平移模态会被
   判成机构并跳过，返回的「前几阶模态」实为弯曲模态。实测边界：默认容差下需 k_w ≳ 10⁵
   （阈值 1.27×10³）；容差取 1e-12 可降到 k_w ≈ 10²；k_w = 10 时两者都仍误判。这是**既有设计**
   （同一容差服务支撑边界的 fail-closed 检查），本单不改默认值，但把它写成可用性边界并用
   `test_soft_foundation_needs_a_tighter_rigid_mode_tolerance` 锁定，调用方可用
   `rigid_body_relative_tolerance` 收紧。
3. **Ritz 参考的 κ 位移不是机器精度**：特征值量级从 κ 跨越到 `λ²_max ≈ 1.2×10³`，标准特征值问题的
   条件数把位移残差放大到 ~1e-7（阶 16 时 ~1.7e-7）。所以③的门限取 1e-5·κ，而不是 1e-12；
   真正达到机器精度的是锚点①②。
4. **Ritz 只有三个刚体模态，FE 有四个**（多一个 SRI 沙漏）。所以 Ritz 弹性谱从索引 3 开始，
   FE 从索引 4 开始；错开这一位会得到荒谬的「误差」（本单第一版即踩此坑，10⁷ 量级）。
5. **模型层面仍是 Kirchhoff（参考）vs Mindlin（FE）**：a/h = 100 时一阶剪切修正使频率偏低
   ~3×10⁻⁴，属模型差异而非离散误差；h/a > 0.1 时该口径失效，须改用厚板参考。
6. **不覆盖**：非均匀（变刚度）地基、双参数 Pasternak 地基、地基+预紧力组合、地基+流固耦合、
   自由边+几何缺陷、各向异性/层合板。

## 5. 误差判定（逐项回答是否 < 3%）

| 关键量 | 基准 | 实测误差 | < 3%？ |
|---|---|---|---|
| 平移模态 ω（方形 6×6、2:1 8×4；k_w = 5×10⁶/1×10⁹） | 解析 `k_w/(ρh)` | 2.22×10⁻¹⁶ | **是** |
| 地基阵行和（6×6、8×4） | 解析汇水面积 | 8.74×10⁻¹⁶ | **是** |
| Ritz 位移恒等式（κ = 0.5/1/10） | 精确 κ | ≤ 1.8×10⁻⁸（相对 κ） | **是** |
| 自由板 12×12，k_w = 1×10⁶，mode 1/2/3 | Ritz + κ | 0.0207 / 1.3911 / 2.2957 % | **是（三项全 <3%）** |
| 自由板 12×12，k_w = 1×10⁸，mode 1/2/3 | Ritz + κ | −0.0169 / 0.0641 / 0.2080 % | **是** |
| 2:1 板 16×8，k_w = 1×10⁶，mode 1/2/3 | Ritz + κ | 0.9420 / −0.4256 / 0.5203 % | **是** |
| 自由板 6×6，k_w = 1×10⁶，mode 3 | Ritz + κ | 10.2526 % | **否（粗网格不达标，fail-closed 锁定）** |
| 2:1 板 8×4，k_w = 1×10⁶，mode 1/3 | Ritz + κ | 3.9617 / 4.9777 % | **否（粗网格不达标，如实保留）** |

结论口径：**自由边界 + Winkler 地基路径在 12×12 方形与 16×8（2:1）网格上对「精确位移后的独立
Ritz 参考」误差 < 3%（最差 2.30%），三条解析锚点达 10⁻¹⁶ 量级；粗网格（6×6 / 8×4）的第三模态
与 2:1 首模态超 3%，不得宣称**。该结论仅覆盖薄板（a/h = 100）、均匀地基、线性自由振动。
