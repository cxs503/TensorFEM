## 1. 案例介绍

### 1.1 物理背景

模态叠加法是船体梁振动、甲板加速度（ISO 6954 评价）、冰激振/砰击响应的主力算法。它依赖三件互相独立的性质：

1. **正交归一性**：振型对质量矩阵满足 `phi_i^T M phi_j = delta_ij`；
2. **完备性**：若保留的自由度数 = 自由模态数，则有效模态质量之和恒等于 `r^T M r`（`r` = 单位刚体位移影响向量），
   这是**代数恒等式**，与网格、物理无关，任何偏离都是装配/约束/归一化错误；
3. **方向对称性**：对称结构在对称平移影响向量下，反对称模态的参与系数恒为 0。符号错误靠频率查不出来，靠这条能查出来。

有效模态质量 `m_eff,n = (phi_n^T M r)^2 / (phi_n^T M phi_n)`，其分布直接决定模态截断误差。
它同时把"取几个模态"从经验变成可分级的判据。

### 1.2 几何与参数表

| 项目 | 取值 |
|---|---|
| 结构 | 均匀 Euler–Bernoulli 梁，`L = 1`、`EI = 1`、`mu = 1`（无量纲，故 `sqrt(EI/(mu L^4)) = 1`）|
| 单元 | Hermite 三次梁单元（`tensorfem.modal.uniform_beam_matrices`），每节点 `(w, theta)` |
| 网格 | 8 / 16 / 32 / 64 / 128 单元 |
| 边界 | 悬臂（`w = theta = 0` 于 x=0）、两端固支、自由–自由 |
| 影响向量 | 单位横向平移：位移自由度取 1，转角自由度取 0 |
| 闭式参照 | 均匀梁精确振型，48 点 Gauss–Legendre 积分（见 §2.2）|

## 2. 怎么做的

### 2.1 模块

`src/tensorfem/modal_participation.py`（仅依赖 torch，不新增 numpy-only 债务）：

- `modal_participation(K, M, influence, constrained_dofs, modes)` → `ParticipationSummary`：
  广义质量、参与系数、有效模态质量、`r^T M r`、累积分数、归一化残差；
- `ParticipationSummary.fraction_of(reference_mass)`：把有效质量除以**外部给定**的惯量（连续体 `mu L`），
  以便与闭式值比较——这与 `effective_mass_fraction`（除以离散 `r^T M r`）是**两个不同口径**，§5 说明差异来源；
- `mode_count_for(fraction)`：达到给定额度所需的最少模态数；基不够时返回 `mode_count + 1` 而不是谎报足够的模态数；
- `rigid_body_candidates(ratio)`：把频率远低于最高频率的模态标出来（未约束模型的刚体模态 vs 被 round-off 污染的伪刚体模态）；
- `beam_effective_mass_reference(boundary, modes)` / `beam_reference_frequencies` / `beam_shape_value`：闭式梁参照。

### 2.2 闭式参照为什么能算到机器精度

均匀梁振型 `phi(xi) = cosh(lam xi) - cos(lam xi) - sigma (sinh(lam xi) - sin(lam xi))`（`xi = x/L`、`lam = beta L`），
悬臂 `sigma = (cosh lam + cos lam)/(sinh lam + sin lam)`，两端固支 `sigma = (cosh lam - cos lam)/(sinh lam - sin lam)`。
`lam >= 20` 时 `cosh` 已达 `1e13`，与 `sigma` 的抵消是**灾难性**的：直接求值在第 5 阶以上相对误差到 `1e-3`。
因此实现对同一函数做指数缩放：

```
delta = 1 - sigma = (sin lam - cos lam - e^-lam)/(cosh lam - e^-lam + sin lam)   # 悬臂
phi(xi) = 0.5 [delta e^{lam xi} + (2 - delta) e^{-lam xi}] - cos(lam xi) + (1 - delta) sin(lam xi)
```

关键是用稳定恒等式 `cosh lam - sinh lam = e^{-lam}` 消掉大数，`delta e^{lam xi}` 全程 O(1)。
特征根同样改写为 `cos lam + s * 2 e^{-lam}/(1 + e^{-2 lam}) = 0`（`s = +1` 悬臂、`s = -1` 两端固支）再二分。
Gauss–Legendre 节点/权重用 Newton 迭代在纯 math 下生成（48 点，权值和 = 1 到 1e-16）。

**参照自身先被验**：特征根与 `tensorfem.modal` 里 Blevins (1979) Table 8-1 表值最大相对差 **4.85e-16**；
悬臂一阶振型满足 `phi(0) = phi'(0) = 0`、`phi(1) = 2`（经典归一化）到 1e-9；
一阶有效质量分数 **0.61307609** 与文献光滑悬臂值 **0.6131** 一致。

### 3.3 恒等式与量级

| 检查 | 结果 |
|---|---|
| 完备性 `sum m_eff / (r^T M r) - 1`（8/16/32/64/128 单元，全自由模态）| 1.2e-16 / 2.3e-16 / 2.3e-16 / 1.1e-16 / 7.8e-16 |
| 振型质量正交归一残差 `max|phi^T M phi - I|` | ≤ 1.8e-15 |
| 离散刚体惯量 `r^T M r /(mu L)`（8→128 单元）| 0.921429 / 0.960714 / 0.980357 / 0.990179 / 0.995089 |
| 两端固支 FE（64 单元）反对称模态最大分数 | 3.0e-21 |
| 静力尖端位移截断比（取 1/2/3 阶）| 0.970692 / 0.995412 / 0.998568，网格无关到 1.2e-5 |

`r^T M r` 的亏量严格是 `0.62857 / n_el`（实测 8–128 单元内偏差 < 1e-9）：缺陷来自**唯一的固支端单元**——
节点平移取 1、转角取 0 时，Hermite 场在该单元内部不恒为 1，故 `int mu w_h^2 dx < mu L`。这是"节点影响向量"
的一阶损失，不是特征值求解器的问题。

## 4. 注意点（踩到的坑与适用范围）

1. **两个归一化口径不能混用。** 除以离散 `r^T M r` 时完备性恒等式逐位成立，但分数整体被抬高 `1/(1-0.62857/n_el)`，
   与闭式比较会出现 O(h) 的假误差（64 单元时约 0.99 %）；除以连续体 `mu L` 才能得到 §3.2 的二阶以上收敛。
   因此 API 同时提供 `effective_mass_fraction`（离散口径，用于恒等式判定）与 `fraction_of(mu L)`（物理口径，用于对闭式/文献）。
   **"90 % 判据"因此是口径相关的**：本案例离散口径下 3 个模态即达 90 %（8/16 单元）/4 个（32 单元以上），
   物理口径下需 **5 个**（0.6131+0.1883+0.0647+0.0331 = 0.8992 < 0.9，加第 5 阶 0.0200 → 0.9192）。报告两种口径都不藏。
2. **自由–自由模型的刚体子空间不可靠（本仓库既有行为的实测局限）。** `modal.solve_modes` 用 `values > eps*max`
   过滤非正特征值：16 单元时留下一个 `f = 4.759e-5 Hz` 的伪模态，承担 73.5 % 惯量（干净平移应为 100 %）；
   32/64 单元时两个刚体模态**被静默丢弃**（首个频率直接是 3.5608 Hz），弹性模态参与系数 ≤ 4.6e-9。
   同一模型换个网格，要么多一个近零频模态、要么少两个——都没有任何告警。本模块的 `rigid_body_candidates`
   是检出手段（16 单元时正确标出 mode 0）。本报告不改 `modal.solve_modes`（多处在用），只把行为钉进门禁与证据。
3. **静力精度 ≫ 有效质量分数。** 一阶模态就给出 97.07 % 的尖端静位移，而一阶有效质量只有 61.3 %。用"有效质量达到 90 %"
   去推断静力精度会**低估**；反过来用静力精度推断动力截断会**高估**。二者不是同一件事。
4. **反对称零参与是判据，不是巧合。** 它同时能抓住符号/装配错误；若某结构模型出现非零反对称参与，先查影响向量与单元定向。
5. **适用范围**：均匀 Euler–Bernoulli 梁（无转动惯量、无剪切变形）与一维平移影响向量。Timoshenko 梁、板壳、
   三向平移/扭转影响向量的闭式参照未在本报告覆盖；`modal_participation` 本身对任意 `K/M/r` 适用，但那时只有
   恒等式与对称性两条判据可用，没有闭式锚点。
6. 高模态闭式求值必须先做指数缩放（§2.2）：直接写 `cosh - sigma*sinh` 在 5 阶以上就会给出 1e-3 量级的假误差，
   而且看起来"很合理"。这是本任务里唯一一次差点误判参照本身的地方。

## 5. 误差判定（关键量 vs 基准，逐项，显式回答是否 < 3 %）

| 量 | 基准 | 实测 | < 3 % ? |
|---|---|---|---|
| 特征根 `beta L`（两边界各 4 阶）| Blevins (1979) Table 8-1 表值 | 最大 4.85e-16 | **是** |
| 悬臂一阶有效质量分数（闭式）| 文献 0.6131 | 0.61307609（偏差 3.8e-6）| **是** |
| 悬臂一阶分数（FE，64 单元，物理口径）| 闭式参照 | 0.0002 % | **是** |
| 悬臂前 3 阶分数（FE，32 单元）| 闭式参照 | 最大 0.0943 % | **是** |
| 完备性恒等式（128 单元全基）| `r^T M r` | 7.8e-16 | **是** |
| 方向对称性（两端固支 64 单元）| 0 | 3.0e-21 | **是** |
| 两端固支前 3 个对称阶（64 单元，离散口径）| 闭式参照 | 2.00 % / 1.97 % / 1.88 % | **是** |
| 离散刚体惯量 `r^T M r`（8 单元）| `mu L` | 7.86 % | **否**（一阶亏量，如实保留）|
| 离散刚体惯量（32 单元 / 128 单元）| `mu L` | 1.96 % / 0.49 % | **是** |
| 粗网格 8 单元模态 3–6 分数 | 闭式参照 | 5.15 % – 37.08 % | **否**（失败项保留，不作任何粉饰）|
| 自由–自由刚体模态参与（16 单元）| 1.0（干净平移）| 0.7354 | **否**（既有 `solve_modes` 行为，见 §4.2）|

结论：**闭式参照与 FE 一致性全部 < 3 %（多数 < 0.1 %），三项超 3 % 的失败项全部如实保留**——
两项是"节点影响向量一阶亏量"的已知机制（8 单元粗网格 / 自由–自由刚体子空间），
一项暴露的是既有 `modal.solve_modes` 的过滤阈值缺陷。本报告不据此声称船体梁动力响应已认证。
