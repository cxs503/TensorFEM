# Saint-Venant 扭转：侧表面峰值剪应力回收（清偿 WITHHELD）

## 1. 欠账是什么

`CHANGELOG` 在引入 [Saint-Venant torsion 验证](saint-vanant-torsion.md) 时明确写下一处
WITHHELD：精确峰值 `|tau|` 位于**侧表面长边中点**，而 `torsion_bar.solve_torsion_bar`
只在**单元形心**采样，形心永远到不了边界，因此 `shear_peak_relative_error` 只做形心-形心
比较，边界峰值「不给数」。本单把这处 WITHHELD 换成一个可复现的测量值。

物理背景：边长 `side × side`、长 `length` 的方截面棱柱受纯端部扭矩 `T`，Saint-Venant
解给 `lap psi = -2`、边界 `psi = 0`、`tau = G theta grad psi`，最大值落在侧表面长边中点。
形心采样的结构性缺口正是「应力最不准的位置恰是峰值所在位置」。

## 2. 怎么做的

新增 `src/tensorfem/torsion_boundary.py`，复用与 `solve_torsion_bar` 完全相同的网格、端面
一致牵引、约束与扭转率提取（`0.25L..0.75L` 窗口最小二乘），只改后处理采样点：

| 估计量 | 定义 |
| --- | --- |
| `centroid` | 旧口径：中段 slab 内所有**形心** `|tau|` 最大值（WITHHELD 的由来） |
| `surface_direct` | 在监测点（`x=side, y=side/2, z=L/2`，即侧表面长边中点）直接用该点的自然坐标 `r=1` 求应变算子，并对共享该点的 ≤4 个单元取平均（标准节点后处理） |
| `surface_extrapolated` | 沿表面法向在两个**内部 Gauss 横坐标**（HEX8 `±1/√3`，HEX20 `±√(3/5)`）取样，线性外推到 `r=1`（Barlow 式） |
| 参考值 | 闭式级数**在边界点上**求值（`torsion_shear_stress` 的 `x=side/2, y=0` 中心坐标），并用 `max_shear_stress` 的内部网格扫描交叉核对（扫描点内缩半格，故必为严格下界） |

参考值使用「FE 实测扭转率」代入闭式解，因此本表只考察**应力回收**，不把
`twist_rate` 的独立误差（另有报告）混进来。

## 4. 误差判定：是否 < 3%

| 量 | 基准 | 最好误差 | < 3%？ |
| --- | --- | ---: | --- |
| 方截面扭转常数 `J` | 教科书系数 0.1406 | 3e-5（绝对） | **是** |
| 边界级数峰值 vs 内部扫描 | 闭式自洽 | <1% | **是** |
| 形心峰值（旧 WITHHELD 口径）HEX8 8 段 | 闭式边界值 | 17.50% | **否**（结构性采样缺口） |
| 表面直接峰值 HEX8 6 段 / 8 段 | 闭式边界值 | 1.68% / 0.92% | **是** |
| 表面直接峰值 HEX8 4 段 | 闭式边界值 | 3.75% | **否**（保留为负控） |
| 表面外推峰值 HEX20 4 段 | 闭式边界值 | 1.76% | **是** |
| 表面直接峰值 HEX20 2 段 | 闭式边界值 | 16.79% | **否**（粗网格超调，保留） |

结论：**侧表面峰值剪应力在 3% 门限内有了实测数字**（HEX8 3675 DOF 起 1.68%，HEX8
8019 DOF 0.92%，HEX20 4515 DOF 外推 1.76%），此前的 WITHHELD 撤销。与此同时，形心口径
在所有网格上都是 17.5%–62.7%，因此「形心采样不能代表边界峰值」这一原判断被数据证实，
不是措辞问题。

## 5. 注意点 / 局限

1. **HEX20 2 段超调**（16.79%）与 **HEX8 4 段刚过门限**（3.75%）都保留为失败/临界记录，
   没有通过调参把粗网格拉进 3%；收敛序列非单调，认证取最细网格。
2. 参考值用 FE 扭转率代入闭式解，这是**有意解耦**：若用精确扭转率，HEX20 2 段的
   1.47% 扭转率误差会放大应力比较，得到的是「耦合误差」而非回收能力。
3. 监测点是**单个**对称等价点（四条长边中点之一）。没有做沿整条边界线的 L2 或最大值
   扫描，也没有覆盖矩形（非方）截面的长边/短边两侧差异；`a≠b` 的形状因子未验证。
4. HEX8 的「外推」与「直接」相同，因为 `hex8_stiffness` 只存形心应变算子，一阶单元内部
   应力本就线性；外推只在 HEX20 上才有区分度。
5. 只覆盖直棱柱纯扭转、弹性均值材料。不含翘曲约束（Vlasov）、变截面、塑性或接触。
