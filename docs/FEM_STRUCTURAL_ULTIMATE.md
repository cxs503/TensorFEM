# TensorFEM 船舶板架结构极限强度验证报告

## 1. 案例介绍

### 1.1 物理背景

船舶板架结构（加筋板）在轴向压缩载荷下的极限强度是船体梁渐进崩溃分析的基础。
本验证针对以下三个关键能力：

1. **弹性屈曲载荷**：经典薄板屈曲理论（Paik2007 Eq.2.1）
2. **极限强度**：Paik-Thayamballi 经验公式（基于100+组实验标定）
3. **渐进崩溃**：Smith方法（截面离散+载荷-缩短曲线积分）

### 1.3 材料参数

- 弹性模量 E = 206 GPa
- 泊松比 ν = 0.3
- 双线性硬化（验证中采用理想弹塑性）

### 1.4 实验参考

Paik JK, Thayamballi AK, Park JS (2007). "Ultimate strength of stiffened panels under combined axial compression and lateral pressure."
6组加筋板压缩实验，文献标定值作为基准。

ISSC2006 船体梁渐进崩溃基准：双壳油轮中剖面（KVLCC2，L=320m, B=58m, D=30m）。

## 2. 方法

### 2.1 弹性屈曲（J1）

经典Navier解，四边简支板单向压缩：

$$\sigma_{cr} = k \frac{\pi^2 D}{b^2 t}$$

其中 $k = (m\frac{b}{a} + \frac{a}{mb})^2$，$D = \frac{Et^3}{12(1-\nu^2)}$

加筋板采用等效正交各向异性板模型，筋条刚度 smeared 到 Dx。

### 2.2 极限强度（J2）

采用 Paik-Thayamballi (2003) 经验公式：

$$\frac{\sigma_u}{\sigma_y} = \frac{C_1}{\beta} + \frac{C_2}{\beta^2} + \frac{C_3}{\beta^3} + C_4$$

系数：a/b ≥ 1.0 时 C1=1.50, C2=-0.30, C3=0, C4=0。

板架极限强度为板与筋条的并联组合：

$$\sigma_{u,panel} = \frac{A_p \sigma_{u,p} + A_s \sigma_{u,s}}{A_p + A_s}$$

筋条采用 Perry-Robertson 柱屈曲公式。

### 2.3 后屈曲路径（J3）

双线性载荷-缩短曲线：
- 弹性段：σ = Eε（至 σ_u）
- 软化段：斜率 = -0.10E，下限 = 0.4σ_u

能量吸收 = 应力-应变曲线下的面积。

### 2.4 Smith方法（J4）

船体梁截面离散为若干单元（板架单元+硬角点），每步：
1. 假设曲率 κ
2. 求解中和轴位置（轴力平衡）
3. 计算各单元应变 ε = κ(y - y_NA)
4. 由载荷-缩短曲线得应力
5. 积分得弯矩 M = Σ A_i σ_i (y_i - y_NA)

### 2.5 CSR校核（J5）

IACS CSR 简化梁模型：

$$Z_{req} = \frac{M_{wave}}{\sigma_{allowable}}$$

$$M_{wave} = 0.19 \cdot C \cdot L^2 \cdot B \cdot C_b \times 10^3 \text{ (kN·m)}$$

校核条件：Z_act / Z_req ≥ 1.0

### 2.6 网格收敛（J6）

GCI (Grid Convergence Index) 按 ASME V&V 20：

$$GCI = F_s \frac{|\epsilon|}{r^p - 1}$$

其中 F_s = 1.25（安全系数），r = 加密比，p = 观测阶数。

## 5. 注意点

### 5.1 局限性

1. **实验值**：为文献标定代理值，非原始试件数据
2. **板极限强度**：采用Paik-Thayamballi经验公式（标定于100+组实验），非壳有限元弧长法
3. **残余应力**：已包含在经验公式标定中，未显式建模
4. **后屈曲软化**：斜率-0.10E为文档化假设
5. **Smith方法**：采用理想弹塑性+屈曲限制，未考虑卸载/循环损伤

### 5.2 适用范围

- 板格柔度 β = 1.0~3.0（常规船舶板架）
- 长宽比 a/b = 1.0~8.0
- 单向压缩（未考虑侧向压力组合）
- 简支边界条件

### 5.3 与壳有限元的关系

本模块为**分析级验证**，不涉及壳有限元弧长法后屈曲。壳有限元能力在
`marine_panel_ultimate_fe.py` 中（当前状态：blocked，待弧长法收敛证据）。
